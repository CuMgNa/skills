# S10U 虚拟终端协议收发工具

本地网页操作的 TCP 协议收发工具：**五类手动单次上行、七项下行回执、原文与字段解析、真实 localhost 演练**。不模拟硬件动作，不把本地收发完成当作平台业务通过。

需求基线：[实施计划](../../docs/manuals/革泰/S10U虚拟终端协议收发工具实施计划.md)。接口边界见 [CONTRACT.md](CONTRACT.md)。

## 1. 安装与运行（Windows）

需要 Python 3.12 和 Node.js（用于首次构建，建议 Node 22.12+ 或 Node 24）。依赖安装只作用于本服务，不使用其他应用的虚拟环境。

在本服务目录打开 PowerShell，首次初始化：

```powershell
.\scripts\setup.ps1
```

该显式初始化命令创建本服务 `.venv`、安装 Python/前端依赖并构建前端。已有锁文件时使用 `npm ci`。若系统策略禁止执行 `.ps1`，无需放宽全局策略，可逐条执行：

```powershell
py -3.12 -m venv .venv
& .\.venv\Scripts\python.exe -m pip install -c requirements.lock -e '.[dev]'
npm --prefix frontend ci
npm --prefix frontend run build
```

之后日常使用可双击 `run.cmd`，或：

```powershell
.\scripts\run.ps1
```

浏览器打开 `http://127.0.0.1:8765`。日常运行由 Python 同时提供已构建的网页，不需要另外启动 Node.js 服务。

更换本地网页端口：

```powershell
.\scripts\run.ps1 -Port 8766
# 或不执行PS脚本：
& .\.venv\Scripts\python.exe -m s10u_tool --host 127.0.0.1 --port 8766
```

本地网页端口与平台的 TCP 端口是两回事。

- 默认只绑定回环地址，不作为局域网或公网服务发布。
- 保持单进程、单 worker，不使用多 worker、热重载维护调测会话。
- 关闭浏览器不等于关闭 TCP；使用网页“断开”按钮。
- `Ctrl+C` 退出本地服务，连接与待发回执结束；**未导出的会话日志会丢失**。
- 不会自动打开 VPN、修改白名单或绕过平台鉴权。

## 2. 没有平台，先用本地演练

1. 启动“本地演练”服务。
2. 选择演练连接，确认本机地址和自动分配的 TCP 端口，填写测试设备 ID，再点击连接。
3. 上行选择 LK，编辑字段、预览、单次发送；演练服务端通过真实 TCP 返回 LK。
4. 选择 UD／UD2／AL／iccid，可加载右侧样本，查看字段与原文后单次发送。
5. 在演练下发入口选择 VERNO 等七项命令，指令经真实 TCP 到达下行板块。
6. 查看收到的指令与回复；可切换手动、不回复、延迟或自定义拒绝模板。
7. 导出所需日志，断开连接。切换真实平台前，先结束旧连接。

演练服务端只对 LK 和 AL 返回规定应答；UD、UD2不要求回复，iccid不编造应答。

**本地演练只验证工具交互。自定义拒绝字节在本地被收到，不代表真实平台能识别为 rejected。**

## 3. 上行使用

支持 LK、iccid、UD、UD2、AL。只有一个动态表单，按选择类型展示字段。

- 点击一次发送一次；不自动心跳、不周期上报、不自动补传、不自动重发AL。
- 完整位置字段按附录一展示，基站和Wi-Fi支持重复记录，复杂字段折叠。
- 右侧保留协议默认样本原文，样本中的已知错误标注，不静默改写参考资料。
- “一键填入”先提示覆盖，使用当前设备ID，不自动发送。
- 自定义样本可命名保存与加载。
- UD可用发送时的实时时间，或固定时间；工具的时区配置不是协议已确认的时区。UD2固定历史定位时间。
- 正常生成自动计算实际内容字节长度，预览显示LEN；字段可编码但异常时，需要确认后发送。
- raw文本／HEX模式保留实际字节，不修LEN、不替换设备ID、不添加换行；身份不匹配时需要留意提示。
- 导入原始报文后可查看解析，再确认填入表单。未知／有剩余字段的报文不强行转换。
- 收发日志记录实际发送值，UD实时预览中的时间可能与最终实际发送值不同。

无自动心跳时，平台可能主动关闭空闲连接；工具不会偷偷发送数据维持连接。

## 4. 下行使用

首版七项：UPLOAD、ZONE、VERNO、CR、POWEROFF、RESET、FIND。

每个命令可配置自动或手动处理，选择正常回执、拒绝回执、不回复。需要回执时，可立即发送或设置延迟。

- VERNO回复预设版本；其他正常回复按对应协议模板生成，不简单回显全部入参。
- 拒绝无标准预置格式：先取得开发确认的完整报文，再保存为自定义拒绝模板。未配置时不自动发送。
- 延迟任务绑定收到指令的原连接，断连后取消，不发到新连接。
- 等待中的自动回复需先取消，再手动替换，避免重复应答。
- 未知或畸形指令保留原文，不自动编造成功回执。
- 不执行实际设备动作：RESET/POWEROFF不重启或断连，CR不启动定位，UPLOAD/ZONE不修改本地工具参数。
- 协议没有统一流水号，本地记录编号不等于平台请求ID；重复同类指令的关联需要平台侧证据。

## 5. 连接与数据

- 保存多环境、多设备档案，但只连接一个设备。
- 保留手动断开和可选定时断开；默认持续连接，计时从建连成功开始。
- 异常重连默认关闭，开启后配置间隔及次数上限。手动／到期断开不会自动重连。
- 重连不会自动发送上行，也不会补发旧连接的待发回执。
- 数据库默认在 `%LOCALAPPDATA%\S10UTcpTool\`，只保存档案、样本及策略。
- 使用独立目录进行实验可指定 `S10U_TOOL_DATA_DIR` 或启动参数 `--data-dir`，不要与真实用户档案混用。
- 通信日志仅在本地程序运行会话内保留；刷新网页可重新查看，退出程序不保留。
- 日志最多500条且总计2,000,000字节，下行记录最多200条；达到上限时显示截断提示。导出是当前仍保留的记录，不是无限全量历史。
- 同一TCP会话的发送操作ID缓存最多512项且8,000,000字节；满后拒绝新操作（HTTP 429），不淘汰旧ID以免重复发送。需要继续调测时，先导出证据，再明确断开并重新连接建立新会话。
- 导出可能包含设备ID、ICCID、坐标和原始指令，分享前检查范围，不会自动上传。

网页到本地后端使用HTTP操作与WebSocket变化通知；后端到平台使用原生TCP。页面通过完整快照恢复状态，不因为浏览器刷新而再建连接。

## 6. 已知协议限制

1. 文档示例存在LEN错误，例如 `UPLOAD,600` 内容长10字节，应为 `000A`，不是示例的 `0009`。原文样本与重新生成的正确长度分别展示。
2. 状态字正文与附录表述冲突，以已核对附录一的标注提供解释，同时保留原始HEX。
3. 非ASCII名称编码、特殊字符转义、零基站布局等边界需要平台确认。首版结构化默认ASCII，无法确定编码时不替换为问号，必要时使用明确字节的raw HEX。
4. 首版基本消息不代表覆盖所有LTE/WCDMA/CDMA变种，厂商头`3G`不代表当前无线制式。
5. 不支持北斗完整接入，北斗载荷不能未经确认发到S10U端口。
6. 平台设备登记、上线绑定、拒绝格式、超时起点及迟到回执规则仍需开发确认。

## 7. 开发与验证

从本服务目录执行：

```powershell
& .\.venv\Scripts\python.exe -m pytest tests -q
npm --prefix frontend run typecheck
npm --prefix frontend run test -- --run
npm --prefix frontend run build
npm --prefix frontend run test:e2e
```

`test:e2e` 会先构建，默认使用本机已安装的 Chrome，自动启动独立后端端口8767，数据位于本服务 `.temps/e2e/`；不需要连接真实平台。可通过 `E2E_BROWSER_CHANNEL` 选择其他已安装的浏览器通道。`E2E_BASE_URL` 仅应指向专用的本地验收实例：测试会修改策略、创建档案并断开连接，不能指向正在使用的调测实例。结束后需清理该次测试数据和 `frontend/test-results/`。

若 pytest 默认系统临时目录报 `WinError 5`，不修改权限，使用本服务内唯一临时目录并自动清理（从本服务目录执行）：

```powershell
& .\.venv\Scripts\python.exe -c "import pathlib,tempfile,pytest; p=pathlib.Path('.temps'); p.mkdir(exist_ok=True); t=tempfile.TemporaryDirectory(prefix='pytest-',dir=p); code=pytest.main(['tests','-q','--basetemp',t.name]); t.cleanup(); raise SystemExit(code)"
```

前端开发时运行 `npm --prefix frontend run dev`（默认5173），同时保持本机Python后端在8765运行。开发代理保留同源Host/Origin，不放宽通配CORS；正式使用优先由FastAPI提供构建页面。

实际测试结果记录在 [VALIDATION.md](VALIDATION.md)，未执行或失败的步骤不记为通过。

测试边界：
- 黄金字节断言独立核对，不能只用同一个编码器和解析器互证。
- TCP拆包粘包、错误长度、残帧、断连和延迟回执竞争均需覆盖。
- 五类消息只在明确发送操作后发出，重连不自动上行。
- 非法Origin/Host或缺失令牌不能操作本地发包API。
- 平台真实入库及acked/rejected/timeout需另行联调，不能从本地发送完成推断。
