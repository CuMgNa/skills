# 天地卫通小程序使用说明书 · 格式标准

> 内容母版与版式以 `天地卫通小程序使用说明书V1.2.0.docx` **现行稿**为准（officecli 实测）。  
> 编号以「与正文自动编号同源 + 逻辑连续」为准；交付前必须 **更新整个目录**，勿盲抄过期 TOC 快照。  
> 后续增补章节、替换截图、修订说明时，均按本标准执行。

---

## 1. 页面

| 项 | 标准 |
| --- | --- |
| 纸张 | A4（21 × 29.7 cm） |
| 页边距 | 上/下 2.54 cm，左/右 3.18 cm |
| 页眉 / 页脚 | 1.5 cm / 1.75 cm |
| 默认字体 | 西文 Times New Roman，中文 **宋体** |
| 默认行距 | **1.5 倍** |
| 页脚 | 页码（footer 样式，约 9pt） |
| 主题语言 | 中文（zh-CN）为主 |

## 2. 标题层级（核心）

本模板按 Word 常规大纲：**一级用 `heading 1`，二级用 `heading 2`**（与旧稿「章用 heading 2」不同，以现行 V1.2.0 为准）。

| 文档层级 | Word 样式 | 大纲 `outlineLvl` | 字号 / 加粗 | 编号方式 | 示例 |
| --- | --- | --- | --- | --- | --- |
| **一级（章）** | `heading 1` | **0** | **15pt** 宋体加粗 | 自动编号 `1.` `2.` … | 登录、控制台、通信信息 |
| **二级（节）** | `heading 2` | **1** | **14pt** 加粗 | 自动编号 `3.1` `3.2` … | 普通通信、对讲群、星豆账户 |
| **三级（小节）** | `Normal` + 多级列表 | **2** | **12pt**（一般不加粗） | 自动编号（`numLevel=2`） | 创建对讲群、求救通信、扫码绑定 |
| 章内分块小标题 | `Normal` | **不进目录**（勿设 outline 0–2） | **9pt** **加粗** | 手写「一、」「二、」 | 一、微信登录/注册 |

### 编号规则

1. **章必须用 `heading 1`**；**节必须用 `heading 2`**。样式库中的 `heading 3` 本模板正文 **不作为目录层级使用**（三级靠 `Normal` + 列表 + `outlineLvl=2`）。
2. 三级标题 **不要手写**「3.3.1.」「5.12.1.」等前缀，只写标题文字，交给自动编号。
3. 新小节必须挂在 **所属二级节** 的正确编号实例上（例如对讲群挂在 3.3，禁止串到 3.2 求救群聊的编号链）。
4. `heading 1` 段前 / 段后间距约 **各 12pt**（随样式）；勿随意改成与旧稿 heading 2 的 5pt 混用。

### 易错对照（旧稿 → 现行）

| 项 | 旧习惯（已废弃） | **现行 V1.2.0** |
| --- | --- | --- |
| 一级（章） | `heading 2` → 目录 `toc 2` | **`heading 1` → 目录 `toc 1`** |
| 二级（节） | `heading 3` → 目录 `toc 3` | **`heading 2` → 目录 `toc 2`** |
| 三级（小节） | `outlineLvl=3` → 目录 `toc 4` | **`outlineLvl=2` → 目录 `toc 3`** |
| 目录域 | `\o "1-4"` | **`\o "1-3"`**（只收三级） |

## 3. 正文与强调

| 类型 | 样式 | 字号 | 首行缩进 | 其他 |
| --- | --- | --- | --- | --- |
| 正文说明 | 优先 `Normal` | **9pt** | 约 **18–21pt** | 对齐跟随上下文；个别历史段可能为 `annotation text`，**新增一律用 Normal** |
| 操作步骤 | `Normal` | **9pt** | 18–21pt | 手写「1、」「2、」；或圆圈序号（见下） |
| 注意 / 警告 | `Normal` | **9pt** | 约 18pt | **加粗 + 红色 `#C00000`** |
| 截图占位 | `Normal` | **9pt** | — | **居中**，灰色 `#666666`，文案：`【截图待补：…】` |

### 列表与序号

| 形式 | 用途 |
| --- | --- |
| 手写「1、」「2、」 | 操作步骤（最常见） |
| 圆圈序号 ①②③ | 部分既有小节（如求救通信流程），`decimalEnclosedCircleChinese` |
| 项目符号（bullet） | **本模板不使用** |

### 用语符号

| 符号 | 用途 |
| --- | --- |
| **【】** | 按钮、操作名（如【区域】） |
| **「」** | 页签、模块、页面入口名（如「微信登录/注册」） |
| **→** | 操作路径 / 状态流转 |
| **《》** | 协议名（如《用户协议》）；一般为纯文本，**不强制做成超链接** |

## 4. 目录（AI 易错 · 必读）

### 4.1 合格形态（提取规则）

目录必须是 Word **真 TOC 域**（常见为 `sdt` 内容控件 + 条目内 `PAGEREF`），由标题样式 / `outlineLvl` / 自动编号生成。

**合格域指令（现行实测）：**

```text
TOC \o "1-3" \h \u
```

| 文档层级 | 正文条件 | 目录样式 | 左缩进（样式定义） | 右制表位 | 页码 |
| --- | --- | --- | --- | --- | --- |
| 一级（章） | `heading 1`，`outlineLvl=0` | **`toc 1`** | **0**（样式无强制 left） | `pos=8306`，`val=right`，`leader=dot` | `PAGEREF … \h` |
| 二级（节） | `heading 2`，`outlineLvl=1` | **`toc 2`** | **21pt**（`left=420` twip，`leftChars=200`） | 同上 | 同上 |
| 三级（小节） | `Normal`+列表，`outlineLvl=2` | **`toc 3`** | **42pt**（`left=840` twip，`leftChars=400`） | 同上 | 同上 |

补充观感参数（实测）：

- 目录条有效字号约 **10.5pt**；行距 **1.5 倍**。
- 条目形如 `1. 登录` / `3.1. 普通通信` / `3.1.1. …`：**编号来自正文自动编号**，禁止在目录里另手写一套。
- 「目录」二字：`Normal`、居中（**不是** heading）；可在 TOC 的 sdt 内。
- **本模板目录只到三级**；不要再依赖 `toc 4` / `\o "1-4"`（旧方案已废弃）。

垂直层级靠 **toc 1 → toc 2（21pt）→ toc 3（42pt）** 阶梯；禁止用「同一行 + `→`」或 Markdown 列表冒充目录。

### 4.2 正文大纲与目录的对应（强制）

| 要进目录的级别 | 必须满足 |
| --- | --- |
| 一级 | 样式 `heading 1` + `outlineLvl=0` |
| 二级 | 样式 `heading 2` + `outlineLvl=1` |
| 三级 | `Normal` + 正确 `numId`/`numLevel=2` + **`outlineLvl=2`** |

**禁止：**

- 「一、二、三」分块小标题设置 `outlineLvl=0/1/2`（会污染目录，与章/节同级）。
- 把三级误标成 `outlineLvl=1`（会与节一起进 `toc 2`）。
- 目录域写成 `\o "1-2"` 或错误的 `"1-4"`（现行必须 **`"1-3"`**）。
- 仅 `officecli refresh` 后以为层级已修好：若域范围或正文 outline 仍错，refresh **不会**自动纠正层级映射。

### 4.3 生成路径（强制优先级）

1. **优先**：在现行 V1.2.0（已含 `toc 1/2/3` + `TOC \o "1-3"`）上改内容，禁止从零手搓目录排版。
2. **若不得不新建**：`add --type toc --prop levels=1-3 --prop hyperlinks=true`；章/节用 heading 1/2；小节 `outlineLvl=2`；toc 缩进按上表。
3. **一律禁止**：假目录（Markdown / 纯文本 / 项目符号）；一级二级挤一行用 `→`；目录编号与正文两套各写各的。

### 4.4 编号与更新域

1. 目录中的 `1.` / `2.1.` / `3.2.1.` 必须与正文自动编号 **同源**。
2. 交付前必须 **更新整个目录**（Word/WPS：「更新域 → 更新整个目录」）。`officecli refresh` 可辅助更新页码，但 **改 outline / 改域范围后，务必在 Word 里整表更新一次** 并人工看层级。
3. 若正文已是 `3.2.1` 而目录仍显示错号，先整表更新；仍不对再查 `numId` 串链。
4. 验收：`通信信息` 等章为 **toc 1**；`普通通信` 等节为 **toc 2**；`3.1.1` 等小节为 **toc 3**；「一、微信登录…」等分块 **不出现在目录**。

### 4.5 双关验收

| 角色 | 必做 |
| --- | --- |
| AI | 核对 TOC 域为 `\o "1-3"`；抽查章/节/小节的样式与 `outlineLvl`；确认真 TOC/`PAGEREF`；编号树连续 |
| 人工 | 打开目录页：一级最左、二级缩进、三级再缩进；点线与页码正常；无分块小标题混入 |

## 5. 插图

| 类型 | 版式 | 常见尺寸 |
| --- | --- | --- |
| 手机竖屏截图 | 嵌入（inline），所在段 **居中** | 宽约 **3.8–5 cm**（常见约 4.6 cm），高度按比例 |
| 宽屏 / 界面图 | inline，所在段居中 | 宽约 **14.6 cm**（近版心）或 9–11 cm |
| 封面装饰图 | 可浮动 | 如 5.7 × 5.7 cm |

补充：

- 正文与截图之间常保留 **空段落** 作间距。
- 截图单独占一段；勿与正文挤在同一段。
- 尚无实图时，用居中灰字占位：`【截图待补：场景简述】`。

## 6. 封面与修订记录

### 封面

- 产品名 / 「使用说明书」：居中、加粗，约 **15pt** 宋体。
- 版本号（如 V1.2.0）：居中、加粗，约 **12pt**。

### 修订记录

- 标题：「Revision Record 修订记录」——`Normal`、居中、**12pt**。
- 表头：灰底 `#D7D7D7`，**9pt 加粗**，居中。
- 列：修订日期 / 修订版本 / 修改章节 / 修改描述 / 作者 / 审核。
- 表体：约 9–10.5pt，有边框。

## 7. 写作与增补对照清单

1. 新章 → **`heading 1`** + 自动编号（15pt 加粗）+ **`outlineLvl=0`** → 目录 **`toc 1`**。
2. 新节 → **`heading 2`** + 自动编号（14pt 加粗）+ **`outlineLvl=1`** → 目录 **`toc 2`**。
3. 新小节 → 12pt `Normal` + 正确多级列表，**不写死编号**；**`outlineLvl=2`** → 目录 **`toc 3`**。
4. 目录域保持 **`TOC \o "1-3" \h \u`**；不要改回 `1-4` / 不要指望 `toc 4`。
5. 优先在现行 V1.2.0 上改；禁止 Markdown/`→` 假目录。
6. 正文 / 步骤 → 9pt，首行缩进约 18–21pt。
7. 警告 → 9pt 加粗红字 `#C00000`。
8. 待补图 → 居中灰字 `【截图待补：…】`。
9. 章内再分块 → 「一、二、三」9pt 加粗，**禁止**设置会进目录的 `outlineLvl`。
10. 按钮用【】，模块/页签用「」，路径用 →。
11. 改标题 / 改 outline / 改域后：**Word 更新整个目录** + 核对章=toc1、节=toc2、小节=toc3。
12. 交付前双关：AI 自检域与 outline；人工目视目录缩进阶梯。
13. **不删改**既有一期功能正文；二期以新增章节为主。
