# 天地卫通小程序 · 登录/注册说明

## 1 进入登录页

打开「天地卫通」小程序后，进入欢迎页，页面提示：**您好，欢迎使用 天地卫通小程序**。

本页提供两种登录入口，以及游客体验入口：

| 入口 | 说明 |
| --- | --- |
| 微信登录/注册 | 使用微信授权的手机号快捷登录或注册（推荐） |
| 账号登录 | 使用已有账号密码登录 |
| 游客模式登录体验 | 不注册，仅体验部分功能 |

---

## 2 微信登录/注册

### 2.1 选择账号类型

在「微信登录/注册」页签下，先选择账号类型（必选其一）：

- **个人账号**：面向个人用户，完成登录/注册后进入个人业务能力。
- **企业账号**：面向企业用户，完成登录/注册后进入企业业务能力。

选中后，对应选项右侧会出现勾选标识。个人账号与企业账号身份相互独立，请按实际使用场景选择，避免选错类型导致后续权限或设备归属不符合预期。

### 2.2 阅读并同意协议

登录/注册前，请勾选：

> 我已阅读并同意《用户协议》和《隐私政策》

可点击蓝色链接查看协议全文。

**说明：**未勾选协议时，「同意协议并手机号快捷登录/注册」按钮为不可用（置灰）状态；勾选后方可继续。

### 2.3 手机号快捷登录/注册

1. 确认已选择正确的账号类型（个人/企业）。
2. 勾选《用户协议》和《隐私政策》。
3. 点击 **同意协议并手机号快捷登录/注册**。
4. 按微信提示授权手机号，完成登录或注册。

- 若该手机号尚未注册：系统将按所选账号类型完成注册并登录。
- 若该手机号已注册：直接登录对应账号。

---

## 3 账号登录

如已有账号，可切换至 **账号登录** 页签，输入账号信息完成登录（具体字段以页面展示为准）。

首次使用或无账号时，建议使用「微信登录/注册」。

---

## 4 游客模式

如仅需临时体验，可点击页面底部 **游客模式登录体验**，无需注册即可进入体验流程。

**说明：**游客模式下可用功能可能受限；涉及设备绑定、对讲群、套餐购买等完整业务时，请使用个人账号或企业账号正式登录。

---

## 5 操作注意

1. 登录前请确认账号类型选择正确（个人/企业）。
2. 必须先同意《用户协议》和《隐私政策》，否则无法进行微信快捷登录/注册。
3. 请保证微信已绑定可用手机号，以便完成授权。
4. 若授权失败或登录无响应，请检查网络后重试；仍失败时，可尝试切换「账号登录」或联系管理员处理。
