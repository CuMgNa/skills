# 个人年度总结 · 文档格式标准

> 模板来源：`docs/童美娜-2025个人年度总结.docx`  
> 用途：下次提供 Markdown 内容时，按本标准用 officecli 输出同版式 Word。

## 1. 页面

| 项 | 标准 |
| --- | --- |
| 纸张 | A4（21 × 29.7 cm） |
| 页边距 | 上/下 2.54 cm，左/右 3.18 cm |
| 页眉 / 页脚 | 1.5 cm / 1.75 cm |
| 默认字体 | 中文 **宋体**，西文 Times New Roman |
| 默认行距 | **1.5 倍**（`lineSpacing=1.5x`） |
| 页脚 | 「第 X 页 共 Y 页」（约 9pt） |
| Word 样式 | **全文几乎均为 `Normal`**（不用 Heading 1/2/3） |

## 2. 标题层级（全部用 Normal + 加粗，不用 heading 样式）

| 层级 | 写法 | 字号 | 加粗 | 编号 / 大纲 | 对齐 |
| --- | --- | --- | --- | --- | --- |
| 文档标题 | `{年}个人年度总结` | **14pt** | 是 | — | **居中** |
| 姓名日期行 | `姓名：xxx 日期：yyyy年m月d日` | **12pt** | 是 | — | **居中** |
| 一级章节 | `一、年度概述`（中文数字） | **12pt** | 是 | 自动中文编号或手写「一、」；`outlineLvl=0` | 左对齐，无首行缩进 |
| 二级小节 | `3.1 重点项目与关键贡献` | **12pt** | 是 | 手写 `X.Y`；`outlineLvl=1` | 左对齐 |
| 项目块标题 | `项目一：星地多网融合…` | **12pt** | 是 | 手写「项目一/二…」 | 左对齐 |
| 条目标签 | `• 项目背景与目标：` | **12pt** | 是 | 项目符号列表 | 悬挂缩进约 21pt |

说明：

- 一级前几章可用列表编号 `chineseCounting`（显示为「一、二、…」），后半部分也可能把「四、」写进正文；**输出时统一为「一、二、三…」+ 12pt 加粗即可**。
- 二级编号与一级对应：`3.1` 属于「三、…」，`9.1` 属于「九、…」。

## 3. 正文与列表

### 3.1 两套列表记号（强制互斥）

| 记号 | 用途 | 禁止混用 |
| --- | --- | --- |
| **`•`（圆点）** | 数据回顾问句、项目条目标签（如「项目背景与目标：」） | 问句/标签不用 ①，也不用 `1.` |
| **手写 `①②③…⑳`** | **凡分点列表**（过程步骤、亮点、建议、规划、资源需求等） | 分点不用 `1. 2. 3.`，不用 Word 自动圆圈编号 |
| **无序号** | 连贯叙述的普通正文 | 需要分点时再改用 ①，勿半叙述半 `1.` |

约定：

- Word / Markdown 均**手写字符** `①`（非 `listStyle` / `decimalEnclosedCircleChinese` 自动编号），与「一、」「3.1」手写编号同一套路。
- 同一组列表可用至 **⑳**；再多则拆成多组小节或改为叙述，**不**改回 `11. 12.`。
- 要连贯叙述时：写成普通正文段落（首行缩进），不要硬套序号。

### 3.2 段落版式

| 类型 | 字号 | 加粗 | 缩进 | 说明 |
| --- | --- | --- | --- | --- |
| 普通正文 | **12pt** | 否 | 首行缩进约 **21pt** | 段落叙述 |
| 问句 / 条目标签 | **12pt** | **是** | 项目符号 `•` + 悬挂约 21pt | `• 你今年写了多少份工作文档？` |
| 问答·答句 | **12pt** | 否 | 首行缩进约 21pt | 紧跟在问句后 |
| 分点项 | **12pt** | 否 | 手写 ①②③…（可带首行缩进） | 过程、建议、规划等一律如此 |
| 强调数字 / 专名 | 同正文 | 可局部加粗 | — | 一般不必整段加粗 |

### 用语符号

| 符号 | 用途 |
| --- | --- |
| **【】** | 客户/产品线前缀、课程名等（如【上合】【自研】【Python+pytest…】） |
| **「」** | 较少；按正文需要 |
| **：** | 条目标签末尾（如「项目背景与目标：」） |
| **；** / **。** | 并列与句末，保持书面语 |

## 4. 表格

| 项 | 标准 |
| --- | --- |
| 边框 | 全框线，细线（single，sz≈4） |
| 表头底色 | `#E7E6E6`（浅灰） |
| 表头文字 | 12pt 宋体，居中（或两端对齐，以表头为准） |
| 表体 | 12pt；类别列可居中，名称列左对齐/两端对齐 |
| 布局 | `autofit`，列宽随内容 |

常见表类型（模板中 3 张）：

1. **项目清单表**：列如「项目类别 | 项目名称」
2. **规划/AI 表**：列如「AI落地动作 | 预期效果」
3. **自评打分表**：列如「维度 | 分数（1–10）」

## 5. 推荐文档大纲（结构模板）

输出 Word / 填写 Markdown 时，默认按下列章节组织（可按年微调，但层级关系保持不变）：

```text
{年}个人年度总结                          ← 14pt 居中加粗
姓名：{姓名} 日期：{日期}                 ← 12pt 居中加粗

一、年度概述                              ← 一级
  （一段总述正文）

二、年度数据回顾                          ← 一级
  • 问句…                                 ← 加粗 + 项目符号
    答句…                                 ← 正文
  • …
  （必要时插入「项目类别|项目名称」表）

三、工作成果与目标达成                    ← 一级
  3.1 重点项目与关键贡献                  ← 二级
    项目一：{名称}                        ← 项目块标题
      • 项目背景与目标：
        …
      • 个人角色与具体职责：
        …
      • 关键成果与贡献：
        …
    项目二：…
  3.2 工作亮点与突破

四、个人能力发展
  4.1 能力提升与技能成长
  4.2 证书与资质获取
  4.3 知识沉淀与分享

五、团队协作与影响
  5.1 团队贡献
  5.2 指导与被指导
  5.3 跨部门协作

六、反思与规划
  6.1 年度反思
  6.2 下一年度规划
  6.3 AI落地规划（可附表）

七、建议与思考
  7.1 公司/部门/制度建议
  7.2 工作流程优化建议
  7.3 业务/产品发展建议
      （凡分点一律 ①②③…；问句/标签用 •）

八、资源与支持需求
  8.1 个人发展所需支持
  8.2 工作开展所需资源

九、自评与期望
  9.1 年度自评(1-10分）                   ← 插入自评表
  9.2 期望与反馈
```

## 6. Markdown → Word 映射约定

下次给你一份 Markdown 时，请尽量按下列写法；我会据此套版：

| Markdown 写法 | 输出为 Word |
| --- | --- |
| 首行 `# {年}个人年度总结` | 文档标题，14pt 居中加粗 |
| 次行 `姓名：… 日期：…`（可加粗） | 姓名日期行，12pt 居中加粗 |
| `## 一、年度概述` | 一级章节，12pt 加粗 |
| `### 3.1 重点项目与关键贡献` | 二级小节，12pt 加粗 |
| `#### 项目一：xxx` | 项目块标题，12pt 加粗 |
| `- **问句或标签：**` 或 `• **…**` | 项目符号 `•` + 12pt 加粗 |
| 普通段落 | 12pt 正文，首行缩进 21pt |
| 分点（含过程/建议） | **一律**手写 `① ② ③…`；Markdown 若写 `1. 2.`，导出时须转为 ① |
| Markdown 表格 | 浅灰表头 `#E7E6E6` + 全边框 12pt 表 |


## 7. 输出检查清单

1. 全文 `Normal`，行距 1.5，中文宋体 12pt（标题行除外）。
2. 文首标题 14pt 居中；姓名日期 12pt 居中加粗。
3. 一级「一、…」/ 二级「X.Y …」均为 12pt 加粗。
4. 问句、项目条目标签：仅用 `•` + 加粗（不加 ①）。
5. 凡分点列表：仅用手写 ①②…⑳（不用 `1. 2. 3.`、不用自动编号）。
6. 正文首行缩进约 21pt。
7. 表格浅灰表头、细边框。
8. 页脚「第 X 页 共 Y 页」。
9. 不插入无关装饰图；本模板默认无插图。
