# 协议映射说明

以 [星联卫士 终端与 APP 交互协议](星联卫士-终端与APP交互协议.md)（**v2.7**）为准。Word 正式版：[星联卫士-终端与APP交互协议v2.7.docx](星联卫士-终端与APP交互协议v2.7.docx)。

| APP `$xxxx` | 卫星 UDP / 说明 |
|-------------|-----------------|
| `$TITXT` / `$TIVOI` / `$TIIMG` | 上行 `0x12` / `0x10` / `0x11`；回执 `$TOACK` ← `0x83` |
| `$TOTXT` / `$TOVOI` | 下行 `0x81` / `0x82` |
| `$TIREL` / `$TOUDP` / `$TIUDP` | 真上电中转：空口改 GATT，载荷仍是原 UDP 字节 |
| `$TILGN` / `$TOLGN` | 空闲 30s 静默重登 `0x00` |
| `$TOLVO` / `$TILVA` | 机身录音推 App；卫星 `0x02` 仍由终端独立上星 |
| `$TIADD` / `$TOADD` | 终端内平台 IP:端口，不映射 UDP 命令字 |
