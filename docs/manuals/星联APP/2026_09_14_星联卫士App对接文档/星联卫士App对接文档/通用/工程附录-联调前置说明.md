# 工程附录（联调前置 · 非产品交互）

> 与 [星联卫士-终端与APP交互协议.md](星联卫士-终端与APP交互协议.md)（APP 交互协议 **v2.7**）配套。  
> **不进用户故事**，但缺任一项则 APP / 固件无法排期联调。  
> GATT UUID 须由终端侧填实后双方签收；编解码默认档已拍板，SDK 名/版本由终端或算法组补齐。

---

## A. 分包状态机（已拍板）

| 项 | 决议 |
|----|------|
| 多包节奏 | **串行**：当前包收到 `$TODST=4`（经 `$TOACK`）后，才允许发下一包 |
| `$TODST=3` | 仅表示「本包已发出、等平台回执」；**不是**「可发下一包」 |
| 同条消息内重试 | **保持同一 `seq`**（及同一 `termBizId`）；仅重发失败的那一包（同 `idx`） |
| 换新 `seq` | 仅当：用户发起**新消息**，或整条已失败/超时后用户**再次点击发送**（整条从第 1 包重来） |
| `$TODST` 是否加 pktIdx | **本期不加**（串行后无歧义）；`$TOACK.pktIdx` 仍带回核对 |

与「同时仅一条消息在途」一致：任意时刻 APP↔终端↔平台，至多一条业务消息、至多一包等 `0x83`。

| 项 | 约定 / 待填 |
|----|-------------|
| 角色 | 终端 = Peripheral；APP = Central |
| Service UUID | **TBD（终端提供）** |
| TX Characteristic（APP→终端 Write） | **TBD**；承载 `$TIxxx` 上行帧 |
| RX Characteristic（终端→APP Notify） | **TBD**；承载 `$TOxxx` 下行帧 |
| CCCD | APP 连接后必须 Enable Notify |
| Write 类型 | Write With Response（默认）；若改 Write Without Response 须双方书面确认 |
| 广播名过滤 | Local Name **包含** `S1` 或 `星联卫士`（大小写敏感按终端实际广播；APP 扫描用 contains） |
| Bond / 配对 | 本期 **不要求** 系统级 Bond；仅 GATT 连接 |

| 目标 MTU | **建议 ≥ 512**（单帧 HEX 约 500 字符 + 帧头）；连接后 APP 请求 MTU |
| ATT 分片 | 若协商 MTU 不足：允许把**一条 `$xxxx` 逻辑帧**拆成多包 ATT Write/Notify，接收方按完整行缓冲至 `\r\n` 再解析；**禁止**把半帧当完整指令 |
| 连接后必推 | 同协议：`$TOSTA` → `$TOLOC` → `$TOSIG` |
| deviceId 窗口 | 扫描列表可用广播名；**seq 持久化键**以首包 `$TOSTA.deviceId` 为准；若与缓存不一致则按新 deviceId 处理（换终端规则） |

## C. 语音 / 图片编解码（已拍板默认档）

| 项 | 决议 |
|----|------|
| 谁压缩 | **APP** 压缩后写入 `$TIVOI`/`$TIIMG` 的 `hex`；终端只透传组 UDP，不二次压缩 |
| 谁解压（下行） | **APP** 解 `$TOVOI.hex`；机身按键短音终端可本机播，同时可推 APP |
| 语音算法 | 对齐 UDP `0x10`：默认版本 **T05_L02_M01（ver=3）**；码率默认 **10（100）**；可选 7/10/12/15 |
| 图片算法 | 对齐 UDP `0x11`：默认版本 **T05_L01_M01（ver=5）**；模型默认 **16**；可选 8/16/24/32/40 |
| SDK 名 / 版本 | **TBD（算法组/终端提供）**；APP 集成同一套编解码库 |
| 录音上限 | 单条语音建议 ≤ **15 s**（超时由 APP 截断并提示）；采样率按 SDK 要求 |
| 图片上限 | 压缩前建议边长 ≤ **1280**；`origKb` 填原图 KB；单条压缩后总分包数由 APP 按 250B 计算 |
| 码率/模型选择 | 本期 **固定默认档**，不做设置页；后续若开放再改 PRD |

## D. 下行已读 `0x05`（已拍板）

| 场景 | 终端行为 |
|------|----------|
| APP 已 BLE 连接 | 终端向 APP **成功推送** `$TOTXT` / `$TOVOI`（整条语音各包推完）后，上报 UDP `0x05`；**不依赖**用户是否点开气泡 |
| APP 未连接 | 终端本机展示/播报完成后上报 `0x05`；该条 **不进入** APP 会话（本期不做后连补推） |
| APP 本机「已读」UI | 仅本地气泡态；**不发**任何蓝牙已读帧（无 `$TIRD`） |

接收回执 `0x03`：终端收到平台下行并完成本机处理后尽快上报（与是否推 APP 独立；约 15 s 无 `0x03` 由平台判失败）。

## E. 禁用 / 额度与 APP 上行（已拍板）

依据 UDP 附录 A 本地持久化状态：

| 本地状态 | `$TITXT`/`0x12` | `$TIVOI`/`0x10` | `$TIIMG`/`0x11` |
|----------|-----------------|-----------------|-----------------|
| 设备禁用 | `$TODST=0`，不发 UDP | 同左 | 同左 |
| 短音用完 (bit1) | 允许 | `$TODST=0`，不发 UDP | 允许 |
| 报位用完 | 不影响 APP 上行 | 同左 | 同左 |
| 余额不足 (bit0) | **仍允许**；APP 可 Toast「余额不足」 | 同左 | 同左 |

说明：平台若后续为文本/图片单独计费，再增附录；本期固件按上表实现。

## F. 会话与本地存储（已拍板）

| 项 | 决议 |
|----|------|
| 会话落库 | **是**：按 `$TOSTA.deviceId` 分库持久化气泡（上/下行） |
| 换终端 | 切换会话视图到对应 deviceId；不混库 |
| 后连补推 | **不做**：APP 未连接时平台→终端下行，不在 APP 补历史 |
| 产品提示 | 设置或空会话可文案：「仅手机连着终端时能收到卫星消息」 |
| 机身短音 | `$TOVOI platId=0` **进入同一会话列表**，展示为终端按键短音 |
| 文本超长 | 超过 N≤200 GB2312 时，APP **拆成多条独立消息**（多 seq、多气泡）；失败按条重试 |

## G. 顶栏信号格（已拍板）

用 `$TOSIG`：`valid=0` → **0 格**。`valid≠0` 时按 `rssi`（固件原值，通常为负）：

| rssi | 格数（共 4 格） |
|------|----------------|
| ≥ -70 | 4 |
| ≥ -85 | 3 |
| ≥ -100 | 2 |
| 其余 | 1 |

`snr`/`arfcn` 本期仅调试页展示，不参与格数。

## H. 固件回归（修正「V1.10 不测」）

V1.10 功能不重做，但本期互斥与号段上线后须做 **最小回归**：

1. 机身 `0x02` 短音与 APP `$TIVOI`/`0x10` 不串包  
2. 机身 `0x01` 报位与 APP 上行共用「一条在途」：APP 在途时机身延后；机身在途时 APP `$TODST=0`  
3. termBizId 号段：机身落在 0～32767，APP 上行落在 32800～65535
