# 星联卫士 PRD — 如何发给别人看

本文件夹是**完整静态站点**：不需要安装、不需要服务器、不需要联网。

## 发给对方

1. 发送压缩包或整个 `需求文档` 文件夹
2. 对方解压后，用 **Chrome / Safari / Edge** 打开其中的 `index.html`

## 手机注意

- **不要用微信内置预览**打开 html（样式易错乱、脚本常被拦）
- Android：解压 →「文件」→ 点 `index.html` → 选 Chrome 打开
- iPhone：用「文件」App 解压 → 点 `index.html` → 用 Safari 打开

## 目录不要拆散

`index.html` 必须和 `assets/`、`docs/` 以及同级 `通用/`、`固件/` 放在一起，整包转发。
