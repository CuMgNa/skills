# 天通救援棒 · 上行媒体（语音/图像/文本）· 前端对接说明

> 模块：Monitor Web 平台聊天（终端单聊 / 对讲群 / 求救群）  
> 后端：podium 接收 rstp HTTP 推送后入库并分发  
> 鉴权：与其它 Monitor 接口、WebSocket 相同（登录态 Token）

---

## 1. 产品行为（前端需知）

| 点 | 说明 |
|---|---|
| 来源 | 天通救援棒 APP 经 rstp 推送：speech-report / image-report / **text-report** |
| 扣费 | 发送方 **VOICE 套餐扣 1 条**（无单独 TEXT/IMAGE 枚举） |
| 路由 | 默认 **平台单聊**；SOS 中 → **求救群**；绑定对讲群 → **对讲群** |
| 图像对讲 | 图像**进入对讲群 Web 会话**，但**不对讲终端 TCP 广播** |
| 文本对讲 | 文本**进入对讲群 Web 会话**，且**对群内其它终端 TCP 广播**（与图像不同） |
| 文本载荷 | 内联于推送体 `text` 字段，**无 fileId 拉取** |
| 图像载荷 | rstp decode 后凭 `decodedImageFileId` 拉取入库 |
| 幂等 | 文本：`terminalId_terminalBusinessId` Redis 锁防 HTTP 重推 |

---

## 2. rstp 推送入口（供联调参考）

Base path：`POST /api/rescuesat-tcp-platform/receive-event`

| 事件 | Path | 说明 |
|------|------|------|
| 语音 | `/speech-report` | 异步拉取 WAV/回退 speechContent |
| 图像 | `/image-report` | 异步拉取解码图 |
| **文本** | **`/text-report`** | **同步入库**（`TextReportEvent.text`） |

---

## 3. REST 接口总览

Base path：`/api/monitor`

| # | Method | Path | 场景 |
|---|--------|------|------|
| 1 | GET | `/platform-chats/{addr}` | 平台单聊消息 |
| 2 | GET | `/platform-chats/{id}/album` | 相册（图像单包通常仅主图） |
| 3 | GET | `/files/{fileId}` | **图片/语音预览下载** |
| 4 | GET | `/intercom/message/page?intercomGroupId=` | 对讲消息 |
| 5 | GET | `/emergency/chat/record/page?chatItemId=` | 求救群消息 |
| 6 | GET | `/platform-chats/chat-item/page` | 统一会话列表 |

---

## 4. 字段矩阵：TEXT / IMAGE / VOICE × 三路由

| 路由 | WS type | 类型字段 | content 含义 | 取图/取音 |
|------|---------|----------|--------------|-----------|
| **PLATFORM** | 20 (+21 仅 IMAGE) | `chatType.name` | TEXT 明文；IMAGE 用 **imageInfo.fileId**（勿用 content，可能为 ObjectId） | `/files/{fileId}` |
| **INTERCOM** | 103 | **`sendType`** | TEXT 明文；IMAGE/VOICE **content=fileId** | `/files/{fileId}` |
| **SOS** | 100 | **`sendType`** | TEXT 明文；IMAGE/VOICE **content=fileId** | `/files/{fileId}` |

> **注意**：求救/对讲 WS 实际 DTO 使用 **`sendType`**（非文档旧字段 `chatType`）、**`chatTime` Long**（非 `chatTimeStr`）。

---

## 5. WebSocket 处理（按 type）

| type | 名称 | TEXT | IMAGE | VOICE |
|------|------|------|-------|-------|
| **20** | CHAT | `content` 明文 | `imageInfo.fileId` | `voiceInfo.fileId` |
| **21** | CHAT_UPDATE_IMAGE | — | 仅 PLATFORM，更新 imageInfo | — |
| **100** | EMERGENCY_CHAT_RECORD | `sendType=TEXT`，content 明文 | sendType=IMAGE，content=fileId | sendType=VOICE，content=fileId |
| **103** | INTERCOM_CHAT_RECORD | sendType=TEXT，content 明文 | sendType=IMAGE，content=fileId | sendType=VOICE，content=fileId |
| **104** | INTERCOM_CHAT_RECORD_STATUS | 计数刷新；规则同 103 | 同左 | 同左 |

## 6. JSON 示例

### type20 平台单聊 TEXT

```json
{
  "type": 20,
  "content": {
    "id": "chatRecordId",
    "from": "13800138000",
    "chatType": { "name": "TEXT", "value": "文本" },
    "content": "你好",
    "chatTimeStr": "2026-08-29 14:30:00"
  }
}
```

### type20 平台单聊 IMAGE

```json
{
  "type": 20,
  "content": {
    "id": "chatRecordId",
    "from": "13800138000",
    "chatType": { "name": "IMAGE", "value": "图片" },
    "imageInfo": {
      "total": 1,
      "curTotal": 1,
      "finished": true,
      "fileId": "stored-file-id-001"
    },
    "chatTimeStr": "2026-08-29 14:30:00"
  }
}
```

### type100 求救群 TEXT（rstp 终端）

```json
{
  "type": 100,
  "content": {
    "id": "emergency_001",
    "from": "13800138000",
    "sendType": "TEXT",
    "content": "需要救援！",
    "chatTime": 1756450200000
  }
}
```

### type103 对讲群 TEXT（rstp 终端，会 TCP 广播）

```json
{
  "type": 103,
  "content": {
    "id": "intercomMsgId",
    "groupId": "group001",
    "sendType": "TEXT",
    "content": "对讲群文本",
    "chatTime": 1756450200000
  }
}
```

### type103 对讲群 IMAGE（仅 Web 入群，不广播）

```json
{
  "type": 103,
  "content": {
    "id": "intercomMsgId",
    "sendType": "IMAGE",
    "content": "stored-file-id-001",
    "chatTime": 1756450200000
  }
}
```

## 7. 三路由 UI 对照

| 路由 | 会话入口 | 列表 API | WS | TEXT 展示 | IMAGE/VOICE 取文件 |
|------|---------|---------|-----|-----------|-------------------|
| PLATFORM | SINGLE | platform-chats/{addr} | 20 (+21) | content | imageInfo/voiceInfo.fileId |
| INTERCOM | GROUP | intercom/message/page | 103 | content | content=fileId |
| SOS | SOS_GROUP | emergency/chat/record/page | 100 | content | content=fileId |

---

## 8. 会话列表摘要

- `chatType=IMAGE` 时列表 `content` 可能为 **`[图片消息]`** i18n 文案，**不要**当 fileId
- TEXT 可直接展示 `content` 明文
- 预览图/语音从消息详情或 WS payload 按上表取 fileId

---

## 9. 联调清单

- [ ] 平台 TEXT：收 type20，content 为明文
- [ ] 平台 IMAGE：收 type20+21，图片 `/files/{fileId}` 可打开
- [ ] 对讲 TEXT：收 type103，content 明文；终端侧收到 TCP 广播
- [ ] 对讲 IMAGE：收 type103，content 为 fileId；**终端不广播**
- [ ] SOS TEXT：收 type100，sendType=TEXT
- [ ] SOS IMAGE：收 type100，content 为 fileId
- [ ] 非群平台账号（设备同时在 SOS/对讲）：仍可能收 type20
