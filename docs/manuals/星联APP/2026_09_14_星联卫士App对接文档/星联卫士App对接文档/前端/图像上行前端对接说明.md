# 天通救援棒 · 图像上行 · 前端对接说明

> 模块：Monitor Web 平台聊天（终端单聊 / 对讲群 / 求救群）  
> 后端：podium 接收 rstp 推送后拉取解码图直入库  
> 鉴权：与其它 Monitor 接口、WebSocket 相同（登录态 Token）

---

## 1. 产品行为（前端需知）

| 点 | 说明 |
|---|---|
| 来源 | 天通救援棒 APP 图像经 rstp decode 后，podium 凭 `decodedImageFileId` 拉取并入库 |
| 扣费 | 发送方 **VOICE 套餐扣 1 条**（无单独 IMAGE 枚举） |
| 路由 | 默认 **平台单聊**；SOS 中 → **求救群**；绑定对讲群 → **对讲群** |
| 对讲差异 | 图像**进入对讲群 Web 会话**，但**不对讲终端 TCP 广播**（与语音不同） |
| 分包计数 | rstp 合并后推送 `totalPackets` / `receivedPacketCount`；Podium 写入 `imageInfo.total` / `curTotal`；收齐为 **N/N**，超时未收齐为 **k/N**；`finished=true` 后通常只收一次 type21 |

---

## 2. REST 接口总览

Base path：`/api/monitor`

| # | Method | Path | 场景 |
|---|--------|------|------|
| 1 | GET | `/platform-chats/{addr}` | 平台单聊消息（含 `imageInfo`） |
| 2 | GET | `/platform-chats/{id}/album` | 相册（单包通常仅主图） |
| 3 | GET | `/files/{fileId}` | **图片预览/下载** |
| 4 | GET | `/intercom/message/page?intercomGroupId=` | 对讲消息（IMAGE：`content=fileId`） |
| 5 | GET | `/emergency/chat/record/page?chatItemId=` | 求救群消息（IMAGE：`content=fileId`） |
| 6 | GET | `/platform-chats/chat-item/page` | 统一会话列表（看 `chatType=IMAGE`） |

---

## 3. 公共结构 `ChatImageInfoRespDto`（平台 type20/21）

| 字段 | 类型 | 典型值 |
|---|---|---|
| fileId | string | 必填，拼 `/api/monitor/files/{fileId}` |
| total | number | 协议总包数（单包为 1，多包为 N） |
| curTotal | number | 已收唯一分包数（收齐时等于 total） |
| finished | boolean | **true**（rstp 合并完成或超时兜底后推送） |
| imageType | number | 0（传统图） |
| beforeCompSize | number | 原图 MB（可选） |
| decompSize | number | 解压后 MB（可选） |

---

## 4. WebSocket 处理（按 type）

| type | 名称 | 前端动作 |
|------|------|---------|
| **20** | CHAT | `chatType.name===IMAGE` → 读 `imageInfo.fileId` |
| **21** | CHAT_UPDATE_IMAGE | **仅平台单聊**；更新该 chatId 的 imageInfo |
| **100** | EMERGENCY_CHAT_RECORD | `sendType===IMAGE` → **`content` 即 fileId**（无 imageInfo） |
| **103** | INTERCOM_CHAT_RECORD | `sendType===IMAGE` → **`content` 即 fileId** |
| **104** | INTERCOM_CHAT_RECORD_STATUS | 计数刷新；content 规则同 103 |
| **30** / WsNum | 未读 +1 | 与现网一致 |

---

## 5. 三路由 UI 对照

| 路由 | 会话入口 | 列表 API | WS | 取图 |
|------|---------|---------|-----|------|
| PLATFORM | SINGLE | platform-chats/{addr} | 20 + 21 | imageInfo.fileId |
| INTERCOM | GROUP | intercom/message/page | 103 | content=fileId |
| SOS | SOS_GROUP | emergency/chat/record/page | 100 | content=fileId |

## 6. JSON 示例

### type20 平台单聊（IMAGE）

```json
{
  "type": 20,
  "content": {
    "id": "chatRecordId",
    "from": "13800138000",
    "chatType": { "name": "IMAGE", "value": "图片" },
    "imageInfo": {
      "total": 1,
```

## 7. 会话列表摘要

- `chatType=IMAGE` 时列表 `content` 可能为 **`[图片消息]`** i18n 文案，**不要**当 fileId
- 预览图从消息详情接口或 WS payload 取 fileId

## 8. 联调清单

- [ ] 平台：收 type20+21，图片 `/files/{fileId}` 可打开
