## 2. 预警发布端到端流程（预警发布页）

```mermaid
flowchart TD
    start([🚀 调度员进入预警发布]) --> channel["⚙️ 选择发布渠道<br/>默认全部：LED显示屏/预警广播/短信/邮件<br/>（LED仅入口不实装）"]
    channel --> tpl["📋 可选：模板选择<br/>弹窗搜索→勾选→确定→自动填入内容"]
    tpl --> content["📝 输入发布内容<br/>≤200字符·实时字数统计"]
    content --> target{"🎯 选择发布目标"}
    target -->|"按设备"| bydev["设备列表（仅呼叫器）<br/>搜索/全选耦合/统计数量"]
    target -->|"按区域"| byarea["行政区域树（省→市→县/区）<br/>选择全部/取消/展开/折叠"]
    bydev <-->|"切换时勾选互相重置"| byarea
    bydev --> check
    byarea --> check{"✅ 校验"}
    check -->|"内容为空"| tip1["❌ 提示：发布内容不能为空"]
    check -->|"未选目标"| tip2["❌ 提示：请选择发布目标<br/>（未选设备时按钮置灰）"]
    tip1 --> content
    tip2 --> target
    check -->|"通过"| send["📤 立即发送"]
    send --> dispatch["☁️ 平台按渠道下发"]
    dispatch --> online{"📡 设备在线？"}
    online -->|"是"| ok["✅ 下发成功"]
    online -->|"否"| fail["❌ 下发失败·原因：设备离线"]
    ok --> record["🗄️ 写入发布记录（100%留痕）"]
    fail --> record
    record --> view["🔍 发布记录页查询/查看详情<br/>类型/状态/结果/发布人/时间"]

    classDef step fill:#90EE90,stroke:#333,color:darkgreen
    classDef decision fill:#FFD700,stroke:#333,color:black
    classDef error fill:#FFB6C1,stroke:#DC143C,color:black
    classDef store fill:#E6E6FA,stroke:#333,color:darkblue
    class channel,tpl,content,bydev,byarea,send,dispatch,view step
    class target,check,online decision
    class tip1,tip2,fail error
    class record,ok store
```

## 4. 定时发布任务生命周期

```mermaid
stateDiagram-v2
    [*] --> 新建: 点击+号右侧弹框
    新建 --> 已禁用: 确定保存（必填校验：任务名称/所属区域）
    note right of 新建
        基础信息：任务名称*≤20字符、所属区域*（省→县/区）、发布渠道多选
        任务日程：周期（周一~周日多选）、日期/时间（非必填）
        校验失败 toast：请填写完整基础信息和任务日程
    end note
    已禁用 --> 运行中: 点击启动（按任务周期·北京时间）
    运行中 --> 已禁用: 再次点击暂停
    运行中 --> 执行一次: 点击执行一次（不区分任务日期立即发送）
    执行一次 --> 运行中: 发送完成
    已禁用 --> 编辑: 点击编辑（右侧弹框预填）
    编辑 --> 已禁用: 保存
    已禁用 --> [*]: 删除（弹窗确认）
    运行中 --> [*]: 删除（弹窗确认）
```

## 9. 呼叫器设备入库与斗信绑定流程

```mermaid
sequenceDiagram
    participant admin as 👨‍💼 管理员
    participant backend as 🖥️ 管理后台
    participant dx as 📱 斗信 APP
    participant dev as 📡 呼叫器终端
    participant platform as ☁️ 调度平台

    admin->>backend: 设备入库→选择设备类型【呼叫器（新增）】
    Note over backend: 入库时移出图标选项（图标在平台绑定处使用）
    admin->>backend: 录入设备信息（SN/SIM卡号/区域等）并保存
    backend->>platform: 设备入库同步
    admin->>dx: 用户侧安装/打开斗信 APP
    dx->>dx: 首启弹窗：欢迎使用斗信/个人信息保护指引/斗信隐私协议
    dx-->>dx: 用户点击【同意】
    dx->>dx: 引导开启定位【始终允许】权限
    Note over dx: 未授权则后台无法正常获取定位
    dx->>platform: 绑定设备/上报位置与北斗短报文
    platform->>dev: 预警广播下发（点对点，位置坐标仅随消息传送给接收方）
    dev-->>platform: 终端状态（在线/离线/未连接、值守中等）
```

## 10. 预警消息下发时序（网页端/小程序端一致）

```mermaid
sequenceDiagram
    actor user as 👤 调度员（网页/小程序）
    participant web as 🖥️ 预警发布模块
    participant tpl as 📋 模板/接收人服务
    participant plat as ☁️ 调度平台
    participant term as 📡 呼叫器终端
    participant sms as 📱 短信网关
    participant mail as 📧 邮件服务

    user->>web: 填写渠道/内容/目标（按设备或按区域）
    opt 使用模板
        user->>tpl: 拉起模板弹窗·模糊搜索
        tpl-->>web: 模板内容自动填入
    end
    web->>web: 校验（内容非空·目标已选）
    user->>web: 立即发送
    par 预警广播
        web->>plat: 下发语音/文本指令
        plat->>term: 推送广播
        term-->>plat: 成功/失败（离线→下发失败）
    and 短信
        web->>tpl: 读取启用状态的短信接收人
        web->>sms: 发送短信
    and 邮件
        web->>tpl: 读取启用状态的邮件接收人
        web->>mail: 发送邮件
    end
    web->>plat: 写入发布记录（类型/渠道/状态/结果/发布人/时间）
    user->>web: 发布记录页查询·查看详情
```
