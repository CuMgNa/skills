## 1. 背景与目标

### 1.1 项目背景

现有"星地多网融合指挥调度平台"（pg-podium-tdwt）已具备控制台、多端监控、多端轨迹、设备管理（终端设备/调度设备/LoRa 信标/LoRa 网关）、用户管理、消息管理、电子围栏等能力，并已有调度组、北斗短报文等基础设施。

本项目（钒星应急叫应一期）在该基座上新增**面向应急场景的"叫应"能力**，核心是：

1. 平台端新增**预警发布模块**（预警发布 / 实时广播 / 定时发布 / 发布记录 / 发布管理），将预警与广播消息通过**预警广播、短信、邮件**渠道下发到"呼叫器"终端与相关接收人；
2. 新型终端"**呼叫器**"（入户报警终端）接入：后台设备入库新增该设备类型，配套"斗信"APP（北斗区域短报文专用 APP）完成设备绑定与隐私合规；
3. 存量"呼叫器 APP"做登录账号体系与成员列表调整（企业账号 + 个人账号）；
4. 小程序端（存量调度小程序，底部 5 Tab：控制台/通信/调度台/设备/我的）新增**预警发布入口与模块**，与网页端同款设计。

### 1.2 产品目标

- 应急预警信息可以**一键触达**指定设备（按设备/按区域）与接收人（短信/邮件）；
- 支持**文本语音、实时语音、短语音**三种广播形态，适配不同紧急程度；
- 支持**定时发布任务**的周期化自动执行（周一~周日、任务日期/时间）；
- 全部发布行为**可追溯**（发布记录、成功/失败、失败原因）；
- 消息模板、短信/邮件接收人可维护，提升发布效率。

### 1.3 名词术语

| 术语 | 说明 |
| --- | --- |
| 呼叫器 | 新接入的终端设备类型，产品归属"入户报警终端"，是预警发布的主要目标设备 |
| 斗信 | 北斗区域短报文专用 APP，与呼叫器配套使用（定位、短报文收发） |
| 预警广播 | 下发到呼叫器终端的语音播报渠道 |
| 发布渠道 | LED显示屏、预警广播、短信、邮件（四选多，一期实装后三项） |
| 发布目标 | 按设备（仅呼叫器）/ 按区域（行政区域，到区县一级）；按机构一期不做 |
| 发布方式 | 实时广播的四种形态：文本语音、实时语音、短语音、告警触发（后者一期不开发） |
| 调度组 | 平台已有能力，设备/成员的调度分组，呼叫器 APP 与小程序均围绕调度组工作 |

## 4. 网页平台功能需求

## 4.1 菜单与入口调整

**F-WEB-01 控制台新增"预警发布"入口**

- 在控制台（首页）左侧菜单中，于**【电子围栏】后方**新增【预警发布】入口；点击进入预警发布菜单页面。（依据：画布"预警发布主页"批注 1"新增【预警发布】入口，在电子围栏后方"、批注 15"首页，增加预警发布入口，点击后可进入预警发布菜单页面"）
- 预警发布模块顶部菜单依次为：**预警发布、实时广播、定时发布、发布记录、发布管理**；因页面空间不足，"发布管理"采用与小程序相同的扩展方式（收进"更多"扩展菜单）。（依据：批注 16）
- 基座现有菜单（控制台、多端监控、多端轨迹、设备管理、用户管理、消息管理、电子围栏）保持不变。

## 4.2 预警发布模块

### 4.2.1 预警发布页（消息发布主表单）

**功能描述**：调度员选择发布渠道、填写发布内容、选择发布目标后立即发送预警消息。

**表单字段与规则**：

| 字段 | 类型 | 规则 |
| --- | --- | --- |
| 发布渠道 | 多选下拉 | 选项：LED显示屏、预警广播、短信、邮件；默认**全部勾选**；仅可选择、不支持手动输入；二次点击取消选择。（批注 18、发布管理画布批注 2） |
| 模板选择 | 弹窗选择器 | 点击拉起"选择预警消息模板"弹窗（见下）；表单上有"预警消息模板"文字入口，可跳转发布管理-预警模板页 |
| 发布内容 | 文本域 | 占位"请输入发布内容"；最大 **200 字符**，右下角实时字数统计；为空时点"立即发送"提示"**发布内容不能为空**"（批注 2、26） |
| 发布目标 | Tab：按设备 / 按区域 | 按机构 Tab 一期隐藏/置灰（批注 19：按机构当前版本暂不做） |

**发布目标——按设备**（依据：预警发布-618更新 批注 3、4；页面1 批注 20~22）：

- 设备列表**仅展示设备类型为"呼叫器"（所属产品：入户报警终端）的终端**；
- 列表列：序号、状态（在线/离线/未连接）、设备SN、设备名称、所属产品；
- 右上角"所有设备"复选框与列表逐项勾选**耦合互通**（勾选所有设备 ⇒ 列表自动全选）；
- 支持**按设备名称搜索**；设备较多时支持列表上下滑动；
- 勾选后"已选择"处自动统计设备数量；**未选择设备时"立即发送"按钮置灰**，无法点击（批注 20）。

**发布目标——按区域**（依据：批注 23、25、预警发布-618更新 批注 5）：

- 行政区域树（中国省→市→县/区），**最多到区县一级，不支持乡/村**（⚠️ 另一画布写"省-市-县/区-街道"，以 618 更新版"区县一级"为准，待确认）；
- 快捷操作：**选择全部、取消选择、展开全部、折叠全部**；支持按行政区域名称搜索；
- 支持全选或单选（操作行政单位前复选框）；
- 按区域选择勾选的是"该行政区域内登记的呼叫器设备"。

**切换互斥**：按设备 ⇄ 按区域切换时，原 Tab 的勾选状态**刷新重置**（批注 4-4/4-5）。

**模板选择弹窗**（依据：预警发布-618更新 批注 1、6）：

- 字段：模板名称搜索（支持模糊搜索）+ 复选列表 + 查询/重置 + 确定/取消；
- 勾选模板点"确定"自动将模板内容填入发布内容框；"重置"清空搜索词；"取消"退出弹窗。

**发送与记录**：

- 校验链：发布内容非空 → 发布目标已选（否则提示"**请选择发布目标**"）；
- 点击"立即发送"后，**无论成功或失败，均生成一条发布记录**（批注 4-6）。

### 4.2.2 实时广播页

**功能描述**：面向呼叫器终端的实时语音广播，支持四种发布方式。

**发布方式切换**：文本语音 / 实时语音 / 短语音 / 告警触发；点击切换后**原输入与设置内容重置**。（实时广播画布批注 1）

**① 文本语音**（批注：实时广播画布 1、页面1 批注 26 ⚠️ 两版参数不一致）：

| 参数 | 规则 |
| --- | --- |
| 播放次数 | 默认 1，支持输入与拖动，**1~9**；输入 >9 自动显示 9；仅数字校验"仅支持输入数字1到9"，不弹 toast |
| 播放音量 | 规则同上，**1~9** |
| 播音员 | 普通话女声 / 普通话男声（2 选 1） |
| 提示音 | 警报声 / 门铃声（⚠️ 旧画布含"电话铃音"共 3 种，待确认） |
| 广播内容 | ≤200 字符，右下角字数统计 |

> ⚠️ 旧版批注 26 为"播放次数 1-5、音量 1-10、提示音 3 种"，实时广播专用画布批注为"次数/音量 1-9、提示音 2 种"，本文档采用**实时广播画布（较新）**口径。

**② 实时语音**（页面1 批注 27、实时广播画布）：

- 点击"开始广播"→ 按钮变"结束广播"；再次点击变回"开始广播"；
- 开始广播后，音波展示区显示**动态水波纹音波图**，并展示音频大小/时长（示例：11.99KB、00:08）；
- 广播中底部出现**重置、回放**按钮。

**③ 短语音**（页面1 批注 28）：

- 点击"开始录音"→"结束录音"切换；录音中显示动态音波图与大小/时长；
- 录音结束底部出现**重置、回放、发送**按钮。

**④ 告警触发**（页面1 批注 29）：

- **一期暂不开发**（原型已设计：告警次数、告警间隔、告警等级[一级告警]、开始告警/取消告警，供二期参考）。

**公共规则**：发布目标选择、发送校验、发布记录与 4.2.1 一致；实时广播同样支持按设备/按区域（画布含"按机构"按钮，一期不做）。

### 4.2.3 定时发布页

**功能描述**：创建/管理周期性定时发布任务，由系统按任务周期自动执行。

**任务列表**：

- 筛选：状态（全部 / 运行中 / 已启用 / 已禁用；另一画布为 启用/禁用 + 任务名称 + 开始日期 + 结束日期的查询/重置组合，⚠️ 两版并存，建议合并：状态 Tab + 名称模糊搜索 + 日期范围）（批注 1、2）；
- 列表项结构：上方**任务名称**，下方**发布渠道**，最右侧**启用状态**（已启用 / 运行中 / 已禁用）（批注 3）；
- 任务较多时支持上下滑动、滑动到底部（批注 5）；
- 新增任务**插入列表最顶部**，继续新增依次插队；已启用/运行中/已禁用不做固定排序要求（批注 6）。

**列表操作**（批注 4，定时发布和通信消息画布批注 1）：

| 操作 | 行为 |
| --- | --- |
| 执行一次 | 不区分任务日期，**立即触发发送一次** |
| 启动/暂停 | 启动后按既定任务周期发送（基准时间：**当前网络系统北京时间**）；再次点击暂停 |
| 编辑 | 弹出右侧菜单弹框（同新增表单，内容预填） |
| 删除 | 弹窗确认"是否确定删除"，确定后移除 |

**新增定时发布任务（右侧弹框）**（批注 7~10）：

| 分区 | 字段 | 必填 | 规则 |
| --- | --- | --- | --- |
| 基础信息 | 任务名称 | ✅ | 中英文大小写、中文汉字，**不支持特殊字符**，≤20 字符 |
| 基础信息 | 所属区域 | ✅ | 点击展开中国省级行政单位，最小到**县/区** |
| 基础信息 | 发布渠道 | — | LED显示屏、预警广播、短信、邮件，**多选** |
| 任务日程 | 任务周期 | — | 星期一~星期日，**多选** |
| 任务日程 | 任务日期 | — | 日历选择，开始/结束日期，选择后自动填入输入框；**非必填** |
| 任务日程 | 任务时间 | — | 选择时:分；开始时间/结束时间**非必填** |

- 校验：必填项（任务名称、所属区域）未填直接点确定 → toast"**请填写完整基础信息和任务日程**"；确定后新增成功并加入列表；取消则不新增。

### 4.2.4 发布记录页

**功能描述**：所有发布行为（预警发布/实时广播/定时发布）的留痕与查询。

- 筛选：设备类型、消息类型、消息状态（下拉）+ 查询/重置；（发布记录画布）
- 消息类型枚举：**预警发布、实时广播、定时发布、应急广播、告警通知、短语音**（批注 11）；
- 消息状态：**已完成**（批注 12）；
- 分页：默认 20 条/页，显示总条数（示例：共 1990 条），支持跳页（跳至 X 页）；
- 详情（点击"查看详情"，批注 14、30）：

| 字段 | 说明 |
| --- | --- |
| 消息类型 | 预警发布 / 实时广播 / 定时发布… |
| 设备类型 | 实际下发渠道（示例：邮件,预警广播,短信,LED显示屏） |
| 消息状态 | 已完成 等 |
| 发布结果 | 成功 / 失败 |
| 发布人 | 对应当前账号用户名称 |
| 创建时间 | 预警/实时广播/定时发布的创建时间 |
| 所属机构 | **一期暂不做**（批注 13） |

- **失败留痕**：设备不在线时发送，发送状态为"**下发失败**"，失败原因"**设备离线**"（发布记录画布批注 1）。

### 4.2.5 发布管理页

**功能描述**：维护预警消息模板与短信/邮件接收人。三个子模块 Tab：**预警模板、短信接收人、邮件接收人**（批注 31）。

**通用**：

- 列表操作（从左到右）：**查看详情、复制、编辑、删除**（批注 32；删除需确认弹窗，批注 34）；
- 支持批量勾选/取消全部勾选，批量删除（批注 3）；
- 状态：启用 / 禁用（两种）；
- 平台版本号从页面左侧移至发布管理页展示（发布管理画布批注 2）。

**① 预警模板**（批注 33、35、36）：

- 查询：按模板名称、状态（批注 1）；
- 新增/编辑表单：

| 字段 | 必填 | 规则 |
| --- | --- | --- |
| 模板名称 | — | 文本 |
| 模板内容 | ✅ | ≤200 字符 |
| 状态 | ✅ | 启用/禁用，**互斥不可同时勾选** |
| 排序 | — | **一期暂不实现** |
| 备注 | — | ≤200 字符 |

- 复制：进入新增页并自动填充当前条目内容，便于快速调改；
- 确定后模板加入列表并**按时间倒序**排列；取消不创建。

**② 短信接收人**（发布管理画布批注 6、9）：

- 查询：所属区域、状态、手机号；
- 新增表单：手机号✅、所属区域✅、昵称、状态（默认**启用**）、备注；**所属机构一期暂不实现**。
