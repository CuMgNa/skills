### 2.1 终端型号说明

当前PRD模拟数据中更接近以下关系：

- 产品/设备类型：S18；
- 内部型号：186；
- 测试设备名称：S18-*。

因此，S18与186是否为两个独立终端型号，需要在终端测试资源准备前由硬件或研发团队确认，避免测试资源和型号覆盖口径错误。

## 4. 测试A负责范围

### 4.1 App端

| 模块 | 主要需求点 |
|---|---|
| 登录与启动 | 品牌开屏、自动跳转、跳过开屏、邮箱登录、记住密码、隐私政策、Token失效、登录后加载设备 |
| 注册与找回密码 | 邮箱注册、邮箱重复校验、密码规则、发送重置链接、重置密码 |
| 公共能力 | 中文版/海外版、语言切换、日期、时区、单位及公共提示文案 |
| 设备列表 | 设备状态、在线/离线筛选、搜索、刷新、设备卡片、绑定和解绑 |
| 设备分组 | 新建、改名、删除、筛选、设备改组和未分组处理 |
| 设备详情 | 基础信息、设备状态、资料编辑、分组修改、定位过滤和协议入口 |
| SIM状态 | 卡号、运营商、流量、到期时间、SIM五态和续费提示 |
| 指令与设置 | 七项指令、指令记录、离线拒发、ACK、超时、拒绝、定时开关机、时区和App刷新间隔 |
| 我的 | 账号资料、修改密码、隐私入口和退出登录 |

### 4.2 牧场监控平台

| 模块 | 主要需求点 |
|---|---|
| 登录与账号 | 企业/个人登录入口、账号Role校验、记住账号、资料、改密和退出 |
| 总览设备指标 | 在线、离线、告警和设备合计；设备三态互斥及状态来源一致性 |
| 设备管理 | 设备列表、查询、筛选、绑定、编辑、分组和SIM状态 |
| 服务到期 | 管理端写入到期时间，监控平台只读，不出现自助续费入口 |
| 软件档位 | 展示Basic/Pro/Plus值，一期不执行真正的Pro/Plus功能门控 |

### 4.3 运维管理平台

| 模块 | 主要需求点 |
|---|---|
| 管理员登录 | 登录、失败次数、验证码、15分钟锁定和语言切换 |
| 账号管理 | 企业/个人账号、二三级账号、设备配额、冻结和解冻 |
| 人工赋权 | 手工写入到期时间和软件档位，App及监控平台只读 |
| 全网设备 | 跨租户设备列表、在线率、故障率、型号分布和设备归属 |
| 设备入库 | 单条入库、批量入库、设备分组、SN/IMEI校验和重复校验 |
| 设备激活 | 单台激活、批量激活、激活记录及未入库设备拦截 |
| 指令管理 | 按型号过滤可用指令、单台/批量下发和逐台执行结果 |
| SIM管理 | ICCID绑定、SIM五态、批量绑卡、到期提醒和人工登记充值 |

### 4.4 终端及跨端联调

| 测试方向 | 主要需求点 |
|---|---|
| 终端身份 | 型号、SN、IMEI和ICCID匹配；重复设备数据拦截 |
| 4G接入 | 入库、激活、绑卡、绑定账号和终端上报 |
| 在线状态 | 根据上报间隔判断在线/离线，恢复上报后状态恢复 |
| 设备电量 | 电量数值、低电状态及客户端展示 |
| 指令闭环 | 发送、送达、ACK、超时、拒绝和失败原因 |
| 设备能力 | 不支持的摄像头、心率等能力入口不得错误显示 |
| 服务到期 | 到期后App、监控平台和终端上报表现符合业务规则 |
| 人工赋权 | 修改到期时间后，后续上报和客户端状态正确恢复 |
| 跨端一致性 | App、监控平台、管理后台中的账号、设备、SIM、分组和状态一致 |
