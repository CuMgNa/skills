# US-018 编辑设备资料并查询物联网卡

## POINT-003 定位频率弹层与编辑态

## [P1] 验证在线设备频率弹层选择与整页保存
- 测试类型
  - 功能
- 前置条件
  1. P-201在线，无在途目标，最后确认值为10分钟。
- 测试步骤
  1. 进入编辑态点击Location Interval打开弹层。
  2. 查看60分钟选项并选择，点击弹层Save。
  3. 点击整页Save。
- 预期结果
  1. 弹层自动选中"10分钟（默认模式）"预设。
  2. 弹层Save只写入本地表单，不立即发送指令。
  3. 整页Save创建UPLOAD指令（3600秒），详情展示"1小时（省电模式）（设置中）"。

## [P2] 验证弹层四选项与自定义分钟值
- 测试类型
  - 功能
- 前置条件
  1. P-201在线，进入编辑态频率弹层。
- 测试步骤
  1. 查看弹层选项构成。
  2. 选择Custom输入30并确认保存。
  3. 当前确认值分别为1、10、60分钟时重新打开弹层查看选中态。
- 预期结果
  1. 弹层为1分钟、10分钟、60分钟、自定义四个选项。
  2. 自定义30分钟保存为"自定义模式（30分钟）"，UPLOAD参数1800秒。
  3. 确认值1/10/60打开弹层自动选中对应预设，其他合法值选中Custom并填入N。

## [P4] 验证自定义分钟值边界
- 测试类型
  - 功能
- 前置条件
  1. P-201在线，编辑态频率弹层Custom输入框可用。
- 测试步骤
  1. 输入1保存。
  2. 输入1440保存。
  3. 分别输入0、1441、30.5、空值、非数字"abc"保存。
- 预期结果
  1. 1分钟边界保存成功（映射60秒）。
  2. 1440分钟上边界保存成功（86400秒）。
  3. 0、1441、小数、空、非整数均被拦截，提示合法范围。

## [P1] 验证离线设备频率置灰不禁资料编辑
- 测试类型
  - 功能
- 前置条件
  1. P-003离线，备注"旧名"。
- 测试步骤
  1. 进入P-003详情编辑态查看Location Interval行。
  2. 修改Device Name为"新名"并整页保存。
- 预期结果
  1. 频率行置灰显示"设备离线，无法下发指令"，不能打开弹层。
  2. 普通资料仍可编辑保存成功，离线只禁频率入口。

## [P3][反向] 验证编辑中途设备离线频率独立拦截
- 测试类型
  - 功能
- 前置条件
  1. P-201在线时进入编辑态并选择频率目标60分钟。
  2. 点击整页Save前设备变为离线。
- 测试步骤
  1. 点击整页Save。
  2. 查看资料与频率两部分结果。
- 预期结果
  1. 资料接口独立提交成功。
  2. 频率接口按普通指令入口重新校验离线被拦截，展示"频率未更新"与原因，不创建静默等待上线任务。

## [P2] 验证SENDING后掉线按队列执行
- 测试类型
  - 功能
- 前置条件
  1. P-201在线，频率目标已通过在线校验进入SENDING。
  2. 随后设备离线。
- 测试步骤
  1. 查看详情页频率展示。
  2. 等待设备重新上线后观察指令流转。
- 预期结果
  1. 详情维持目标值+"设置中"，不回退为入口离线失败。
  2. 继续按网关队列式指令逻辑执行，恢复在线后按队列投递。

## [P3][反向] 验证频率失败后不自动补发
- 测试类型
  - 功能
- 前置条件
  1. P-201某条频率指令FAILURE（如网关失败）。
- 测试步骤
  1. 设备恢复在线后等待并刷新详情。
  2. 通过指令记录页对该指令点击重新发送。
- 预期结果
  1. 恢复在线不自动补发，详情恢复最后确认值或"请选择定位频率"。
  2. 只能通过记录页重发或重新进入详情选择目标保存，两种途径均可创建新UPLOAD。

## [P2] 验证退出编辑丢弃全部本地修改
- 测试类型
  - 易用性
- 前置条件
  1. P-201编辑态已修改名称、联系人并暂存频率目标60分钟。
- 测试步骤
  1. 不保存直接返回/取消编辑。
  2. 重新进入查看态与编辑态。
- 预期结果
  1. 直接丢弃全部本地修改，不弹二次确认。
  2. 名称、联系人、电话、分组及频率暂存全部恢复原值，无任何变更落库或指令产生。
