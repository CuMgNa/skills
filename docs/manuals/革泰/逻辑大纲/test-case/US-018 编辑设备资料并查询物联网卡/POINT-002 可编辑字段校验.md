# US-018 编辑设备资料并查询物联网卡

## POINT-002 可编辑字段校验

## [P1] 验证设备名称编辑与首尾空格处理
- 测试类型
  - 功能
- 前置条件
  1. P-201进入详情编辑态，当前名称"牧场一号牛"。
- 测试步骤
  1. 输入"  牧场二号牛  "（首尾空格）保存。
  2. 输入40字符名称保存。
  3. 输入41字符名称保存。
  4. 输入纯空格保存。
- 预期结果
  1. 保存后名称为"牧场二号牛"，首尾空格去除，内部空格保留。
  2. 40字符保存成功（0～40字符上限内点）。
  3. 41字符保存被拦截。
  4. 纯空格归一为空，等同空值保存成功，列表第一行回退展示卡号。

## [P2] 验证设备名称允许重名
- 测试类型
  - 功能
- 前置条件
  1. P-201名称"同名片"，P-202名称"另一个"。
- 测试步骤
  1. 将P-202名称改为"同名片"保存。
  2. 搜索"同名片"。
- 预期结果
  1. 保存成功，名称允许重名，不执行唯一性校验。
  2. 搜索命中两台设备，设备身份仍以Device ID为准。

## [P2] 验证联系人校验规则
- 测试类型
  - 功能
- 前置条件
  1. P-201编辑态，Contact为空。
- 测试步骤
  1. 输入"  张三  "保存。
  2. 输入40字符联系人（如"José María González-De-La-Cruz-Pérez12345678"）保存。
  3. 输入41字符联系人保存。
  4. 输入纯空格保存。
- 预期结果
  1. 保存为"张三"，首尾空格去除。
  2. 40字符Unicode姓名保存成功。
  3. 41字符被拦截。
  4. 纯空格按空值处理保存成功，联系人不要求唯一。

## [P1] 验证电话号码E.164标准化保存
- 测试类型
  - 功能
- 前置条件
  1. P-201编辑态，国家/地区码选择器可用。
- 测试步骤
  1. 选择中国+86，输入"138 0013 8000"保存。
  2. 选择美国+1，输入"(212) 555-0123"保存。
- 预期结果
  1. 输入层允许空格、短横线、括号格式；保存后标准化为+8613800138000。
  2. 美国号码标准化为+12125550123，规范号码最多15位数字，查看态回显E.164标准值。

## [P2] 验证电话国家码按系统Region预选
- 测试类型
  - 功能
- 前置条件
  1. 测试机系统Region为中国，P-202电话为空。
- 测试步骤
  1. 首次进入P-202编辑态查看国家码选择器。
  2. 对已有号码+8613800138000的P-201进入编辑态。
- 预期结果
  1. 空字段优先按系统Region预选中国+86。
  2. 系统Region不静默改写已保存号码，P-201保持+86原值。

## [P3][反向] 验证无法解析的电话禁止保存
- 测试类型
  - 功能
- 前置条件
  1. P-201编辑态电话字段。
- 测试步骤
  1. 选择国家码+86，输入"abc123!@#"保存。
  2. 不选国家码输入"13800138000"保存。
  3. 输入超过15位数字的号码"13800138000123456"保存。
- 预期结果
  1. 非数字主体无法解析，禁止保存并提示。
  2. 填写本地号码前必须主动选择国家/地区，未选择被拦截。
  3. 超长号码无法规范为E.164，禁止保存。

## [P3][反向] 验证分组必填且实时有效
- 测试类型
  - 功能
- 前置条件
  1. P-201编辑态。
  2. 名下真实分组可用。
- 测试步骤
  1. 尝试清空Group保存。
  2. 选择虚拟"全部分组"作为Group。
- 预期结果
  1. Group必填，清空被拦截。
  2. 虚拟项不能作为设备归属，不写入groupId。
