## 2. 覆盖情况

### 2.1 有效等价类：100%

每个 POINT 至少 1 条正向用例（P1/P2），包括：四类账号统一入口登录、账号名/邮箱登录等价、空邮箱账号登录、邮箱归一化、企业层级设备范围、注册真实收码（Gmail / Outlook / iCloud / .com.au）、验证码全生命周期、密码 8~64 边界、退出与切换清理等。

### 2.2 无效等价类：核心异常全覆盖

涵盖：账号名 2/41 字符与非法字符、邮箱 5 类非法格式与超长、密码 7/65 字符与确认不一致、验证码错误/过期/已消费/跨邮箱/跨用途、60 秒频控、冻结（本账号/父级/子级）、过期、删除、锁定 3 次边界、未勾选协议、未选时区、无网络提交、注册夹带企业参数提权、越权访问设备、Token 失效后残留访问等。
