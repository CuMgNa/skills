# US-002 使用账号名或邮箱登录

## POINT-003 登录表单校验、时区和协议

## [P1] 验证登录必填字段完整时Sign In变为可点击
- 测试类型
  - 功能
- 前置条件
  1. 已进入登录页。
- 测试步骤
  1. 输入alice01。
  2. 输入Aa123456。
  3. 选择GMT+8:00 北京。
  4. 勾选User Agreement和Privacy Policy。
- 预期结果
  1. 账号输入框显示alice01。
  2. 密码以密文显示。
  3. 时区字段显示GMT+8:00 北京。
  4. Sign In从灰色禁用变为绿色可点击。

## [P3][反向] 验证未勾选协议时Sign In保持禁用
- 测试类型
  - 功能
- 前置条件
  1. 已进入登录页，账号和密码已填写，时区为GMT+8:00 北京。
- 测试步骤
  1. 保持User Agreement或Privacy Policy任一未勾选。
  2. 观察Sign In并尝试点击。
- 预期结果
  1. Sign In保持灰色禁用。
  2. 点击无登录请求、无会话创建和无业务跳转。

## [P3][反向] 验证未有效选择时区时Sign In保持禁用
- 测试类型
  - 功能
- 前置条件
  1. 已进入登录页，账号alice01、密码Aa123456已填写，协议已勾选。
- 测试步骤
  1. 清空时区选择或不完成时区选择。
  2. 观察Sign In并尝试点击。
- 预期结果
  1. Sign In保持灰色禁用。
  2. 不发送登录请求，页面停留在登录页。

## [P2] 验证时区ActionSheet点击Cancel保持原选择
- 测试类型
  - 易用性
- 前置条件
  1. 登录页当前选择GMT+8:00 北京。
- 测试步骤
  1. 点击时区字段。
  2. 在底部ActionSheet选择GMT-05:00 New York。
  3. 点击Cancel。
- 预期结果
  1. ActionSheet展示GMT偏移和城市名，当前项有绿色勾选。
  2. 临时选择不会立即污染登录页最终值。
  3. 关闭后登录页仍显示GMT+8:00 北京。

## [P2] 验证协议正文可阅读且Cancel不改变勾选状态
- 测试类型
  - 易用性
- 前置条件
  1. 登录页账号、密码、时区已填，两个协议均未勾选。
- 测试步骤
  1. 点击User Agreement链接。
  2. 滚动查看协议正文。
  3. 点击Cancel关闭弹窗。
- 预期结果
  1. 弹出协议全文模态窗口且正文可滚动。
  2. 协议正文可正常阅读。
  3. 关闭后登录页原勾选状态保持未勾选。
