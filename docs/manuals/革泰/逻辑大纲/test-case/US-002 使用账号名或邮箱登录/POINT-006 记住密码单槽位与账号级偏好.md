# US-002 使用账号名或邮箱登录

## POINT-006 记住密码单槽位与账号级偏好

## [P1] 验证账号A勾选记住密码后下次带出凭证但不自动登录
- 测试类型
  - 功能
- 前置条件
  1. 账号alice01密码Aa123456，已进入登录页。
- 测试步骤
  1. 输入alice01和Aa123456。
  2. 勾选记住密码并完成登录。
  3. 退出登录并再次进入登录页。
- 预期结果
  1. 账号A登录成功。
  2. 退出后返回登录页。
  3. 登录页带出alice01和密码Aa123456，密码默认密文展示。；不会自动跳过登录动作，必须手动点击Sign In。

## [P2] 验证账号B勾选记住密码覆盖账号A单槽位
- 测试类型
  - 功能
- 前置条件
  1. 账号A已按单槽位记住alice01和Aa123456；账号B密码Bb123456。
- 测试步骤
  1. 使用bob01和Bb123456登录并勾选记住密码。
  2. 退出并重新进入登录页。
- 预期结果
  1. 账号B登录成功。
  2. 登录页只带出bob01和Bb123456。；alice01和Aa123456不再出现在页面、缓存或自动填充中。

## [P2] 验证账号B不勾选记住密码时清除A凭证并只带出B账号标识
- 测试类型
  - 功能
- 前置条件
  1. 账号A已记住alice01和Aa123456。
- 测试步骤
  1. 使用bob01和Bb123456登录且不勾选记住密码。
  2. 退出并重新进入登录页。
- 预期结果
  1. 账号B登录成功。
  2. 登录页带出bob01。；密码为空，alice01和Aa123456被清除。

## [P3][反向] 验证登录失败账号不写入记住密码
- 测试类型
  - 安全性
- 前置条件
  1. 账号A已记住alice01和Aa123456。
- 测试步骤
  1. 输入unknown01和Wrong1234并勾选记住密码。
  2. 点击Sign In并等待失败。
  3. 退出或重新打开登录页。
- 预期结果
  1. 登录失败且停留在登录页。
  2. unknown01不会覆盖记住密码槽位。
  3. 原有凭证按最后一次成功登录规则保留或按当前版本清理，不能写入失败账号。

## [P2][反向] 验证不同设备的记住密码和时区不互相共享
- 测试类型
  - 安全性
- 前置条件
  1. 设备1登录alice01并保存GMT-05:00 New York，设备2登录bob01并保存GMT+10:00 Sydney。
- 测试步骤
  1. 分别在两台设备退出并重新进入登录页。
  2. 比较两台设备的回显内容。
- 预期结果
  1. 设备1只回显alice01及其账号级偏好。
  2. 设备2只回显bob01及其账号级偏好。；账号凭证和时区不跨设备共享。
