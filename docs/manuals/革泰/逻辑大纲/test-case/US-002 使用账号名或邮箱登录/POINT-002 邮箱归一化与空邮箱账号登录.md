# US-002 使用账号名或邮箱登录

## POINT-002 邮箱归一化与空邮箱账号登录

## [P2] 验证邮箱首尾空格登录成功
- 测试类型
  - 功能
- 前置条件
  1. 账号alice01关联邮箱alice01@gmail.com，密码Aa123456。
- 测试步骤
  1. 在登录标识输入框输入三个前导空格和两个尾随空格的字符串：   alice01@gmail.com  。
  2. 输入Aa123456，完成时区和协议选择并登录。
- 预期结果
  1. 系统去除邮箱首尾空格后进行匹配。
  2. 账号alice01登录成功，设备范围为P-001和P-002。

## [P2] 验证邮箱大小写混写登录成功
- 测试类型
  - 功能
- 前置条件
  1. 账号alice01关联邮箱alice01@gmail.com，密码Aa123456。
- 测试步骤
  1. 输入ALICE01@GMAIL.COM。
  2. 输入Aa123456并点击Sign In。
- 预期结果
  1. 系统按统一大小写口径匹配邮箱。
  2. 登录到alice01，不创建新账号或访问其他账号数据。

## [P1] 验证无邮箱账号可使用账号名登录
- 测试类型
  - 功能
- 前置条件
  1. 后台创建账号noemail01，邮箱字段为空，密码NoEmail1234，账号状态正常。
- 测试步骤
  1. 输入noemail01和NoEmail1234。
  2. 选择有效时区并勾选协议。
  3. 点击Sign In。
- 预期结果
  1. 账号名和密码校验通过。
  2. 账号正常创建会话并加载其授权业务数据。
  3. 登录页不要求必须填写邮箱。

## [P3][反向] 验证无邮箱账号使用邮箱标识不能登录
- 测试类型
  - 功能
- 前置条件
  1. 账号noemail01邮箱字段为空，密码NoEmail1234。
- 测试步骤
  1. 输入noemail01@ranch.com和NoEmail1234。
  2. 完成时区和协议选择后点击Sign In。
- 预期结果
  1. 邮箱与账号不匹配，登录失败。
  2. 不进入noemail01账号，也不展示任何设备或告警数据。

## [P5][反向] 验证Gmail点号和加号别名按待确认口径记录
- 测试类型
  - 功能
- 前置条件
  1. 账号alice01关联alice01@gmail.com，测试邮箱可收信。
  2. Gmail别名处理规则尚未确认。
- 测试步骤
  1. 分别使用a.l.i.c.e.01@gmail.com和alice01+test@gmail.com作为登录标识。
  2. 输入Aa123456并提交登录。
- 预期结果
  1. 记录当前版本对两种别名的实际匹配结果。
  2. 不得在需求未定稿前将别名必然等同或必然区分作为固定通过条件。
