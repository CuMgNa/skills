# US-002 使用账号名或邮箱登录

## POINT-001 账号名与邮箱登录等价性

## [P1] 验证使用账号名登录个人账号成功
- 测试类型
  - 功能
- 前置条件
  1. 个人账号alice01，邮箱alice01@gmail.com，密码Aa123456，绑定P-001和P-002。
  2. 账号状态正常。
- 测试步骤
  1. 输入账号alice01。
  2. 输入密码Aa123456。
  3. 选择GMT+8:00 北京并勾选两个协议。
  4. 点击Sign In。
- 预期结果
  1. 账号名、密码和登录条件校验通过。
  2. 密码框以密文展示。
  3. 协议和时区信息随请求提交。
  4. 进入设备加载流程，完成后仅展示P-001和P-002。

## [P1] 验证使用注册邮箱登录同一账号成功
- 测试类型
  - 功能
- 前置条件
  1. 账号alice01及其邮箱alice01@gmail.com状态正常。
  2. 已完成引导。
- 测试步骤
  1. 输入邮箱alice01@gmail.com。
  2. 输入密码Aa123456并完成时区和协议选择。
  3. 点击Sign In。
- 预期结果
  1. 邮箱被识别为账号alice01。
  2. 登录成功创建会话。
  3. 进入的设备、围栏和告警范围与使用alice01登录完全一致。

## [P3][反向] 验证不存在账号或密码错误时保留登录标识
- 测试类型
  - 功能
- 前置条件
  1. 已进入登录页。
- 测试步骤
  1. 输入unknown01和Wrong1234。
  2. 选择GMT+8:00 北京并勾选两个协议。
  3. 点击Sign In。
- 预期结果
  1. 登录请求被服务端拒绝。
  2. 账号输入框仍显示unknown01。
  3. 页面不展示任何其他账号的设备、围栏、告警或邮箱信息。

## [P2] 验证APP与监控平台使用同一邮箱登录权限一致
- 测试类型
  - 兼容性
- 前置条件
  1. 账号alice01在APP和监控平台均可用，绑定P-001和P-002。
- 测试步骤
  1. 在APP使用alice01@gmail.com和Aa123456登录。
  2. 在监控平台使用alice01@gmail.com和Aa123456登录。
  3. 分别查看设备列表和围栏列表。
- 预期结果
  1. 两个端均完成登录。
  2. 两个端解析到同一账号。
  3. 两个端展示的授权设备、围栏和告警范围一致。
