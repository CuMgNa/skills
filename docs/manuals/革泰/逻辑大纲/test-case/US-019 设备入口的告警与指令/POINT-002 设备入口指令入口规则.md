# US-019 设备入口的告警与指令

## POINT-002 设备入口指令入口规则

## [P1] 验证各状态设备均可进入指令详情页
- 测试类型
  - 功能
- 前置条件
  1. P-001在线、P-003离线、P-004未连接、P-005告警，均属alice01可见。
- 测试步骤
  1. 分别从四台设备更多菜单点击Send Command。
  2. 查看跳转页面。
- 预期结果
  1. 四种状态均成功进入对应设备的指令详情页。
  2. 跳转目标不因通信状态不同改变，入口不区分在线、离线、未连接或告警。

## [P1] 验证指令详情页携带设备唯一标识
- 测试类型
  - 功能
- 前置条件
  1. P-001与P-002备注均为"牛群一号"。
- 测试步骤
  1. 从P-001更多菜单进入Send Command。
  2. 从P-002更多菜单进入Send Command。
  3. 对比两页的设备身份与历史记录。
- 预期结果
  1. P-001指令详情页以P-001唯一标识查询。
  2. P-002指令详情页以P-002唯一标识查询。
  3. 同名设备不串页，历史指令记录各归各设备。

## [P2] 验证历史指令记录各状态可查看
- 测试类型
  - 功能
- 前置条件
  1. P-003离线但有历史指令记录3条。
- 测试步骤
  1. 从P-003更多菜单进入Send Command。
  2. 查看历史指令记录。
- 预期结果
  1. 正常进入页面。
  2. 3条历史记录可查看，离线状态不阻断历史记录查看。

## [P2] 验证具体指令下发沿用模块规则
- 测试类型
  - 功能
- 前置条件
  入口设备P-001在线，指令详情页正常。
- 测试步骤
  1. 在指令详情页选择具体指令提交下发。
  2. 查看下发闭环。
- 预期结果
  1. 下发前置判断、参数校验沿用单设备指令下发模块规则。
  2. 提交结果与执行闭环正常，本入口不前置额外拦截。

## [P3][反向] 验证设备失权拦截越权指令记录
- 测试类型
  - 安全性
- 前置条件
  1. alice01已进入P-001指令详情页。
  2. 另一端解除alice01与P-001绑定。
- 测试步骤
  1. 停留页面继续查看历史指令记录或发起下发。
  2. 查看页面返回结果。
- 预期结果
  1. 按统一权限与数据访问规则处理。
  2. 不展示越权指令记录，下发请求被服务端拒绝。
