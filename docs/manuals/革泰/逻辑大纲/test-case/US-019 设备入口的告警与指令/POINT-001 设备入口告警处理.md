# US-019 设备入口的告警与指令

## POINT-001 设备入口告警处理

## [P1] 验证未处理告警打开处理弹窗备注必填
- 测试类型
  - 功能
- 前置条件
  1. P-201存在未处理告警AL-20260922-01。
- 测试步骤
  1. 从设备入口进入告警记录，点击AL-20260922-01。
  2. 尝试不填备注直接提交处理。
  3. 输入"  已现场核实  "（首尾空格）提交。
- 预期结果
  1. 打开处理弹窗，备注为必填项。
  2. 备注为空或纯空格被拦截提交。
  3. 去空格后"已现场核实"保存成功，≤200字符约束生效。

## [P4] 验证处理备注长度边界
- 测试类型
  - 功能
- 前置条件
  1. P-201存在未处理告警。
  2. 准备200字符与201字符备注文本。
- 测试步骤
  1. 输入200字符备注提交处理。
  2. 输入201字符备注提交。
- 预期结果
  1. 200字符上点保存成功。
  2. 201字符离点被拦截，提示长度限制。

## [P2] 验证已处理告警打开只读详情卡片
- 测试类型
  - 功能
- 前置条件
  1. P-201存在已处理告警AL-20260920-01（处理备注"已电话确认"）。
- 测试步骤
  1. 从设备入口进入告警记录点击该已处理记录。
  2. 查看卡片内容与可用操作。
- 预期结果
  1. 打开只读详情卡片，可查看告警详情与处理备注"已电话确认"。
  2. 不提供再次编辑处理的入口。

## [P3][反向] 验证告警中心历史报警仅只读
- 测试类型
  - 功能
- 前置条件
  1. 告警中心存在P-201相关告警卡片。
- 测试步骤
  1. 从告警中心卡片进入历史报警页面。
  2. 查找处理按钮、批量处理入口、页签与筛选。
- 预期结果
  1. 历史报警页面仅只读查询。
  2. 无处理与批量入口，不继承告警中心的页签与筛选，与设备入口告警页不互相替代。

## [P2] 验证两个告警页面数据同源
- 测试类型
  - 功能
- 前置条件
  1. P-201存在未处理告警AL-20260922-01。
- 测试步骤
  1. 从设备入口处理AL-20260922-01并填写备注。
  2. 从告警中心进入P-201历史报警查看同一条。
- 预期结果
  1. 设备入口处理成功。
  2. 告警中心侧记录同步为已处理，两处读取同源告警记录，状态一致。

## [P3][反向] 验证设备关系失效拦截越权处理
- 测试类型
  - 安全性
- 前置条件
  1. alice01已进入P-201告警记录页。
  2. 另一端解除alice01与P-201绑定。
- 测试步骤
  1. 在页面停留期间对未处理告警提交处理。
  2. 查看处理请求结果与告警状态。
- 预期结果
  1. 服务端按最新权限校验失败。
  2. 处理不落库，不产生越权处理副作用。
