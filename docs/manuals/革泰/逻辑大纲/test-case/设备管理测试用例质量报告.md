### 2.1 有效等价类：100%

## 5. 使用建议

1. **执行顺序**：先跑 45 条 P1 作为冒烟集（计数、绑定、解绑级联、改组、频率主链路），再按 ITEM 推进 P3/P4。
2. **数据准备**：
   - 企业三级链 owner01 → worker02 → worker03（+worker04/05/06…分支）需后台预配分配关系；
   - 物联卡场景需 mock 工具支持按卡返回不同 code/status/payload；
   - 频率指令场景需可控设备或模拟终端配合 commandId 反馈。
3. **与既有产物关系**：本报告与登录注册 README 并列，物联卡字段映射（US-015/POINT-007~008）与 SIM 五态、到期规则同源，执行时可与《革泰海外平台一期测试计划》对齐排期。
