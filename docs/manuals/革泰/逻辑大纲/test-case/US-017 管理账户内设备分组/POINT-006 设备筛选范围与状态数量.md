# US-017 管理账户内设备分组

## POINT-006 设备筛选范围与状态数量

## [P1] 验证首次进入默认全部分组
- 测试类型
  - 功能
- 前置条件
  1. alice01登录后首次进入设备首页。
- 测试步骤
  1. 进入设备首页查看分组栏选中项。
  2. 查看列表范围与顶部状态数量。
- 预期结果
  1. 默认选择虚拟"全部分组"。
  2. 列表展示账户全部可见设备，状态数量按全部设备统计。

## [P2] 验证同会话保留上次有效分组选择
- 测试类型
  - 功能
- 前置条件
  1. alice01同一登录会话内已选择"天河区"。
- 测试步骤
  1. 切换到首页其他模块后返回设备首页。
  2. 查看分组栏筛选。
- 预期结果
  1. 返回设备首页。
  2. 保留上次有效的"天河区"选择，不重置为全部分组。

## [P3][反向] 验证切换账号不复用上一账号筛选
- 测试类型
  - 安全性
- 前置条件
  1. alice01退出前筛选为"天河区"。
- 测试步骤
  1. alice01退出登录。
  2. bob02登录进入设备首页查看分组栏。
  3. bob02退出，alice01重新登录进入设备首页查看分组栏。
- 预期结果
  1. alice01的会话与筛选状态被清理。
  2. bob02进入后从虚拟"全部分组"开始，不复用alice01的筛选。
  3. alice01重新登录后同样从"全部分组"开始，账号间筛选隔离。

## [P2] 验证父组筛选不聚合子组设备
- 测试类型
  - 功能
- 前置条件
  1. 广东省直属2台（1在线1离线），子组广州市直属3台在线，天河区直属5台告警。
- 测试步骤
  1. 选择"广东省"分组。
  2. 查看列表与顶部状态数量。
- 预期结果
  1. 列表仅展示广东省直属2台。
  2. 全部=2、在线=1、离线=1、告警=0，不聚合广州市、天河区设备。

## [P2] 验证关键词不缩小分组数量与状态数量
- 测试类型
  - 功能
- 前置条件
  1. 当前分组"广东省"（直属2台），状态"在线"。
- 测试步骤
  1. 输入关键词"P-2"并确认。
  2. 查看列表、分组括号数量与顶部状态数量。
- 预期结果
  1. 列表按关键词∩分组∩状态重算。
  2. 分组括号数量与顶部状态数量不因关键词缩小，仅列表结果缩小。

## [P2] 验证切换分组后状态数量重算
- 测试类型
  - 功能
- 前置条件
  1. 全部范围：全部=10、在线=6、离线=4、告警=1。
  2. "天河区"直属5台：4在线1告警（在线）。
- 测试步骤
  1. 从"全部分组"切换到"天河区"。
  2. 查看顶部四个数量。
- 预期结果
  1. 切换生效。
  2. 数量重算为全部=5、在线=5（告警设备同时在线）、离线=0、告警=1，按当前分组范围统计。
