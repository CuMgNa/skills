# US-017 管理账户内设备分组

## POINT-004 分组删除规则与交互

## [P1] 验证空组无子组删除成功
- 测试类型
  - 功能
- 前置条件
  1. alice01名下三级组"天河区"无子组、无直属设备。
- 测试步骤
  1. 点击"天河区"删除按钮。
  2. 在二次确认弹窗点击确认。
- 预期结果
  1. 服务端实时校验通过，弹出删除确认并展示分组名称"天河区"。
  2. 删除成功，刷新分组列表，"天河区"消失。

## [P3][反向] 验证存在子组时禁止删除并优先提示
- 测试类型
  - 功能
- 前置条件
  1. 一级组"广东省"下有二级"广州市"（广州市下另有三级"天河区"），且广东省无直属设备。
- 测试步骤
  1. 点击"广东省"删除按钮。
  2. 查看提示与是否进入确认。
- 预期结果
  1. 检测到存在子组（直接或间接）。
  2. 阻止删除并提示先处理子分组；即使同时无直属设备，也只提示子分组阻塞原因，不进入二次确认。

## [P3][反向] 验证存在直属设备时禁止删除
- 测试类型
  - 功能
- 前置条件
  1. 二级组"深圳市"无子组，直属设备P-203、P-204。
- 测试步骤
  1. 点击"深圳市"删除按钮。
  2. 查看提示内容。
- 预期结果
  1. 先校验子组（无），再校验直属设备（有）。
  2. 阻止删除并提示先迁移组内设备，不隐式迁移或级联删除设备。

## [P2] 验证删除确认弹窗取消保留分组
- 测试类型
  - 功能
- 前置条件
  1. 空组"旧牧场"满足删除条件。
- 测试步骤
  1. 点击"旧牧场"删除按钮进入二次确认。
  2. 点击取消。
- 预期结果
  1. 确认弹窗展示分组名称。
  2. 取消后分组保留，列表不变。

## [P2] 验证删除服务端失败保留分组并提示
- 测试类型
  - 可靠性
- 前置条件
  1. 空组"失败测试组"满足前端删除条件。
  2. mock删除接口返回失败。
- 测试步骤
  1. 点击删除并确认。
  2. 查看页面与分组状态。
- 预期结果
  1. 提交删除后服务端返回失败。
  2. 保留分组并展示服务端原因。

## [P2] 验证删除当前筛选组回退全部分组
- 测试类型
  - 功能
- 前置条件
  1. 当前设备列表筛选为"旧分区"（空组）。
- 测试步骤
  1. 在管理页删除"旧分区"并确认。
  2. 返回设备列表查看筛选与数量。
- 预期结果
  1. 删除成功。
  2. 筛选切换到虚拟"全部分组"，设备列表与状态数量刷新；删除非当前筛选组时保留当前有效筛选。

## [P5] 验证删除最后一个真实分组允许零分组状态
- 测试类型
  - 功能
- 前置条件
  1. alice01名下仅剩空组"我的分组"（最后一个真实分组）。
- 测试步骤
  1. 删除"我的分组"并确认。
  2. 查看选择器与管理页。
  3. 发起设备绑定。
- 预期结果
  1. 满足空组条件允许删除，不自动重建。
  2. 账户只剩虚拟"全部分组"，设备不能归属虚拟项。
  3. 绑定时无可选分组，引导进入分组管理页创建一级组。

## [P3][反向] 验证管理页不凭文案判断空组实时校验
- 测试类型
  - 功能
- 前置条件
  1. 分组"表面空组"在管理页不展示设备数量。
  2. 实际该组有直属设备1台（Web侧可见）。
- 测试步骤
  1. 在APP点击"表面空组"删除按钮。
  2. 查看服务端校验结果。
- 预期结果
  1. 点击后向服务端实时校验可删除条件。
  2. 服务端返回有直属设备，阻止删除并提示先迁移，不因页面无数量展示而放行。
