# US-017 管理账户内设备分组

## POINT-001 分组入口与数据来源

## [P1] 验证分组管理唯一常规入口路径可达
- 测试类型
  - 功能
- 前置条件
  1. alice01已登录，名下有分组"广东省""浙江省"。
- 测试步骤
  1. 设备首页点击当前分组栏打开Select Group。
  2. 点击底部Manage Groups。
- 预期结果
  1. Select Group打开并展示当前账号分组结构与直属设备数。
  2. 进入Device Groups分组管理页，展示该账号名下一级、二级、三级分组。

## [P2] 验证管理页全量查询含空组与Web创建组
- 测试类型
  - 功能
- 前置条件
  1. alice01名下：一级组"广东省"（空组）、Web创建的二级组"广州市"、三级组"天河区"。
- 测试步骤
  1. 从Manage Groups进入分组管理页。
  2. 查看列表分组构成。
- 预期结果
  1. 管理页重新请求服务端全量分组。
  2. 空组"广东省"、二级"广州市"、三级"天河区"均展示，不从设备列表反向聚合分组，不按创建端过滤。

## [P2] 验证管理页不渲染设备数量
- 测试类型
  - 功能
- 前置条件
  1. alice01名下"广东省"组有直属设备3台。
- 测试步骤
  1. 进入分组管理页查看"广东省"卡片。
  2. 打开分组选择器查看"广东省"条目。
- 预期结果
  1. 管理页卡片展示名称、Level、父组信息、重命名删除入口，无Devices: N数量行。
  2. 选择器中"广东省"括号内展示直属设备数3，数量只在设备首页选择器展示。

## [P3][反向] 验证接口失败不用空数组冒充无分组
- 测试类型
  - 可靠性
- 前置条件
  1. 使用mock使分组查询接口返回失败。
- 测试步骤
  1. 打开Select Group触发分组查询失败。
  2. 查看页面展示。
- 预期结果
  1. 保留原有效页面状态。
  2. 展示可重试的失败提示，不用空数组冒充账号无分组。

## [P2] 验证Web跨端变更后APP读取最新结果
- 测试类型
  - 兼容性
- 前置条件
  1. alice01在APP查看过分组结构。
  2. 随后在Web将二级组"广州市"重命名为"羊城"。
- 测试步骤
  1. APP重新打开Select Group。
  2. 从Select Group进入Manage Groups查看结构。
- 预期结果
  1. 选择器展示最新名称"羊城"。
  2. 管理页再次请求全量分组，不维护独立APP分组副本，跨端以服务端数据为准。

## [P2] 验证从管理页返回保留有效选择
- 测试类型
  - 功能
- 前置条件
  1. 当前设备列表筛选为"天河区"（groupId有效）。
- 测试步骤
  1. 从选择器进入Manage Groups后直接返回。
  2. 查看设备列表筛选与分组栏。
- 预期结果
  1. 返回时重新查询分组数据。
  2. 原选中"天河区"仍有效则保留筛选；列表与状态数量正常。

## [P3][反向] 验证原分组失效回退全部分组
- 测试类型
  - 功能
- 前置条件
  1. 当前设备列表筛选为"旧分组"（groupId=G100）。
  2. 在Web删除该分组。
- 测试步骤
  1. APP从管理页返回（触发重新查询）。
  2. 查看分组栏与设备列表。
- 预期结果
  1. 检测到G100已删除。
  2. 筛选回退虚拟"全部分组"，提示原分组已失效，设备列表与状态数量刷新。

## [P3][反向] 验证APP不能替换前端账号参数读取他账分组
- 测试类型
  - 安全性
- 前置条件
  1. alice01已登录。
  2. 抓包工具可用。
- 测试步骤
  1. 抓取分组查询请求。
  2. 将请求中账号参数改为bob02后重放。
- 预期结果
  1. 服务端按登录会话身份确定账号范围。
  2. 重放请求被拒绝或仍返回alice01范围数据，不返回bob02的分组数据。

## [P2] 验证APP操作成功后同源刷新
- 测试类型
  - 功能
- 前置条件
  1. alice01在分组管理页。
- 测试步骤
  1. APP新增一级组"牧场新区"。
  2. 返回并重新打开Select Group。
- 预期结果
  1. 管理页以服务端返回结果刷新，出现"牧场新区"。
  2. 选择器同步看到最新结构和数量，两页同源。
