# US-017 管理账户内设备分组

## POINT-005 分组选择器展示排序与搜索

## [P1] 验证选择器默认结构与父组不聚合
- 测试类型
  - 功能
- 前置条件
  1. 结构：广东省（直属2台）→广州市（直属3台）→天河区（直属5台）；深圳市（直属1台）；浙江省（直属0台空组）。
- 测试步骤
  1. 打开Select Group查看完整列表构成。
  2. 核对各组括号内数量与账户全部去重数。
- 预期结果
  1. 依次展示：全部分组（账户全部去重数）、广东省（2）L1、广州市（3）L2属于广东省、天河区（5）L3属于广州市、深圳市（1）L2属于广东省、浙江省（0）L1。
  2. 各组括号内仅为直接归属设备数，父组数量可小于子组，空组也展示。

- 测试类型
  - 功能
