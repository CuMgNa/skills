# US-017 管理账户内设备分组

## POINT-007 设备改组

## [P1] 验证设备改组随整页保存生效
- 测试类型
  - 功能
- 前置条件
  1. P-201当前归属"天河区"。
  2. alice01名下有目标分组"深圳市"。
- 测试步骤
  1. 进入P-201设备详情编辑页，将Group从"天河区"改为"深圳市"，不点击保存。
  2. 查看两侧分组设备数。
  3. 点击整页Save。
- 预期结果
  1. 选择分组只更新本地表单，不立即改组。
  2. 保存后详情、设备列表、分组设备数与状态数量刷新：深圳市+1、天河区-1。
  3. 改组以groupId提交，不以名称代替。

## [P2] 验证取消编辑不产生变更
- 测试类型
  - 功能
- 前置条件
  1. P-201归属"天河区"，进入编辑页已改选"深圳市"。
- 测试步骤
  1. 不保存直接返回/取消编辑。
  2. 查看P-201分组与两侧数量。
- 预期结果
  1. 本地修改被丢弃。
  2. P-201仍归属"天河区"，无任何分组数量变化。

## [P3][反向] 验证保存前分组失效被拦截
- 测试类型
  - 功能
- 前置条件
  1. 编辑页已选择目标分组"旧目标组"（groupId=G200）。
  2. 保存前该组在Web被删除。
- 测试步骤
  1. 点击整页Save。
  2. 查看保存结果。
- 预期结果
  1. 服务端保存前重新校验分组有效性。
  2. G200已删除，保存失败并提示可读原因，设备仍归属原分组，编辑内容保留。

## [P3][反向] 验证单分组容量超限保存失败
- 测试类型
  - 功能
- 前置条件
  1. 服务端当前配置单分组设备容量上限（如已接近上限）。
- 测试步骤
  1. 将设备改入已满分组并保存。
  2. 查看结果与提示。
- 预期结果
  1. 保存失败。
  2. 展示服务端可读提示，APP不写死具体上限，设备保持原分组。

## [P2] 验证改组只影响当前账户分组关系
- 测试类型
  - 功能
- 前置条件
  1. alice01与owner01双绑P-202。
  2. alice01侧归属"广东省"，owner01侧归属"企业A组"。
- 测试步骤
  1. alice01将P-202改组为"浙江省"并保存。
  2. 登录owner01查看P-202分组。
- 预期结果
  1. alice01侧改组成功。
  2. owner01侧P-202仍属"企业A组"，改组只更新当前账户的设备分组关系。

## [P2] 验证改组成功后列表与搜索同步
- 测试类型
  - 功能
- 前置条件
  1. P-201原备注"旧名牛只"，改组同时不改名称。
- 测试步骤
  1. 完成P-201改组保存。
  2. 按分组"深圳市"筛选查看列表。
  3. 修改P-201备注为"新名牛只"保存后搜索"新名牛只"。
- 预期结果
  1. 改组成功后详情与列表刷新。
  2. "深圳市"分组下出现P-201。
  3. 名称变更后列表展示与搜索结果同步更新，名称展示与搜索同源。
