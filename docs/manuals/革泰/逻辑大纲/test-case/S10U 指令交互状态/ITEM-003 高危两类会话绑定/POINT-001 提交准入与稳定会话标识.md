# 用户故事

## [P1] 验证当前可写会话允许高危指令提交并绑定稳定标识
- 测试类型
  - 功能
- 前置条件
  1. S10U000001当前可写会话为session-A，sessionEpoch为epoch-101，channelId为channel-01
  2. 账号qa_s10u_admin具有RESET权限且其他校验通过
- 测试步骤
  1. 提交RESET，使用CMD-20261015-030与ATT-20261015-030-A1
  2. 查询任务保存的会话绑定字段
- 预期结果
  1. 服务端以提交时实时会话复检结果准入，记录进入SENDING
  2. 任务保存boundSessionId=session-A、sessionEpoch=epoch-101、channelId=channel-01

## [P3][反向] 验证无当前可写会话时拒绝高危指令
- 测试类型
  - 安全性
- 前置条件
  1. S10U000002无当前可写会话但路由和设备关系有效
  2. 账号qa_s10u_admin已登录
- 测试步骤
  1. 构造请求绕过前端为S10U000002提交POWEROFF，使用CMD-20261015-031与ATT-20261015-031-A1
  2. 查询记录与队列
- 预期结果
  1. 服务端实时复检后拒绝请求，不受页面旧在线快照影响
  2. 记录状态为FAILURE，失败原因明确为无当前可写会话，且不存在待写出高危任务

## [P3][反向] 验证会话查询异常时高危指令明确失败
- 测试类型
  - 可靠性
- 前置条件
  1. S10U000001页面最近在线快照为在线
  2. S10U会话查询服务对本次请求返回异常
- 测试步骤
  1. 提交RESET，使用CMD-20261015-032与ATT-20261015-032-A1
  2. 查询失败记录
- 预期结果
  1. 服务端不使用页面快照兜底准入且不创建可写出任务
  2. 记录状态为FAILURE，failureStage指向会话查询，failureReason记录会话查询异常并写入failedAt

## [P2] 验证页面恢复与通信变化后刷新会话但服务端仍最终裁决
- 测试类型
  - 功能
- 前置条件
  1. APP后台期间S10U000001由session-A切换为session-B
  2. 页面恢复前仍缓存session-A在线快照
- 测试步骤
  1. 将APP切回前台并进入POWEROFF操作页
  2. 确认提交POWEROFF并观察服务端复检
- 预期结果
  1. APP触发当前S10U会话刷新并展示session-B对应的实时可操作提示
  2. 最终准入以服务端提交时复检为准，任务绑定session-B而非缓存的session-A
