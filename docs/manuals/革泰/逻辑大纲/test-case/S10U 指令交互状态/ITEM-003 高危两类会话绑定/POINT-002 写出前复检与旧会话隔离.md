# 用户故事

## [P1] 验证同一绑定会话内完成高危写出
- 测试类型
  - 功能
- 前置条件
  1. RESET任务ATT-20261015-033-A1绑定session-A、epoch-101、channel-01且状态SENDING
  2. 写出前当前会话仍为session-A、epoch-101、channel-01
- 测试步骤
  1. 触发写出前会话比较
  2. 在session-A完成TCP写出并回调
- 预期结果
  1. 当前会话与绑定标识一致，任务允许写出
  2. 记录进入SENT并写入sentAt，写出目标会话为session-A

## [P3][反向] 验证绑定会话断开立即失败并出队
- 测试类型
  - 可靠性
- 前置条件
  1. POWEROFF任务ATT-20261015-034-A1绑定session-A且状态SENDING
  2. 任务尚未TCP写出
- 测试步骤
  1. 断开session-A并触发断线事件
  2. 查询任务状态与队列
- 预期结果
  1. 绑定会话断开事件只结算一次最终结果
  2. 记录立即进入FAILURE并写入会话断开原因及failedAt，任务从队列删除

## [P3][反向] 验证会话标识变化阻止旧高危任务写出
- 测试类型
  - 安全性
- 前置条件
  1. RESET任务ATT-20261015-035-A1绑定session-A、epoch-101、channel-01
  2. 设备当前仍显示在线但sessionEpoch变化为epoch-102
- 测试步骤
  1. 触发旧任务写出前会话比较
  2. 查询写出记录与任务状态
- 预期结果
  1. 比较结果不一致，旧任务不进行TCP写出
  2. 任务进入FAILURE并记录会话变化原因，sentAt为空

## [P3][反向] 验证新会话不得执行旧高危任务
- 测试类型
  - 安全性
- 前置条件
  1. RESET任务ATT-20261015-036-A1绑定session-A后设备断线
  2. 设备随后建立新会话session-B、epoch-201、channel-02
- 测试步骤
  1. 触发session-B的队列处理
  2. 查询ATT-20261015-036-A1及session-B写出日志
- 预期结果
  1. 旧任务不被迁移或重新绑定到session-B
  2. 旧任务为FAILURE且session-B写出日志中不存在ATT-20261015-036-A1

## [P3][反向] 验证断线与写出回调竞态只保留一个最终结果
- 测试类型
  - 可靠性
- 前置条件
  1. ATT-20261015-037-A1绑定session-A且状态SENDING
  2. 准备并发注入session-A断线事件与TCP写出成功回调
- 测试步骤
  1. 并发发送断线事件和写出成功回调各一次
  2. 重复发送相同事件并查询最终记录及通知计数
- 预期结果
  1. 系统按可靠事实幂等结算，最终状态只能是SENT或FAILURE之一且不可来回翻转
  2. 仅记录一次最终统计、一次通知和一次队列删除副作用
