## [P1] 验证在线设备普通指令从SENDING流转到SENT
- 测试类型
  - 功能
- 前置条件
  1. 设备S10U000001在线且当前链路可写
  2. 账号qa_s10u_admin具有控制权限
- 测试步骤
  1. 提交CR，使用CMD-20261015-020与ATT-20261015-020-A1
  2. 模拟网关完成TCP写出并回调ATT-20261015-020-A1
- 预期结果
  1. 记录与队列任务创建成功，初始状态为SENDING
  2. 状态唯一流转为SENT并记录sentAt，SENT仅表示TCP写出完成

## [P1] 验证离线设备普通五类均可提交等待
- 测试类型
  - 功能

  2. 账号qa_s10u_admin已登录

  - 功能

## [P3][反向] 验证普通任务明确网关失败进入FAILURE
- 测试类型
  - 功能
- 前置条件
  1. CMD-20261015-023为S10U000001的CR任务且状态SENDING
  2. 网关返回可归因的系统写出失败
- 测试步骤
  1. 网关回调ATT-20261015-023-A1写出失败
  2. 查询记录状态、failedAt与sentAt
- 预期结果
  1. 记录由SENDING进入FAILURE并保存网关失败阶段和原因
  2. failedAt非空且sentAt为空，不以离线替代真实失败原因
