## [P1] 验证高危重发绑定重发时的新当前会话
- 测试类型
  - 功能
- 前置条件
  1. CMD-20261015-064的A1绑定session-A后因断线FAILURE
  2. 重发时S10U000001当前可写会话为session-B、epoch-201、channel-02
- 测试步骤
  1. 完成RESET主动重发二次确认
  2. 查询新attempt与会话绑定
- 预期结果
  1. 生成ATT-20261015-064-A2且重发次数增加1
  2. A2进入SENDING并绑定session-B、epoch-201、channel-02，不复活或改绑A1

## [P1] 验证网络安全重试复用相同attempt
- 测试类型
  - 可靠性
- 前置条件
  1. 首次UPLOAD请求使用CMD-20261015-066、ATT-20261015-066-A1、businessId BIZ-20261015-066-A1
  2. 客户端在收到响应前发生网络超时
- 测试步骤
  1. 使用相同ATT-20261015-066-A1和相同请求体重试三次
  2. 查询attempt、businessId和队列任务数量
- 预期结果
  1. 三次重试均返回同一attempt处理结果，不被计为用户主动重发
  2. 仅存在一个ATT-20261015-066-A1、一个BIZ-20261015-066-A1和一个队列任务，重发次数为0

## [P3][反向] 验证同一attempt载荷冲突被幂等校验拒绝
- 测试类型
  - 安全性
- 前置条件
  1. ATT-20261015-067-A1已用于S10U000001的UPLOAD值300
  2. 该attempt对应businessId BIZ-20261015-067-A1
- 测试步骤
  1. 复用ATT-20261015-067-A1提交UPLOAD值600
  2. 查询原任务和冲突请求处理结果
- 预期结果
  1. 服务端识别幂等键载荷冲突并拒绝新请求，不覆盖原目标值300
  2. 原attempt和businessId映射不变，仅保留一个队列任务且不产生重复写出
