# 用户故事

## [P1] 验证服务端识别操作意图后校验成功创建记录和任务
- 测试类型
  - 功能
- 前置条件
  1. 账号qa_s10u_admin状态正常并与设备S10U000001关系有效
  2. 设备S10U000001路由、型号、CR参数、幂等标识及限流校验均通过
- 测试步骤
  1. 提交CR请求，指定commandId CMD-20261015-010、attemptId ATT-20261015-010-A1
  2. 查询指令记录与普通队列任务
- 预期结果
  1. 服务端校验登录会话、账号状态、设备关系、唯一标识、路由、型号、参数、幂等、批量上限和限流并返回受理结果
  2. 存在CMD-20261015-010与ATT-20261015-010-A1记录及唯一队列任务，状态为SENDING

## [P3][反向] 验证APP本地格式校验失败不创建后台记录
- 测试类型
  - 功能
- 前置条件
  1. 账号qa_s10u_admin已登录
  2. APP的UPLOAD周期仅允许提交合法数值，本次输入文本abc
- 测试步骤
  1. 在S10U000001的UPLOAD输入框输入abc并点击确认
  2. 查询后台是否出现与本次本地操作对应的新commandId或attemptId
- 预期结果
  1. APP阻止请求发送并提示参数格式错误
  2. 后台无新commandId、attemptId、队列任务或失败记录

## [P3][反向] 验证服务端参数复检失败仍保留失败记录
- 测试类型
  - 功能
- 前置条件
  1. 账号qa_s10u_admin与设备S10U000001关系有效
  2. 请求已到达服务端且服务端可识别账号、设备和UPLOAD操作意图
- 测试步骤
  1. 绕过前端提交UPLOAD非法值-1，指定commandId CMD-20261015-011和attemptId ATT-20261015-011-A1
  2. 查询记录状态及失败字段
- 预期结果
  1. 服务端拒绝非法参数且不创建可写出队列任务
  2. CMD-20261015-011状态为FAILURE，并保存参数校验对应的failureStage、failureReason和非空failedAt

## [P3][反向] 验证失效登录会话与冻结账号均由服务端拒绝
- 测试类型
  - 安全性
- 前置条件
  1. 设备S10U000001路由与型号能力正常
  2. 准备已失效登录令牌token-expired-101和冻结账号qa_s10u_frozen
- 测试步骤
  1. 使用token-expired-101提交FIND，服务端识别设备及操作意图后查询结果
  2. 使用qa_s10u_frozen提交VERNO，服务端识别设备及操作意图后查询结果
- 预期结果
  1. FIND记录进入FAILURE，failureStage指向登录会话校验且不创建队列任务
  2. VERNO记录进入FAILURE，failureStage指向账号状态校验且不创建队列任务

## [P3][反向] 验证重复幂等请求只创建一个任务
- 测试类型
  - 可靠性
- 前置条件
  1. 首次CR请求使用attemptId ATT-20261015-012-A1且已被服务端受理
  2. 设备S10U000001尚未写出该任务
- 测试步骤
  1. 使用相同attemptId ATT-20261015-012-A1和相同请求体连续重试两次
  2. 查询该attemptId对应记录及队列任务数量
- 预期结果
  1. 两次请求返回同一受理结果，不生成新的attemptId
  2. ATT-20261015-012-A1仅对应一个commandId和一个队列任务，未触发重复副作用
