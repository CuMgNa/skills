## 执行前测试夹具

1. 账号：`qa_s10u_admin`、`qa_s10u_frozen`、`qa_s10u_new`。
2. 设备：`S10U000001`至`S10U000004`；均为测试夹具ID，不断言真实唯一标识格式。
3. 会话：`session-A/session-B`、`epoch-101/epoch-201`、`channel-01/channel-02`，支持断线、替换、查询异常与回调注入。
4. 标识：准备独立`commandId/attemptId/businessId`，保证businessId与attemptId一一映射。
5. 数据：支持在线、离线、未连接、告警、路由缺失、关系失效、型号不支持、参数错误、白名单限制和系统异常。
6. 时间：支持固定时间、推进30天、注入迟到及重复回调，以核对`sentAt/failedAt/feedbackTime`。
7. 可观测性：可查询业务记录、队列、TCP日志、状态历史、通知与统计次数、失败追踪日志。
