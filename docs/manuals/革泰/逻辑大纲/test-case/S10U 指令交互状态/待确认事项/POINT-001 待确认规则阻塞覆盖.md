## [P3] 验证需求阻塞：核对高危同一会话最大有效时间
- 测试类型
  - 功能
- 前置条件
  1. 已知RESET和POWEROFF绑定提交时当前可写会话
  2. 产品与服务端尚未确认是否存在最大有效时间及其起算点
- 测试步骤
  1. 向产品核对是否设置最大有效时间、具体时长和起算事件
  2. 向服务端核对超时后的状态、出队、failedAt与failureReason行为
- 预期结果
  1. 形成书面确认项，在确认前不对同一会话持续在线多久后失效作通过或失败结论
  2. 确认后补充边界前、边界值、边界后及取消写出竞态用例；当前仅标记需求阻塞

## [P3] 验证需求阻塞：核对UPLOAD和ZONE前序失败取消后的推进
- 测试类型
  - 功能
- 前置条件
  1. 已知同设备同配置项按提交顺序执行且任务不合并
  2. 前序任务FAILURE或CANCEL后后序任务如何推进尚未确认
- 测试步骤
  1. 向产品核对失败与取消是否阻断后序及是否允许人工继续
  2. 向服务端核对队列游标、出队条件和后序触发机制
- 预期结果
  1. 记录两类前序结果各自的明确推进规则，在确认前不对后序是否自动写出作通过或失败结论
  2. 确认后补充FAILURE后、CONFIRMED取消后、取消被SENT覆盖后三组顺序用例；当前仅标记需求阻塞

  - 功能

## [P3] 验证需求阻塞：核对会话接口标识与错误码契约
- 测试类型
  - 功能
- 前置条件
  1. 已知高危任务需保存boundSessionId、sessionEpoch、channelId等稳定标识
  2. 会话查询接口字段、标识组合和错误码契约尚未确认
- 测试步骤
  1. 向服务端核对接口请求响应Schema、可写判定、标识稳定性和超时重试语义
  2. 核对无会话、会话查询异常、会话变化及系统异常的实际错误码与映射
- 预期结果
  1. 确认前仅校验失败分类和不误放行，不臆造任何接口错误码或唯一标识格式并不作契约通过失败结论
  2. 获得正式契约后补充Schema、错误码、兼容性和异常映射用例；当前仅标记需求阻塞
