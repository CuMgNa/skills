# US-031 退出并清理当前会话

## POINT-003 退出后的登录偏好与记住密码

## [P2] 验证退出后按保存偏好回显账号和时区
- 测试类型
  - 功能
- 前置条件
  1. alice01已登录并保存时区GMT-05:00 New York，记住密码已勾选。
- 测试步骤
  1. 点击退出登录。
  2. 观察登录页回显。
- 预期结果
  1. 返回登录页。
  2. 回显alice01和GMT-05:00 New York。；若记住密码槽位仍归属alice01则密码带出且默认密文展示，仍需手动点击登录。

## [P2] 验证退出后账号B不勾选记住密码时清除旧密码
- 测试类型
  - 功能
- 前置条件
  1. alice01已记住Aa123456。
  2. bob01密码Bb123456。
- 测试步骤
  1. 登录bob01且不勾选记住密码。
  2. 退出bob01并重新进入登录页。
- 预期结果
  1. bob01登录成功。
  2. 登录页回显bob01，密码为空。；alice01和Aa123456不再回显。

## [P3][反向] 验证本地偏好字段不完整时不自动登录
- 测试类型
  - 安全性
- 前置条件
  1. 本地仅保存alice01和GMT+8:00 北京，未保存密码或登录Token。
- 测试步骤
  1. 启动 APP进入登录页。
  2. 观察页面并尝试进入地图。
- 预期结果
  1. 最多回显账号标识和时区。
  2. 不能自动登录或进入地图首页。；必须重新完成在线认证。

## [P2] 验证Android和iOS退出后均不保留可见业务缓存
- 测试类型
  - 兼容性
- 前置条件
  1. Android 13和iOS 17均登录过alice01并产生设备P-001、告警AL-001缓存。
- 测试步骤
  1. 分别在两个系统点击退出。
  2. 杀进程后重新启动并检查登录页和地图入口。
- 预期结果
  1. 两个系统均返回登录页。
  2. 重启后不展示P-001和AL-001。；登录页回显规则按账号偏好执行，不因系统不同泄露业务数据。
