# US-031 退出并清理当前会话

## POINT-001 主动退出登录与返回登录页

## [P1] 验证主动退出结束会话并返回登录页
- 测试类型
  - 功能
- 前置条件
  1. 账号alice01已登录并进入地图首页。
- 测试步骤
  1. 点击我的页面。
  2. 点击退出登录。
  3. 观察页面和会话状态。
- 预期结果
  1. 展示退出登录操作。
  2. 当前业务会话结束并返回登录页。
  3. 页面不再显示已登录账号的地图和设备操作入口。

## [P3][反向] 验证退出后访问业务页面必须重新认证
- 测试类型
  - 安全性
- 前置条件
  1. 账号alice01刚完成退出登录。
- 测试步骤
  1. 点击系统返回或打开地图深链。
  2. 尝试请求设备列表接口。
- 预期结果
  1. 页面保持登录页或跳转登录页。
  2. 业务接口请求被拒绝或返回未认证。；不能继续查看P-001、围栏F-001和告警AL-001。

## [P3][反向] 验证重复点击退出不会产生异常副作用
- 测试类型
  - 可靠性
- 前置条件
  1. 账号alice01已登录。
- 测试步骤
  1. 连续快速点击退出登录两次。
  2. 查看当前页面和退出接口记录。
- 预期结果
  1. 最终只保留一个登录页。
  2. 不会产生重复会话销毁错误、崩溃或错误提示。

## [P5][反向] 验证退出请求异常时按安全策略处理
- 测试类型
  - 可靠性
- 前置条件
  1. 账号alice01已登录，退出接口返回HTTP 500或超时。
  2. 客户端与服务端责任边界尚未确认。
- 测试步骤
  1. 点击退出登录。
  2. 观察页面和再次访问设备列表的结果。
- 预期结果
  1. 记录当前版本在退出接口异常时的本地会话处理。
  2. 无论服务端响应如何，不能在用户已明确退出后继续无提示展示敏感业务数据；最终断言按确认口径固化。
