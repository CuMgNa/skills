# US-031 退出并清理当前会话

## POINT-005 强制下线、Token失效与弱网后台恢复

## [P1] 验证账号被冻结后回到前台强制下线
- 测试类型
  - 安全性
- 前置条件
  1. alice01已登录，APP处于后台。
  2. 后台将alice01状态改为冻结。
- 测试步骤
  1. 将 APP切回前台。
  2. 尝试打开设备P-001和告警AL-001。
- 预期结果
  1. APP检测到账号状态变化并跳转登录页。
  2. 当前会话和展示数据被清理。；不能继续访问P-001或AL-001。

## [P1] 验证Token失效后跳转登录页并切断长连接
- 测试类型
  - 安全性
- 前置条件
  1. alice01已登录并建立WebSocket实时连接。
  2. 服务端使当前Token失效。
- 测试步骤
  1. 继续操作设备或等待下一条实时消息。
  2. 观察页面、WebSocket状态和接口请求。
- 预期结果
  1. 业务接口返回未认证后APP回到登录页。
  2. WebSocket被切断，不再接收实时业务消息。；旧账号设备、围栏和告警展示数据被清理。

## [P3] 验证删除或过期账号强制下线
- 测试类型
  - 功能
- 前置条件
  1. 账号alice01已登录，准备分别模拟后台删除和服务到期。
- 测试步骤
  1. 模拟账号删除或到期。
  2. 在前台继续点击设备列表。
  3. 切换后台再回到前台。
- 预期结果
  1. 账号状态变化被检测。
  2. APP按最终过期/删除口径强制下线或进入只读状态；删除必须强制下线。
  3. 回到前台后不能继续使用失效账号会话。

## [P3][反向] 验证弱网和后台恢复不允许静默续期访问业务接口
- 测试类型
  - 安全性
- 前置条件
  1. alice01已登录，Token即将失效，设备网络不稳定。
- 测试步骤
  1. 将 APP切到后台并断开网络。
  2. 恢复网络后切回前台。
  3. 观察是否自动刷新Token并访问设备接口。
- 预期结果
  1. 断网期间不创建新的业务请求。
  2. 恢复网络后若会话失效，进入登录页要求重新认证。
  3. 不能通过后台静默续期直接访问P-001或告警AL-001。

## [P3][反向] 验证强制下线期间在途响应不污染新会话
- 测试类型
  - 安全性
- 前置条件
  1. alice01设备请求在途，后台即刻冻结alice01。
  2. bob01可正常登录且可见P-003。
- 测试步骤
  1. 让alice01在途请求返回P-001。
  2. 完成alice01强制下线。
  3. 登录bob01并等待加载完成。
- 预期结果
  1. alice01被强制下线。
  2. 在途P-001响应不写入本地展示缓存。
  3. bob01只显示P-003，不出现P-001。
