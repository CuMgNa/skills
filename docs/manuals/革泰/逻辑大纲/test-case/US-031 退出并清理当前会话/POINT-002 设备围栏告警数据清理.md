# US-031 退出并清理当前会话

## POINT-002 设备围栏告警数据清理

## [P1][反向] 验证退出后清理设备围栏告警会话数据
- 测试类型
  - 安全性
- 前置条件
  1. alice01已登录，页面存在设备P-001、围栏F-001、告警AL-001。
- 测试步骤
  1. 记录退出前页面数据。
  2. 点击退出登录。
  3. 退出后重新打开地图入口但不登录。
- 预期结果
  1. 退出前可以看到P-001、F-001和AL-001。
  2. 退出后清理这些会话展示数据。
  3. 未重新认证时不能在地图入口看到任何上一账号业务数据。

## [P1][反向] 验证新账号登录不混入旧账号数据
- 测试类型
  - 安全性
- 前置条件
  1. alice01可见P-001、F-001、AL-001；bob01可见P-003且无权访问前述数据。
- 测试步骤
  1. 登录alice01后退出。
  2. 登录bob01并等待设备加载完成。
  3. 查看设备、围栏和告警列表。
- 预期结果
  1. alice01退出时其数据被清理。
  2. bob01只看到P-003及其授权业务数据。
  3. 不显示P-001、F-001、AL-001、alice01邮箱或账号标识。

## [P3][反向] 验证退出时在途请求返回数据不写入缓存
- 测试类型
  - 安全性
- 前置条件
  1. alice01设备请求、告警请求处于在途状态。
- 测试步骤
  1. 点击退出登录。
  2. 让在途请求返回P-001和AL-001。
  3. 登录bob01并查看业务页面。
- 预期结果
  1. 退出动作清理alice01会话。
  2. 在途响应不写入当前展示缓存。
  3. bob01页面不出现P-001或AL-001。

## [P2] 验证无设备和多设备缓存均能清理
- 测试类型
  - 功能
- 前置条件
  1. 分别准备无设备账号worker02和多设备账号alice01。
- 测试步骤
  1. 登录worker02后退出。
  2. 登录alice01并退出。
  3. 分别检查本地展示和缓存。
- 预期结果
  1. 无设备账号退出后展示空态数据不残留。
  2. 多设备账号退出后P-001和P-002等设备数据均清理。
  3. 两种场景都不能残留上一账号业务数据。
