# US-031 退出并清理当前会话

## POINT-004 账号切换后的数据和偏好隔离

## [P1] 验证账号A退出后账号B只加载自身设备
- 测试类型
  - 功能
- 前置条件
  1. alice01可见P-001和P-002，bob01可见P-003。
  2. 两个账号状态正常。
- 测试步骤
  1. 登录alice01并确认地图显示P-001和P-002。
  2. 退出alice01。
  3. 登录bob01并等待设备加载完成。
- 预期结果
  1. alice01登录数据正确。
  2. 退出时清理alice01业务数据。
  3. bob01只显示P-003，不显示P-001和P-002。

## [P2] 验证账号B使用自己的时区而不是账号A时区
- 测试类型
  - 功能
- 前置条件
  1. alice01保存GMT-05:00 New York，bob01保存GMT+10:00 Sydney。
  2. alice01已退出。
- 测试步骤
  1. 登录bob01。
  2. 进入我的→时区设置并查看今日日期边界。
- 预期结果
  1. bob01登录后回显GMT+10:00 Sydney。
  2. 今日、昨日和日历边界按bob01时区计算。；不继承alice01的GMT-05:00 New York。

## [P3][反向] 验证切换账号过程中不展示上一账号页面残留
- 测试类型
  - 安全性
- 前置条件
  1. alice01当前地图正在展示P-001、F-001和AL-001。
- 测试步骤
  1. 点击退出登录。
  2. 在登录页输入bob01但在设备加载完成前快速返回或切换页面。
  3. 等待bob01加载完成。
- 预期结果
  1. 退出后先进入登录页，不保留alice01地图。
  2. bob01加载中不展示P-001、F-001或AL-001。
  3. 加载完成后只展示bob01授权数据。

## [P2] 验证新账号首次登录按默认偏好初始化
- 测试类型
  - 功能
- 前置条件
  1. bob01首次在当前设备登录，设备没有bob01本地偏好。
  2. 首次默认时区来源待确认。
- 测试步骤
  1. 退出alice01。
  2. 登录bob01。
  3. 查看登录页回显和个人中心时区。
- 预期结果
  1. 创建bob01账号级本地偏好。
  2. 默认时区按最终确认来源初始化。
  3. 不读取alice01账号级偏好。
