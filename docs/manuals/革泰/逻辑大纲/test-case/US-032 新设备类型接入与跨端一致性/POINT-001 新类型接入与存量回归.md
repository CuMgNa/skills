# US-032 新设备类型接入与跨端一致性

## POINT-001 新类型接入与存量回归

## [P1] 验证牛马定位器完整接入链路
- 测试类型
  - 功能
- 前置条件
  1. 管理后台已入库牛马定位器P-300，类型字段维护为牛马定位器。
- 测试步骤
  1. 依次执行：库存查询 → alice01绑定 → 归入分组 → 设备列表展示 → 详情/物联卡查询。
  2. 核对链路各环节数据一致性。
- 预期结果
  1. 库存→绑定→分组→列表→查询完整走通。
  2. 各环节设备身份、类型、归属一致，不只改显示名称。

## [P1] 验证三端设备口径一致
- 测试类型
  - 兼容性
- 前置条件
  1. P-300已绑定alice01，当前在线，SIM在用，服务到期2027-06-30。
- 测试步骤
  1. 分别在APP、监控平台Web、管理后台查看P-300的账号归属、设备归属、分组、SIM状态、在线状态、到期时间。

  2. 账号、设备归属、分组、SIM状态、在线状态、到期时间三端一致，无口径漂移。

## [P2] 验证旧设备类型规则不变
- 测试类型
  - 兼容性
- 前置条件
  1. 平台存量为旧类型设备（如北斗终端）及其围栏、告警、历史分页。
- 测试步骤
  1. 牛马定位器类型上线后，回归旧类型设备的绑定、围栏判定、告警同步、历史分页。
  2. 对比上线前后旧类型业务行为。
- 预期结果
  1. 旧类型的绑定、围栏、告警、指令规则不变。
  2. 旧多边形围栏、原告警同步、原历史分页无规则变化，存量业务无回归。

## [P2] 验证协议不兼容时只隔离适配边界
- 测试类型
  - 可扩展性
- 前置条件
  1. 存在协议差异的牛马定位器新型号P-301。
- 测试步骤
  1. P-301入库并绑定后查看定位、告警、指令。
  2. 对比原平台业务流程。
- 预期结果
  1. 补齐该类型必要的数据与指令适配后业务走通。
  2. 沿用原权限、查询与记录链，不新建授权入口或独立设备事实库，只隔离必要的协议适配边界。
