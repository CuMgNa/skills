# US-016 绑定牛马定位器

## POINT-004 绑定确认页与非绑定前置

## [P1] 验证绑定确认页默认名称与分组必选
- 测试类型
  - 功能
- 前置条件
  1. alice01昵称为"牧场主Alice"，名下有分组"我的分组""牧场东区"。
  2. P-117已通过前序校验。
- 测试步骤
  1. 进入P-117绑定确认页。
  2. 查看Device Name默认值与Group默认选中。
  3. 尝试不选分组直接点击确认。
- 预期结果
  1. Device Name默认写入"牧场主Alice"（账号昵称快照），可编辑、允许为空。
  2. Group默认选中排序最靠前的一级分组。
  3. 未选择真实分组时停留确认页并提示补全，不建立绑定关系。

## [P3][反向] 验证虚拟全部分组不能作为归属分组
- 测试类型
  - 功能
- 前置条件
  1. alice01名下有真实分组，绑定确认页分组选择器可打开。
- 测试步骤
  1. 在绑定确认页打开分组选择器。
  2. 尝试选择虚拟"全部分组"作为Group提交。
- 预期结果
  1. 分组选择器中虚拟"全部分组"不可选或提交时被拦截。
  2. 设备groupId不写入虚拟项，归属必须为真实一级/二级/三级分组。

## [P2] 验证确认页不能切换成另一设备
- 测试类型
  - 功能
- 前置条件
  1. alice01已进入P-118的绑定确认页。
- 测试步骤
  1. 在确认页查找更换设备、重新扫码等切换入口。
  2. 直接完成确认。
- 预期结果
  1. 确认页使用前序流程确定的设备唯一标识与卡号，无切换设备入口。
  2. 绑定关系落在P-118，不串设备。

## [P2] 验证定位频率已移出绑定流程
- 测试类型
  - 功能
- 前置条件
  1. alice01进入P-119绑定确认页。
- 测试步骤
  1. 查看确认页字段构成。
  2. 绑定成功后查看设备详情定位频率与指令记录。
- 预期结果
  1. 确认页无Location Interval字段，不填写、暂存或下发定位频率。
  2. 绑定成功后不自动下发频率指令，不创建等待设备上线后执行的配置任务，详情显示"请选择定位频率"。

## [P2] 验证绑定成功后同步范围正确
- 测试类型
  - 功能
- 前置条件
  1. owner01绑定P-120前记录设备总数、状态数量、分组数量、地图可见设备。
- 测试步骤
  1. owner01完成P-120绑定。
  2. 查看APP设备列表、状态数量、分组直属设备数与地图。
  3. 登录worker02查看是否自动获得P-120。
- 预期结果
  1. 列表、设备总数、在线/离线/告警数量、分组直属设备数与地图可见设备全部刷新。
  2. 不自动创建二级或三级分配关系，worker02不可见P-120，需一级在Web分配。
  3. 不自动创建围栏设备关联。
