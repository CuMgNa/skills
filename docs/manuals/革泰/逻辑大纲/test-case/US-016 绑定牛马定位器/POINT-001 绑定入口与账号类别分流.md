# US-016 绑定牛马定位器

## POINT-001 绑定入口与账号类别分流

## [P1] 验证个人账号展示绑定设备入口并绑定成功
- 测试类型
  - 功能
- 前置条件
  1. 个人账号alice01已登录APP，名下无设备。
  2. 设备P-100已在管理后台入库，类型为牛马定位器。
  3. alice01有剩余绑定配额，名下已有分组"我的分组"。
- 测试步骤
  1. 进入设备管理，查看「绑定设备」入口。
  2. 点击绑定设备，手动输入P-100的设备卡号。
  3. 通过全部校验后在确认页选择"我的分组"，点击确认。
- 预期结果
  1. 设备管理页展示「绑定设备」入口。
  2. 校验通过进入绑定确认页。
  3. 绑定关系落到alice01名下，设备列表出现P-100，各状态数量+1。

## [P1] 验证企业一级账号展示绑定设备入口并绑定成功
- 测试类型
  - 功能
- 前置条件
  1. 企业一级账号owner01已登录APP，有剩余一级配额，名下有分组"我的分组"。
  2. P-101已入库，类型牛马定位器，未被任何企业一级绑定。
- 测试步骤
  1. owner01进入设备管理，点击「绑定设备」。
  2. 扫描P-101机身二维码。
  3. 确认页保持默认名称与分组，点击确认。
- 预期结果
  1. 绑定入口展示，扫码取得P-101设备卡号。
  2. 绑定关系落到owner01（企业一级）名下。
  3. APP与监控平台Web的owner01设备列表同步可见P-101。

## [P3][反向] 验证企业二级账号隐藏绑定入口
- 测试类型
  - 功能
- 前置条件
  1. 企业二级账号worker02已登录APP，已获父级owner01分配的设备P-101。
- 测试步骤
  1. worker02进入设备管理页。
  2. 查找「绑定设备」入口与设备空状态文案。
- 预期结果
  1. 设备管理页不展示「绑定设备」入口。
  2. 正常展示父级已分配的P-101；若无设备时展示普通设备空状态，不展示"联系上级分配"等权限说明。

## [P3][反向] 验证企业三级账号隐藏绑定入口
- 测试类型
  - 功能
- 前置条件
  1. 企业三级账号worker03已登录APP，已获父级worker02分配的设备P-101。
- 测试步骤
  1. worker03进入设备管理页。
  2. 查找「绑定设备」入口。
- 预期结果
  1. 不展示「绑定设备」入口。
  2. 只读取直属二级分配的设备，不进入绑定流程。

## [P3][反向] 验证个人账号不能作为后台代绑目标
- 测试类型
  - 功能
- 前置条件
  1. 管理后台运营账号可执行代绑操作。
  2. 个人账号alice01存在。
- 测试步骤
  1. 在管理后台发起代绑，尝试选择alice01作为代绑目标。
  2. 换用企业一级账号owner01作为代绑目标执行代绑P-102。
- 预期结果
  1. 后台不提供个人账号作为代绑目标选项。
  2. 代绑owner01成功，绑定关系落owner01名下不落操作员名下，owner01在APP与Web同步可见P-102。

## [P2] 验证APP唯一常规绑定入口为设备管理绑定设备
- 测试类型
  - 易用性
- 前置条件
  1. alice01已登录，名下无设备。
- 测试步骤
  1. 依次检查首页、无设备空状态页、全局扫码入口是否存在绑定快捷入口。
  2. 从设备管理 → 绑定设备发起绑定。
- 预期结果
  1. 首页、空状态页、全局位置均无额外绑定快捷入口。
  2. 唯一常规入口为设备管理 → 绑定设备。

## [P2] 验证Web绑定与APP绑定使用同一绑定关系
- 测试类型
  - 兼容性
- 前置条件
  1. alice01同时可用APP与监控平台Web。
  2. P-103已入库为牛马定位器。
- 测试步骤
  1. alice01在监控平台Web绑定P-103。
  2. APP下拉刷新设备列表。
  3. alice01在APP解绑P-103后，登录Web查看。
- 预期结果
  1. Web绑定成功。
  2. APP同步可见P-103，任一端绑定成功后两端同步可见。
  3. Web同样不可见P-103，两端使用同一绑定关系，无独立副本。

## [P3][反向] 验证APP不提供企业向下分配入口
- 测试类型
  - 功能
- 前置条件
  1. owner01已登录APP，名下已绑定P-101。
- 测试步骤
  1. 在APP设备管理、设备详情、更多菜单中查找"分配设备给下级"类入口。
  2. owner01在监控平台Web将P-101分配给worker02。
  3. worker02登录APP查看。
- 预期结果
  1. APP无任何向下分配入口。
  2. Web分配操作成功。
  3. worker02的APP列表出现P-101，APP只读取分配结果。
