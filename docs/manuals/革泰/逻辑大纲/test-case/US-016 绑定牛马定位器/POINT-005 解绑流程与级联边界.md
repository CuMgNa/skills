# US-016 绑定牛马定位器

## POINT-005 解绑流程与级联边界

## [P1] 验证个人账号解绑仅影响个人侧
- 测试类型
  - 功能
- 前置条件
  1. alice01与owner01双绑P-130。
  2. alice01已将P-130加入个人侧分组与围栏。
- 测试步骤
  1. alice01在APP从P-130更多菜单点击Unbind Device并确认。
  2. 分别查看alice01、owner01的设备列表。
  3. 查看P-130历史轨迹与告警记录。
- 预期结果
  1. alice01在APP与Web均不可见P-130，个人侧分组与围栏设备关联被清除。
  2. owner01的企业链路不受影响，P-130仍可见。
  3. 历史位置、轨迹、告警、指令记录保留。

## [P1] 验证企业一级解绑级联失效全部下级
- 测试类型
  - 功能
- 前置条件
  1. owner01绑定P-131并已分配给worker02（下有三级worker03）、worker04。
- 测试步骤
  1. owner01在APP从P-131更多菜单点击Unbind Device并确认。
  2. 分别登录worker02、worker03、worker04查看设备列表。
  3. 查看个人账号bob02（同设备个人绑定）列表。
- 预期结果
  1. owner01不可见P-131。
  2. worker02、worker03、worker04的P-131关系全部立即失效，整条企业链路分组与围栏关联清除。
  3. bob02的个人绑定关系不受影响，仍可见P-131。

## [P1] 验证企业二级移除仅自身及下三级失效
- 测试类型
  - 功能
- 前置条件
  1. owner01绑定P-132并分配给worker02、worker05。
  2. worker02已将P-132再分配给三级worker06。
- 测试步骤
  1. worker02在APP从P-132更多菜单点击Unbind Device并确认。
  2. 登录worker06查看设备列表。
  3. 登录owner01、worker05查看设备列表。
- 预期结果
  1. worker02不可见P-132。
  2. worker06（该二级下三级）立即失效不可见。
  3. owner01仍可见，worker05及其他分支三级不受影响，级联只向下不向上。

## [P1] 验证企业三级移除仅自身失效
- 测试类型
  - 功能
- 前置条件
  1. worker03已获worker02分配的P-133。
  2. 同二级下另有三级worker07也获分配P-133。
- 测试步骤
  1. worker03在APP从P-133更多菜单点击Unbind Device并确认。
  2. 分别查看owner01、worker02、worker07的设备列表。
- 预期结果
  1. 仅worker03不可见P-133。
  2. 一级、直属二级、同二级下其他三级均不受影响，仅清除该三级的分组与围栏关联。

## [P2] 验证Web用户管理一级回收二级分配
- 测试类型
  - 功能
- 前置条件
  1. owner01绑定P-134并分配给worker02，worker02已再分配给worker08。
- 测试步骤
  1. owner01在Web用户管理移除worker02的P-134。
  2. 登录worker02、worker08查看设备列表。
  3. 登录owner01查看设备列表。
- 预期结果
  1. 移除操作成功提交。
  2. worker02不可见P-134，其下worker08立即失效。
  3. owner01仍可见P-134，其他二级及其三级不受影响，被回收链路分组与围栏关联清除。

## [P2] 验证Web用户管理二级回收三级分配
- 测试类型
  - 功能
- 前置条件

## [P3][反向] 验证后台改绑等价解绑A加绑定B
- 测试类型
  - 功能
- 前置条件
  1. 企业一级corpA01绑定P-136，已分配给二级subA02（下有三级）。
  2. 企业一级corpB01配额充足。
- 测试步骤
  1. 管理后台执行改绑corpA01 → corpB01。
  2. 分别查看corpA01链路与corpB01链路。
  3. 查看P-136的个人绑定账号bob02。
- 预期结果
  1. corpA01绑定关系删除，其下二/三级分配立即失效，原分组与围栏关联清除。
  2. corpB01获得企业一级绑定，其下二/三级默认不可见，需重新分配。
  3. bob02的个人绑定关系保留，历史数据保留。

## [P2] 验证重新绑定后原分配与围栏不自动恢复
- 测试类型
  - 功能
- 前置条件
  1. owner01曾绑定P-137并分配给worker02、配置围栏后解绑。
- 测试步骤
  1. owner01重新绑定P-137。
  2. 查看worker02设备列表与P-137围栏关联。
- 预期结果
  1. 重新绑定成功。
  2. 原二/三级分配关系不自动恢复，原围栏关联不自动恢复、不迁移，需重新操作。

## [P3][反向] 验证解绑不删除设备本体与历史数据
- 测试类型
  - 功能
- 前置条件
  1. alice01绑定P-138期间产生过轨迹、告警、指令记录。
  2. alice01执行解绑。
- 测试步骤
  1. 解绑后在管理后台查看P-138库存与物联网卡。
  2. alice01重新绑定P-138后查看历史轨迹与告警。
- 预期结果
  1. 设备本体、库存、物联网卡保留，解绑不等于删除设备。
  2. 历史位置、轨迹、告警、指令记录保留；解绑期间无可见关系时不可查看。
