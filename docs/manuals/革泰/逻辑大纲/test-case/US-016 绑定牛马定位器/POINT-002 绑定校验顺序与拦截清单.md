# US-016 绑定牛马定位器

## POINT-002 绑定校验顺序与拦截清单

## [P1] 验证已入库牛马定位器通过全部校验绑定成功
- 测试类型
  - 功能
- 前置条件
  1. alice01已登录，P-100已入库且类型牛马定位器，配额充足，槽位空闲。
- 测试步骤
  1. 发起绑定输入P-100卡号。
  2. 通过全部校验，确认页选择"我的分组"后确认。
  3. 查看设备列表与状态数量。
- 预期结果
  1. 各项校验通过，进入绑定确认页。
  2. 绑定成功，列表出现P-100。
  3. 设备总数与状态计数刷新，分组直属设备数+1。

## [P3][反向] 验证扫码或输入无法取得有效卡号被拦截
- 测试类型
  - 功能
- 前置条件
  1. 准备一张内容为非设备编码的二维码（如URL https://example.com）。
- 测试步骤
  1. 点击绑定设备选择扫码，扫描上述二维码。
  2. 手动输入"###"等无效字符提交。
- 预期结果
  1. 提示输入/扫码结果无效。
  2. 不进入后续查库与确认页，停留输入阶段。

## [P3][反向] 验证未入库设备绑定被拦截
- 测试类型
  - 功能
- 前置条件
  1. 卡号P-999未在管理后台入库。
  2. alice01绑定配额同时已满（剩余0）。
- 测试步骤
  1. alice01发起绑定输入P-999。
  2. 查看提示内容。
- 预期结果
  1. 绑定被拒绝。
  2. 提示设备不存在/未入库；同时命中未入库与配额满时，优先提示未入库，不以配额不足作为本次结果（校验顺序第2优先于第5）。

## [P3][反向] 验证不支持设备类型绑定被拦截
- 测试类型
  - 功能
- 前置条件
  1. 设备P-200已入库，类型为北斗终端（非牛马定位器）。
- 测试步骤
  1. alice01发起绑定输入P-200卡号。
  2. 查看提示内容。
- 预期结果
  1. 绑定被拒绝。
  2. 提示"当前设备类型暂不支持"，不误提示为设备不存在（类型以后台入库维护的类型字段为准，不以名称或二维码文案判断）。

## [P3][反向] 验证账号已绑定该设备提示已绑定不重复新增
- 测试类型
  - 功能
- 前置条件

- 测试步骤

  2. 设备列表保持一条记录，数量不增加，不重复占用配额，可直接打开该设备详情。

## [P3][反向] 验证无有效分组时绑定引导创建一级组
- 测试类型
  - 功能
- 前置条件
  1. 新账号alice02登录APP，名下删除了初始"我的分组"后处于零业务分组状态。
  2. P-107已入库牛马定位器，其余绑定条件满足。
- 测试步骤
  1. alice02发起绑定P-107。
  2. 在引导进入的分组管理页点击「＋」创建一级组"牧场东区"。
  3. 创建成功后观察绑定流程。
- 预期结果
  1. 绑定流程引导进入分组管理页创建一级组。
  2. 一级组"牧场东区"创建成功。
  3. 返回绑定流程并自动选中"牧场东区"，继续完成绑定。

## [P2] 验证设备未激活无SIM离线仍可绑定

  - 功能
- 前置条件
  1. P-108已入库牛马定位器，未激活、无SIM、从未上报数据。
  2. 其余绑定条件满足。
- 测试步骤
  1. alice01发起绑定输入P-108。
  2. 完成确认页并提交。
- 预期结果
