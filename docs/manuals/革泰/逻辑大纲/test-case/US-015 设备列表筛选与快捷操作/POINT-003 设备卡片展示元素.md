# US-015 设备列表筛选与快捷操作

## POINT-003 设备卡片展示元素

## [P1] 验证有备注设备卡片第一行展示备注加卡号
- 测试类型
  - 功能
- 前置条件
  1. 设备P-001备注为"运牛车A"。
- 测试步骤
  1. 进入设备列表查看P-001卡片第一行。
  2. 查看卡片是否展示分组名称、字段分隔符或右侧状态文字标签。
- 预期结果
  1. 第一行展示"运牛车A（P-001）"。
  2. 卡片内不展示分组名称、字段分隔符和右侧在线/离线/告警文字标签。

## [P1] 验证无备注设备卡片第一行直接展示卡号
- 测试类型
  - 功能
- 前置条件
  1. 设备P-002未设置备注。
- 测试步骤
  1. 进入设备列表查看P-002卡片第一行。
- 预期结果
  1. 第一行直接展示卡号"P-002"，不展示"（卡号）"括号结构，不新增备注唯一性限制。

## [P2] 验证有效电量展示电池图标电量与最近更新时间
- 测试类型
  - 功能
- 前置条件
  1. P-001在线，电量85%，接口返回"最近更新于"时间2026-09-22 10:30。
  2. P-003离线，电量60%，有历史电量返回。
- 测试步骤
  1. 查看P-001卡片第二行。
  2. 查看P-003卡片第二行。
- 预期结果
  1. P-001第二行展示电池图标、85%、"最近更新于2026-09-22 10:30"，图标绿色。
  2. P-003离线仍展示电池图标、60%与最近更新时间，在线离线均适用电量展示。

## [P4] 验证电量颜色边界19与20
- 测试类型
  - 功能
- 前置条件
  1. P-005电量19%，P-006电量20%，均为有效电量。
- 测试步骤
  1. 查看P-005卡片电池图标颜色。
  2. 查看P-006卡片电池图标颜色。
- 预期结果
  1. P-005电量19%<20%，电池图标红色。
  2. P-006电量20%≥20%，电池图标绿色，阈值边界判定正确。

## [P3][反向] 验证无有效电量时隐藏电池图标与数值
- 测试类型
  - 功能
- 前置条件
  1. P-007接口未返回有效电量（缺失或越界如150%）。
- 测试步骤
  1. 查看P-007卡片第二行。
  2. 对比相邻有电量设备卡片的第二行布局高度。
- 预期结果
  1. P-007卡片隐藏电池图标和电量数值，不展示技术状态占位文案，不显示0%。
  2. 第二行布局高度保持不变，仅展示"最近更新于"时间，越界电量不按0%触发低电红色。

## [P2] 验证在线设备第三行展示定位频率预设文案
- 测试类型
  - 功能
- 前置条件
  1. P-001最后确认频率1分钟，P-002为10分钟，P-003为60分钟，均在线。
- 测试步骤
  1. 查看P-001卡片第三行。
  2. 查看P-002卡片第三行。
  3. 查看P-003卡片第三行。
- 预期结果

  2. P-002展示"10分钟定位（默认模式）"。
  3. P-003展示"1小时定位（省电模式）"，三档预设文案与分钟值映射正确。

## [P2] 验证长备注单行尾部省略不挤压更多入口
- 测试类型
  - 易用性
- 前置条件
  1. P-010备注为40字符长文本"这是一个用于验证卡片布局边界的超长设备备注名称AAAA"。
- 测试步骤
  1. 查看P-010卡片第一行展示与右上角更多入口。
  2. 查看左侧设备图标位置。
- 预期结果
  1. 第一行超长尾部省略号截断，不换行挤压更多入口，更多入口可正常点击。
  2. 设备图标与角标固定尺寸和位置，不被长文本挤压或遮挡。

## [P2] 验证卡片本体点击各状态均进入设备详情
- 测试类型
  - 功能
- 前置条件
  1. P-001在线、P-003离线、P-004未连接、P-005告警，四台设备均可见。
- 测试步骤
  1. 依次点击P-001、P-003、P-004卡片本体。
  2. 点击P-005告警卡片本体。
- 预期结果
  1. 在线、离线、未连接三种状态均跳转到对应设备详情页，离线与未连接卡片不呈现为不可点击整卡置灰。
  2. 告警状态同样跳转到P-005详情页，跳转均携带设备唯一标识。
