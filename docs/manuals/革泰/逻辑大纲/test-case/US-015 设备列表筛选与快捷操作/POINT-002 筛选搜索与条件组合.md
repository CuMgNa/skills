# US-015 设备列表筛选与快捷操作

## POINT-002 筛选搜索与条件组合

## [P1] 验证关键词搜索命中编号名称备注与序列号
- 测试类型
  - 功能
- 前置条件
  1. alice01名下：P-001备注"运牛车A"、P-002序列号SN8866、P-003名称含"cow"、P-004无备注。
- 测试步骤
  1. 在搜索框输入"P-001"并确认。
  2. 清空后输入"运牛车A"并确认。
  3. 清空后输入"SN8866"并确认。
  4. 清空后输入"cow"并确认。
- 预期结果
  1. 列表仅展示设备编号命中"P-001"的设备。
  2. 列表仅展示备注为"运牛车A"的P-001。
  3. 列表仅展示序列号含"SN8866"的P-002。
  4. 列表仅展示名称含"cow"的P-003，四类字段均可作为检索入口。

## [P1] 验证状态分组关键词三条件取交集
- 测试类型
  - 功能
- 前置条件
  1. alice01名下：P-001在线属"天河区"组、P-002在线属"深圳市"组、P-003离线属"天河区"组。
- 测试步骤
  1. 选择状态"在线"、分组"天河区"，输入关键词"P-001"确认。
  2. 查看列表结果。
  3. 删除关键词保留状态与分组，查看列表。
- 预期结果
  1. 三个条件同时应用。
  2. 列表仅展示同时满足在线、属天河区、编号含P-001的设备，即仅P-001。
  3. 清空关键词后恢复展示天河区的P-001与P-003中的在线设备P-001，状态与分组条件保留。
