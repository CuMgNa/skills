# US-015 设备列表筛选与快捷操作

## POINT-005 设备告警记录入口与数据范围

## [P1] 验证从设备更多菜单进入只查询该设备告警
- 测试类型
  - 功能
- 前置条件
  1. P-001有3条历史告警，P-002有2条历史告警，均属alice01可见范围。
- 测试步骤
  1. 从P-001卡片更多菜单点击Device Alert History。
  2. 查看告警记录列表内容。
- 预期结果
  1. 携带P-001唯一标识进入Device Alert页面。
  2. 列表仅出现P-001的3条告警，不混入P-002的任何记录。

## [P2] 验证设备告警与告警中心同源数据
- 测试类型
  - 功能
- 前置条件
  1. P-001存在1条未处理告警AL-20260922-01。
- 测试步骤
  1. 进入告警中心查看AL-20260922-01的描述与时间。
  2. 从P-001更多菜单进入Device Alert History查看同一条记录。
  3. 对比两处记录内容。
- 预期结果
  1. 告警中心正常展示该记录。
  2. 设备入口也能查询到AL-20260922-01。
  3. 两处描述、时间、状态一致，数据同源，仅设备入口固定增加当前设备范围。

## [P2] 验证无告警记录展示设备专属空态
- 测试类型
  - 功能
- 前置条件
  1. P-004从未产生任何告警记录。
- 测试步骤
  1. 从P-004更多菜单进入Device Alert History。
  2. 查看页面展示。
- 预期结果
  1. 查询正常返回。
  2. 展示该设备暂无告警记录的空态，不用其他设备告警填充页面。

## [P3][反向] 验证同名设备各自进入只查各自告警
- 测试类型
  - 功能
- 前置条件
  1. 设备A（P-001）与设备B（P-002）名称均为"牛群一号"，各有1条不同告警。
- 测试步骤
  1. 从设备A更多菜单进入Device Alert History查看记录。
  2. 返回列表，从设备B更多菜单进入查看记录。
- 预期结果
  1. 从A进入只能查询A的告警。
  2. 从B进入只能查询B的告警，不复用上一次查看设备，不按名称匹配。

## [P3][反向] 验证设备关系失效时拦截不展示越权数据
- 测试类型
  - 安全性
- 前置条件
  1. alice01已从P-001更多菜单进入过Device Alert History。
  2. 在另一端解除alice01与P-001的绑定关系。
- 测试步骤
  1. APP内从P-001更多菜单再次进入Device Alert History。
  2. 查看页面返回内容。
- 预期结果
  1. 服务端按最新权限返回失败结果。
  2. 页面展示对应失败结果，不回退查询其他设备告警，不展示越权历史数据。
