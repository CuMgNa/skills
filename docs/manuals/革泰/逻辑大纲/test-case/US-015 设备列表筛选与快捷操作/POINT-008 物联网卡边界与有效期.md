# US-015 设备列表筛选与快捷操作

## POINT-008 物联网卡边界与有效期

## [P4] 验证有效期当天仍有效
- 测试类型
  - 功能
- 前置条件
  1. 系统时间2026-09-22，第三方 mock 返回expiry_date=2026-09-22。
- 测试步骤
  1. 进入P-001的IoT SIM Query页面。
  2. 查看有效期展示。
- 预期结果
  1. 有效期展示2026-09-22。
  2. 当天不显示为已失效，不提前一天按过期处理。

- 测试类型
  - 功能

## [P5] 验证访问频率限制场景可稍后刷新
- 测试类型
  - 功能
- 前置条件
  1. 使用脚本对同一卡连续发起超过160次/分钟的单卡查询触发第三方505。
- 测试步骤
  1. 触发505后进入P-001的IoT SIM Query页面。
  2. 查看页面展示。
  3. 等待1分钟后点击刷新。
- 预期结果
  1. 展示访问频率受限的可读原因。
  2. 页面可正常交互，不无限加载。
  3. 稍后刷新恢复查询成功（本节不验证新增倒计时或冷却交互）。

## [P3][反向] 验证非JSON与缺data响应进入统一失败态
- 测试类型
  - 可靠性
- 前置条件
  1. 使用 mock 使第三方分别返回HTML错误页（非JSON）与缺少data字段的JSON。
- 测试步骤
  1. 非JSON场景进入P-001的IoT SIM Query页面。
  2. 切换为缺data场景后刷新页面。
- 预期结果
  1. 非JSON响应进入统一查询失败态，设备摘要保留、明细"—"、可读原因与刷新入口齐备。
  2. 缺data响应同样进入统一失败态，两种异常均不保留本次未确认的伪成功数据。
