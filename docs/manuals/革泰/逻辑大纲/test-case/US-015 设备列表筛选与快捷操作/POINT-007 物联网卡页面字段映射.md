# US-015 设备列表筛选与快捷操作

## POINT-007 物联网卡页面字段映射

## [P1] 验证查询成功时全字段正常展示与单位换算
- 测试类型
  - 功能
- 前置条件
  1. 第三方 mock 返回code=200，active=true，iccid=8986001234567890123，carrier=中国移动，account_status=00，data_plan=2048（MB），当月已用data_usage=512（MB），data_balance=1536（MB），expiry_date=2027-06-30。
- 测试步骤
  1. 从P-001更多菜单进入IoT SIM Query。
  2. 逐项核对页面字段。
- 预期结果
  1. 顶部展示Active；ICCID原值8986001234567890123；运营商"中国移动"；卡状态"正使用"。
  2. 流量套餐、已用流量、剩余流量按接口值等价换算展示（如512MB可展示为0.5GB，数值等价），有效期展示2027-06-30，各字段与返回一致。

## [P2] 验证卡状态码表映射正确
- 测试类型
  - 功能
- 前置条件

- 测试步骤

## [P3][反向] 验证接口状态码不当作卡状态展示
- 测试类型
  - 功能
- 前置条件
  1. 第三方 mock 返回code=502（物联卡不存在或未启用）。
  2. 另一次 mock 返回code=505（访问频率限制）。
- 测试步骤
  1. 进入P-001的IoT SIM Query页面查看502场景。
  2. 切换 mock 为505后刷新页面。
- 预期结果
  1. 502场景展示"物联卡不存在或未启用"可读原因，SIM明细为"—"，卡状态不展示502。
  2. 505场景展示访问频率受限的可读原因并允许稍后刷新，不无限加载，接口code不进入卡状态字段。

## [P2] 验证页面固定元素不受接口影响
- 测试类型
  - 功能
- 前置条件
  1. P-001设备名称为"牧场一号牛"，型号为TL-100。
- 测试步骤
  1. 查询成功场景进入IoT SIM Query页面。
  2. 查询失败场景（第三方断开）再次进入。
  3. 两种场景下核对标题、返回按钮、刷新按钮、设备摘要。
- 预期结果
  1. 标题固定展示"IoT SIM Query"，返回与刷新按钮固定展示。
  2. 设备名称展示"牧场一号牛"、类型展示TL-100，查询失败后摘要仍保留。
  3. 查询失败后刷新按钮仍可重试。
