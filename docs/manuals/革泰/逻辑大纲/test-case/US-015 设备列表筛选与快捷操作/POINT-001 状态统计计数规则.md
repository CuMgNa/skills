# US-015 设备列表筛选与快捷操作

## POINT-001 状态统计计数规则

## [P1] 验证设备列表四种状态筛选及计数正确
- 测试类型
  - 功能
- 前置条件
  1. 个人账号alice01可见5台设备：P-001在线、P-002在线、P-003离线、P-004初始化未连接、P-005告警且在线。
- 测试步骤
  1. alice01登录APP进入设备列表。
  2. 查看顶部"全部/在线/离线/告警"四个筛选项的数量。
  3. 依次点击"在线""离线""告警""全部"筛选并查看列表内容。
- 预期结果
  1. 全部=5、在线=3、离线=2、告警=1，满足在线数+离线数=设备总数。
  2. "在线"列表展示P-001、P-002、P-005；"离线"列表展示P-003、P-004；"告警"列表仅展示P-005。
  3. "全部"恢复展示5台设备，各筛选数量不变。

## [P1] 验证未连接设备统一按离线展示筛选与计数
- 测试类型
  - 功能
- 前置条件
  1. 设备P-004初始化绑定后尚无任何数据上报，未完成过有效下发与通信建立。
- 测试步骤
  1. alice01登录APP进入设备列表。
  2. 查看P-004卡片状态图标与第三行文案。
  3. 点击"离线"筛选查看P-004是否命中。
  4. 查看顶部筛选项数量。
- 预期结果
  1. 设备列表正常展示，P-004出现在列表中。
  2. P-004卡片状态图标为离线灰色，第三行展示"离线，无法下发指令"。
  3. "离线"筛选可命中P-004，"全部"中也可找到。
  4. 顶部不存在"未连接"筛选项，P-004计入离线数，不额外增加第三类基础状态。

## [P2] 验证告警加在线设备同时计入在线与告警
- 测试类型
  - 功能
- 前置条件
  1. 设备P-005当前在线且触发未处理告警。
- 测试步骤
  1. 进入设备列表查看P-005卡片。
  2. 点击"在线"筛选。
  3. 点击"告警"筛选。
- 预期结果
  1. P-005卡片左侧图标为告警红色并带在线角标，卡片右侧状态优先展示"告警"。
  2. "在线"筛选结果包含P-005。
  3. "告警"筛选结果包含P-005，P-005同时计入在线数与告警数。

  3. "告警"筛选结果包含P-006，P-006同时计入离线数与告警数。

## [P2] 验证多关系可见设备按唯一标识去重计数
- 测试类型
  - 功能
- 前置条件
  1. 企业一级账号owner01绑定P-101并已通过Web分配给二级worker02和worker03。
  2. worker02名下另有机型相同的P-102在线。
- 测试步骤
  1. owner01登录APP查看设备总数与状态数量。
  2. worker02登录APP查看设备总数与状态数量。
  3. worker03登录APP查看设备总数与状态数量。
- 预期结果
  1. owner01列表P-101只出现一条，总数、在线数、离线数、告警数均按设备唯一标识去重。
  2. worker02总数为2（P-101、P-102各计一台）。
  3. worker03总数为1，各端计数不因多条可见关系重复累计。

## [P3][反向] 验证状态筛选一次只选一项
- 测试类型
  - 功能
- 前置条件
  1. 设备列表顶部展示全部/在线/离线/告警四个筛选项。
- 测试步骤
  1. 点击"在线"筛选。
  2. 不取消"在线"直接点击"告警"筛选。
  3. 查看列表结果与筛选选中态。
- 预期结果
  1. "在线"筛选生效，列表仅展示在线设备。
  2. 切换后仅"告警"为选中态，"在线"取消选中。
  3. 列表仅展示告警设备，不出现在线∩告警的叠加结果。

## [P3][反向] 验证默认离线设备在全部与离线筛选中均可找到
- 测试类型
  - 功能
- 前置条件

- 测试步骤

- 预期结果

  2. "离线"筛选中P-003、P-004均可见，无离线设备遗漏在筛选之外。

## [P2] 验证告警为设备卡片状态优先展示项
- 测试类型
  - 功能
- 前置条件
  1. 设备P-005在线且触发告警，同列表存在普通在线设备P-001。
- 测试步骤
  1. 进入设备列表查看P-005与P-001卡片右侧状态。
  2. 触发P-001产生一条未处理告警后刷新列表。
- 预期结果
  1. P-005卡片右侧优先展示"告警"，P-001展示在线状态。
  2. P-001产生告警后卡片右侧优先切换为"告警"，告警数+1。
