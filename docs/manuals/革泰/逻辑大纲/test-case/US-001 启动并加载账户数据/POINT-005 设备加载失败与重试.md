# US-001 启动并加载账户数据

## POINT-005 设备加载失败与重试

## [P1] 验证设备加载失败后点击重试可以重新加载
- 测试类型
  - 可靠性
- 前置条件
  1. 账号alice01状态正常。
  2. 首次设备接口返回HTTP 503，第二次请求返回P-001和P-002。
- 测试步骤
  1. 登录alice01并等待首次设备加载。
  2. 点击重试。
  3. 等待第二次设备加载完成。
- 预期结果
  1. 首次失败页面显示失败原因和重试入口。
  2. 点击重试后重新请求设备、围栏和告警数据。
  3. 成功后进入地图首页并展示P-001、P-002。

## [P3][反向] 验证连续设备加载失败时不展示上一账号数据
- 测试类型
  - 安全性
- 前置条件
  1. 账号alice01可见P-001。
  2. 账号bob01可见P-003。
  3. bob01设备接口连续返回HTTP 503。
- 测试步骤
  1. 先登录alice01并退出。
  2. 登录bob01。
  3. 等待设备加载失败并点击重试。
- 预期结果
  1. alice01退出后其业务缓存被清理。
  2. bob01加载失败时显示失败状态。
  3. 失败页不展示P-001、alice01告警或其他账号数据。

## [P3][反向] 验证设备加载请求在Token失效后不写入本地展示数据
- 测试类型
  - 安全性
- 前置条件
  1. 账号alice01已登录，设备加载请求处于在途状态。
  2. 服务端使alice01的Token失效。
- 测试步骤
  1. 让在途设备接口返回P-001。
  2. 观察 APP当前页面和本地设备列表。
- 预期结果
  1. APP跳转登录页并清理当前会话。
  2. 在途响应中的P-001不写入当前展示数据或新账号缓存。

## [P5][反向] 验证加载页超时口径未定时记录实际表现
- 测试类型
  - 可靠性
- 前置条件
  1. 账号alice01状态正常，设备接口持续不返回。
  2. 设备加载超时判定时长尚未最终确认。
- 测试步骤
  1. 登录alice01并保持设备接口无响应。
  2. 观察达到当前版本超时阈值后的页面。
- 预期结果
  1. 记录当前版本实际超时阈值、文案和重试入口。
  2. 不得以未确认的固定秒数作为通过或失败依据；若无限转圈且无反馈，记录为待确认风险。
