# US-001 启动并加载账户数据

## POINT-003 本地偏好与账号隔离启动

## [P1] 验证首次启动无本地偏好时进入登录页
- 测试类型
  - 功能
- 前置条件
  1. 已清理 APP 本地登录偏好、时区和记住密码数据。
  2. 引导完成标记为true。
- 测试步骤
  1. 冷启动革泰 APP。
- 预期结果
  1. 开屏页后进入登录页。；登录标识、密码和时区按首次启动规则展示；默认时区具体来源按最终确认结果校验。

## [P2] 验证账号A上次保存的时区在下次启动回显
- 测试类型
  - 功能
- 前置条件
  1. 账号alice01上次成功登录并保存时区GMT-05:00 New York。
  2. 引导完成标记为true。
- 测试步骤
  1. 退出账号alice01。
  2. 重新启动 APP并进入登录页。
- 预期结果
  1. 登录页回显alice01的登录标识。
  2. 时区回显GMT-05:00 New York，不被其他账号或设备默认值覆盖。

## [P2][反向] 验证账号A与账号B本地偏好互不混用
- 测试类型
  - 安全性
- 前置条件
  1. 账号alice01时区为GMT-05:00 New York。
  2. 账号bob01时区为GMT+10:00 Sydney。
  3. 账号alice01已退出。
- 测试步骤
  1. 使用bob01和Bb123456登录。
  2. 退出bob01并重新进入登录页。
- 预期结果
  1. 登录后应用账号bob01的业务数据和时区。
  2. 登录页回显bob01及GMT+10:00 Sydney，不展示alice01的密码、邮箱或时区。

## [P3][反向] 验证升级旧版本后不使用旧Token自动进入业务页
- 测试类型
  - 安全性
- 前置条件
  1. 旧版本曾登录alice01，已存在旧版本本地Token。
  2. APP已升级到当前版本。
- 测试步骤
  1. 启动升级后的 APP。
  2. 观察是否进入地图首页。
- 预期结果
  1. 当前版本重新校验登录态。
  2. 旧Token不能绕过认证直接进入地图首页；失效时进入登录页。
