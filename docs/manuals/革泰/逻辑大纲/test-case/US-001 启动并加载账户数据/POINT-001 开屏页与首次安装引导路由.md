# US-001 启动并加载账户数据

## POINT-001 开屏页与首次安装引导路由

## [P1] 验证首次安装未完成引导时开屏页自动进入引导页1
- 测试类型
  - 功能
- 前置条件
  1. 设备为首次安装状态，引导完成标记为false。
- 测试步骤
  1. 冷启动革泰 APP。
  2. 观察开屏页约1.8秒后的页面。
- 预期结果
  1. 展示纯静态品牌开屏页，页面无按钮、账号或业务数据。
  2. 开屏页自动进入引导页1，不需要点击继续。

## [P2] 验证已完成引导时开屏页直接进入登录页
- 测试类型
  - 功能
- 前置条件
  1. 设备已完成引导，引导完成标记为true。
- 测试步骤
  1. 冷启动革泰 APP。
  2. 观察开屏页自动过渡后的页面。
- 预期结果
  1. 开屏页正常展示并自动过渡。
  2. 不再展示引导页，直接进入登录页。

## [P3][反向] 验证开屏页期间点击屏幕不会触发未定义跳转
- 测试类型
  - 易用性
- 前置条件
  1. 设备为首次安装状态，引导完成标记为false。
- 测试步骤
  1. 冷启动革泰 APP。
  2. 开屏页展示期间连续点击屏幕3次。
- 预期结果
  1. 开屏页保持纯静态展示。
  2. 点击不会提前跳转、弹出按钮或进入地图首页。

## [P4][反向] 验证不同移动端系统开屏页不泄露上一账号数据
- 测试类型
  - 安全性
- 前置条件
  1. Android 13和iOS 17测试设备均完成过账号alice01登录。
  2. 当前已退出登录。
- 测试步骤
  1. 分别在Android 13和iOS 17上冷启动 APP。
  2. 观察开屏页和自动过渡过程。
- 预期结果
  1. 两个系统均正常展示品牌开屏页。
  2. 开屏页及过渡页面不展示alice01的密码、Token、设备P-001或告警AL-001。
