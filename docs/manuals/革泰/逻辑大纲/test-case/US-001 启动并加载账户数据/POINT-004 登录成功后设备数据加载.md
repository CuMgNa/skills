# US-001 启动并加载账户数据

## POINT-004 登录成功后设备数据加载

## [P1] 验证个人账号登录成功后按顺序加载设备数据
- 测试类型
  - 功能
- 前置条件
  1. 账号alice01已注册，密码Aa123456，绑定设备P-001和P-002。
  2. 账号状态正常。
- 测试步骤
  1. 在登录页输入alice01和Aa123456。
  2. 选择GMT+8:00 北京并勾选用户协议与隐私政策。
  3. 点击Sign In。
- 预期结果
  1. 登录请求通过并创建业务会话。
  2. 先展示Loading devices...及加载动画。
  3. 加载完成后进入地图首页，仅展示P-001、P-002及其对应围栏和告警。

## [P1] 验证企业一级账号登录后加载自己绑定及后台代绑设备
- 测试类型
  - 功能
- 前置条件
  1. 企业一级账号owner01密码Owner1234。
  2. 账号绑定E1-001，后台代绑E1-002。
  3. 账号状态正常。
- 测试步骤
  1. 输入owner01和Owner1234并完成协议及时区选择。
  2. 点击Sign In并等待设备加载完成。
- 预期结果
  1. 登录成功并进入设备加载页。
  2. 地图首页展示E1-001和E1-002。；页面展示绑定设备入口，但不展示用户管理、子账号管理或向下分配入口。

## [P2] 验证无可见设备账号进入明确空态
- 测试类型
  - 功能
- 前置条件
  1. 企业二级账号worker02密码Worker1234，当前无直属一级分配设备。
- 测试步骤
  1. 使用worker02和Worker1234登录。
  2. 等待设备加载完成。
- 预期结果
  1. 登录会话创建成功。
  2. 地图或设备页展示无设备空态，不展示其他账号设备；空态文案按最终确认结果校验。

## [P3][反向] 验证设备接口失败时不直接进入空白地图首页
- 测试类型
  - 可靠性
- 前置条件
  1. 账号alice01状态正常。
  2. 已将设备列表接口配置为返回HTTP 503。
- 测试步骤
  1. 使用alice01和Aa123456登录。
  2. 等待设备加载响应。
- 预期结果
  1. 登录鉴权成功后进入设备加载流程。
  2. 设备接口失败后显示失败原因和重试入口，不进入展示旧数据或空白地图首页。
