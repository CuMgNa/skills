# US-004 通过邮箱重置密码

## POINT-004 新密码和确认密码规则

## [P4] 验证重置密码8位和64位边界有效
- 测试类型
  - 功能
- 前置条件
  1. alice01@gmail.com重置验证码654321有效。
- 测试步骤
  1. 使用8位新密码NewAa12及相同确认密码完成一次重置。
  2. 重新获取验证码后使用64位新密码A123456789012345678901234567890123456789012345678901234567890完成一次重置。
- 预期结果
  1. 8位新密码被接受。
  2. 64位新密码被接受。

## [P4][反向] 验证重置密码7位和65位被阻止
- 测试类型
  - 功能
- 前置条件
  1. 已进入新密码设置页，验证码有效。
- 测试步骤
  1. 输入7位Aa12345及相同确认密码。
  2. 输入65位A1234567890123456789012345678901234567890123456789012345678900及相同确认密码。
- 预期结果
  1. 7位新密码显示长度错误并阻止提交。
  2. 65位新密码显示长度错误并阻止提交。

## [P3][反向] 验证重置确认密码不一致时不能提交
- 测试类型
  - 功能
- 前置条件
  1. 验证码有效，已进入新密码设置页。
- 测试步骤
  1. 输入NewAa1234。
  2. 确认密码输入NewAa1235。
  3. 点击Change password。
- 预期结果
  1. 按钮保持禁用或提交被拒绝。
  2. 确认密码字段显示不一致提示。
  3. 账号密码不发生变化。

## [P5][反向] 验证新密码是否允许复用旧密码按待确认口径记录
- 测试类型
  - 功能
- 前置条件
  1. 账号alice01当前密码Aa123456，重置验证码654321有效。
  2. 密码复用规则尚未确认。
- 测试步骤
  1. 将新密码和确认密码均填写Aa123456。
  2. 提交密码重置。
- 预期结果
  1. 记录当前版本是否允许复用旧密码。
  2. 待产品确认前不把允许或禁止复用作为固定断言。
