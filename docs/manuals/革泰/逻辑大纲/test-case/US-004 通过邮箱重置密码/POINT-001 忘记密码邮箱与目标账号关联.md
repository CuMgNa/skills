# US-004 通过邮箱重置密码

## POINT-001 忘记密码邮箱与目标账号关联

## [P1] 验证已关联邮箱可以进入重置密码流程
- 测试类型
  - 功能
- 前置条件
  1. 账号alice01关联alice01@gmail.com，当前未登录。
- 测试步骤
  1. 在登录页点击Forgot password。
  2. 输入alice01@gmail.com。
  3. 点击Get Code。
- 预期结果
  1. 进入忘记密码页，输入框只接受邮箱。
  2. 系统识别邮箱关联账号alice01。
  3. 发送密码重置用途验证码并进入后续步骤。

## [P3][反向] 验证忘记密码输入账号名时提示输入注册邮箱
- 测试类型
  - 功能
- 前置条件
  1. 当前未登录，已进入忘记密码页。
- 测试步骤
  1. 输入alice01。
  2. 点击Get Code。
- 预期结果
  1. 系统不把alice01解析为账号名。
  2. 显示“请输入注册邮箱”或最终确认的等价提示。；不发送验证码。

## [P3][反向] 验证未注册邮箱不能申请重置验证码
- 测试类型
  - 功能
- 前置条件
  1. 当前未登录，准备未注册邮箱none999@outlook.com。
- 测试步骤
  1. 输入none999@outlook.com。
  2. 点击Get Code。
- 预期结果
  1. 提示邮箱未注册或无关联账号，最终文案按确认结果校验。
  2. 不发送验证码，不影响其他账号。

## [P2] 验证邮箱首尾空格和大小写按统一口径关联账号
- 测试类型
  - 功能
- 前置条件
  1. alice01关联alice01@gmail.com。
- 测试步骤
  1. 输入三个前导空格和两个尾随空格的邮箱：   alice01@gmail.com  。
  2. 重新输入ALICE01@GMAIL.COM。
  3. 分别点击Get Code进行验证。
- 预期结果
  1. 首尾空格被去除后可以识别alice01。
  2. 大小写混写按统一口径识别alice01。
  3. 两种输入不会解析为其他账号。
