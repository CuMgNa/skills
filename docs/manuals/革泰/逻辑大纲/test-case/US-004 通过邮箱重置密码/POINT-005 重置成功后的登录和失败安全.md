# US-004 通过邮箱重置密码

## POINT-005 重置成功后的登录和失败安全

## [P1] 验证重置成功后新密码可登录且旧密码失效
- 测试类型
  - 功能
- 前置条件
  1. alice01邮箱alice01@gmail.com，重置验证码654321有效，旧密码Aa123456。
- 测试步骤
  1. 将新密码设置为NewAa1234并完成重置。
  2. 返回登录页使用alice01和NewAa1234登录。
  3. 退出后使用旧密码Aa123456登录。
- 预期结果
  1. 密码修改成功并返回登录页。
  2. 使用新密码登录成功并按权限加载P-001、P-002。
  3. 使用旧密码登录失败，不创建会话。

## [P3][反向] 验证重置成功后验证码不能重复消费
- 测试类型
  - 安全性
- 前置条件
  1. alice01刚使用654321成功重置为NewAa1234。
- 测试步骤
  1. 再次提交相同邮箱、相同验证码和另一个密码OtherAa12。
  2. 使用新密码NewAa1234登录。
- 预期结果
  1. 重复提交被拒绝，不再次修改密码。
  2. 新密码NewAa1234仍然有效。

## [P3] 验证重置失败时旧密码仍然有效
- 测试类型
  - 可靠性
- 前置条件
  1. alice01当前密码Aa123456，验证码输入错误123456。
- 测试步骤
  1. 使用错误验证码提交新密码NewAa1234。
  2. 返回登录页使用alice01和Aa123456登录。
- 预期结果
  1. 重置操作失败并保留表单可重试。
  2. 旧密码仍可登录成功。；NewAa1234未生效。

## [P2][反向] 验证重置成功后不自动进入业务首页
- 测试类型
  - 安全性
- 前置条件
  1. alice01已完成密码重置。
- 测试步骤
  1. 观察重置成功后的页面。
  2. 不输入密码直接尝试访问地图深链。
- 预期结果
  1. 页面返回登录页或明确的重新认证页面。
  2. 不会凭重置流程直接创建登录会话或展示设备数据。
