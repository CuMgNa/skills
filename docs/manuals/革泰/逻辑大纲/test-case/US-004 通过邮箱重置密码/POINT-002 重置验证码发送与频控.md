# US-004 通过邮箱重置密码

## POINT-002 重置验证码发送与频控

## [P1] 验证密码重置验证码发送成功
- 测试类型
  - 功能
- 前置条件
  1. alice01@gmail.com关联有效账号且可收码。
- 测试步骤
  1. 在忘记密码页输入alice01@gmail.com。
  2. 点击Get Code。
- 预期结果
  1. 收到密码重置用途6位数字验证码654321。
  2. Get Code进入60秒倒计时。；页面进入验证码、新密码和确认新密码填写状态。

## [P3][反向] 验证重置验证码60秒内不可重复发送
- 测试类型
  - 可靠性
- 前置条件
  1. alice01@gmail.com刚发送重置验证码，倒计时剩余59秒。
- 测试步骤
  1. 连续点击Get Code 3次。
  2. 检查邮件收件箱和发送记录。
- 预期结果
  1. 按钮保持禁用倒计时状态。
  2. 60秒内不重复发送验证码。

## [P2] 验证重置验证码60秒结束后允许重发
- 测试类型
  - 功能
- 前置条件
  1. 重置验证码倒计时剩余1秒。
- 测试步骤
  1. 等待倒计时结束。
  2. 点击Get Code。
- 预期结果
  1. Get Code恢复可点击。
  2. 发送新的密码重置验证码并重新倒计时。

## [P3][反向] 验证无效邮箱不发送重置验证码
- 测试类型
  - 功能
- 前置条件
  1. 已进入忘记密码页。
- 测试步骤
  1. 输入alice@@gmail.com并点击Get Code。
  2. 清空输入后再次点击Get Code。
- 预期结果
  1. 格式错误时提示格式问题且不发送验证码。
  2. 邮箱为空时提示必填且不发送验证码。
