# US-003 验证邮箱并注册个人账户

## POINT-003 邮箱格式唯一性与国际邮箱兼容

## [P1] 验证北美主流邮箱可以用于真实收码注册
- 测试类型
  - 兼容性
- 前置条件
  1. 准备可登录且可收码的邮箱：qa.gta.gmail@gmail.com、qa.gta.outlook@outlook.com、qa.gta.icloud@icloud.com。
  2. 每个邮箱未被系统占用。
- 测试步骤
  1. 分别使用三个邮箱进入注册页并点击Get Code。
  2. 从对应收件箱读取验证码并完成注册。
- 预期结果
  1. 三个邮箱均允许发送验证码。
  2. 验证码能在对应邮箱收件箱或垃圾箱中找到。；使用有效验证码后均可完成个人账户注册。

## [P2] 验证澳大利亚多级域名邮箱不被格式校验误拦
- 测试类型
  - 兼容性
- 前置条件
  1. 准备可收码邮箱qa.gta@service.com.au和qa.gta@service.net.au。
  2. 邮箱未被占用。
- 测试步骤
  1. 分别将两个邮箱输入注册页Email字段。
  2. 点击Get Code并完成注册验证。
- 预期结果
  1. .com.au和.net.au多级域名通过格式校验。
  2. 系统发送验证码，不提示格式错误。；收到验证码后可以完成注册。

## [P3][反向] 验证明显非法邮箱不发送验证码
- 测试类型
  - 功能
- 前置条件
  1. 已进入注册页。
- 测试步骤
  1. 依次输入alice02gmail.com、alice@@gmail.com、@gmail.com、alice02@、alice02@gmail。
  2. 分别点击Get Code。
- 预期结果
  1. 每个非法邮箱均显示格式错误。
  2. Get Code不发送邮件、不进入有效倒计时或按最终频控规则处理。

## [P4] 验证邮箱本地部分和整体长度边界
- 测试类型
  - 功能
- 前置条件
  1. 已进入注册页，准备可收码域名example.com。
- 测试步骤
  1. 输入本地部分64字符且整体不超过254字符的邮箱并点击Get Code。
  2. 输入本地部分65字符的邮箱并点击Get Code。
  3. 输入整体超过254字符的邮箱并点击Get Code。
- 预期结果
  1. 本地部分64字符且整体合法时通过格式校验。
  2. 本地部分65字符时提示格式错误。
  3. 整体超过254字符时提示格式错误。

## [P3][反向] 验证已占用邮箱不能重复注册
- 测试类型
  - 功能
- 前置条件
  1. 账号alice01已占用alice01@gmail.com，准备新账号alice05。
- 测试步骤
  1. 在注册页输入alice05和alice01@gmail.com。
  2. 输入有效验证码、Aa123456及确认密码并提交。
- 预期结果
  1. 注册被拒绝。
  2. 提示邮箱已注册或对应唯一性错误。；账号alice01的原有登录、找回密码和通知能力不受影响。
