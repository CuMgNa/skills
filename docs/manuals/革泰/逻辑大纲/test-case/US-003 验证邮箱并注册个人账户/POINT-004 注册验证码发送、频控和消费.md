# US-003 验证邮箱并注册个人账户

## POINT-004 注册验证码发送、频控和消费

## [P1] 验证注册验证码发送成功并进入60秒倒计时
- 测试类型
  - 功能
- 前置条件
  1. 邮箱qa.gta.2026@gmail.com格式正确、未注册且可收码。
- 测试步骤
  1. 输入邮箱qa.gta.2026@gmail.com。
  2. 点击Get Code。
- 预期结果
  1. 系统发送注册用途验证码。
  2. 收到6位数字验证码。；Get Code进入60秒倒计时，倒计时期间按钮不可重复点击。

## [P3][反向] 验证60秒内重复点击Get Code不会重复发送
- 测试类型
  - 可靠性
- 前置条件
  1. 邮箱qa.gta.2026@gmail.com刚成功发送验证码，倒计时剩余59秒。
- 测试步骤
  1. 连续点击Get Code 3次。
  2. 检查邮箱收件箱和验证码发送记录。
- 预期结果
  1. 按钮保持倒计时不可点击状态。
  2. 60秒内不新增注册验证码邮件或重复发送请求。

## [P2] 验证60秒结束后可以重新获取验证码
- 测试类型
  - 功能
- 前置条件
  1. 同一邮箱注册验证码倒计时即将结束。
- 测试步骤
  1. 等待倒计时结束。
  2. 再次点击Get Code。
- 预期结果
  1. 按钮恢复可点击。
  2. 系统发送新的注册验证码并重新开始60秒倒计时。

## [P3][反向] 验证邮箱为空或格式错误时不发送验证码
- 测试类型
  - 功能
- 前置条件
  1. 已进入注册页。
- 测试步骤
  1. 邮箱留空并点击Get Code。
  2. 输入alice02gmail.com并点击Get Code。
- 预期结果
  1. 邮箱为空时显示必填提示，不发送邮件。
  2. 邮箱格式错误时显示格式提示，不发送邮件。

## [P3][反向] 验证重发后旧验证码失效且新验证码生效
- 测试类型
  - 安全性
- 前置条件
  1. 邮箱qa.gta.2026@gmail.com已收到旧验证码123456。
  2. 等待60秒并再次获取新验证码789012。
- 测试步骤
  1. 先输入旧验证码123456提交注册验证。
  2. 再输入新验证码789012提交注册验证。
- 预期结果
  1. 旧验证码被拒绝，不能完成注册。
  2. 新验证码在有效期内校验通过。

## [P3][反向] 验证验证码绑定注册用途和目标邮箱
- 测试类型
  - 安全性
- 前置条件
  1. qa.gta.2026@gmail.com收到注册验证码123456；qa.gta.outlook@outlook.com收到其他用途或其他请求验证码。
- 测试步骤
  1. 将Gmail验证码填入Outlook邮箱的注册表单。
  2. 将Gmail注册验证码填入密码重置流程。
- 预期结果
  1. 跨邮箱使用被拒绝。
  2. 跨用途使用被拒绝，注册验证码不能用于密码重置。
