# US-003 验证邮箱并注册个人账户

## POINT-005 注册密码、确认密码与提交

## [P4] 验证注册密码8位和64位边界可以提交
- 测试类型
  - 功能
- 前置条件
  1. 账号alice06和邮箱qa.gta.2026+pwd@gmail.com未占用，验证码123456有效。
- 测试步骤
  1. 使用8位密码Aa123456及相同确认密码完成注册。
  2. 使用64位密码A123456789012345678901234567890123456789012345678901234567890及相同确认密码完成另一账号注册。
- 预期结果
  1. 8位密码注册成功。
  2. 64位密码注册成功，系统接受最大长度边界。

## [P4][反向] 验证注册密码7位或65位不能提交
- 测试类型
  - 功能
- 前置条件
  1. 已进入注册页，账号、邮箱和验证码有效。
- 测试步骤
  1. 输入7位密码Aa12345及相同确认密码并提交。
  2. 输入65位密码A1234567890123456789012345678901234567890123456789012345678900及相同确认密码并提交。
- 预期结果
  1. 7位密码被阻止并显示长度错误。
  2. 65位密码被阻止并显示长度错误。

## [P3][反向] 验证确认密码必须与密码完全一致
- 测试类型
  - 功能
- 前置条件
  1. 已进入注册页，其他字段均有效。
- 测试步骤
  1. 密码输入Aa123456，确认密码输入Aa123457并提交。
  2. 密码输入Aa123456，确认密码输入aa123456并提交。
  3. 密码输入Aa123456，确认密码输入Aa123456加一个空格并提交。
- 预期结果
  1. 每种不一致情况均阻止注册。
  2. 确认密码字段显示不一致提示，服务端不创建账号。
  3. 确认密码不作为账户资料写入。

## [P2] 验证注册密码和确认密码眼睛图标分别切换显示
- 测试类型
  - 易用性
- 前置条件
  1. 已进入注册页。
- 测试步骤
  1. 在Password输入Aa123456。
  2. 点击Password眼睛图标。
  3. 在Confirm Password输入Aa123456。
  4. 点击Confirm Password眼睛图标。
- 预期结果
  1. 两个密码默认以密文显示。
  2. Password只切换自身明文状态。
  3. Confirm Password只切换自身明文状态。
  4. 两个字段内容均保持不变。

## [P3][反向] 验证注册请求重复提交只创建一个账号
- 测试类型
  - 可靠性
- 前置条件
  1. 账号alice07和邮箱qa.gta.2026+dup2@gmail.com未占用，验证码123456有效。
- 测试步骤
  1. 填写完整注册表单。
  2. 快速连续点击Register两次。
  3. 查询账号列表和注册接口记录。
- 预期结果
  1. 客户端或服务端只允许一次有效提交。
  2. 最多创建一个alice07账号。
  3. 不会产生重复账号、重复邮箱归属或两次成功副作用。
