## 已处理的规则冲突

1. 注册成功流转：采用“返回空白登录页且不自动登录”。
2. 过期账号：采用“本账号直接拦截；父级过期不级联子账号”。
3. 密码锁定：采用“APP 错误不自锁；同步平台锁定；另测服务端限流/风控”。
4. 验证码消费：采用“业务成功后原子消费”，避免创建或改密失败时错误烧码。
