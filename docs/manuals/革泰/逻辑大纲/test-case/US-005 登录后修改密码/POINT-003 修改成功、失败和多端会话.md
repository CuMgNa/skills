# US-005 登录后修改密码

## POINT-003 修改成功、失败和多端会话

## [P1] 验证修改密码成功后提示明确且新密码生效
- 测试类型
  - 功能
- 前置条件
  1. alice01当前密码Aa123456，已登录。
- 测试步骤
  1. 输入当前密码Aa123456。
  2. 输入新密码NewAa1234和确认密码NewAa1234。
  3. 点击提交。
  4. 退出后使用alice01和NewAa1234登录。
- 预期结果
  1. 当前密码校验通过。
  2. 新密码校验通过。
  3. 显示“密码已修改”或最终确认的成功提示。
  4. 退出后新密码登录成功。

## [P3][反向] 验证修改成功后旧密码失效
- 测试类型
  - 安全性
- 前置条件
  1. alice01已将密码修改为NewAa1234。
- 测试步骤
  1. 退出登录。
  2. 使用alice01和Aa123456登录。
- 预期结果
  1. 旧密码登录失败。
  2. 不创建会话、不加载设备数据。

## [P3][反向] 验证修改请求失败时旧密码继续有效
- 测试类型
  - 可靠性
- 前置条件
  1. alice01当前密码Aa123456。
  2. 修改密码接口配置为HTTP 500。
- 测试步骤
  1. 提交当前密码Aa123456、新密码NewAa1234和确认密码。
  2. 退出或返回登录页后使用Aa123456登录。
- 预期结果
  1. 页面显示失败原因并保留表单或按当前错误处理规则展示。
  2. 密码未被修改。；旧密码Aa123456仍可登录。

## [P3][反向] 验证连续点击提交不产生重复密码修改副作用
- 测试类型
  - 可靠性
- 前置条件
  1. alice01已登录，当前密码Aa123456，新密码NewAa1234。
- 测试步骤
  1. 填写完整表单。
  2. 快速连续点击提交按钮两次。
  3. 查看密码修改记录并重新登录。
- 预期结果
  1. 客户端或服务端只允许一次有效提交。
  2. 最多产生一条密码修改成功记录。
  3. NewAa1234可登录，旧密码不能登录。

## [P5][反向] 验证密码修改后其他端会话按待确认规则记录
- 测试类型
  - 安全性
- 前置条件
  1. alice01同时在APP和监控平台Web登录，密码Aa123456。
  2. 多端会话失效规则尚未确认。
- 测试步骤
  1. 在APP修改密码为NewAa1234。
  2. 在Web端继续访问设备列表。
  3. 在Web端使用旧密码重新登录。
- 预期结果
  1. 记录Web现有会话是否失效及接口返回。
  2. 记录旧密码是否立即失效。
  3. 待产品确认多端会话规则后固化断言。
