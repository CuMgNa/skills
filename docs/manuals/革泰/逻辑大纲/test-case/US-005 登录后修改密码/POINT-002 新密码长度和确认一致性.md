# US-005 登录后修改密码

## POINT-002 新密码长度和确认一致性

## [P4] 验证修改密码8位和64位边界有效
- 测试类型
  - 功能
- 前置条件
  1. alice01当前密码Aa123456，已登录。
- 测试步骤
  1. 将新密码设置为Aa12345678并确认一致后提交。
  2. 再次登录后将新密码设置为A123456789012345678901234567890123456789012345678901234567890并确认一致。
- 预期结果
  1. 8位新密码满足8～64字符规则。
  2. 64位新密码满足8～64字符规则。

## [P4][反向] 验证修改密码7位和65位无效
- 测试类型
  - 功能
- 前置条件
  1. alice01已进入修改密码页，当前密码正确。
- 测试步骤
  1. 新密码输入Aa12345，确认密码输入Aa12345并提交。
  2. 新密码输入A1234567890123456789012345678901234567890123456789012345678900，确认密码相同并提交。
- 预期结果
  1. 7位新密码被阻止并显示长度错误。
  2. 65位新密码被阻止并显示长度错误。

## [P3][反向] 验证修改密码确认字段必须完全一致
- 测试类型
  - 功能
- 前置条件
  1. alice01当前密码正确。
- 测试步骤
  1. 新密码输入NewAa1234。
  2. 确认密码输入newaa1234。；点击提交。
- 预期结果
  1. 确认密码大小写不同，校验失败。
  2. 页面停留在修改密码页，密码不发生变化。

## [P2] 验证修改密码眼睛图标不改变字段内容
- 测试类型
  - 易用性
- 前置条件
  1. 已进入修改密码页。
- 测试步骤
  1. 在三个密码字段分别输入Aa123456、NewAa1234、NewAa1234。
  2. 分别点击密码字段眼睛图标。
- 预期结果
  1. 三个字段默认密文展示。
  2. 每个眼睛图标只切换对应字段的明文或密文。；已输入内容不丢失且不会复制到其他字段。
