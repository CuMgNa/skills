# US-005 登录后修改密码

## [P1] 验证已登录用户使用正确当前密码可提交修改
[测试类型] 功能
[前置条件] 海外版个人账号gt_us005_p01状态正常，当前密码为OldPass2026!，已登录并进入“我的 → 修改密码”页面
[测试步骤] 1. 在当前密码输入框输入OldPass2026!。2. 在新密码和确认新密码输入框均输入NewPass2026!。3. 点击提交按钮
[预期结果] 1. 当前密码输入被正常接收且默认以密文展示。2. 三个密码字段通过客户端完整性校验。3. 服务端校验当前密码正确，修改请求成功并提示“密码已修改”

## [P2] 验证未登录状态不能访问修改密码页面
[测试类型] 安全性
[前置条件] 海外版APP未登录，设备中不存在有效Access Token和Refresh Token
[测试步骤] 1. 通过历史页面恢复或页面路由直接尝试打开“修改密码”页面。2. 尝试调用修改密码接口，当前密码输入OldPass2026!，新密码和确认新密码均输入NewPass2026!
[预期结果] 1. APP不展示可操作的修改密码页面，跳转到登录页。2. 接口拒绝未认证请求，不修改任何账号密码，也不返回账号资料或密码校验细节
