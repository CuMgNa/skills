# US-005 登录后修改密码

## POINT-001 登录态和当前密码校验

## [P1] 验证已登录账号可以进入修改密码页面
- 测试类型
  - 功能
- 前置条件
  1. 账号alice01已使用Aa123456登录，Token有效。
- 测试步骤
  1. 进入我的页面。
  2. 点击修改密码。
- 预期结果
  1. 打开修改密码页面。
  2. 页面展示当前密码、新密码和确认新密码字段。

## [P3][反向] 验证未登录访问修改密码被拦截
- 测试类型
  - 安全性
- 前置条件
  1. APP当前处于登录页，无有效Token。
- 测试步骤
  1. 通过页面入口或深链访问修改密码页面。
- 预期结果
  1. 页面跳转登录页。；不展示或不允许提交密码修改表单。

## [P1] 验证当前密码正确才允许修改
- 测试类型
  - 功能
- 前置条件
  1. alice01当前密码Aa123456，已进入修改密码页。
- 测试步骤
  1. 当前密码输入Aa123456。
  2. 新密码输入NewAa1234，确认密码输入NewAa1234。
  3. 点击提交。
- 预期结果
  1. 当前密码校验通过。
  2. 新密码和确认密码校验通过。
  3. 提交密码修改请求。

## [P3][反向] 验证当前密码错误时不修改密码
- 测试类型
  - 安全性
- 前置条件
  1. alice01当前密码Aa123456，已进入修改密码页。
- 测试步骤
  1. 当前密码输入Wrong1234。
  2. 新密码输入NewAa1234，确认密码输入NewAa1234。
  3. 点击提交。
- 预期结果
  1. 服务端拒绝当前密码校验。
  2. 显示当前密码错误提示。
  3. 密码仍为Aa123456，NewAa1234不能登录。
