S10U 协议数据构造器

链路保持（LK） · ICCID 指令 · 位置数据上报（UD / UD_LTE） · 盲点补传（UD2） · 报警数据上报（AL） · 反向解析

单文件纯离线 ASCII 严格校验 LEN 自动计算 数据仅保留在当前页面 可反向逐字段解析

1. 报文类型

LK、ICCID、UD、UD2、UD_LTE、AL 会写回对应指令。其余 3G/4G 命令只解析，不改写成 UD

    2. 包头与位置数据

    厂商固定为 3G；设备 ID 必须为 10 位数字

    写入报文头，对应协议里的设备 ID。文档实例为 0708590578。

    可留空、填 0 或手改。空值、0 和越界仍可复制；含逗号、星号、方括号时只警告。

    3. 终端状态与报警位

    低 16 bit 为状态，高 16 bit 为报警；自动生成 8 位十六进制

    UD / UD2 / UD_LTE 按普通位置数据处理，高 16 位报警必须全部为 0。

    4. 基站信息

    第 1 条为连接基站；后续条目为附近基站

    协议未定义基站最大数量，工具不设置业务上限；为避免浏览器页面失控，最多添加 50 条。

    5. WiFi 信息

    UD / UD2 / AL 最多 5 条。UD_LTE 按实测样例放行到 6 条，SSID 可空
