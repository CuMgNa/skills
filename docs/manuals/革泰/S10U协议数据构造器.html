S10U 协议数据构造器

位置数据上报（UD） · 盲点补传（UD2） · 报警数据上报（AL）

单文件纯离线 ASCII 严格校验 LEN 自动计算 数据仅保留在当前页面

1. 报文类型

三类命令共用同一套位置数据结构

2. 包头与位置数据

厂商固定为 3G；设备 ID 必须为 10 位数字

协议字段 n；必须为大于或等于 0 的数字

3. 终端状态与报警位

低 16 bit 为状态，高 16 bit 为报警；自动生成 8 位十六进制

UD / UD2 严格按普通位置数据处理，高 16 位报警必须全部为 0。

普通状态（低 16 bit）

报警状态（高 16 bit）

Hex00000010
Binary · bit31 → bit00000 0000 0000 0000 0000 0000 0001 0000

4. 基站信息

第 1 条为连接基站；后续条目为附近基站

协议未定义基站最大数量，工具不设置业务上限；为避免浏览器页面失控，最多添加 50 条。

5. WiFi 信息

最多 5 条，建议按信号强度从强到弱排列
