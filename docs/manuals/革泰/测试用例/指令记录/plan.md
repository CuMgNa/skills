- 需求真源：`docs/manuals/革泰/逻辑大纲/革泰 APP 指令记录逻辑点梳理 plan.md` v2.4（2026-10-10）。冲突时以该文 §9「当前有效结论与作废口径」为准。

## 测试对象与边界

### 覆盖范围

- 批量下发指令记录 L1：入口、卡片三行式、四态统计、排序、刷新、分页、无筛选、从 L2 返回、空态与加载异常。
- 批量指令详情 L2：汇总卡、统一制设备卡字段、状态优先排序、筛选弹窗（卡号×状态）、取消、单台重发、一键重发全部失败、失败原因枚举。
- 设备指令记录：入口与页面结构、融合卡字段显隐与版式、列表行为、筛选弹窗（状态×类型）、取消/重发、空态/加载/查询异常。
- 记录归属（按入口）、建单边界、账号隔离、解绑/失权历史归属、永久保留与 30 天丢弃同步、L1/L2 最终一致、UPLOAD 联动结论。

### 不覆盖或不写死的内容

- 指令投递通道、终端协议、回文产生与串扰匹配（见 S10U / PN06）。
- 下发前三道闸门细节（见下发 plan），本用例集只验证记录侧结果。
- 失败原因的最终措辞：真源只定枚举占位，用例统一断言“前端原样展示接口返回的失败原因字段”，示例文案仅作为测试桩数据。
- 设备详情页定位频率编辑控件自身的展示与视觉方案。
- 非 prod 环境白名单限制：真源标注为占位，只验证“禁止下发并作为失败原因展示”，不写死文案。

### 待确认项与执行处理

| 待确认项 | 本用例集处理 |
| --- | --- |
| L2 同状态内“按发送时间/卡号次序”的升降序未明确 | 只断言状态分组顺序和刷新后顺序稳定，不写死同组内升降序。 |
| L2「重发全部失败（N）」在筛选生效时 N 是全部失败数还是筛选结果内失败数 | 本用例集只在未筛选场景断言 N，筛选场景不断言。 |
| L2 卡片中非失败态是否显示“失败时间”占位 | 依据版式图与“仅失败卡片多一个失败原因”，只断言非失败卡不出现失败时间的具体时间值与失败原因。 |
| 批量页（L1/L2）首屏加载、查询异常的具体表现 | 真源 §1.1 要求两页共通，细节仅在 §4.6 给出；批量页用例按 §4.6 口径验证（骨架屏、错误态+重新加载、刷新失败保留旧数据），具体文案不写死。 |
| L1 与 L2 最终一致的同步时限 | 断言“同步时限内最终一致”，时限数值执行前向后端确认。 |
| 反馈内容超长的折叠阈值字数 | 只用明显超长文本与明显短文本验证有/无展开控件，不写死阈值。 |
| 记录页时间展示使用的时区 | 真源未定义，由 US-029 管辖，本用例集创建时间使用 APP 当前展示时区下的同一值，不单独验证时区转换。 |
