# US-034-C 归属隔离与联动

> 口径依据：指令记录大纲 §2.2 统一建单边界、§2.3。APP 本地格式校验未通过、请求未发出时不创建后台记录；用户已确认且请求到达服务端后，只要能识别账号、设备和操作意图，无论后续校验成功或失败均创建记录；服务端权限、关系、路由、型号、参数、容量或高危会话复检失败时记录直接进入 FAILURE；批量最终目标范围内每台设备必须建立明细，失败设备不得静默丢失；单设备结果未知时进入“正在确认提交结果”，用原幂等标识查询，确认期间禁止重复创建新指令。
>
> 数据约定：GT-REC-E1 绑定 D001（在线）、D002（离线）、D003（在线）、D004（离线）、D005（在线，用于异常场景）。

## [P1] 验证本地格式校验未通过不创建记录
- 测试类型
  - 功能
- 前置条件
  1. GT-REC-E1 进入 D001 单设备下发页，选择“设置上传间隔”，参数留空；设备指令记录页当前 0 条记录
- 测试步骤
  1. 点击提交。
  2. 查看页面提示与网络请求。
  3. 进入设备指令记录页。
- 预期结果
  1. 本地校验未通过，出现参数必填类提示，不弹出二次确认。
  2. 无下发请求发出到服务端。
  3. 设备指令记录页显示“暂无指令记录”，无新增记录。

## [P1][反向] 验证请求到达服务端后校验失败仍创建失败记录
- 测试类型
  - 功能
- 前置条件
  1. GT-REC-E1 在 D005 单设备下发页选择“设置上传间隔 600 秒”，服务端返回失败原因“当前型号不支持该指令”
- 测试步骤
  1. 提交并确认。
  2. 进入 D005 设备指令记录页。
  3. 查看新卡。
- 预期结果
  1. 请求到达服务端，校验失败。
  2. 设备指令记录页出现 1 张新卡。
  3. 新卡状态“失败”，失败原因“当前型号不支持该指令”，发送时间“—”，按钮为“重新发送”。

## [P1] 验证服务端权限关系路由型号参数容量失败均进入失败记录
- 测试类型
  - 功能
- 前置条件
  1. 通过测试桩依次令服务端返回：账号对该设备无操作权限、S10U 路由缺失无法下发、当前型号不支持该指令、参数不合法、下发队列容量已满
- 测试步骤
  1. 对 D001 单设备下发，服务端返回“账号对该设备无操作权限”。
  2. 对 D001 单设备下发，服务端返回“S10U 路由缺失，无法下发”。
  3. 对 D001 单设备下发，服务端返回“当前型号不支持该指令”。
  4. 对 D001 单设备下发，服务端返回“参数不合法”。
  5. 对 D001 单设备下发，服务端返回“下发队列容量已满”，然后进入 D001 设备指令记录页。
- 预期结果
  1. 请求到达服务端后创建记录，直接为失败。
  2. 创建记录，直接为失败。
  3. 创建记录，直接为失败。
  4. 创建记录，直接为失败。
  5. 设备指令记录页共 5 张卡，状态均为“失败”，失败原因依次为各自接口返回文案，原样展示。

## [P1] 验证批量流程每台设备都建立明细失败设备不丢失
- 测试类型
  - 功能
- 前置条件
  1. GT-REC-E1 批量选择 D001、D002、D003、D004、D005 五台，下发“设置上传间隔 600 秒”；服务端对 D003、D005 返回校验失败（原因“当前型号不支持该指令”、“S10U 路由缺失，无法下发”），其余受理
- 测试步骤
  1. 提交并确认，查看结果弹窗。
  2. 点击“查看记录”，进入 L1 后点击该记录进入 L2。
  3. 查看汇总卡与设备卡数量、失败卡内容。
- 预期结果
  1. 弹窗显示部分受理，含“查看记录”与“完成”。
  2. 进入该批次 L2。
  3. 汇总卡台数 5，设备卡 5 张；D003、D005 为“失败”并分别显示各自失败原因，其余 3 台为发送中或已发送，失败设备未被静默丢弃。

## [P1] 验证批量全部失败仍有批量记录与全部明细
- 测试类型
  - 功能
- 前置条件
  1. GT-REC-E1 批量选择 D001、D003 两台，服务端对两台均返回校验失败“当前型号不支持该指令”
- 测试步骤
  1. 提交并确认，查看结果弹窗。
  2. 点击“查看记录”，进入 L1，点击该记录进入 L2。
- 预期结果
  1. 弹窗显示全部失败，含“查看记录”与“完成”。
  2. L1 有 1 条“台数 2”的记录，统计“发送中 0 · 已发送 0 · 失败 2 · 已取消 0”；L2 有 2 张失败卡，均有失败原因。

## [P1] 验证高危会话复检失败直接创建失败记录
- 测试类型
  - 功能
- 前置条件
  1. GT-REC-E1 对离线 D004 通过 Send Command 下发远程重启，服务端复检无当前可写会话
- 测试步骤
  1. 提交并确认。
  2. 进入 D004 设备指令记录页，查看新卡。
- 预期结果
  1. 请求到达服务端，复检失败。
  2. 新卡状态“失败”，失败原因“无当前可写会话”，未进入发送中，按钮为“重新发送”。

## [P2] 验证单设备结果未知时确认期间不重复创建且最终仅1条记录
- 测试类型
  - 可靠性
- 前置条件
  1. GT-REC-E1 在 D001 下发“查找设备”，提交时请求超时无响应，但服务端实际已受理
- 测试步骤
  1. 点击提交并确认，等待超时。
  2. 在“正在确认提交结果”状态下尝试再次点击提交。
  3. 等待用原幂等标识查询完成，进入 D001 设备指令记录页。
- 预期结果
  1. 页面进入“正在确认提交结果”状态。
  2. 提交按钮不可用，无法重复创建新指令。
  3. 确认后给出受理结果提示；设备指令记录页仅有 1 张“查找设备”卡，无重复记录。
