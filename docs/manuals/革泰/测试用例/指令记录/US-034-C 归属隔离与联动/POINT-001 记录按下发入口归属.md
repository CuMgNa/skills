# US-034-C 归属隔离与联动

> 口径依据：指令记录大纲 §2.2。记录产生自哪个下发流程就归哪个页面，与设备数量无关：设备管理 → 指令下发批量流程（含只选 1 台）→ 1 条批量记录 → 批量下发指令记录；设备卡片更多菜单 → Send Command（七类）→ 每次 1 条单设备记录 → 设备指令记录；设备详情 → Edit → Location Interval → Save（UPLOAD）→ 1 条单设备记录 → 设备指令记录。批量页只收批量流程记录，单设备页只收单设备入口记录；设备被批量下发波及不会在其设备指令记录页出现该记录。
>
> 数据约定：GT-REC-E1 绑定 GT-REC-D001、D003、D005 且均在线。

## [P1] 验证批量流程多台下发只产生批量记录
- 测试类型
  - 功能
- 前置条件
  1. GT-REC-E1 的 D001、D003、D005 在线，三台的设备指令记录页与批量页当前均无相关记录
- 测试步骤
  1. 在设备管理中选择 D001、D003、D005，通过批量指令下发流程下发“设置上传间隔 600 秒”并确认。
  2. 进入“我的 → 批量下发指令记录”，查看 L1。
  3. 分别进入 D001、D003、D005 的设备指令记录页。
- 预期结果
  1. 批量提交成功受理。
  2. L1 出现 1 条“上报间隔600秒（3台）”记录。
  3. 三台设备的设备指令记录页均显示“暂无指令记录”，该批量记录不在其中。

## [P1] 验证批量流程只选1台仍进入批量页
- 测试类型
  - 功能
- 前置条件
  1. GT-REC-E1 的 D001 在线，D001 设备指令记录页为空
- 测试步骤
  1. 在设备管理批量流程中只选择 D001，下发“设置上传间隔 600 秒”并确认。
  2. 进入 L1，查看记录。
  3. 进入 D001 的设备指令记录页。
- 预期结果
  1. 批量提交成功。
  2. L1 新增 1 条“上报间隔600秒（1台）”记录。
  3. D001 设备指令记录页显示“暂无指令记录”，不因只选 1 台而归入设备页。

## [P1] 验证Send Command七类指令均归入设备指令记录页
- 测试类型
  - 功能
- 前置条件
  1. GT-REC-E1 的 D001 在线；批量页当前无记录
- 测试步骤
  1. 通过 Send Command 向 D001 下发立即定位。
  2. 通过 Send Command 向 D001 下发查询版本。
  3. 通过 Send Command 向 D001 下发查找设备。
  4. 通过 Send Command 向 D001 下发设置上传间隔 600 秒。
  5. 通过 Send Command 向 D001 下发设置设备时区 UTC+08:00。
  6. 通过 Send Command 向 D001 下发远程重启。
  7. 通过 Send Command 向 D001 下发远程关机，然后查看 D001 设备指令记录页与批量 L1。
- 预期结果
  1. 提交成功，产生 1 条单设备记录。
  2. 提交成功，产生 1 条单设备记录。
  3. 提交成功，产生 1 条单设备记录。
  4. 提交成功，产生 1 条单设备记录。
  5. 提交成功，产生 1 条单设备记录。
  6. 提交成功，产生 1 条单设备记录。
  7. 设备指令记录页共 7 张独立卡片，类型各不相同；批量 L1 显示“暂无指令记录”，7 次单设备下发均不在批量页。

## [P1] 验证设备详情定位频率保存产生的UPLOAD归入设备指令记录页
- 测试类型
  - 功能
- 前置条件
  1. GT-REC-E1 的 D001 在线，当前确认值 10 分钟；设备指令记录页与批量页均无记录
- 测试步骤
  1. 进入 D001 设备详情 → Edit → Location Interval，选择 60 分钟，点击 Save。
  2. 进入 D001 设备指令记录页，查看记录。
  3. 进入批量 L1。
- 预期结果
  1. 保存请求提交，产生 1 条 UPLOAD 记录。
  2. 设备指令记录页显示 1 张卡：类型“设置上传间隔”，内容对应 3600 秒，创建时间为保存时间。
  3. 批量 L1 无该记录。

## [P1] 验证设备被批量波及不在其设备指令记录页出现
- 测试类型
  - 功能
- 前置条件
  1. GT-REC-E1 对 D001 通过 Send Command 下发过 1 条查询版本（R-S1）；随后在批量流程中对 D001、D003 下发“设置上传间隔 600 秒”（R-B1）
- 测试步骤
  1. 进入 D001 设备指令记录页，查看卡片。
  2. 进入 L1，点击 R-B1 进入 L2，查看设备卡片。
- 预期结果
  1. D001 设备指令记录页仅有 R-S1 一张卡，不含 R-B1。
  2. R-B1 的 L2 包含 D001、D003 两张设备明细，D001 的明细只在批量 L2 中可见。

## [P2] 验证同一设备批量与单设备记录各归其页互不混入
- 测试类型
  - 功能
- 前置条件
  1. GT-REC-E1 对 D001 在同一天先通过批量流程下发“设置上传间隔 600 秒”（R-B1，D001 与 D003），再通过 Send Command 下发“设置上传间隔 600 秒”（R-S1，仅 D001），两次指令与参数完全相同
- 测试步骤
  1. 进入 L1，查看记录数量。
  2. 进入 D001 设备指令记录页，查看记录数量。
- 预期结果
  1. L1 有 1 条 R-B1，不含 R-S1。
  2. 设备指令记录页有 1 条 R-S1，不含 R-B1，两者不被合并。

## [P2] 验证批量页不含UPLOAD详情保存记录
- 测试类型
  - 功能
- 前置条件
  1. GT-REC-E1 在 D001、D003 的设备详情中各保存 1 次定位频率 60 分钟
- 测试步骤
  1. 进入批量 L1，查看记录。
  2. 分别进入 D001、D003 设备指令记录页。
- 预期结果
  1. L1 无这两次保存产生的记录。
  2. D001、D003 设备指令记录页各有 1 张“设置上传间隔”卡。
