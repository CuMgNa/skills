# US-034-A 批量下发指令记录

> 口径依据：指令记录大纲 §2.1、§2.3、§9.1 第 3 条。批量下发指令记录（L1）入口为“我的模块”与批量提交结果弹窗“查看记录”；弹窗三种结果均显示“查看记录”与“完成”；“查看记录”进入 L1 刷新全量记录，不定位、不高亮、不预置筛选；“完成”或关闭清空本次操作并返回设备列表。

## [P1] 验证从我的模块进入L1默认查询当前账号全部批量记录
- 测试类型
  - 功能
- 前置条件
  1. GT-REC-E1 已登录，名下有 3 条批量记录：BATCH-A01（UPLOAD 600 秒，5 台，创建时间 2026-10-12 15:00:21）、BATCH-A02（CR，3 台，创建时间 2026-10-12 14:00:00）、BATCH-A03（FIND，2 台，创建时间 2026-10-12 10:00:05）
  2. GT-REC-E1 另有 3 条单设备入口下发的设备指令记录
- 测试步骤
  1. 进入“我的模块”，点击“批量下发指令记录”。
  2. 查看列表卡片数量、排列顺序和页头操作。
  3. 核对列表中是否出现单设备入口产生的记录。
- 预期结果
  1. 进入批量下发指令记录 L1，页面标题为“批量下发指令记录”。
  2. 列表显示 BATCH-A01、BATCH-A02、BATCH-A03 共 3 张卡片，创建时间倒序，页头无筛选入口。
  3. 3 条单设备入口记录均不出现在 L1。

## [P1] 验证三种批量结果弹窗的查看记录均进入L1全量刷新且不定位高亮不预置筛选
- 测试类型
  - 功能
- 前置条件
  1. GT-REC-E1 名下已有历史批量记录 BATCH-H01、BATCH-H02
  2. 可分别触发全部受理（GT-REC-D001、GT-REC-D003）、部分受理（GT-REC-D001 成功、GT-REC-D005 因 S10U 路由缺失失败）、全部失败（GT-REC-D005 单台失败）三种批量结果弹窗
- 测试步骤
  1. 触发全部受理弹窗，查看按钮后点击“查看记录”。
  2. 返回设备列表后触发部分受理弹窗，点击“查看记录”。
  3. 返回设备列表后触发全部失败弹窗，点击“查看记录”。
  4. 每次进入 L1 后检查筛选区、高亮状态、列表滚动位置和记录范围。
- 预期结果
  1. 全部受理弹窗同时显示“查看记录”与“完成”，点击后进入 L1 并刷新全量记录。
  2. 部分受理弹窗同时显示“查看记录”与“完成”，进入 L1 刷新全量记录，不携带失败筛选。
  3. 全部失败弹窗同时显示“查看记录”与“完成”，进入 L1 刷新全量记录。
  4. 三次进入 L1 均无筛选、无高亮、不定位到本次记录；本次新记录按创建时间倒序位于列表顶部，BATCH-H01、BATCH-H02 等历史记录同时可见。

## [P2] 验证完成按钮与关闭按钮清空本次操作并返回设备列表
- 测试类型
  - 易用性
- 前置条件
  1. 两次批量下发均选择 GT-REC-D001、GT-REC-D003，指令 UPLOAD，参数 600 秒，结果弹窗内容相同
- 测试步骤
  1. 在第一个结果弹窗点击“完成”，返回后查看设备列表选择态。
  2. 在第二个结果弹窗点击右上角关闭按钮，返回后查看设备列表选择态。
  3. 再次进入批量下发流程，查看设备、指令与参数的初始值。
- 预期结果
  1. “完成”返回设备列表，已选设备、指令和参数被清空，退出多选模式。
  2. 关闭按钮的返回与清理结果与“完成”完全一致。
  3. 再次进入流程时设备未选中，指令与参数为空，不保留 600 秒。

## [P2] 验证批量流程只选一台设备时记录仍进入批量页
- 测试类型
  - 功能
- 前置条件
  1. GT-REC-E1 通过设备管理批量流程仅选择 GT-REC-D001，指令 UPLOAD，参数 600 秒，并提交成功
- 测试步骤
  1. 在结果弹窗点击“查看记录”，查看 L1 最新卡片。
  2. 进入 GT-REC-D001 的单设备下发页，点击底部“指令记录”。
  3. 查看设备指令记录页是否出现本次记录。
- 预期结果
  1. L1 顶部出现 1 张卡片，行 1 显示“上报间隔600秒（1台）”。
  2. 可进入 GT-REC-D001 的设备指令记录页。
  3. 设备指令记录页不出现本次批量记录，按入口归属而非按设备台数判定。

## [P3] 验证全部失败的批量提交在L1仍有记录且失败数守恒
- 测试类型
  - 可靠性
- 前置条件
  1. GT-REC-E1 批量选择 GT-REC-D005、GT-REC-D004、GT-REC-D002，三台均因服务端校验失败（S10U 路由缺失、型号不支持、账号关系失效各 1 台）
  2. 结果弹窗显示全部失败
- 测试步骤
  1. 点击“查看记录”进入 L1。
  2. 查看最新卡片的行 1 和行 2。
  3. 点击该卡片进入 L2，核对设备明细数量。
- 预期结果
  1. 进入 L1，不因 0 台受理而没有本次记录。
  2. 行 1 显示指令语义化内容与“（3台）”，行 2 显示“发送中 0 · 已发送 0 · 失败 3 · 已取消 0”。
  3. L2 存在 3 张设备卡，状态均为失败，失败设备未被静默丢失。
