# US-034-B 设备指令记录

> 口径依据：指令记录大纲 §4.4。右上角筛选图标 → 底部弹窗；维度为状态（4 态单选）× 指令类型（七类单选），两条件交集；无“全部”选项（空选即不限）；初始为空；按钮为重置 + 应用筛选；无卡号维度；重置清空本次勾选；应用 loading 防重；关闭未应用丢弃；回显当前生效条件；生效条件仅弹窗内可见（含筛选图标无角标）；筛选无结果“未筛选到相关指令记录”。
>
> 数据约定：GT-REC-D001 有 8 条记录：R1 立即定位·已发送、R2 查询版本·失败、R3 查找设备·已发送、R4 设置上传间隔·发送中、R5 设置设备时区·已取消、R6 远程重启·失败、R7 远程关机·已发送、R8 设置上传间隔·失败。

## [P1] 验证弹窗结构仅含状态与类型且无全部选项无卡号
- 测试类型
  - 功能
- 前置条件
  1. 已进入 GT-REC-D001 的设备指令记录页，无筛选
- 测试步骤
  1. 点击右上角筛选图标。
  2. 查看弹窗位置与筛选项。
  3. 查看各项初始选中状态。
- 预期结果
  1. 底部弹出筛选弹窗。
  2. 弹窗含状态 4 项（发送中、已发送、失败、已取消）、指令类型 7 项（立即定位、查询版本、查找设备、设置上传间隔、设置设备时区、远程重启、远程关机）、“重置”和“应用筛选”按钮；无“全部”选项，无卡号输入。
  3. 状态与类型均无选中项。

## [P2] 验证重置只清空本次勾选
