# US-034-B 设备指令记录

> 口径依据：指令记录大纲 §4.2。融合卡字段：指令类型、指令内容（语义化，非协议原文）、状态、创建时间恒显；发送时间恒显，未发出为“—”；失败时间、失败原因仅失败态显示；反馈内容、反馈时间恒显，无回文“—”；“已重发 N 次”重发过才显示；按钮：发送中=取消发送、失败=重新发送、已发送/已取消无按钮。
>
> 数据约定：GT-REC-D001 在设备指令记录页的记录均为 UPLOAD（类型“设置上传间隔”，内容“上报间隔 600 秒”）。
