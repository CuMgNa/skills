# US-034-B 设备指令记录

> 口径依据：指令记录大纲 §2.1、§2.3、§4.1。设备指令记录为单层页，唯一入口为设备更多菜单 → Send Command → 单设备下发页底部“指令记录”（始终显示）；返回回到原下发页，不主动重置指令与参数；页头为返回 + 标题“设备指令记录” + 右上筛选图标；设备身份行有备注显示“备注（卡号）”，无备注仅显示卡号；不显示在线/服务状态；无顶部汇总卡；点卡片不进二级页。
>
> 数据约定：GT-REC-D001 备注“张三的车”，卡号 106480001234，在线；GT-REC-D004 无备注，卡号 106480003456，离线。

## [P1] 验证设备指令记录唯一入口为下发页底部指令记录
- 测试类型
  - 功能
- 前置条件
  1. GT-REC-E1 已登录，设备列表含 GT-REC-D001
- 测试步骤
  1. 点击 GT-REC-D001 卡片更多菜单，查看菜单项。
  2. 点击 Send Command，进入单设备下发页，查看页面底部。
  3. 点击底部“指令记录”。
- 预期结果
  1. 更多菜单中有进入下发页的 Send Command，无直接进入“设备指令记录”的菜单项。
  2. 单设备下发页底部显示“指令记录”入口。
  3. 进入“设备指令记录”页，页头标题为“设备指令记录”。

## [P1] 验证离线设备仍可进入下发页并查看记录
- 测试类型
  - 功能
- 前置条件
  1. GT-REC-D004 离线，GT-REC-E1 此前对其下发过 1 条上报间隔 600 秒指令
- 测试步骤
  1. 点击 GT-REC-D004 卡片更多菜单 → Send Command。
  2. 在下发页底部点击“指令记录”。
- 预期结果
  1. 离线设备可进入单设备下发页，底部“指令记录”入口显示。
  2. 记录页显示该条记录，可正常查看。

## [P1] 验证页头与有备注设备身份行
- 测试类型
  - 功能
- 前置条件
  1. GT-REC-D001 备注“张三的车”
- 测试步骤
  1. 进入 GT-REC-D001 的设备指令记录页。
  2. 查看页头左上角、标题、右上角图标。
  3. 查看页头下方设备身份行。
- 预期结果
  1. 页面打开。
  2. 左上角为返回，标题“设备指令记录”，右上角为筛选图标。
  3. 设备身份行显示“张三的车（1064****1234）”。

## [P1] 验证无备注设备仅显示卡号且不显示实时状态
- 测试类型
  - 功能
- 前置条件
  1. GT-REC-D004 无备注，离线，服务状态正常
- 测试步骤
  1. 进入 GT-REC-D004 的设备指令记录页。
  2. 查看设备身份行。
  3. 在页面内查找在线状态和服务状态展示。
- 预期结果
  1. 页面打开。
  2. 设备身份行仅显示“1064****3456”，无括号与备注。
  3. 页面任何位置无“离线”“在线”“服务正常/过期”等设备实时状态文案。

## [P2] 验证无顶部汇总卡且点击卡片不进入二级页
- 测试类型
  - 功能
- 前置条件
  1. GT-REC-D001 在设备指令记录页有 3 条记录
- 测试步骤
  1. 进入 GT-REC-D001 的设备指令记录页，查看页头下方区域。
  2. 点击第 1 张卡片的指令内容区域。
  3. 点击第 1 张卡片的空白区域。
- 预期结果
  1. 页头下方直接是融合卡列表，无“发送中 · 已发送 · 失败 · 已取消”汇总卡。
  2. 页面不跳转，仍停留在设备指令记录页。
  3. 页面不跳转，仍停留在设备指令记录页，卡片内容不变。

## [P2] 验证返回回到下发页且指令与参数不重置
- 测试类型
  - 功能
- 前置条件
  1. 已进入 GT-REC-D001 的单设备下发页，选择“设置上传间隔”并填入 300 秒，未提交
- 测试步骤
  1. 点击底部“指令记录”进入记录页。
  2. 点击左上角返回。
  3. 查看下发页指令选择和参数。
- 预期结果
  1. 进入设备指令记录页。
  2. 返回单设备下发页，不跳到设备列表。
  3. 指令仍为“设置上传间隔”，参数仍为 300 秒，未被重置。

## [P2] 验证记录页不出现新的下发入口
- 测试类型
  - 功能
- 前置条件
  1. GT-REC-D001 在设备指令记录页有失败、发送中、已发送记录各 1 条
- 测试步骤
  1. 进入设备指令记录页，查看页面所有可点击控件。
- 预期结果
  1. 页面仅有返回、筛选图标、卡片内的“取消发送”“重新发送”、反馈内容展开收起控件，无新建下发指令的入口。
