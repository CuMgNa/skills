# US-031 退出并清理当前会话

## [P1] 验证登录账号主动退出后结束当前会话并返回登录页
- 测试类型
  - 功能
- 前置条件
  1. 海外版个人账号 ranch_owner_01（accountId=P001，密码 Ranch@2026）已登录并进入地图首页，当前可见设备 GT-S10U-0001
- 测试步骤
  1. 进入“我的”页面并点击“退出登录”
  2. 在退出确认弹窗中点击“确认”
  3. 观察页面落点并检查当前登录态
  4. 点击系统返回键尝试返回退出前页面
- 预期结果
  1. 页面展示退出登录入口并可正常触发
  2. 当前账号会话结束，退出动作只生效一次
  3. APP 返回登录页，不再显示地图首页、设备 GT-S10U-0001 或账号资料
  4. 仍停留在登录流程，不能返回已登录业务页面

## [P2] 验证取消退出登录后保持当前会话和业务页面
- 测试类型
  - 易用性
- 前置条件
  1. 海外版企业一级账号 ranch_admin_01（accountId=E001）已登录，地图首页展示设备 GT-S10U-1001
- 测试步骤
  1. 进入“我的”页面并点击“退出登录”
  2. 在退出确认弹窗中点击“取消”
  3. 返回地图首页查看当前账号及设备数据
- 预期结果
  1. 正常展示退出确认弹窗，当前会话尚未结束
  2. 弹窗关闭且不发送退出提交，不跳转登录页
  3. 仍为 accountId=E001 的登录态，设备 GT-S10U-1001 正常展示

## [P3][反向] 验证连续点击退出不会产生重复副作用或异常页面
- 测试类型
  - 可靠性
- 前置条件
  1. 国内版个人账号（手机号 13800138000，accountId=P138，密码 China@2026）已登录，网络延迟为 800ms
- 测试步骤
  1. 进入“我的”页面并快速连续点击两次“退出登录”
  2. 在确认弹窗中快速连续点击两次“确认”
  3. 等待退出请求完成并观察页面
  4. 重新打开 APP 检查登录状态
- 预期结果
  1. 最多展示一个退出确认弹窗，不叠加重复弹窗
  2. 仅执行一次有效退出，不出现重复跳转、崩溃或错误提示叠加
  3. 最终稳定停留在登录页且当前会话已结束
  4. 仍需重新认证，不能恢复 accountId=P138 的旧会话

## [P3][反向] 验证退出后通过历史页面和业务深链不能绕过重新认证
- 测试类型
  - 安全性
- 前置条件
  1. 海外版个人账号 ranch_owner_01（accountId=P001）已登录并访问设备详情 GT-S10U-0001，已准备该设备详情深链 gtapp://device/GT-S10U-0001
- 测试步骤
  1. 主动退出登录并确认已返回登录页
  2. 从系统最近任务尝试恢复退出前的设备详情页面
  3. 从外部打开深链 gtapp://device/GT-S10U-0001
  4. 观察是否能读取设备详情接口和页面数据
- 预期结果
  1. accountId=P001 的当前会话结束且登录页正常显示
  2. 不恢复退出前的已登录页面，仍进入登录流程
  3. 深链被认证门禁拦截并落到登录页，不直接打开设备详情
  4. 不展示设备名称、位置、轨迹或告警数据，业务数据必须在重新认证后才能访问

## [P3][反向] 验证退出请求响应异常时客户端仍清除本地登录态
- 测试类型
  - 可靠性
- 前置条件
  1. 海外版个人账号 ranch_owner_02（accountId=P002）已登录，模拟退出接口返回 HTTP 500
- 测试步骤
  1. 进入“我的”页面点击“退出登录”并确认
  2. 等待退出接口返回 HTTP 500
  3. 观察页面落点并检查本地当前账号状态
  4. 关闭并重新启动 APP
- 预期结果
  1. APP 发起退出流程并禁止继续提交重复退出
  2. 服务端退出失败不阻止本地会话清理，不继续保留可用登录态
  3. 返回登录页且不再展示 accountId=P002 的业务页面
  4. 冷启动后仍停留在登录流程，不使用旧会话自动进入首页
