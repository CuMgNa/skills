# US-031 退出并清理当前会话

## [P1] 验证不同账号的业务缓存按 accountId 隔离
- 测试类型
  - 安全性
- 前置条件
  1. 账号 A ranch_owner_01（accountId=P001）拥有设备 GT-S10U-0001 和围栏 FENCE-P001-01；账号 B ranch_owner_02（accountId=P002）拥有设备 GT-S10U-0002 和围栏 FENCE-P002-01
- 测试步骤
  1. 登录账号 A 并完成设备、围栏和告警数据加载
  2. 退出账号 A
  3. 登录账号 B 并完成数据加载
  4. 检查本地缓存键、页面列表和详情入口对应的 accountId
- 预期结果
  1. 数据写入 accountId=P001 对应缓存，不使用账号名或设备号作为账户主键
  2. 退出时清理或失活 P001 的会话展示数据
  3. 账号 B 仅从 accountId=P002 对应空间重建数据
  4. 页面仅展示 GT-S10U-0002 和 FENCE-P002-01，不能访问 P001 的缓存或详情

## [P1] 验证同手机号个人与企业双账号切换时不串 Token 和数据
- 测试类型
  - 安全性
- 前置条件
  1. 国内版手机号 13800138000 对应个人账号 accountId=P138、设备 GT-S10U-P138；企业账号 accountId=E138、设备 GT-S10U-E138，两账号密码均为 China@2026
- 测试步骤
  1. 选择“个人”登录 P138 并记录当前 Token 中的 accountId 和设备列表
  2. 退出个人账号
  3. 使用同一手机号选择“企业”登录 E138
  4. 检查新 Token、用户资料、设备列表和接口请求身份
- 预期结果
  1. Token 身份为 accountId=P138，页面仅展示 GT-S10U-P138
  2. P138 的 Access Token、Refresh Token 和业务展示数据不再作为当前会话使用
  3. 新会话身份为 accountId=E138，不复用个人账号 Token
  4. 所有请求携带 E138 会话身份且仅展示 GT-S10U-E138，不因手机号相同混入个人数据

## [P2] 验证海外账号名与邮箱登录同一 accountId 时使用同一账号偏好
- 测试类型
  - 功能
- 前置条件
  1. 海外版账号 accountId=P002 同时具有账号名 ranch_owner_02、邮箱 owner02@example.com，已保存时区 GMT-5:00 New York
- 测试步骤
  1. 使用账号名 ranch_owner_02 登录并确认时区为 GMT-5:00 New York
  2. 退出登录
  3. 改用邮箱 owner02@example.com 登录同一账号
  4. 检查 accountId、时区和业务数据范围
- 预期结果
  1. 登录解析到 accountId=P002 并应用该账号时区
  2. 当前会话结束但 P002 的账号级偏好保持可供下次认证后使用
  3. 邮箱登录仍解析到 accountId=P002，不创建第二套账号空间
  4. 时区仍为 GMT-5:00 New York，设备与权限范围和账号名登录一致

## [P1] 验证不同账号的时区与登录偏好互不覆盖
- 测试类型
  - 功能
- 前置条件
  1. 账号 A accountId=P001 保存时区 GMT+8:00 Beijing、登录标识 ranch_owner_01；账号 B accountId=P002 保存时区 GMT-5:00 New York、登录标识 owner02@example.com
- 测试步骤
  1. 登录账号 A 并核对时区后退出
  2. 登录账号 B 并核对时区与登录标识后退出
  3. 再次登录账号 A
  4. 检查日期边界、时区和登录偏好
- 预期结果
  1. A 使用 GMT+8:00 Beijing，退出后不把偏好写入 B 的 accountId 空间
  2. B 使用 GMT-5:00 New York 且退出页回显 owner02@example.com
  3. A 重新认证后读取 accountId=P001 的偏好
  4. A 的时区恢复 GMT+8:00 Beijing，今日边界按该时区计算，不继承 B 的时区或邮箱偏好

## [P3][反向] 验证上一账号在途请求回包不会覆盖新账号页面
- 测试类型
  - 可靠性
- 前置条件
  1. 账号 A accountId=P001 的设备分页第 2 页请求延迟 3 秒并将返回 GT-S10U-A009；账号 B accountId=P002 的设备列表仅含 GT-S10U-B001
- 测试步骤
  1. 登录账号 A 并发起设备分页第 2 页请求
  2. 在请求返回前退出账号 A 并立即登录账号 B
  3. 等待账号 A 的延迟响应返回
  4. 检查账号 B 的设备列表、缓存和分页状态
- 预期结果
  1. 请求绑定 accountId=P001 和 A 的会话世代标识
  2. 切换后建立 accountId=P002 新会话并使 A 的请求结果失效
  3. 延迟响应被丢弃，不写入当前页面或 P002 缓存
  4. 仅展示 GT-S10U-B001，分页状态不包含 A 的游标或 GT-S10U-A009

## [P3][反向] 验证首次登录新账号不继承上一账号的页面恢复状态
- 测试类型
  - 安全性
- 前置条件
  1. 账号 A accountId=P001 退出前停留在告警详情 ALARM-P001-001；账号 C accountId=P003 从未在该设备登录且没有告警数据
- 测试步骤
  1. 退出账号 A
  2. 首次登录账号 C
  3. 将 APP 切到后台后再恢复前台
  4. 检查首页落点、页面恢复状态和空数据提示
- 预期结果
  1. A 的详情页恢复状态随当前会话被清理
  2. C 按 accountId=P003 创建全新偏好和业务缓存空间
  3. 后台恢复仍属于 C 的当前会话，不恢复 A 的页面
  4. 不显示 ALARM-P001-001，按 C 的权限展示无告警空态或 C 自有首页
