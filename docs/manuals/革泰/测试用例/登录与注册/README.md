## 口径说明

- 国内/海外差异文档优先处理互斥规则。
- 注册成功后不自动登录，返回空白登录页；国内版账号类型切回个人。
- 过期账号本身直接拦截；父级过期不自动导致有效子账号过期。
- APP 密码错误不累计平台锁定且不建立本地自锁；平台已锁定账号在 APP 同步拦截，并保留服务端防暴力破解测试。
- 海外版设置新密码为 8～64 字符，国内版为 8～30 字符；登录密码输入需兼容账号体系 64 字符上限。
- 验证码在账号创建或密码修改业务成功后原子消费。
