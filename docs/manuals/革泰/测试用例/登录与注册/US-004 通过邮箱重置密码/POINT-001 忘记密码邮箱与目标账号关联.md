- 测试类型
  - 功能
- 前置条件
  1. 海外个人账号 accountId=P1001，账号名 rancher_us_01，关联邮箱 rancher.us@gmail.com，邮箱状态正常且账号可用
- 测试步骤

  2. 查询验证码发送记录中的目标邮箱、用途和目标 accountId

  2. 发送记录的目标邮箱为 rancher.us@gmail.com、用途为密码重置、目标 accountId 为 P1001，未关联到其他账号

## [P3][反向] 验证未注册邮箱使用通用提示避免账号枚举
- 测试类型
  - 安全性
- 前置条件
  1. unregistered.reset@proton.me 未关联任何个人或企业账号，系统可查看邮件投递记录
- 测试步骤
  1. 在海外版忘记密码页输入 unregistered.reset@proton.me 并点击 Get Code
  2. 对比已注册邮箱 rancher.us@gmail.com 发起相同操作时的页面响应结构、状态和提示
  3. 查询邮件投递及验证码存储记录
- 预期结果
  1. 页面显示通用提示“If the email is associated with an account, a verification code has been sent.”，最终文案待产品安全定稿，不明确提示邮箱未注册
  2. 两次请求的外部可见响应结构、状态和提示一致，不能据此判断账号是否存在
  3. 未注册邮箱不实际发送邮件、不生成可用验证码且不关联任何 accountId
