# US-004 通过邮箱重置密码

## [P4] 验证海外版新密码 8 字符下边界可重置
- 测试类型
  - 功能
- 前置条件
  1. 海外个人账号 P1001 已取得有效密码重置验证码 482731，原密码为 OldPass123!
- 测试步骤
  1. 输入新密码 Aa1!bcde 和确认密码 Aa1!bcde
  2. 提交密码重置
- 预期结果
  1. 两个输入均为 8 字符且完全一致，字段校验通过
  2. 密码重置成功，P1001 的新密码为 Aa1!bcde

## [P3][反向] 验证确认密码与新密码不完全一致时不能重置
- 测试类型
  - 功能
- 前置条件
  1. 海外个人账号 P1002 已取得有效密码重置验证码 908172，原密码为 OldStation123!
- 测试步骤
  1. 新密码输入 NewPass123!，确认密码输入 newpass123! 并提交
  2. 将确认密码改为“NewPass123! ”并再次提交
  3. 查询 P1002 密码和验证码状态
- 预期结果
  1. 因大小写不一致显示确认密码不一致提示，不提交有效重置
  2. 因确认密码多一个尾随空格仍显示不一致，不自动裁剪密码内容
  3. P1002 原密码不变，验证码未因两次输入校验失败而消费
