# US-005 登录后修改密码

## [P1] 验证修改成功后旧密码失效且新密码可登录
- 测试类型
  - 功能
- 前置条件
  1. 海外版个人账号gt_us005_success状态正常，当前密码为OldPass2026!，已登录并进入修改密码页面
- 测试步骤
  1. 当前密码输入OldPass2026!，新密码和确认新密码均输入NewPass2026!并提交
  2. 退出当前账号，使用账号gt_us005_success和旧密码OldPass2026!登录
  3. 使用账号gt_us005_success和新密码NewPass2026!登录
- 预期结果
  1. 修改成功并提示“密码已修改”，服务端保存新密码
  2. 旧密码立即失效，登录失败且不创建新会话
  3. 新密码登录成功并进入该账号的数据加载流程

## [P1] 验证国内版修改密码后跨版本统一使用新密码
- 测试类型
  - 兼容性
- 前置条件
  1. 共享个人账号的国内手机号为13800138010、海外账号名为user13800138010，当前密码为OldPass2026!，账号状态正常
- 测试步骤
  1. 在国内版使用手机号13800138010和个人类型登录，将密码修改为NewPass2026!
  2. 在海外版使用账号名user13800138010和旧密码OldPass2026!登录
  3. 在海外版使用账号名user13800138010和新密码NewPass2026!登录
  4. 在国内版再次使用手机号13800138010、个人类型和新密码NewPass2026!登录
- 预期结果
  1. 国内版修改成功并提示“密码已修改”
  2. 旧密码在海外版同样失效，登录失败
  3. 新密码定位同一accountId并在海外版登录成功
  4. 新密码在国内版也可登录，国内外版本不存在两套密码或延迟不一致

## [P3][反向] 验证修改请求业务失败时不产生密码变更副作用
- 测试类型
  - 可靠性
- 前置条件
  1. 海外版企业二级账号gt_us005_fail状态正常，当前密码为OldPass2026!；服务端测试桩将本次修改请求返回明确业务失败且不落库
- 测试步骤
  1. 当前密码输入OldPass2026!，新密码和确认新密码均输入NewPass2026!并提交
  2. 查看失败提示和三个输入字段
  3. 退出后分别使用NewPass2026!和OldPass2026!登录
- 预期结果
  1. 页面不显示成功提示，明确展示服务端返回的失败原因
  2. 页面保留表单供修正或重试，不暴露密码明文
  3. NewPass2026!登录失败，OldPass2026!仍可登录，失败请求未产生部分更新

## [P3][反向] 验证网络中断或响应超时时不误报修改成功
- 测试类型
  - 稳定性
- 前置条件
  1. 国内版个人账号手机号13800138011状态正常，当前密码为OldPass2026!，已进入修改密码页面；提交时可模拟断网或响应超时
- 测试步骤
  1. 当前密码输入OldPass2026!，新密码和确认新密码均输入NewPass2026!
  2. 提交时断开网络并等待请求超时
  3. 恢复网络后先使用OldPass2026!重新认证；若失败，再使用NewPass2026!重新认证并查询服务端最终结果
- 预期结果
  1. 表单数据完整且可提交
  2. APP提示网络异常或结果未知，不显示确定的“密码已修改”，并保留可重试路径
  3. 最终仅有一个密码有效，客户端展示与服务端最终状态一致，不出现新旧密码同时有效或页面成功状态与实际密码相反

## [P3] 验证重复点击和响应丢失重试只产生一次有效修改
- 测试类型
  - 安全性
- 前置条件
  1. 海外版个人账号gt_us005_idempotent状态正常，当前密码为OldPass2026!；已开启请求抓包并可模拟首次成功响应丢失
- 测试步骤
  1. 当前密码输入OldPass2026!，新密码和确认新密码均输入NewPass2026!，连续点击提交两次
  2. 模拟首次请求服务端成功但客户端未收到响应，使用同一表单再次提交
  3. 退出后分别使用OldPass2026!和NewPass2026!登录
- 预期结果
  1. 客户端提交期间按钮防重复或服务端保证重复请求不会执行两次独立密码变更
  2. 首次成功后OldPass2026!已失效，后续重复请求不得基于失效的当前密码再次覆盖密码或产生矛盾结果
  3. 仅NewPass2026!可登录，OldPass2026!不可登录，账号保持一个确定的最终密码

## [P2] 验证修改密码后的多端会话行为与当前配置一致
- 测试类型
  - 兼容性
- 前置条件
  1. 测试开始前从当前环境配置中心、认证接口契约或服务端发布说明读取“修改密码后会话失效范围”生效策略并留存证据；账号gt_us005_session已同时登录Android设备A、iOS设备B和Web浏览器C，当前密码为OldPass2026!
- 测试步骤
  1. 记录生效策略规定的会话范围、Access Token处理、Refresh Token处理和生效时机
  2. 在Android设备A将密码修改为NewPass2026!
  3. 在设备A、设备B和浏览器C分别调用用户资料接口及一个受保护业务接口，并尝试刷新Token
  4. 对照步骤1记录逐端核对结果
- 预期结果
  1. 获得唯一、可追溯的当前环境策略；若策略未发布或无法查询，本用例标记阻塞，不把任一会话行为写成默认正确
  2. 密码修改成功，旧密码OldPass2026!立即失效
  3. 各端会话、Access Token和Refresh Token按生效策略继续有效或失效，失效端重新认证前不能访问受保护数据
  4. Android、iOS、Web与服务端配置完全一致，不出现同类Token在不同端执行不同策略

## [P2] 验证会话失效策略在前台后台和长连接场景保持一致
- 测试类型
  - 可靠性
- 前置条件
  1. 已取得当前环境“修改密码后会话失效范围”配置并留存证据；账号gt_us005_realtime已登录Android前台设备A、iOS后台设备B和保持WebSocket连接的Web端C，当前密码为OldPass2026!
- 测试步骤
  1. 在设备A将密码修改为NewPass2026!
  2. 将设备B从后台切回前台，并在Web端C触发一次实时消息和一次受保护接口请求
  3. 等待到配置规定的生效时机后，再次检查三端页面数据、HTTP会话和WebSocket状态
- 预期结果
  1. 修改成功且旧密码OldPass2026!立即失效
  2. 设备B和Web端C不因后台恢复或长连接而绕过配置规定的会话处理
  3. 配置要求失效的端必须停止访问、停止接收受保护实时数据并引导重新登录；配置允许保留的端应继续正常工作，三端表现与同一策略一致

## [P3] 验证两个终端并发修改同一账号密码时最终状态唯一
- 测试类型
  - 安全性
- 前置条件
  1. 账号gt_us005_concurrent状态正常，当前密码为OldPass2026!，Android设备A和iOS设备B均持有有效登录态并已打开修改密码页面
- 测试步骤
  1. 设备A使用当前密码OldPass2026!提交新密码NewPassA2026!
  2. 同一时刻设备B使用当前密码OldPass2026!提交新密码NewPassB2026!
  3. 等待两个请求完成后，分别使用OldPass2026!、NewPassA2026!和NewPassB2026!登录
- 预期结果
  1. 设备A请求参与服务端原子校验和更新，不在客户端本地直接判定成功
  2. 两个请求中最多一个基于OldPass2026!修改成功，另一个因当前密码已失效或并发冲突被拒绝
  3. OldPass2026!不可登录，NewPassA2026!与NewPassB2026!中仅成功请求对应的一个密码可登录，账号不存在双重有效密码
