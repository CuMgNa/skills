# US-002 使用账号名或邮箱登录

## [P1] 验证无网络时登录页和本地时区列表可正常打开
- 测试类型
  - 可靠性
- 前置条件
  1. 测试设备已安装海外版 APP，关闭 Wi-Fi 和蜂窝网络，本机无有效登录会话
- 测试步骤
  1. 冷启动 APP 并进入登录页
  2. 点击时区字段打开 ActionSheet
  3. 选择 GMT+10:00 Sydney 并返回登录页
- 预期结果
  1. 登录页由本地资源正常渲染，不因无网络白屏或崩溃
  2. 本地内置时区列表可打开并展示 GMT 偏移与地区名称
  3. GMT+10:00 Sydney 可被选中并在登录页回显

## [P1][反向] 验证无网络提交后保留全部输入并提供重试
- 测试类型
  - 易用性
- 前置条件
  1. 海外版账号 offline_owner_01，密码 Offline#2026；设备保持无网络
- 测试步骤
  1. 输入 offline_owner_01、密码 Offline#2026，选择 GMT+10:00 Sydney，勾选协议和记住密码
  2. 点击 Sign In
  3. 查看失败提示、重试入口及表单各字段
- 预期结果
  1. 表单允许完整填写并发起登录动作
  2. 请求因网络不可用失败，页面明确提示网络异常并提供重试入口
  3. 账号、密码、时区、协议和记住密码状态全部保留，不要求用户重复填写

## [P1][反向] 验证无网络不能使用历史凭证或业务缓存离线登录
- 测试类型
  - 安全性
- 前置条件
  1. 本机曾成功登录 accountId=P7001 并记住账号 offline_owner_01，随后已退出；设备保存过 P7001 的设备和告警缓存，当前无网络
- 测试步骤
  1. 打开 APP 查看带出的历史登录凭证
  2. 点击 Sign In 并尝试通过返回键、深链或页面恢复进入地图首页
  3. 检查 Token、业务接口权限和缓存展示
- 预期结果
  1. 可按记住密码规则带出凭证，但不自动恢复有效会话
  2. 所有绕过登录的方式均不能进入可操作业务页面
  3. 不签发或复用旧 Token，不展示 P7001 的设备、围栏、告警等业务缓存

## [P1] 验证网络恢复后无需重启即可沿原表单重试成功
- 测试类型
  - 功能
- 前置条件
  1. 已在无网络状态使用 offline_owner_01、Offline#2026 提交失败，账号、密码、GMT+10:00 Sydney、协议和记住密码状态仍保留
- 测试步骤
  1. 恢复 Wi-Fi 网络并保持 APP 在前台
  2. 点击页面重试入口
  3. 查看登录请求、设备加载和最终首页
- 预期结果
  1. 页面识别网络恢复且不清空原表单
  2. 重试走完整账号、密码、状态、时区和协议校验链路并成功签发 P7001 的 Token
  3. 完成设备加载后进入地图首页，无需重启 APP

## [P1][反向] 验证无网络失败不创建会话或写入登录偏好
- 测试类型
  - 可靠性
- 前置条件
  1. 本机最后成功登录账号为 old_owner_00，时区 GMT-7:00 Denver，记住密码槽位为 old_owner_00；新账号 offline_owner_01 状态正常，当前无网络
- 测试步骤
  1. 输入 offline_owner_01、Offline#2026，选择 GMT+10:00 Sydney 并勾选记住密码后提交
  2. 登录请求失败后强制结束并重开 APP
  3. 检查当前会话、记住密码槽位和账号级时区偏好
- 预期结果
  1. 网络失败不创建 offline_owner_01 会话
  2. 重开后仍无登录态，失败账号不写入记住密码槽位
  3. old_owner_00 的已保存槽位与 GMT-7:00 Denver 偏好不被失败尝试覆盖

## [P1] 验证弱网重复重试只建立一个有效会话
- 测试类型
  - 稳定性
- 前置条件
  1. 账号 accountId=P7002，账号名 retry_owner_02，密码 Retry#2026；网络模拟为 30% 丢包、800ms 延迟，登录接口支持请求追踪
- 测试步骤
  1. 填写有效表单后连续快速点击重试 5 次
  2. 等待全部请求返回并检查 Token、设备加载任务和 WebSocket 连接
  3. 查看服务端会话记录和客户端最终页面
- 预期结果
  1. 客户端防重复提交或服务端幂等控制生效，不因多次点击产生冲突状态
  2. 最终仅保留一个有效账号会话、一个当前 Token 上下文和一个 WebSocket 连接，重复回包不重复初始化业务数据
  3. 页面进入 P7002 的首页且无重复设备、重复告警或多次跳转

## [P1][反向] 验证账号切换后的迟到登录响应不能覆盖当前 accountId
- 测试类型
  - 安全性
- 前置条件
  1. 国内版手机号 13800138000 对应个人账号 P7101 和企业账号 E7101；已配置网络代理延迟个人账号登录响应 10 秒
- 测试步骤
  1. 选择个人并提交 P7101 登录，使请求保持在途
  2. 取消或离开该流程后选择企业，使用企业密码成功登录 E7101
  3. 放行 P7101 的迟到响应并检查 Token、缓存、页面和 WebSocket
- 预期结果
  1. 个人登录请求具有可识别的请求上下文且尚未建立可见会话
  2. 当前有效会话为 accountId=E7101，仅加载企业数据
  3. P7101 迟到响应被丢弃，不能覆盖 E7101 的 Token、账号类型、缓存、页面或 WebSocket
