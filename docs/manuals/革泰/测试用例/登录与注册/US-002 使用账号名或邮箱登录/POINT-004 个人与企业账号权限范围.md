- 测试类型
  - 功能
- 前置条件
  1. 个人账号 accountId=P4001，账号名 owner_personal_01，密码 Owner#2026，直接绑定设备 GT-S1-P401 和 GT-S1-P402；设备 GT-S1-E499 属于其他企业
- 测试步骤

  2. 查看设备列表和绑定设备入口
  3. 请求访问设备 GT-S1-E499 的详情接口

## [P1][反向] 验证篡改账号类型或企业层级不能扩大登录后权限
- 测试类型
  - 安全性
- 前置条件
  1. 企业二级账号 accountId=E4201，tenantId=T410，密码 Sub2#2026；已准备可修改请求参数的代理工具
- 测试步骤
  1. 提交 E4201 的有效登录请求并将 accountType 改为个人、enterpriseLevel 改为一级
  2. 使用返回 Token 请求绑定设备 GT-S1-X001 和访问未分配设备 GT-S1-E411
  3. 检查 Token 声明、服务端授权结果和审计日志
- 预期结果
  1. 服务端以真实账号资料识别 E4201 为企业二级，忽略或拒绝伪造类型与层级
  2. 两个越权请求均被服务端拒绝且不产生设备关系变更
  3. Token 不含伪造权限，审计日志记录失败操作的 accountId、目标资源和来源

## [P1] 验证国内版使用手机号加个人或企业类型定位对应账号
- 测试类型
  - 兼容性
- 前置条件
  1. 手机号 13800138000 同时关联个人账号 accountId=P4401、密码 Personal#2026，以及企业账号 accountId=E4401、密码 Enterprise#2026
- 测试步骤
  1. 国内版输入 13800138000，选择个人并输入 Personal#2026 登录
  2. 退出后输入同一手机号，选择企业并输入 Enterprise#2026 登录
  3. 对比两次 Token、账号资料和设备范围
- 预期结果

  2. 第二次唯一定位 E4401 并加载企业设备范围
  3. 两次会话以不同 accountId 隔离，手机号不能作为 Token、缓存或权限判断的唯一键

  - 安全性

## [P1] 验证同账号使用账号名和邮箱登录后权限范围不变
- 测试类型
  - 可靠性
- 前置条件
  1. 企业一级账号 accountId=E4101，账号名 corp_level1_01，邮箱 admin4101@northfarm.com.au，密码 Corp#2026，授权设备 GT-S1-E411 和 GT-S1-E412
- 测试步骤

  2. 退出清理后使用邮箱登录
  3. 对比两次服务端授权结果
- 预期结果

  2. 邮箱登录仍定位 E4101
  3. 设备范围、绑定权限及企业管理能力边界完全一致，不因登录标识不同产生权限漂移
