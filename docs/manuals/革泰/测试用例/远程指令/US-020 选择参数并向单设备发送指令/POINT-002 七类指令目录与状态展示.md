# 用户故事：US-020 选择参数并向单设备发送指令 - POINT-002 七类指令目录与状态展示

## [P1] 验证指令页按四个分类完整展示七类指令
- 测试类型
  - 功能
- 前置条件
  1. 账号 GT-CMD-U010 已进入支持七类指令的在线设备 GT-CMD-D101 指令页
  2. GT-CMD-D101 当前存在可写会话 SID-D101-01
- 测试步骤
  1. 查看“常用指令”分类。
  2. 查看“现场操作”和“参数设置”分类。
  3. 查看“设备控制”分类并统计全部指令项。
- 预期结果
  1. “常用指令”包含立即定位 CR 和查询版本 VERNO。
  2. “现场操作”包含查找设备 FIND，“参数设置”包含设置上传间隔 UPLOAD 和设置设备时区 ZONE。
  3. “设备控制”包含远程重启 RESET 和远程关机 POWEROFF，页面合计恰好七类指令且无重复项。

## [P1] 验证在线且有当前可写会话时七类指令状态可操作
- 测试类型
  - 功能
- 前置条件
  1. 设备 GT-CMD-D102 页面状态为在线
  2. S10U 返回 GT-CMD-D102 当前可写会话 SID-D102-07，型号能力支持七类指令
- 测试步骤
  1. 依次查看 CR、VERNO、FIND、UPLOAD、ZONE 的可操作状态。
  2. 查看 RESET 和 POWEROFF 的可操作状态。
  3. 点击 RESET 进入下一步但不确认提交。
- 预期结果
  1. 普通五类均可选择，UPLOAD 和 ZONE 会进入各自参数选择流程。
  2. RESET 和 POWEROFF 均可选择，但仍需经过高危确认及提交时服务端复检。
  3. 页面进入 RESET 高危确认流程，未确认前不创建任务。

## [P2] 验证离线页面普通五类可选且高危两类展示受限原因
- 测试类型
  - 易用性
- 前置条件
  1. 设备 GT-CMD-D103 当前离线且无可写 S10U 会话
  2. GT-CMD-D103 关系、路由和型号均有效
- 测试步骤
  1. 打开 GT-CMD-D103 指令页。
  2. 检查 CR、VERNO、FIND、UPLOAD、ZONE 的状态。
  3. 检查 RESET 和 POWEROFF 的状态及原因说明。
- 预期结果
  1. 页面正常打开并展示离线快照。
  2. 普通五类保持可选，不出现统一“离线不可下发”的拦截。
  3. 高危两类不可直接提交并展示缺少当前在线会话的原因语义，未创建高危任务。

## [P3][反向] 验证页面显示在线但无当前会话时不错误放开高危指令
- 测试类型
  - 安全性
- 前置条件
  1. GT-CMD-D104 页面缓存状态为在线
  2. S10U 当前会话查询确认 GT-CMD-D104 无可写会话
- 测试步骤
  1. 打开 GT-CMD-D104 指令页。
  2. 尝试点击远程关机 POWEROFF。
  3. 检查普通指令 CR 的状态。
- 预期结果
  1. 页面在线标签仅作为快照展示，不作为高危准入凭据。
  2. POWEROFF 不进入可提交状态，并展示当前会话不可用的原因语义。
  3. CR 仍可选择，普通队列能力不受当前会话缺失影响。

## [P2] 验证告警叠加状态不改变七类指令分类规则
- 测试类型
  - 功能
- 前置条件
  1. 在线设备 GT-CMD-D105 存在未处理低电告警并有可写会话 SID-D105-03
  2. 离线设备 GT-CMD-D106 存在未处理围栏告警且无当前会话
- 测试步骤
  1. 打开 GT-CMD-D105 指令页并检查七类指令状态。
  2. 返回后打开 GT-CMD-D106 指令页并检查七类指令状态。
  3. 比较两台设备的告警标识与通信状态对指令状态的影响。
- 预期结果
  1. GT-CMD-D105 的普通五类和高危两类均按在线会话条件展示可操作，告警不单独禁用指令。
  2. GT-CMD-D106 的普通五类可选、高危两类受限，判定依据为当前会话而非告警类型。
  3. 告警作为叠加状态独立展示，不新增第八类指令或改变普通与高危分类。
