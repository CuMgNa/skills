# 用户故事：US-020 选择参数并向单设备发送指令 - POINT-006 高危指令当前会话复检

## [P1] 验证远程重启提交时绑定当前可写会话
- 测试类型
  - 安全性
- 前置条件
  1. 在线设备 GT-CMD-D501 支持 RESET 且当前会话为 SID-D501-11
  2. 当前账号关系、S10U 路由和型号能力均有效
- 测试步骤
  1. 选择远程重启 RESET 并查看高危影响说明。
  2. 完成二次确认并提交。
  3. 查询任务状态和会话绑定属性。
- 预期结果
  1. 页面明确表达重启影响以及任务只对当前会话有效的语义。
  2. 服务端在最终提交时重新查询 GT-CMD-D501 的当前可写会话。
  3. 任务进入 SENDING 并绑定 SID-D501-11，不只保存 online=true。

## [P1] 验证远程关机提交时绑定当前可写会话
- 测试类型
  - 安全性
- 前置条件
  1. 在线设备 GT-CMD-D502 支持 POWEROFF 且当前会话为 SID-D502-04
  2. 当前账号具有 GT-CMD-D502 的控制权限
- 测试步骤
  1. 选择远程关机 POWEROFF。
  2. 阅读影响说明后确认提交。
  3. 检查任务和 S10U 高危队列。
- 预期结果
  1. 页面进入普通点击式二次确认，不要求未确认的长按手势。
  2. 服务端最终复检通过后只受理一次本次操作。
  3. 高危任务绑定 SID-D502-04，设备断开该会话后不得转入普通离线队列。

## [P3][反向] 验证确认时当前会话已断开则高危提交失败
- 测试类型
  - 安全性
- 前置条件
  1. GT-CMD-D503 打开页面时会话为 SID-D503-01
  2. 用户打开 RESET 确认面板后 SID-D503-01 已断开且未建立新会话
- 测试步骤
  1. 在确认面板点击确认提交。
  2. 检查服务端最终会话复检结果。
  3. 检查任务状态和高危队列。
- 预期结果
  1. APP 不使用页面进入时的在线快照直接放行。
  2. 服务端确认无当前可写会话并返回明确失败语义。
  3. 本次操作形成 FAILURE 审计结果且不进入高危队列，不等待下次上线补发。

## [P2] 验证离线页面恢复在线后刷新会话再进入高危确认
- 测试类型
  - 可靠性
- 前置条件
  1. GT-CMD-D504 进入页面时离线，高危指令不可直接提交
  2. 页面停留期间设备建立当前可写会话 SID-D504-09
- 测试步骤
  1. 在设备恢复在线后点击原受限的 RESET 项。
  2. 等待页面刷新当前 S10U 会话能力。
  3. 进入确认并提交 RESET。
- 预期结果
  1. 用户操作触发当前会话刷新，不永久依赖进入页面时的离线快照。
  2. 刷新确认 SID-D504-09 可写后允许进入高危确认。
  3. 最终提交仍再次复检并将新任务绑定 SID-D504-09。

## [P3][反向] 验证会话查询系统异常不伪装为设备离线
- 测试类型
  - 可靠性
- 前置条件
  1. GT-CMD-D505 页面显示在线并支持 RESET
  2. 最终提交时 S10U 会话查询服务返回系统异常
- 测试步骤
  1. 对 GT-CMD-D505 确认提交 RESET。
  2. 查看页面失败反馈。
  3. 查询任务失败原因和高危队列。
- 预期结果
  1. 服务端不在会话查询失败时猜测设备离线。
  2. 页面表达系统暂不可确认或同等系统异常语义，不使用“设备离线”冒充原因。
  3. 本次操作进入 FAILURE 且不进入高危队列；不限定具体错误码和最终提示文案。

## [P3][反向] 验证复检期间会话变化时旧会话不得被绑定
- 测试类型
  - 安全性
- 前置条件
  1. GT-CMD-D506 开始复检时会话为 SID-D506-A
  2. 创建任务前当前会话已切换为 SID-D506-B
- 测试步骤
  1. 对 GT-CMD-D506 确认提交 POWEROFF。
  2. 检查任务创建结果及绑定会话字段。
  3. 检查 SID-D506-A 和 SID-D506-B 的写出记录。
- 预期结果
  1. 服务端识别会话生命周期已经变化，不沿用旧快照。
  2. 本次操作进入会话变化语义的 FAILURE，不创建绑定 SID-D506-A 或 SID-D506-B 的旧意图任务。
  3. 两个会话均不写出本次 POWEROFF，新会话不得承接旧高危意图。
