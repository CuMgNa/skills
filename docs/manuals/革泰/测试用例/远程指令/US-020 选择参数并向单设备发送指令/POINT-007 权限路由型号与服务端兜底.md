# 用户故事：US-020 选择参数并向单设备发送指令 - POINT-007 权限路由型号与服务端兜底

## [P1] 验证有效权限路由与型号通过服务端共同校验
- 测试类型
  - 功能
- 前置条件
  1. 个人账号 GT-CMD-U070 对设备 GT-CMD-D601 具有控制关系 REL-D601-V3
  2. GT-CMD-D601 的路由 ROUTE-D601 有效，型号 S10U-A 支持 CR
- 测试步骤
  1. 对 GT-CMD-D601 选择 CR 并确认提交。
  2. 检查服务端权限、关系、路由和型号校验结果。
  3. 检查受理任务的设备标识和状态。
- 预期结果
  1. 请求携带 GT-CMD-D601 的唯一标识和本次操作幂等标识。
  2. 四项共同校验均通过，服务端不额外要求设备必须在线。
  3. 仅为 GT-CMD-D601 创建一条 SENDING 普通任务。

## [P3][反向] 验证页面打开后设备关系失效时服务端拒绝提交
- 测试类型
  - 安全性
- 前置条件
  1. 企业子账号 GT-CMD-U071 打开 GT-CMD-D602 指令页时关系 REL-D602-V5 有效
  2. 提交前管理员已回收该设备，当前关系版本变为无权访问
- 测试步骤
  1. 在旧页面选择 VERNO 并确认提交。
  2. 检查服务端关系复检和页面反馈。
  3. 检查普通队列和失败审计结果。
- 预期结果
  1. APP 发出的旧页面请求不能绕过当前关系校验。
  2. 服务端拒绝本次提交，页面表达当前无权操作或关系已失效的语义。
  3. 不创建待写出普通任务；服务端可识别设备和操作意图时保留 FAILURE 审计结果。

## [P3][反向] 验证缺少S10U路由不能伪装成离线排队
- 测试类型
  - 可靠性
- 前置条件
  1. 离线设备 GT-CMD-D603 与当前账号关系有效
  2. GT-CMD-D603 缺少合法 S10U 路由，型号支持 FIND
- 测试步骤
  1. 对 GT-CMD-D603 提交 FIND。
  2. 检查页面反馈和服务端任务状态。
  3. 检查普通队列中是否存在本次任务。
- 预期结果
  1. 服务端执行路由校验，不把“离线可受理”扩大为“无路由也可受理”。
  2. 本次操作进入路由不可用语义的 FAILURE，不提示设备恢复通信后发送。
  3. 普通队列不存在 GT-CMD-D603 的本次 FIND 任务。

## [P3][反向] 验证型号不支持目标指令时明确失败
- 测试类型
  - 功能
- 前置条件
  1. 在线设备 GT-CMD-D604 的型号 S10U-LITE 不支持 ZONE
  2. 当前账号关系和 ROUTE-D604 均有效
- 测试步骤
  1. 构造对 GT-CMD-D604 提交 ZONE UTC+08:00 的有效格式请求。
  2. 检查服务端型号能力校验结果。
  3. 检查设备队列和失败反馈。
- 预期结果
  1. 服务端不因参数格式有效而跳过型号能力校验。
  2. 本次操作进入型号不支持目标指令的 FAILURE 语义。
  3. 设备队列不存在该 ZONE 任务，页面不把失败归因为离线或参数为空。

## [P3][反向] 验证绕过前端向离线设备提交高危指令仍被服务端拦截
- 测试类型
  - 安全性
- 前置条件
  1. 离线设备 GT-CMD-D605 无当前可写会话，关系、路由和 RESET 型号能力有效
  2. 测试客户端可直接构造单设备 RESET 请求
- 测试步骤
  1. 使用有效登录凭证和设备标识提交 RESET。
  2. 检查服务端最终会话复检结果。
  3. 检查高危队列和任务绑定字段。
- 预期结果
  1. 服务端不信任前端按钮状态并执行当前会话复检。
  2. 本次操作因无当前可写会话进入 FAILURE。
  3. 高危队列无本次任务，boundSessionId 为空且任务不会等待设备重连。

## [P3][反向] 验证登录会话失效后提交不会产生越权任务
- 测试类型
  - 安全性
- 前置条件
  1. 账号 GT-CMD-U072 已打开 GT-CMD-D606 指令页并选中 UPLOAD 600 秒
  2. 提交前登录 Token 已失效
- 测试步骤
  1. 点击确认提交。
  2. 检查认证处理和页面路由。
  3. 查询 GT-CMD-D606 的新任务和配置目标值。
- 预期结果
  1. 服务端拒绝无效登录会话，不继续执行设备业务校验和建队列。
  2. APP 进入重新认证流程并表达会话失效语义，不显示指令已提交。
  3. GT-CMD-D606 不新增 UPLOAD 任务，原配置目标值保持不变。
