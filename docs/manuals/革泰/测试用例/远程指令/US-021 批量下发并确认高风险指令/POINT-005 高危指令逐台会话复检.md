# 用户故事：US-021 批量下发并确认高风险指令 - POINT-005 高危指令逐台会话复检

## [P1] 验证全部设备通过高危最终会话复检
- 测试类型
  - 功能
- 前置条件
  1. 验证GT-D001当前可写会话为SID-001且GT-D004当前可写会话为SID-004
  2. 验证两台设备关系、路由和型号均支持RESET
- 测试步骤
  1. 选择GT-D001和GT-D004并提交远程重启RESET
  2. 查询两条高危任务的状态和绑定会话属性
- 预期结果
  1. 服务端逐台查询当前会话，结果为2台submitted和0台failedToSubmit
  2. 两条任务均进入SENDING并分别保存SID-001和SID-004，不只保存online=true

## [P3][反向] 验证高危最终复检部分失败且不回滚成功设备
- 测试类型
  - 功能
- 前置条件
  1. 验证已选GT-D001、GT-D004、GT-D008、GT-D009、GT-D010
  2. 验证GT-D008无当前会话、GT-D009会话发生变化、GT-D010会话查询系统异常
- 测试步骤
  1. 提交远程重启RESET
  2. 查询5台设备的任务状态和失败原因
- 预期结果
  1. GT-D001和GT-D004进入SENDING，GT-D008记录SESSION_NOT_ACTIVE，GT-D009记录SESSION_CHANGED，GT-D010记录SYSTEM_ERROR
  2. 结果为2台submitted和3台failedToSubmit，成功设备不回滚且5台设备均有明细

## [P3][反向] 验证高危最终复检全部失败
- 测试类型
  - 功能
- 前置条件
  1. 验证GT-D002离线、GT-D003未连接、GT-D008页面显示在线但最终无当前会话
  2. 验证3台设备均不存在可写S10U会话
- 测试步骤
  1. 选择3台设备并提交远程关机POWEROFF
  2. 查询结果弹窗、设备明细和高危队列
- 预期结果
  1. 结果为0台submitted和3台failedToSubmit，弹窗显示Submission Failed
  2. 3台设备均建立FAILURE明细且均未进入高危队列

## [P3][反向] 验证批量会话查询系统异常不伪装为设备离线
- 测试类型
  - 可靠性
- 前置条件
  1. 验证仅选择GT-D010
  2. 验证S10U会话查询接口对GT-D010返回SYSTEM_ERROR
- 测试步骤
  1. 提交远程重启RESET
  2. 查看结果弹窗和GT-D010失败明细
- 预期结果
  1. GT-D010提交失败并建立FAILURE明细，不进入高危队列
  2. 失败原因明确为系统异常，不显示为设备离线或SESSION_NOT_ACTIVE

## [P3][反向] 验证复检期间会话变化时旧会话不得继续使用
- 测试类型
  - 安全性
- 前置条件
  1. 验证GT-D009复检开始时会话为SID-009-A
  2. 验证任务创建前当前会话已切换为SID-009-B
- 测试步骤
  1. 对GT-D009提交远程关机POWEROFF
  2. 查询任务创建结果和两个会话的写出记录
- 预期结果
  1. 本次提交建立FAILURE明细并记录SESSION_CHANGED，不创建绑定SID-009-A的SENDING任务
  2. SID-009-A和SID-009-B均未写出本次旧意图任务，新会话不得承接旧会话高危任务
