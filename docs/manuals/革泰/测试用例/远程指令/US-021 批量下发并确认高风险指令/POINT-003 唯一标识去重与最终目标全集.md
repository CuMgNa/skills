# 用户故事：US-021 批量下发并确认高风险指令 - POINT-003 唯一标识去重与最终目标全集

## [P1] 验证分页重叠设备按唯一标识去重
- 测试类型
  - 功能
- 前置条件
  1. 验证第一页返回GT-D001和GT-D002
  2. 验证第二页因数据重叠再次返回GT-D001
- 测试步骤
  1. 对两页设备结果执行全选
  2. 查看最终选择数量并提交普通指令CR
- 预期结果
  1. GT-D001按Device ID只计算一次，最终去重数量为2
  2. 批次仅建立GT-D001和GT-D002各一条设备明细，不产生重复任务

## [P3][反向] 验证重复Device ID请求不会重复受理
- 测试类型
  - 可靠性
- 前置条件
  1. 验证提交请求设备序列为GT-D001、GT-D001、GT-D002
  2. 验证operationId为OP-US021-003-02且idempotencyKey为IDEM-US021-003-02
- 测试步骤
  1. 向服务端提交包含重复Device ID的CR批量请求
  2. 查询批次统计、设备明细和队列任务
- 预期结果
  1. 服务端最终目标设备数为2，不按3台累计
  2. GT-D001和GT-D002各自只有一条明细和一个任务，无重复计数或重复副作用

## [P3][反向] 验证高危指令最终目标全集包含离线和未连接设备
- 测试类型
  - 功能
- 前置条件
  1. 验证已选择在线GT-D001、离线GT-D002、未连接GT-D003
  2. 验证仅GT-D001存在当前可写会话SID-001
- 测试步骤
  1. 选择远程重启RESET并进入高危确认面板
  2. 确认提交并查询逐设备复检结果
- 预期结果
  1. 确认面板目标设备数量为3，不预先移除GT-D002或GT-D003
  2. GT-D001进入SENDING，GT-D002和GT-D003各建立FAILURE明细，最终明细数量为3

## [P3][反向] 验证重复设备和校验失败设备并存时无静默丢失
- 测试类型
  - 可靠性
- 前置条件
  1. 验证原始设备序列为GT-D001、GT-D001、GT-D005、GT-D006
  2. 验证GT-D005缺少路由且GT-D006型号不支持CR
- 测试步骤
  1. 提交普通指令CR
  2. 查询最终去重统计和全部设备明细
- 预期结果
  1. 最终去重目标数量为3，GT-D001只受理一次
  2. 结果为1台submitted和2台failedToSubmit，3台唯一设备均有明确明细
