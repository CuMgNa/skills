# 用户故事：US-021 批量下发并确认高风险指令 - POINT-009 记录跳转与结束清理

## [P2] 验证全部受理弹窗跳转批量指令记录L1
- 测试类型
  - 功能
- 前置条件
  1. 验证当前显示全部受理批次BATCH-009-A的结果弹窗
  2. 验证批量指令记录L1中另有历史批次BATCH-HISTORY-01
- 测试步骤
  1. 点击Command History
  2. 查看目标页面请求参数、记录列表和筛选状态
- 预期结果
  1. 页面直接进入“我的→批量下发指令记录”L1并刷新全量记录
  2. 列表同时展示可见的历史批次，不自动筛选、定位或高亮BATCH-009-A

## [P2] 验证部分受理弹窗跳转时不携带失败筛选
- 测试类型
  - 功能

  2. 筛选条件保持全部状态，不预置部分失败筛选且不高亮BATCH-009-B

  - 功能

## [P2] 验证Done与关闭按钮执行相同结束清理
- 测试类型
  - 易用性
- 前置条件
  1. 验证两个测试批次均选择GT-D001、GT-D002和UPLOAD参数600秒
  2. 验证两个批次结果弹窗内容相同
- 测试步骤
  1. 在第一个结果弹窗点击Done
  2. 在第二个结果弹窗点击右上角关闭按钮
- 预期结果
  1. Done清空设备、指令和参数，退出多选模式并返回普通设备列表
  2. 关闭按钮产生完全相同的清理和返回结果，不保留隐藏选择或600秒参数
