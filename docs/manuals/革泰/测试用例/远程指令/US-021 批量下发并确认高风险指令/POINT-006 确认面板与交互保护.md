# 用户故事：US-021 批量下发并确认高风险指令 - POINT-006 确认面板与交互保护

## [P1] 验证普通指令确认面板展示提交摘要
- 测试类型
  - 功能
- 前置条件
  1. 验证已选择GT-D001、GT-D002、GT-D003共3台设备
  2. 验证已选择UPLOAD且上传间隔为600秒
- 测试步骤
  1. 进入普通指令确认面板
  2. 查看设备数量、指令名称、参数摘要和操作按钮
- 预期结果
  1. 面板显示已选择3台设备、UPLOAD和600秒参数摘要
  2. 面板同时显示取消和确认下发按钮，不新增离线设备前置处理步骤

## [P1] 验证高危确认面板展示风险和当前会话约束
- 测试类型
  - 易用性
- 前置条件
  1. 验证已选择GT-D001、GT-D002、GT-D003共3台设备
  2. 验证已选择远程关机POWEROFF
- 测试步骤
  1. 进入高危指令确认面板
  2. 查看设备摘要、风险说明和确认方式
- 预期结果
  1. 面板显示3台设备摘要、关机影响、任务只对当前在线会话有效以及断线后不会补发的说明
  2. 面板使用普通二次确认按钮，不要求长按1秒且不预先剔除离线或未连接设备

- 测试类型

  2. GT-D001、GT-D002、UPLOAD和3600秒参数均保持原选择状态

## [P3][反向] 验证连续点击最终确认不会产生重复任务
- 测试类型
  - 可靠性
- 前置条件
  1. 验证已选择GT-D001和GT-D004并进入RESET确认面板
  2. 验证本次操作operationId为OP-US021-006-06且idempotencyKey为IDEM-US021-006-06
- 测试步骤
  1. 在100毫秒内连续点击确认按钮3次
  2. 查询按钮状态、请求次数和逐设备任务数量
- 预期结果
  1. 首次点击后按钮立即进入loading并禁用，后续点击不重复触发有效提交
  2. GT-D001和GT-D004各自只产生一个任务和一条设备明细，不重复统计或重复写出
