# 用户故事：US-021 批量下发并确认高风险指令 - POINT-002 筛选全选取消与选择清空

## [P1] 验证全选仅选择当前筛选交集中的设备
- 测试类型
  - 功能
- 前置条件
  1. 验证G-A组离线筛选结果为GT-D002、GT-D003、GT-D005
  2. 验证GT-D002名称含OFFLINE、GT-D003名称含UNCONNECTED、GT-D005名称含NOROUTE
- 测试步骤
  1. 设置分组为G-A、状态为离线、关键词为GT-
  2. 点击“全选当前结果”
- 预期结果
  1. 列表展示GT-D002、GT-D003、GT-D005共3台交集设备
  2. 仅3台当前结果被选中，其他分组或在线设备未被选择，已选数量为3

## [P2] 验证取消全选仅清空选择且保留筛选条件
- 测试类型
  - 功能
- 前置条件
  1. 验证当前筛选为G-A组和离线状态
  2. 验证GT-D002、GT-D003、GT-D005已全选且已选数量为3
- 测试步骤
  1. 点击“取消全选”
  2. 查看筛选条件、设备列表和底部按钮
- 预期结果
  1. 3台设备复选框全部取消，已选数量归零
  2. G-A组和离线筛选保持不变，列表仍显示3台设备，底部按钮恢复未选择状态
