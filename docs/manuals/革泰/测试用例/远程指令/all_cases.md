# US-020 选择参数并向单设备发送指令

## POINT-001 指令页初始化与目标锁定

### [P1] 验证在线设备进入指令页后初始化信息与目标一致
- 测试类型
  - 功能
- 前置条件
  1. 账号 GT-CMD-U001 已登录并有权控制在线设备 GT-CMD-D001
  2. GT-CMD-D001 的设备名称为“北区一号”、设备卡号为 898604781001000001
- 测试步骤
  1. 从 GT-CMD-D001 的设备卡片进入 Send Command 页面。
  2. 查看页面标题、设备摘要和通信状态。
  3. 选择“立即定位”但不提交，检查当前目标设备标识。
- 预期结果
  1. 页面仅打开一次且目标设备唯一标识为 GT-CMD-D001。
  2. 页面展示“北区一号”、卡号尾号及在线快照，信息均来自 GT-CMD-D001。
  3. 当前指令选择绑定 GT-CMD-D001，不使用设备名称或列表位置代替唯一标识。

### [P2] 验证离线与尚未连接设备初始化时保留事实状态
- 测试类型
  - 易用性
- 前置条件
  1. 账号 GT-CMD-U001 有权控制离线设备 GT-CMD-D002 和尚无有效通信记录的设备 GT-CMD-D003
  2. 两台设备均具有合法 S10U 路由
- 测试步骤
  1. 进入 GT-CMD-D002 的 Send Command 页面并查看设备摘要。
  2. 返回后进入 GT-CMD-D003 的 Send Command 页面并查看设备摘要。
  3. 比较两次页面的目标标识和状态说明。
- 预期结果
  1. GT-CMD-D002 页面正常初始化并展示离线语义，不因离线拒绝进入。
  2. GT-CMD-D003 页面正常初始化并表达“离线且尚未连接”的原因语义，不新增独立通信筛选状态。
  3. 两次页面分别锁定 GT-CMD-D002 和 GT-CMD-D003，状态说明不导致目标串换。

### [P3][反向] 验证同名设备不会导致指令目标串设备
- 测试类型
  - 可靠性
- 前置条件
  1. 账号 GT-CMD-U002 可见设备 GT-CMD-D011 和 GT-CMD-D012
  2. 两台设备名称均为“东区定位器”，卡号分别为 898604781011000001 和 898604781012000001
- 测试步骤
  1. 从 GT-CMD-D011 进入 Send Command 页面并记录目标标识。
  2. 返回设备列表，从 GT-CMD-D012 进入 Send Command 页面并记录目标标识。
  3. 在第二个页面选择“查询版本”，检查待提交请求的设备标识。
- 预期结果
  1. 第一个页面目标标识为 GT-CMD-D011，不因同名匹配到 GT-CMD-D012。
  2. 第二个页面目标标识为 GT-CMD-D012，未残留 GT-CMD-D011 上下文。
  3. 待提交请求指向 GT-CMD-D012，设备名称只用于展示。

### [P3][反向] 验证快速往返不同设备时不复用旧页面目标
- 测试类型
  - 稳定性
- 前置条件
  1. 账号 GT-CMD-U003 可控制在线设备 GT-CMD-D021 和 GT-CMD-D022
  2. GT-CMD-D021 上次在指令页选择过 UPLOAD 600 秒，GT-CMD-D022 尚未选择指令
- 测试步骤
  1. 从 GT-CMD-D021 进入指令页后立即返回。
  2. 在 2 秒内从 GT-CMD-D022 进入指令页。
  3. 查看目标摘要、已选指令和待提交设备标识。
- 预期结果
  1. 返回动作结束 GT-CMD-D021 的本次页面会话，不触发任何指令提交。
  2. 新页面以 GT-CMD-D022 为唯一目标完成初始化。
  3. 页面不带出 GT-CMD-D021 的 UPLOAD 选择，待提交设备标识为 GT-CMD-D022。

### [P2] 验证前后台切换刷新状态但不改变目标设备
- 测试类型
  - 可靠性
- 前置条件
  1. 账号 GT-CMD-U004 已进入 GT-CMD-D031 的指令页，页面快照为离线
  2. APP 切后台期间 GT-CMD-D031 恢复在线并建立可写会话 SID-D031-02
- 测试步骤
  1. 将 APP 切到后台 10 秒后恢复前台。
  2. 等待页面完成设备通信状态刷新。
  3. 检查页面目标标识、设备摘要和指令选择状态。
- 预期结果
  1. APP 恢复原单设备指令页，不跳转到其他设备或批量页面。
  2. 页面状态更新为当前在线事实，可反映新的可写会话能力。
  3. 目标仍为 GT-CMD-D031，设备摘要不串换，尚未提交的选择不产生后台任务。

## POINT-002 七类指令目录与状态展示

### [P1] 验证指令页按四个分类完整展示七类指令
- 测试类型
  - 功能
- 前置条件
  1. 账号 GT-CMD-U010 已进入支持七类指令的在线设备 GT-CMD-D101 指令页
  2. GT-CMD-D101 当前存在可写会话 SID-D101-01
- 测试步骤
  1. 查看“常用指令”分类。
  2. 查看“现场操作”和“参数设置”分类。
  3. 查看“设备控制”分类并统计全部指令项。
- 预期结果
  1. “常用指令”包含立即定位 CR 和查询版本 VERNO。
  2. “现场操作”包含查找设备 FIND，“参数设置”包含设置上传间隔 UPLOAD 和设置设备时区 ZONE。
  3. “设备控制”包含远程重启 RESET 和远程关机 POWEROFF，页面合计恰好七类指令且无重复项。

### [P1] 验证在线且有当前可写会话时七类指令状态可操作
- 测试类型
  - 功能
- 前置条件
  1. 设备 GT-CMD-D102 页面状态为在线
  2. S10U 返回 GT-CMD-D102 当前可写会话 SID-D102-07，型号能力支持七类指令
- 测试步骤
  1. 依次查看 CR、VERNO、FIND、UPLOAD、ZONE 的可操作状态。
  2. 查看 RESET 和 POWEROFF 的可操作状态。
  3. 点击 RESET 进入下一步但不确认提交。
- 预期结果
  1. 普通五类均可选择，UPLOAD 和 ZONE 会进入各自参数选择流程。
  2. RESET 和 POWEROFF 均可选择，但仍需经过高危确认及提交时服务端复检。
  3. 页面进入 RESET 高危确认流程，未确认前不创建任务。

### [P2] 验证离线页面普通五类可选且高危两类展示受限原因
- 测试类型
  - 易用性
- 前置条件

  2. GT-CMD-D103 关系、路由和型号均有效

  1. 打开 GT-CMD-D103 指令页。
  2. 检查 CR、VERNO、FIND、UPLOAD、ZONE 的状态。
  3. 检查 RESET 和 POWEROFF 的状态及原因说明。
- 预期结果
  1. 页面正常打开并展示离线快照。
  2. 普通五类保持可选，不出现统一“离线不可下发”的拦截。
  3. 高危两类不可直接提交并展示缺少当前在线会话的原因语义，未创建高危任务。

### [P3][反向] 验证页面显示在线但无当前会话时不错误放开高危指令
- 测试类型
  - 安全性
- 前置条件
  1. GT-CMD-D104 页面缓存状态为在线
  2. S10U 当前会话查询确认 GT-CMD-D104 无可写会话

  2. 尝试点击远程关机 POWEROFF。
  3. 检查普通指令 CR 的状态。

  2. POWEROFF 不进入可提交状态，并展示当前会话不可用的原因语义。
  3. CR 仍可选择，普通队列能力不受当前会话缺失影响。

### [P2] 验证告警叠加状态不改变七类指令分类规则
- 测试类型
  - 功能
- 前置条件
  1. 在线设备 GT-CMD-D105 存在未处理低电告警并有可写会话 SID-D105-03
  2. 离线设备 GT-CMD-D106 存在未处理围栏告警且无当前会话
- 测试步骤
  1. 打开 GT-CMD-D105 指令页并检查七类指令状态。
  2. 返回后打开 GT-CMD-D106 指令页并检查七类指令状态。
  3. 比较两台设备的告警标识与通信状态对指令状态的影响。
- 预期结果
  1. GT-CMD-D105 的普通五类和高危两类均按在线会话条件展示可操作，告警不单独禁用指令。

  3. 告警作为叠加状态独立展示，不新增第八类指令或改变普通与高危分类。

## POINT-003 普通五类离线受理

### [P1] 验证离线设备提交立即定位进入普通队列
- 测试类型
  - 功能
- 前置条件
  1. 账号 GT-CMD-U020 有权控制离线设备 GT-CMD-D201
  2. GT-CMD-D201 的 Device ID、S10U 路由和 CR 型号能力均有效，当前无可写会话
- 测试步骤
  1. 在 GT-CMD-D201 指令页选择立即定位 CR。
  2. 确认提交并等待服务端返回受理结果。
  3. 查询本次操作对应的任务状态和普通队列。
- 预期结果
  1. CR 可进入确认流程，不因设备离线被禁用。
  2. 服务端受理本次操作，页面反馈已提交且说明后续发送可能等待设备恢复通信。
  3. 仅建立一条 SENDING 任务并进入普通队列，不创建高危会话绑定任务。

### [P1] 验证尚未连接设备提交查询版本可被受理
- 测试类型
  - 功能
- 前置条件
  1. 设备 GT-CMD-D202 尚无有效通信记录但具有合法 S10U 路由 ROUTE-D202
  2. 当前账号与 GT-CMD-D202 的控制关系有效，型号支持 VERNO
- 测试步骤
  1. 在 GT-CMD-D202 指令页选择查询版本 VERNO。
  2. 确认提交。
  3. 检查受理结果、任务状态和设备页面状态。
- 预期结果
  1. VERNO 可选择，页面不把“尚未连接”解释为路由缺失。
  2. 服务端创建 SENDING 任务并返回受理成功语义。
  3. 设备仍展示离线且尚未连接，任务等待后续通信，不伪造版本回复。

### [P1] 验证离线告警设备提交查找设备进入普通队列

## POINT-004 UPLOAD参数与秒值换算

### [P1] 验证三个上传间隔预设分别换算为正确秒值
- 测试类型
  - 功能
- 前置条件
  1. 在线设备 GT-CMD-D301 支持 UPLOAD，当前账号有控制权限
  2. 抓包环境可查看实际提交的协议参数
- 测试步骤
  1. 选择“1 分钟”预设并提交一次 UPLOAD。
  2. 选择“10 分钟”预设并提交一次 UPLOAD。
