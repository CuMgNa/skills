# 用户故事：US-022 查看指令状态、补发和覆盖结果 - POINT-006 写出断线取消竞态单终态

## [P1] 验证TCP写出原子事实先完成时竞态结果收敛为SENT
- 测试类型
  - 可靠性
- 前置条件
  1. 高危RESET任务CMD-2206-001绑定SESSION-220601-A且状态为SENDING
  2. 模拟TCP写出提交成功发生在会话断开清理之前
- 测试步骤
  1. 并发触发TCP写出成功回调和SESSION-220601-A断开事件
  2. 查询CMD-2206-001最终状态、队列、统计和通知
- 预期结果
  1. TCP写出成功事实被记录且仅记录一次
  2. CMD-2206-001最终仅为SENT，不同时出现FAILURE；队列清理不重复累计失败统计或发送通知

## [P1] 验证断线清队列原子事实先完成时竞态结果收敛为FAILURE
- 测试类型
  - 可靠性
- 前置条件
  1. 高危POWEROFF任务CMD-2206-002绑定SESSION-220602-A且尚未写出
  2. 模拟断线清队列成功发生在TCP写出提交之前
- 测试步骤
  1. 并发触发SESSION-220602-A断开清理和写出请求
  2. 查询TCP通道日志、任务状态和失败统计
- 预期结果
  1. 断线清理成功后CMD-2206-002从队列移除，后续写出请求不能越过终态裁决
  2. CMD-2206-002最终仅为FAILURE且无TCP写出记录，失败统计只累计一次

## [P1] 验证未写出任务取消删除先完成时维持CANCEL
- 测试类型
  - 功能
- 前置条件
  1. 普通CR任务CMD-2206-003为SENDING且尚未写出
  2. 用户取消请求CAN-2206-003已到达服务端
- 测试步骤
  1. 在写出前完成队列删除并返回取消确认
  2. 查询CMD-2206-003的状态、cancelResolution和TCP写出日志
- 预期结果
  1. 队列删除成功且任务不再可写出
  2. CMD-2206-003维持CANCEL，cancelResolution为CONFIRMED且TCP写出日志为空

## [P1] 验证乐观CANCEL后发现已写出时修正为SENT
- 测试类型
  - 功能
- 前置条件
  1. UPLOAD任务CMD-2206-004参数600秒，APP已因用户取消乐观展示CANCEL
  2. 网关权威事实表明该任务在取消删除前已完成TCP写出
- 测试步骤
  1. 发送CMD-2206-004的可靠写出回调
  2. 查询记录状态、cancelResolution、sentAt和用户提醒
- 预期结果
  1. 可靠写出事实将CMD-2206-004从CANCEL修正为SENT
  2. cancelResolution为OVERRIDDEN_BY_SENT，sentAt有值，并产生一次“取消未生效，指令已下发”提醒

## [P3][反向] 验证SENT后迟到取消结果不能覆盖写出事实
- 测试类型
  - 可靠性
- 前置条件
  1. FIND任务CMD-2206-005已为SENT，sentAt为2026-10-11 15:30:20
  2. 迟到取消结果CAN-2206-005-LATE即将到达
- 测试步骤
  1. 提交CAN-2206-005-LATE
  2. 查询任务状态、sentAt、统计和通知记录
- 预期结果
  1. 迟到取消结果不能将CMD-2206-005改为CANCEL
  2. 记录保持SENT且sentAt不变，已发送统计不减、已取消统计不增，不重复通知

## [P3][反向] 验证关系失效清理与写出并发时只有一个权威终态
- 测试类型
  - 可靠性
- 前置条件
  1. ZONE任务CMD-2206-006参数UTC+08:00且状态为SENDING
  2. 模拟关系失效清理与TCP写出提交同时竞争
- 测试步骤
  1. 并发触发关系失效事件REL-2206-006和TCP写出请求
  2. 查询原子裁决结果、TCP日志、任务状态和统计
- 预期结果
  1. 系统根据先完成的权威原子事实裁决结果，不产生双写或双终态
  2. CMD-2206-006最终只能是SENT或FAILURE之一，统计总数保持1且通知不重复

## [P3][反向] 验证重复写出断线取消回调不产生重复副作用
- 测试类型
  - 可靠性
- 前置条件
  1. RESET任务CMD-2206-007已经裁决为SENT
  2. 已处理回调WRITE-2206-007、DISC-2206-007和CAN-2206-007各一次
- 测试步骤
  1. 将WRITE-2206-007、DISC-2206-007和CAN-2206-007各重复投递两次
  2. 查询最终状态、状态变更历史、统计、通知和终端写出次数
- 预期结果
  1. 所有重复回调均被幂等处理，CMD-2206-007保持SENT
  2. 终端实际写出次数仍为1，状态统计只累计1条记录，通知和业务副作用不重复
