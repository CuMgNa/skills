## 7. 关键守恒量和安全红线覆盖

| 红线 | 覆盖结论 |
| --- | --- |
| 普通五类不得因离线或未连接被拒绝 | US-020 POINT-003、US-021 POINT-004 |
| RESET/POWEROFF 必须复检当前可写会话 | US-020 POINT-006、US-021 POINT-005 |
| 高危任务绑定具体会话且不迁移至新会话 | US-022 POINT-001、POINT-008 |
| 会话查询异常不得伪装成设备离线 | US-020 POINT-006、US-021 POINT-005 |

## 8. 规则冲突处理

| 冲突 / 旧口径 | 本次处理 |
| --- | --- |
| 七类指令统一在线限制 | 按普通五类离线可受理、高危两类当前会话复检建例 |
| 批量离线设备不可选择或直接跳过 | 允许选择；普通指令可受理，高危失败设备建立逐设备 FAILURE |
| 批量关机长按 1 秒 | 按普通二次确认建例，不验证长按手势 |
| 批量成功、拒绝、跳过三类 | 改为全部受理、部分受理、全部失败三状态 |
| 记录跳转携带 batchId 锁定本批次 | 按进入批量记录 L1 全量刷新、不定位建例 |
| QUEUED/COMPLETED/REJECTED/CANCELLED/EXPIRED | 统一使用 SENDING/SENT/FAILURE/CANCEL |
| ACKED/TIMEOUT 作为 APP 状态 | 回文与发送四态分离，不新增第五状态 |
| 新配置覆盖并取消旧待发任务 | 所有已受理配置任务保留，按 configSequence 处理 |
| Location Interval 仅展示 | 页面级能力复用设备管理 US-018，不在本目录复制 |
| 我的页统一展示全部指令记录 | 单设备记录从下发页进入；我的模块只承载批量记录 |
