# US-014 接收设备进入和离开围栏事件

> 口径依据：地理围栏大纲 10.1、10.4。终端位置与围栏圆心使用同一坐标系计算球面距离，距离≤半径为圆内、距离＞半径为圆外；半径合法范围为 50～20000m（见 US-011 POINT-004）。本 POINT 补充最小/最大半径、跨 180° 经线、高纬度和“危险侧反方向”的边界判定，距离由定位模拟器按球面距离精确注入。

## [P4] 验证最小半径 50m 的 49.9m、50.0m、50.1m 判定
- 测试类型
  - 功能
- 前置条件
  1. 安全区 GF-R50 圆心 (116.397128°E, 39.916527°N)，半径 50m，DEV-GF-190 已用 r50-base（圆心处）建立圆内基线
- 测试步骤
  1. 注入 r50-001，距圆心 49.9m。
  2. 注入 r50-002，距圆心 50.0m。
  3. 注入 r50-003，距圆心 50.1m，并查询事件。
- 预期结果
  1. 49.9m 小于半径，判为圆内，不生成事件。
  2. 50.0m 等于半径，归圆内，不生成事件。
  3. 50.1m 大于半径，判为圆外，生成 1 条「离开安全区」事件。

## [P4] 验证跨 180° 经线的圆形判定按球面距离计算
- 测试类型
  - 功能
- 前置条件
  1. 安全区 GF-ANTI 圆心 (179.9990°E, 17.7000°S)，半径 500m，DEV-GF-192 已用 anti-base（圆心处）建立圆内基线
- 测试步骤
  1. 注入 anti-001，坐标 (-179.9990°, -17.7000°)，球面距圆心约 212m。
  2. 注入 anti-002，坐标 (-179.9950°, -17.7000°)，球面距圆心约 636m。
  3. 查询两条消息的计算距离和事件。
- 预期结果
  1. anti-001 虽经度数值符号相反，按球面距离判为圆内，不生成事件。
  2. anti-002 判为圆外，生成 1 条「离开安全区」事件。
  3. 判定距离分别约为 212m 和 636m，不出现按经度差 358° 直接相减得到的圆外误判。

## [P4] 验证安全区边界内侧不告警与禁入区边界外侧不告警
- 测试类型
  - 功能
- 前置条件
  1. 安全区 GF-BND-S 半径 500m，DEV-GF-194 已建立圆外基线（距圆心 650m）
  2. 禁入区 GF-BND-F 半径 500m，DEV-GF-195 已建立圆内基线（距圆心 100m）
- 测试步骤
  1. 为 DEV-GF-194 注入 bnd-s-001，距圆心 499.9m。
  2. 为 DEV-GF-194 注入 bnd-s-002，距圆心 500.0m。
  3. 为 DEV-GF-195 注入 bnd-f-001，距圆心 500.1m。
  4. 查询两台设备的状态和事件。
- 预期结果
  1. 499.9m 判为圆内，安全区正常侧，不生成事件。
  2. 500.0m 归圆内，安全区正常侧，不生成事件。
  3. 500.1m 判为圆外，禁入区正常侧，不生成事件。
  4. DEV-GF-194 lastInside 为圆内，DEV-GF-195 lastInside 为圆外，两围栏事件数均为 0。
