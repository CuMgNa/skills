# US-014 接收设备进入和离开围栏事件

> 口径依据：地理围栏大纲 11.4、11.5、11.8 B01～B09。事件只由本次所在区域决定；相离围栏可因跳点从 A 直接到 B；边界点、外切/内切切点归圆内；同心同半径围栏逐一判定。几何不可达前态不得被强行修正。
>
> 几何约定（同心）：A、B 圆心均为 (116.397128°E, 39.916527°N)，半径均 500m；圆外取距圆心 650m，圆内取距圆心 100m。

## [P2] 验证相离围栏跳点只按目标区域判定且不补发路径事件
- 测试类型
  - 功能
- 前置条件
  1. 安全区 A=GF-DISJ-A 圆心 (116.397128°E, 39.916527°N)、半径 500m；禁入区 B=GF-DISJ-B 圆心 (116.420553°E, 39.916527°N)、半径 500m，两圆相距 2000m 相离
  2. DEV-GF-170 已绑定二者，已用 disj-base（A 圆心处）建立 A 圆内、B 圆外基线，事件数为 0
- 测试步骤
  1. 注入 disj-001，直接位于 B 圆心处，中间无任何 O 区报文。
  2. 查询 A、B 的 lastInside 与事件。
  3. 查询历史轨迹和告警中心，核对是否存在路径中间位置的事件。
- 预期结果
  1. disj-001 按目标 B 区判定：A 在圆外、B 在圆内。
  2. 生成 A 的「离开安全区」和 B 的「进入禁入区」共 2 条事件，lastInside 更新为 A 圆外、B 圆内。
  3. 不补发路径中可能经过 O 区的事件，事件总数为 2。

## [P5][反向] 验证嵌套围栏出现几何不可达前态时不强行修正且分别计算
- 测试类型
  - 可靠性
- 前置条件
  1. 安全区 A=GF-ABN-A 半径 1000m、安全区 B=GF-ABN-B 半径 300m，B 位于 A 内，二者嵌套，DEV-GF-171 已绑定
  2. 通过测试手段注入错误缓存，使 lastInside 为 A 圆外、B 圆内（嵌套下几何不可能的前态），事件数为 0
- 测试步骤
  1. 注入 abn-001，位于 B 圆内（X 区）。
  2. 查询 A、B 的 lastInside、事件和诊断日志。
  3. 注入 abn-002，位于 A、B 圆外（O 区），查询事件。
- 预期结果
  1. abn-001 对 A、B 分别按本次位置计算，均为圆内，不生成事件。
  2. 不对前态做强行区域修正，lastInside 更新为 A、B 均圆内，并留有记录该几何不可达前态的诊断日志。
  3. abn-002 生成「离开安全区」A 和 B 共 2 条事件。

## [P4] 验证边界点对禁入区持续告警而对安全区不告警
- 测试类型
  - 功能
- 前置条件
  1. 禁入区 GF-B02-F 半径 500m，DEV-GF-172 已建立圆外基线（距圆心 650m）
  2. 安全区 GF-B02-S 半径 500m，DEV-GF-173 已建立圆外基线（距圆心 650m）
  3. 两围栏圆心相同，边界点指距圆心精确 500.0m
- 测试步骤
  1. 为 DEV-GF-172 注入 b02-f-001，位于边界点 500.0m。
  2. 为 DEV-GF-172 注入 b02-f-002，仍位于边界点 500.0m。
  3. 为 DEV-GF-173 注入 b02-s-001，位于边界点 500.0m。
  4. 查询两台设备的 lastInside 与事件。
- 预期结果
  1. b02-f-001 归圆内，生成「进入禁入区」1 条事件。
  2. b02-f-002 仍停在边界点，再生成「进入禁入区」1 条事件，共 2 条。
  3. b02-s-001 归圆内，安全区正常侧，不生成事件。
  4. 两台设备 lastInside 均为圆内，GF-B02-F 共 2 条事件，GF-B02-S 共 0 条。
