# US-014 接收设备进入和离开围栏事件

> 口径依据：地理围栏大纲 11.2、11.3。两个围栏均有基线时，事件结果只取决于本次位置所在区域和类型组合（SS/FF/SF/FS），共 4 区域×4 组合 = 16 个格子。本 POINT 每个组合用一个用例依次覆盖 O、A、B、X 四个区域，补足 POINT-007 只覆盖少数格子的缺口。
>
> 几何约定（相交）：A 圆心 (116.397128°E, 39.916527°N)，B 圆心在 A 正东 600m (116.404155°E, 39.916527°N)，两圆半径均 500m。沿东西轴取点，纬度均为 39.916527°N：O 区 = A 圆心西 800m (116.387758°E)，A 区 = A 圆心西 300m (116.393614°E)，X 区 = A 圆心东 300m (116.400642°E)，B 区 = A 圆心东 800m (116.406498°E)。各点与两圆心的球面距离由定位模拟器校准。

## [P1] 验证 SS 组合在 O、A、B、X 四个区域的事件结果
- 测试类型
  - 功能
- 前置条件
  1. DEV-GF-150 绑定安全区 A=GF-MX-SS-A、安全区 B=GF-MX-SS-B，几何为相交约定
  2. A、B 均已用 mx-ss-base（O 区）建立圆外基线，当前事件数为 0
- 测试步骤
  1. 注入 mx-ss-001，位于 O 区。
  2. 注入 mx-ss-002，位于 A 区。
  3. 注入 mx-ss-003，位于 B 区。
  4. 注入 mx-ss-004，位于 X 区，并查询 A、B 的 lastInside 与事件。
- 预期结果
  1. O 区 A、B 均在圆外，生成「离开安全区」A 和 B 共 2 条事件。
  2. A 区 A 在圆内、B 在圆外，只生成 B 的「离开安全区」1 条事件。
  3. B 区 A 在圆外、B 在圆内，只生成 A 的「离开安全区」1 条事件。
  4. X 区 A、B 均在圆内，不生成事件；全序列共 4 条，最终 A、B 的 lastInside 均为圆内。
