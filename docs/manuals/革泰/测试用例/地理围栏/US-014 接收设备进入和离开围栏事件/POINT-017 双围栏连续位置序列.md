# US-014 接收设备进入和离开围栏事件

> 口径依据：地理围栏大纲 11.11 Q01～Q08。每个序列第一项用于建立基线，后续每一项都是消息 ID 不同的新有效定位；连续序列只按离散报文判断，不推测两点之间穿越的区域；处理旧告警不抑制新事件。
>
> 几何约定（相交）：A 圆心 (116.397128°E, 39.916527°N)，B 圆心在 A 正东 600m (116.404155°E, 39.916527°N)，半径均 500m；O 区 = 圆心西 800m (116.387758°E)，X 区 = 圆心东 300m (116.400642°E)。
> 几何约定（嵌套）：A 半径 1000m，圆心 (116.397128°E, 39.916527°N)；B 半径 300m，圆心在 A 正东 200m (116.399470°E, 39.916527°N)；O 区 = A 圆心西 1500m (116.379560°E)，A 环带 = A 圆心西 600m (116.390101°E)，X 区 = B 圆心 (116.399470°E)。
> 几何约定（同心）：A、B 圆心均为 (116.397128°E, 39.916527°N)，半径均 500m；O 区 = 圆心外 650m，X 区 = 圆心内 100m。

## [P1] 验证 Q01 嵌套 SS 序列 O→A→X→A→O→O 的逐步事件
- 测试类型
  - 功能
- 前置条件
  1. DEV-GF-160 绑定安全区 A=GF-Q01-A、安全区 B=GF-Q01-B，几何为嵌套约定
  2. 事件数为 0，lastInside 均为空
- 测试步骤
  1. 注入 q01-001，位于 O 区（基线）。
  2. 注入 q01-002，位于 A 环带。
  3. 注入 q01-003，位于 X 区。
  4. 注入 q01-004，位于 A 环带。
  5. 注入 q01-005，位于 O 区。
  6. 注入 q01-006，位于 O 区，并统计总事件。
- 预期结果
  1. q01-001 为两围栏建立圆外基线，事件 0 条。
  2. q01-002 A 在圆内、B 在圆外，生成「离开安全区」B 1 条。
  3. q01-003 A、B 均在圆内，事件 0 条。
  4. q01-004 再生成「离开安全区」B 1 条。
  5. q01-005 A、B 均在圆外，生成「离开安全区」A 和 B 共 2 条。
  6. q01-006 继续生成 A 和 B 共 2 条；全序列合计 6 条。

## [P2] 验证 Q04 每次告警产生后立即人工处理不抑制后续事件

  - 功能
- 前置条件

  2. E1 对两围栏和设备均有处理权，事件数为 0
- 测试步骤

  2. 注入 q04-003（O 区），并由 E1 处理产生的全部事件。
  3. 注入 q04-004（X 区）和 q04-005（O 区），并由 E1 处理新产生的全部事件。

  4. 事件总数 4 条与 Q03 相同，且 4 条均为已处理。
