# US-014 接收设备进入和离开围栏事件

> 口径依据：地理围栏大纲 10.4、10.6。单围栏决策表共 11 行：关闭任意状态不判断；安全区“首次/内→外/外→外/外→内/内→内”，禁入区“首次/外→内/内→内/内→外/外→外”。本 POINT 用连续位置序列把安全区、禁入区的全部状态迁移逐行验证，补足 POINT-003 只覆盖“首次危险侧、持续危险侧”的缺口。

## [P1] 验证安全区全部状态迁移的告警与不告警结果
- 测试类型
  - 功能
- 前置条件
  1. 安全区 GF-DT-S 圆心 (116.397128°E, 39.916527°N)，半径 500m，已绑定 DEV-GF-100，设备×围栏 lastInside 为空
  2. 设备对 E1 可见，当前无历史围栏事件
- 测试步骤
  1. 注入 dt-s-001，位于圆内 100m（首次）。
  2. 注入 dt-s-002，位于圆内 120m（内→内）。
  3. 注入 dt-s-003，位于圆外 650m（内→外）。
  4. 注入 dt-s-004，位于圆外 660m（外→外）。
  5. 注入 dt-s-005，位于圆内 90m（外→内）。
  6. 注入 dt-s-006，位于圆内 80m（内→内），并查询全部事件。
- 预期结果
  1. dt-s-001 只写入圆内基线和时间水位，不生成事件。
  2. dt-s-002 保持圆内，不生成事件。
  3. dt-s-003 更新为圆外，生成 1 条「离开安全区」事件。
  4. dt-s-004 保持圆外，再生成 1 条「离开安全区」事件，与 dt-s-003 事件相互独立。
  5. dt-s-005 更新为圆内，不生成恢复事件，dt-s-003、dt-s-004 两条历史事件保持未处理且不被删除。
  6. dt-s-006 不生成事件；全序列共 2 条事件，最终 lastInside 为圆内。

  2. 设备对 E1 可见，当前无历史围栏事件
- 测试步骤

  2. 注入 dt-f-002，位于圆外 710m（外→外）。
  3. 注入 dt-f-003，位于圆内 200m（外→内）。
  4. 注入 dt-f-004，位于圆内 210m（内→内）。
  5. 注入 dt-f-005，位于圆外 800m（内→外）。
  6. 注入 dt-f-006，位于圆外 810m（外→外），并查询全部事件。
- 预期结果
  1. dt-f-001 只写入圆外基线和时间水位，不生成事件。
  2. dt-f-002 保持圆外，不生成事件。
  3. dt-f-003 更新为圆内，生成 1 条「进入禁入区」事件。

  5. dt-f-005 更新为圆外，不生成“离开禁入区”类恢复事件，dt-f-003、dt-f-004 两条历史事件保持未处理且不被删除。
  6. dt-f-006 不生成事件；全序列共 2 条事件，最终 lastInside 为圆外。

## [P2] 验证关闭围栏对任意位置均不判断且不建立基线
- 测试类型
  - 功能
- 前置条件
  1. 安全区 GF-DT-C 半径 500m 已切换为关闭，DEV-GF-102 的物理绑定关系保留，lastInside 已清空
  2. 当前判定水位记录为空
- 测试步骤
  1. 注入 dt-c-001，位于圆内 100m。
  2. 注入 dt-c-002，位于圆外 650m。
  3. 注入 dt-c-003，位于圆外 660m。
  4. 查询 DEV-GF-102 对 GF-DT-C 的 lastInside、判定水位、事件和绑定关系。
- 预期结果
  1. dt-c-001 不参与围栏判断，不写入基线。
  2. dt-c-002 不参与围栏判断，不生成事件。
  3. dt-c-003 同样不参与判断，关闭围栏不因持续圆外而告警。
  4. lastInside 和判定水位仍为空，事件数为 0，物理绑定关系仍保留。

## [P2] 验证首条危险侧位置只建基线后回到正常侧全程不告警
- 测试类型
  - 功能
- 前置条件
  1. 安全区 GF-DT-R 半径 500m，已绑定 DEV-GF-103，lastInside 为空
  2. 当前无历史围栏事件
- 测试步骤
  1. 注入 dt-r-001，位于圆外 700m（首次且处于危险侧）。
  2. 注入 dt-r-002，位于圆内 100m（外→内）。
  3. 注入 dt-r-003，位于圆内 110m（内→内）。
  4. 注入 dt-r-004，位于圆外 720m（内→外），查询事件。
- 预期结果
  1. dt-r-001 只写入圆外基线，不因位于危险侧而告警。
  2. dt-r-002 更新为圆内，不生成事件。
  3. dt-r-003 保持圆内，不生成事件。
  4. dt-r-004 生成 1 条「离开安全区」事件，全序列共 1 条；首条危险侧位置未被事后补发告警。
