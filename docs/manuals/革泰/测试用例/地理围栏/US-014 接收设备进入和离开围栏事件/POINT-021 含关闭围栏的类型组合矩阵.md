# US-014 接收设备进入和离开围栏事件

> 口径依据：地理围栏大纲 11.6。关闭围栏不判断、不更新有效基线、不生成事件；启用围栏仍按本次位置是否处于自身危险侧判断。共 5 种含关闭的类型组合，每种覆盖 O、A、B、X 四个区域；POINT-007 仅覆盖“安全区+关闭”的 O 区。
>
> 几何约定（相交）：A 圆心 (116.397128°E, 39.916527°N)，B 圆心在 A 正东 600m (116.404155°E, 39.916527°N)，半径均 500m。沿东西轴取点：O 区 = A 圆心西 800m (116.387758°E)，A 区 = A 圆心西 300m (116.393614°E)，X 区 = A 圆心东 300m (116.400642°E)，B 区 = A 圆心东 800m (116.406498°E)。

## [P1] 验证 A 安全区且 B 关闭时四个区域的事件结果
- 测试类型
  - 功能
- 前置条件
  1. DEV-GF-210 绑定安全区 A=GF-CL1-A 和关闭围栏 B=GF-CL1-B，几何为相交约定
  2. A 已用 cl1-base（X 区）建立圆内基线，B 无有效基线，事件数为 0
- 测试步骤
  1. 注入 cl1-001，位于 O 区。
  2. 注入 cl1-002，位于 A 区。
  3. 注入 cl1-003，位于 B 区。
  4. 注入 cl1-004，位于 X 区，并查询 B 的基线和事件。
- 预期结果
  1. O 区 A 在圆外，生成「离开安全区」A 1 条。
  2. A 区 A 在圆内，不生成事件。
  3. B 区 A 在圆外，生成「离开安全区」A 1 条。
  4. X 区 A 在圆内，不生成事件；B 全程无基线、无事件，合计 2 条。
