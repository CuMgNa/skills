# US-014 接收设备进入和离开围栏事件

> 口径依据：地理围栏大纲 11.7 F01～F08。“首次”指设备×围栏 lastInside 为空；首次只为该围栏建基线，即使已处于危险侧也不告警，其他已有基线的围栏继续正常判断；关闭围栏不判断。POINT-008 已覆盖 F02 的“A 首次 + B 安全区已有基线”，本 POINT 补齐其余行。
>
> 几何约定（相交）：A 圆心 (116.397128°E, 39.916527°N)，B 圆心在 A 正东 600m (116.404155°E, 39.916527°N)，半径均 500m。沿东西轴取点：O 区 = A 圆心西 800m (116.387758°E)，A 区 = A 圆心西 300m (116.393614°E)，X 区 = A 圆心东 300m (116.400642°E)，B 区 = A 圆心东 800m (116.406498°E)。

## [P2] 验证 F01 首次与关闭围栏组合的首条位置不产生事件
- 测试类型
  - 功能
- 前置条件
  1. DEV-GF-200 绑定安全区 A=GF-F01-A（lastInside 为空）和关闭围栏 B=GF-F01-B，几何为相交约定
  2. 事件数为 0
- 测试步骤
  1. 注入 f01-001，位于 O 区（A 的危险侧）。
  2. 查询 A、B 的 lastInside 和事件。
  3. 注入 f01-002，位于 O 区，并查询事件。
- 预期结果
  1. f01-001 对 A 只建立圆外基线，对 B 不判断。
  2. A lastInside 为圆外，B 仍为空，事件 0 条。
  3. f01-002 对 A 生成 1 条「离开安全区」事件，B 仍不判断。
