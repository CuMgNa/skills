# US-014 接收设备进入和离开围栏事件

> 口径依据：地理围栏大纲 12.1、12.2、12.4、12.6。围栏关系依赖设备可见范围；地图使用正式配置和有效位置；告警中心展示单物理事件及账号关系，各模块统计口径不得混用。

## [P1] 验证设备管理失权级联清理围栏账号关系
- 测试类型
  - 功能
- 前置条件
  1. E1向 E2、E3分配 DEV-GF-080，三账号均关联共享围栏 GF-MOD-01
  2. 设备×围栏物理关系已有基线
- 测试步骤
  1. 在设备管理中回收 E2的设备分配，使 E2及其下游 E3失去设备可见权。
  2. 查询围栏账号关系与物理关系。
  3. 注入一条危险侧有效位置 gf-module-001。
- 预期结果
  1. E2、E3对应围栏设备账号关系被清理，E1关系保留。
  2. 因仍有 E1关系，物理关系与唯一基线保留；设备重新分配后原围栏账号关系不自动恢复。
  3. 生成 1 条物理事件且只为 E1建立关系，E2、E3不可见。

## [P1] 验证围栏配置变更后地图范围最终一致且不使用旧缓存
- 测试类型
  - 功能
- 前置条件
  1. GF-MOD-02 当前圆心为 151.200000°E、33.860000°S，半径 500m
  2. 地图首页、列表缩略图、统计页均已加载旧范围
- 测试步骤
  1. 将圆心改为 151.210000°E、33.870000°S，半径改为 800m并保存。
  2. 刷新地图首页、围栏列表和统计页。
  3. 查询三处展示使用的围栏 ID、圆心、半径和配置版本。
- 预期结果
  1. 编辑成功并主动失效 GF-MOD-02旧缓存。
  2. 三处最终均展示新圆心和 800m 范围，不继续使用旧缩略图或旧圆形。
  3. 三处引用同一围栏 ID和已提交配置版本；地图全局统计不冒充单围栏统计。

## [P3][反向] 验证无效位置不把地图设备点移动到异常坐标
- 测试类型
  - 可靠性
- 前置条件
  1. DEV-GF-081 最近有效位置为 151.215000°E、33.875000°S
  2. 设备已绑定 GF-MOD-03且地图显示正常点位
- 测试步骤
  1. 注入 gf-map-invalid-001，经纬度均为 0。
  2. 注入 gf-map-invalid-002，经度 181.0、纬度 -91.0。
  3. 刷新地图首页、围栏统计页和实时追踪页。
- 预期结果
  1. 零坐标报文被丢弃，不更新最新有效位置或围栏基线。
  2. 越界坐标报文被丢弃，不参与围栏判定。
  3. 三个页面继续显示最近有效位置，不移动到(0,0)或异常经纬度。

## [P1] 验证告警中心明细与围栏统计按不同口径联动
- 测试类型
  - 功能
- 前置条件
  1. GF-MOD-04绑定 DEV-GF-082和 DEV-GF-083
  2. DEV-GF-082已有 2 条未处理围栏事件，DEV-GF-083已有 1 条未处理围栏事件
- 测试步骤
  1. 查看告警中心 GF-MOD-04相关事件记录数。
  2. 查看围栏统计页告警设备数。
  3. 处理 DEV-GF-082的全部 2 条事件。
  4. 重新查看两处统计。
- 预期结果
  1. 告警中心显示 3 条独立事件明细。
  2. 围栏统计页按存在未处理告警的设备去重，告警设备数为 2。
  3. 仅 DEV-GF-082两条关系变为已处理，不影响 DEV-GF-083事件。
  4. 告警中心仍保留 3 条历史明细，围栏统计告警设备数更新为 1。
