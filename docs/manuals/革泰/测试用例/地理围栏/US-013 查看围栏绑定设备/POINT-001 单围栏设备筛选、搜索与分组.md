# US-013 查看围栏绑定设备

> 口径依据：需求真源第 6.2 节、第 6.4 节。状态、设备分组、关键词三个条件取交集，修改任一条件不得清空其他有效条件；搜索支持编号、名称、备注、序列号模糊匹配，忽略关键词首尾空格且英文大小写不敏感；“当前显示 N 台”必须与列表实际渲染数量一致。

## [P1] 验证状态分组关键词三条件按交集筛选
- 测试类型
  - 功能
- 前置条件
  1. 账号 corp_level2_01 已进入 GF-FILTER-001 统计页
  2. 东区分组有 D2001（名称 Rescue-Alpha-01，在线）、D2002（名称 Rescue-Beta-01，在线）、D2003（名称 Rescue-Alpha-02，离线）、D2005（名称 Patrol-East-01，在线且告警）、D2006（名称 Rescue-Alpha-03，在线且告警）
  3. 西区分组有 D2004（名称 Rescue-Alpha-04，在线）
- 测试步骤
  1. 选择状态“在线”。
  2. 选择设备分组“东区”。
  3. 输入关键词“rescue-alpha”。
  4. 核对列表设备和“当前显示 N 台”。
- 预期结果
  1. 列表仅保留在线设备，其他筛选条件尚未选择。
  2. 列表范围缩小为同时满足在线且属于东区的设备。
  3. 最终仅显示 D2001、D2006，三个条件按交集生效。
  4. “当前显示 2 台”，与列表实际渲染的 2 行一致；不得用东区分组总数 5 代替。

## [P2] 验证修改状态条件不清空已有分组和关键词
- 测试类型
  - 功能
- 前置条件
  1. GF-FILTER-001 已应用状态“在线”、分组“东区”、关键词“rescue-alpha”
  2. 当前列表为 D2001、D2006，其中仅 D2006 存在未处理围栏告警
- 测试步骤
  1. 将状态由“在线”切换为“告警”。
  2. 查看分组选择值与搜索框关键词。
  3. 核对筛选后的设备列表和显示数量。
- 预期结果
  1. 状态改为告警后立即按新交集刷新。
  2. 分组仍为东区，关键词仍为 rescue-alpha，未被状态变化清空。
  3. 列表仅显示 D2006，“当前显示 1 台”与实际列表行数一致。

## [P2] 验证清空关键词恢复当前状态与分组交集
- 测试类型
  - 功能
- 前置条件
  1. GF-FILTER-001 已应用状态“告警”、分组“东区”、关键词“rescue-alpha”
  2. 东区告警设备为 D2005、D2006，当前关键词结果仅有 D2006
- 测试步骤
  1. 点击清空搜索关键词。
  2. 查看状态和分组控件是否保留原值。
  3. 核对恢复后的设备列表与显示数量。
- 预期结果
  1. 关键词变为空，列表重新按剩余条件查询。
  2. 状态仍为告警，分组仍为东区。
  3. 列表恢复为 D2005、D2006，“当前显示 2 台”，不扩大到非告警或非东区设备。

## [P2] 验证编号名称备注序列号搜索归一化与模糊匹配
- 测试类型
  - 功能
- 前置条件
  1. GF-FILTER-002 已绑定 D2101（编号 710045，名称 Field Beacon，备注 North Gate，序列号 GT-SN-A9X21）
  2. 当前未选择状态和分组条件
- 测试步骤
  1. 输入编号片段“0045”执行搜索。
  2. 输入名称关键词“  field bea  ”执行搜索。
  3. 输入备注关键词“north gat”执行搜索。
  4. 输入序列号关键词“gt-sn-a9x”执行搜索。
- 预期结果
  1. 列表命中 D2101，编号支持包含匹配。
  2. 首尾空格被忽略且英文大小写不敏感，列表命中 D2101。
  3. 备注支持包含匹配，列表命中 D2101。
  4. 序列号支持包含匹配且英文大小写不敏感，列表命中 D2101。
