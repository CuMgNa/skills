# US-013 查看围栏绑定设备

> 口径依据：产品需求文档电子围栏统计页主流程第 3、5、6 步及验收标准（2026-09-10 修订：地图与列表同步搜索）。状态、分组、关键词三个条件取交集，同时过滤地图和列表；地图仅绘制匹配设备中的有效位置；匹配设备无有效位置时保留列表行、当前显示数量和绑定总数，不伪造地图点；点击设备行或地图设备点按设备唯一标识进入实时追踪，返回后保留围栏统计上下文，实时追踪刷新不得改变围栏判定基线。此前“设备搜索只过滤列表、不移除地图点位”的口径已作废。

## [P1] 验证设备搜索同步过滤列表与地图有效点位
- 测试类型
  - 功能
- 前置条件
  1. GF-MAP-001 当前账号可见绑定设备为 D3001～D3005，五台设备均在线、均有合法最新位置并在地图显示 5 个点位
  2. 仅 D3001 名称包含“Beacon-A”，其余四台名称不含该关键词
- 测试步骤
  1. 进入 GF-MAP-001 统计页，记录地图点位数、列表行数和围栏绑定总数。
  2. 在设备搜索框输入“Beacon-A”。
  3. 核对搜索后的列表设备和“当前显示 N 台”。
  4. 核对搜索后的地图点位和围栏绑定总数。
  5. 清空搜索关键词，核对列表与地图。
- 预期结果
  1. 地图显示 D3001～D3005 共 5 个有效点位，列表显示 5 行，绑定总数为 5。
  2. 搜索条件生效，同时刷新地图和下方列表。
  3. 列表仅显示 D3001，“当前显示 1 台”。
  4. 地图仅显示 D3001 的 1 个点位，D3002～D3005 的点位不显示；绑定总数仍为 5，任何设备均未被解绑。
  5. 列表恢复 D3001～D3005 共 5 行，地图同步恢复 5 个点位，“当前显示 5 台”。

## [P2] 验证无搜索结果时列表与地图同步为空且绑定关系不变
- 测试类型
  - 功能
- 前置条件
  1. GF-MAP-001 地图已显示 D3001～D3005 共 5 个有效点位，围栏绑定总数为 5
  2. 五台设备的编号、名称、备注、序列号均不包含“ZZ-999-NONE”
- 测试步骤
  1. 输入关键词“ZZ-999-NONE”执行搜索。
  2. 查看设备列表和当前显示数量。
  3. 查看地图设备点位。
  4. 查看围栏绑定总数并清空关键词。
- 预期结果
  1. 搜索请求同时作用于列表和地图的设备范围。
  2. 列表显示“当前筛选条件下没有设备”，“当前显示 0 台”。
  3. 地图不显示任何设备点，圆形围栏范围仍正常显示。
  4. 绑定总数仍为 5，设备绑定关系未变化；清空关键词后列表恢复 5 行，地图恢复 5 个点位。

## [P1] 验证状态、分组、关键词交集同步过滤地图与列表
- 测试类型
  - 功能
- 前置条件
  1. GF-MAP-002 绑定 D3101（在线、北区）、D3102（在线、南区）、D3103（离线、北区）、D3104（离线、南区），四台均有合法地图点位
  2. 四台设备名称依次为 Alpha-3101、Alpha-3102、Alpha-3103、Alpha-3104
- 测试步骤
  1. 从围栏列表进入 GF-MAP-002 统计页，核对默认状态、分组、关键词、列表和地图。
  2. 选择状态“离线”。
  3. 再选择分组“北区”。
  4. 输入关键词“Alpha-3104”。
  5. 清空关键词。
- 预期结果
  1. 默认状态为“在线”、全部分组、空关键词；列表显示 D3101、D3102，“当前显示 2 台”，地图仅显示这 2 个点位。
  2. 列表显示 D3103、D3104，“当前显示 2 台”，地图仅显示这 2 个点位，在线设备点位不显示。
  3. 列表仅显示 D3103，“当前显示 1 台”，地图仅显示 D3103 点位。
  4. 关键词与离线、北区取交集后无匹配，列表空态、“当前显示 0 台”，地图无设备点；状态和分组条件保持不变。
  5. 列表恢复 D3103，“当前显示 1 台”，地图同步恢复 D3103 点位，状态“离线”和分组“北区”仍保持。

## [P3] 验证匹配设备无有效位置时保留列表行但不伪造地图点
- 测试类型
  - 功能
- 前置条件
  1. GF-MAP-004 绑定 D3201（在线，最后有效位置 WGS84（121.4737，31.2304））和 D3202（在线，从未有过有效位置）
  2. 两台设备名称均包含“Beacon-B”，当前账号均可见
- 测试步骤
  1. 进入 GF-MAP-004 统计页，状态保持“在线”，输入关键词“Beacon-B”。
  2. 核对列表设备、“当前显示 N 台”和设备在线状态。
  3. 核对地图设备点位及 (0,0) 附近是否出现点位。
  4. 核对围栏绑定总数和在线数量。
- 预期结果
  1. 搜索条件生效，列表与地图按同一设备范围刷新。
  2. 列表显示 D3201 和 D3202 共 2 行，“当前显示 2 台”，D3202 仍显示为在线。
  3. 地图仅显示 D3201 的 1 个点位，不为 D3202 伪造点位，(0,0) 附近无点位。
  4. 绑定总数为 2、在线数为 2，D3202 未因缺少有效位置被判为离线；地图点数少于列表行数属于预期。

## [P1] 验证按设备唯一标识下钻实时追踪并保留统计页上下文
- 测试类型
  - 功能
- 前置条件
  1. GF-MAP-003 已选择状态“离线”、分组“北区”、关键词“alpha”，筛选结果有 8 台设备，地图显示这 8 台设备中有有效位置的点位
  2. D3023 与 D3024 名称均为 Alpha Beacon，D3023 唯一标识 device-id=dev-3023，最后有效位置为 WGS84（121.4737，31.2304），当前离线
  3. 当前列表已滚动到第 4 行 D3023，D3023 的 lastInside=true
- 测试步骤
  1. 点击列表第 4 行 D3023。
  2. 核对实时追踪页加载的设备标识、位置和在线状态。
  3. 在实时追踪页连续刷新 3 次。
  4. 返回 GF-MAP-003 统计页。
  5. 核对围栏 ID、状态、分组、关键词、滚动位置、地图点位及 D3023 的 lastInside。
- 预期结果
  1. 使用 device-id=dev-3023 下钻，不因 D3023、D3024 同名而进入错误设备。
  2. 实时追踪页显示 D3023、最后有效位置（121.4737，31.2304）和离线状态，未显示无效坐标。
  3. 三次页面刷新仅更新追踪展示，不改变服务端围栏判断频率，不写入新的围栏配置或基线。
  4. 返回同一围栏 GF-MAP-003 的统计页。
  5. 状态仍为离线、分组仍为北区、关键词仍为 alpha，列表恢复到第 4 行附近，地图仍只显示筛选结果内的有效点位；D3023 的 lastInside 仍为 true。

## [P2] 验证点击地图设备点按设备唯一标识下钻实时追踪
- 测试类型
  - 功能
- 前置条件
  1. GF-MAP-005 已选择状态“在线”、分组“全部分组”、关键词“Gamma”，匹配 D3301 与 D3302，名称均为 Gamma Beacon，且均有合法地图点位
  2. D3302 唯一标识 device-id=dev-3302，最后有效位置为 WGS84（121.5000，31.2400）
- 测试步骤
  1. 点击地图上 D3302 的设备点。
  2. 核对实时追踪页加载的设备标识和位置。
  3. 返回 GF-MAP-005 统计页。
  4. 核对围栏、状态、分组、关键词、列表和地图点位。
- 预期结果
  1. 使用 device-id=dev-3302 下钻，不因与 D3301 同名而进入错误设备。
  2. 实时追踪页显示 D3302 及最后有效位置（121.5000，31.2400）。
  3. 返回同一围栏 GF-MAP-005 的统计页。
  4. 状态仍为在线、分组仍为全部分组、关键词仍为 Gamma，列表显示 D3301、D3302，地图仍显示这 2 个点位。
