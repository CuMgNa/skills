# US-012 管理围栏与设备关联

> 口径依据：地理围栏大纲 8.5、12.1、13.2 章及设备管理大纲 3.3～3.4。设备解绑、分配回收和后台改绑应清理失效链路内的围栏设备账号关系；重新绑定或重新分配设备后，原围栏关系不得自动恢复，历史位置、轨迹和告警保留。

## [P1] 验证三级在设备管理移除设备只清理三级围栏关系
- 测试类型
  - 功能
- 前置条件
  1. GT-D-000101 由 GT-E1-1001 分配给 GT-E2-2101，再分配给 GT-E3-3101
  2. GF-A-0530 对三级、二级、一级可见，三层均有该设备的围栏账号关系
  3. 物理关系 lastInside = true
- 测试步骤
  1. 以 GT-E3-3101 在设备管理中移除 GT-D-000101。
  2. 分别查询三级、二级、一级的设备可见关系和 GF-A-0530 围栏设备账号关系。
  3. 查询设备×围栏物理关系和 lastInside。
  4. 将 GT-D-000101 再次分配给 GT-E3-3101并刷新围栏。
- 预期结果
  1. 三级设备分配关系及其 GF-A-0530 账号关系被清理。
  2. 二级、一级仍可见设备且围栏关系保留，级联不向上扩散。
  3. 仍有父级账号关系，物理关系和 lastInside=true 保留。
  4. 三级重新获得设备可见权后，GF-A-0530 关系不自动恢复，需用户重新执行围栏绑定。

## [P1] 验证二级移除或被一级回收设备向下清理围栏关系
- 测试类型
  - 功能
- 前置条件
  1. GT-D-000102 已分配给 GT-E2-2101 及其下 GT-E3-3101
  2. GF-A-0531 对一级、二级、三级可见，三层均有该设备的围栏账号关系
  3. GT-E1-1001 仍保有设备和围栏关系
- 测试步骤
  1. 由 GT-E1-1001 在用户管理中回收 GT-E2-2101 的 GT-D-000102。
  2. 查询 GT-E2-2101、GT-E3-3101 和 GT-E1-1001 的设备及 GF-A-0531 关系。
  3. 查询物理关系和唯一基线。
  4. 将设备重新分配给 GT-E2-2101、GT-E3-3101并刷新 GF-A-0531。
- 预期结果
  1. 二级分配关系及其下三级分配关系失效，对应围栏账号关系同步清理。
  2. 一级设备可见性和 GF-A-0531 关系保留，其他二级分支不受影响。
  3. 因一级关系仍在，物理关系和唯一基线不清除。
  4. 重新分配只恢复设备可见权，不自动恢复二级、三级原围栏关系。

## [P1] 验证一级设备解绑清理整条企业链围栏关系
- 测试类型
  - 功能
- 前置条件
  1. GT-D-000103 直接绑定 GT-E1-1001，并逐级分配给 GT-E2-2101、GT-E3-3101
  2. GF-A-0532 与该设备仅存在上述三级企业链账号关系，物理基线已建立
  3. 个人账号 GT-P-9001 同时直接绑定同一物理设备，但关联的是独立围栏 GF-P-0902
- 测试步骤
  1. 以 GT-E1-1001 在设备管理中解绑 GT-D-000103。
  2. 查询企业一级、二级、三级的设备可见关系及 GF-A-0532 账号关系。
  3. 查询 GF-A-0532 的物理关系、基线，以及 GT-P-9001 的设备与 GF-P-0902 关系。
  4. 将设备重新绑定一级并重新分配给二级、三级，刷新 GF-A-0532。
- 预期结果
  1. 企业一级直接绑定和整条下游分配链失效，GF-A-0532 的三级账号关系全部清理。
  2. 企业三级账号均不再显示该设备；围栏本体仍保留。
  3. GF-A-0532 最后关系删除后物理关系和基线清空；个人绑定及 GF-P-0902 独立关系不受影响。
  4. 重绑和重新分配不自动恢复 GF-A-0532 关系，必须重新关联围栏。

## [P2] 验证管理后台改绑企业一级不迁移原围栏关系
- 测试类型
  - 可靠性
- 前置条件
  1. GT-D-000105 当前绑定链 A 一级 GT-E1-1001，并已分配给 GT-E2-2101、GT-E3-3101
  2. 设备已关联链 A 围栏 GF-A-0533，物理基线已建立
  3. 链 B 一级账号为 GT-E1-1002，链 B 围栏为 GF-B-0533
  4. 设备已有 5 条历史轨迹和 2 条历史围栏告警
- 测试步骤
  1. 管理后台将 GT-D-000105 从 GT-E1-1001 改绑到 GT-E1-1002。
  2. 查询链 A 各级设备关系、GF-A-0533 账号关系及物理关系。
  3. 查询 GT-E1-1002、链 B 下级和 GF-B-0533 的设备围栏关系。
  4. 核对设备历史轨迹与历史告警，再由链 B 重新分配设备后刷新 GF-B-0533。
- 预期结果
  1. 改绑等价于解绑链 A 再绑定链 B；链 A 一级及下游设备关系失效。
  2. GF-A-0533 的链 A 围栏账号关系被清理，最后关系删除时物理关系和基线清空。
  3. 仅 GT-E1-1002 获得设备直接绑定；链 B 下级默认不可见，GF-A-0533 不迁移，GF-B-0533 也不自动建立关系。
  4. 5 条历史轨迹和 2 条历史告警保留；重新分配后仍需手动把设备绑定到 GF-B-0533。
