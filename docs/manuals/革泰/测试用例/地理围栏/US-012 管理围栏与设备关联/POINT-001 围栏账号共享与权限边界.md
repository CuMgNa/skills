# US-012 管理围栏与设备关联

> 口径依据：地理围栏大纲 3.1～3.4、8.3、12.6 章。企业子级创建的围栏沿直属组织链向上共享，一级创建不自动下发；个人账号与企业链、不同企业一级分支相互隔离；同一共享链内已获得围栏关系的账号对同一围栏同权管理。

## [P1] 验证企业三级创建围栏向直属二级和一级共享
- 测试类型
  - 功能
- 前置条件
  1. 企业链 A 包含一级账号 GT-E1-1001、直属二级账号 GT-E2-2101、直属三级账号 GT-E3-3101
  2. GT-E3-3101 创建安全区“北区牧场-三级共享”，围栏 ID 为 GF-A-0501
- 测试步骤
  1. 分别以 GT-E3-3101、GT-E2-2101、GT-E1-1001 查询电子围栏列表并打开“北区牧场-三级共享”。
  2. 核对三个账号取得的围栏 ID、创建账号、圆心、半径和类型。
  3. 以非直属二级账号 GT-E2-2201 查询围栏名称和围栏 ID GF-A-0501。
- 预期结果
  1. GT-E3-3101、GT-E2-2101、GT-E1-1001 均可查看“北区牧场-三级共享”。
  2. 三个账号读取同一围栏 ID GF-A-0501 和同一份配置，创建账号保持为 GT-E3-3101，未复制出多份围栏。
  3. GT-E2-2201 无法查询或访问 GF-A-0501，且不产生围栏账号关系。

## [P1] 验证企业二级向一级共享且一级创建不自动下发
- 测试类型
  - 功能
- 前置条件
  1. GT-E2-2101 属于 GT-E1-1001，GT-E3-3101 属于 GT-E2-2101
  2. GT-E2-2101 已创建禁入区“饲料仓-二级创建”，围栏 ID 为 GF-A-0502
  3. GT-E1-1001 已创建安全区“总部仓库-一级创建”，围栏 ID 为 GF-A-0503
- 测试步骤
  1. 以 GT-E1-1001 查询 GF-A-0502，以 GT-E3-3101 查询 GF-A-0502。
  2. 以 GT-E2-2101 和 GT-E3-3101 分别查询 GF-A-0503。
  3. 核对 GF-A-0502、GF-A-0503 的围栏账号关系记录。
- 预期结果
  1. GT-E1-1001 可查看 GF-A-0502；GT-E3-3101 不因下属关系自动获得该围栏。
  2. GT-E2-2101、GT-E3-3101 均不可查看 GF-A-0503，一级创建的围栏不自动向下发放。
  3. GF-A-0502 仅建立 GT-E2-2101 与 GT-E1-1001 的围栏账号关系；GF-A-0503 仅建立 GT-E1-1001 的关系。

## [P1] 验证共享账号具备查看编辑删除和设备管理同等权限
- 测试类型
  - 功能
- 前置条件
  1. GF-A-0504 由 GT-E3-3101 创建，已向 GT-E2-2101、GT-E1-1001 共享
  2. 三个账号均可见支持定位设备 GT-D-000101
  3. 已准备可独立删除的同链共享围栏 GF-A-0505“南区临时栏”
- 测试步骤
  1. 以 GT-E1-1001 打开 GF-A-0504 的列表卡片和统计页。
  2. 以 GT-E2-2101 将 GF-A-0504 名称修改为“北区牧场-已复核”并保存，再由 GT-E1-1001、GT-E3-3101刷新查看。
  3. 以 GT-E1-1001 将设备 GT-D-000101 绑定至 GF-A-0504，再由三个账号核对各自有权设备展示。
  4. 以非创建者 GT-E2-2101 删除 GF-A-0505，再由 GT-E1-1001、GT-E3-3101 查询该围栏。
- 预期结果
  1. GT-E1-1001 可查看 GF-A-0504 的配置与统计，不因不是创建者而只读。
  2. 修改作用于同一围栏，三个账号刷新后均显示名称“北区牧场-已复核”。
  3. 设备管理操作提交成功，三个同时拥有围栏权和设备权的账号均显示 GT-D-000101，且只存在一条设备×围栏物理关系。
  4. 非创建者具备删除权限；GF-A-0505 对整条关联链全局消失，不残留任一账号关系。

## [P3][反向] 验证个人账号隔离和跨企业一级分支越权被拒绝
- 测试类型
  - 安全性
- 前置条件
  1. 个人账号 GT-P-9001 创建围栏 GF-P-0901“个人马场”
  2. 企业链 A 的 GT-E3-3101 创建围栏 GF-A-0506“链A草场”
  3. 企业链 B 包含 GT-E1-1002、GT-E2-2102、GT-E3-3102
- 测试步骤
  1. 以 GT-E1-1001、GT-E2-2101、GT-E3-3101 搜索 GF-P-0901，并尝试通过围栏 ID 直接读取。
  2. 以 GT-P-9001 搜索 GF-A-0506，并尝试通过围栏 ID 直接读取。
  3. 以链 B 的 GT-E1-1002、GT-E2-2102、GT-E3-3102 分别通过搜索、历史缓存入口和围栏 ID 访问 GF-A-0506。
  4. 核对上述失败访问未创建账号关系、未返回围栏配置或设备信息。
- 预期结果
  1. 企业链 A 各账号均不可见或读取个人围栏 GF-P-0901。
  2. GT-P-9001 不可见或读取企业围栏 GF-A-0506，即使同一物理设备同时存在个人与企业绑定也不共享围栏本体。
  3. 链 B 各账号的搜索、缓存入口和 ID 直访均不能越权读取链 A 围栏。
  4. 服务端不新增越权账号关系，响应不泄露 GF-A-0506 的名称、坐标、半径、绑定设备等受保护数据。
