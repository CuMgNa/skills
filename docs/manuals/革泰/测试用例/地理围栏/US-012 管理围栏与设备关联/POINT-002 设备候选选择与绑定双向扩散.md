# US-012 管理围栏与设备关联

> 口径依据：地理围栏大纲 5.2、8.1～8.3、13.2～13.3 章。设备候选仅包含当前账号可见且支持定位的设备；选择支持多选、服务端分页和跨条件保持；绑定关系仅扩散给同时拥有围栏权与设备权的账号；设备×围栏物理关系及判定基线保持唯一。

## [P1] 验证设备候选仅展示当前账号可见且支持定位的设备
- 测试类型
  - 功能
- 前置条件
  1. GT-E2-2101 可见且支持定位的设备为 GT-D-000101、GT-D-000102
  2. GT-E2-2101 可见但不支持定位的设备为 GT-D-000104
  3. 链 B 专属且支持定位的设备为 GT-D-000201，GT-E2-2101 无设备可见权
  4. GT-E2-2101 对围栏 GF-A-0510 有管理权限
- 测试步骤
  1. 以 GT-E2-2101 从 GF-A-0510 进入设备选择页并查询全部候选。
  2. 分别按编号搜索 GT-D-000101、GT-D-000104、GT-D-000201。
  3. 构造提交请求，同时携带 GT-D-000101、GT-D-000104、GT-D-000201。
- 预期结果
  1. 候选中显示 GT-D-000101、GT-D-000102，不显示不支持定位或当前账号不可见的设备。
  2. GT-D-000101 可搜索并选择；GT-D-000104、GT-D-000201 不作为可选候选返回。
  3. 服务端拒绝本次混合提交，GT-D-000101、GT-D-000104、GT-D-000201 均不创建物理关系或账号关系，不出现部分绑定成功。

## [P1] 验证多选跨页搜索和切换分组后保持已选设备
- 测试类型
  - 功能
- 前置条件
  1. GT-E1-1001 对 GF-A-0511 有管理权限
  2. GT-E1-1001 有 35 台可见且支持定位的设备，编号为 GT-D-001001 至 GT-D-001035，候选列表每页 20 条
  3. GT-D-001001 位于“牛群一组”，GT-D-001021 位于“牛群二组”，GT-D-001035 位于“马群一组”
- 测试步骤
  1. 在第一页勾选 GT-D-001001，上拉加载第二页后勾选 GT-D-001021。
  2. 搜索编号 GT-D-001035 并勾选该设备。
  3. 切换分组为“牛群一组”，再清空分组和搜索条件。
  4. 查看已选汇总并确认本次绑定。
- 预期结果
  1. 翻页后 GT-D-001001 的勾选保持，GT-D-001021 可继续加入选择。
  2. 搜索后前两台设备仍保留在已选集合，GT-D-001035 加入后按设备 ID 去重。
  3. 切换分组不会清空其他页面或条件下的三个已选设备，恢复全部候选后勾选状态一致。
  4. 已选数量为 3，确认后 GF-A-0511 分别与三台设备建立有效关系，不遗漏第二页或搜索结果设备。

## [P1] 验证绑定关系仅扩散给同时拥有围栏权和设备权的账号
- 测试类型
  - 功能
- 前置条件
  1. GF-A-0512 由 GT-E3-3101 创建，GT-E3-3101、GT-E2-2101、GT-E1-1001 均有围栏权
  2. GT-D-000101 对 GT-E1-1001、GT-E2-2101、GT-E3-3101 均可见
  3. GT-D-000102 仅对 GT-E1-1001、GT-E2-2101 可见
  4. GT-D-000103 仅对 GT-E1-1001 可见
- 测试步骤
  1. 以 GT-E2-2101 将 GT-D-000101、GT-D-000102 绑定到 GF-A-0512。
  2. 以 GT-E1-1001 将 GT-D-000103 绑定到 GF-A-0512。
  3. 分别以三级、二级、一级账号查询 GF-A-0512 的绑定设备列表和数量。
  4. 检查三台设备对应的围栏设备账号关系。
- 预期结果
  1. GT-D-000101 向三级、二级、一级建立账号关系；GT-D-000102 仅向二级、一级建立账号关系。
  2. GT-D-000103 仅向一级建立账号关系，不因围栏共享而反向授予下级设备可见权。
  3. 三级显示 1 台、二级显示 2 台、一级显示 3 台，均按当前账号围栏权与设备权交集去重。
  4. 每条账号关系均满足围栏权和设备权同时存在，不产生超出设备分配范围的关系。

## [P2] 验证物理关系唯一且新增账号关系不重置既有基线
- 测试类型
  - 可靠性
- 前置条件
  1. 安全区 GF-A-0513 已与 GT-D-000101 建立唯一物理关系，GT-E1-1001 已有围栏设备账号关系
  2. 物理关系 lastInside = true，最近判定水位为 2026-10-12 08:00:00
  3. GT-E1-1001 新将 GT-D-000101 分配给 GT-E2-2101，GT-E2-2101 同时拥有 GF-A-0513 围栏权
- 测试步骤
  1. 触发设备分配结果同步，查询 GT-E2-2101 的 GF-A-0513 设备关系。
  2. 核对 GT-D-000101×GF-A-0513 的物理关系数量、lastInside 和判定水位。
  3. 由 GT-E2-2101 再次提交将 GT-D-000101 绑定到 GF-A-0513 的请求。
  4. 上报消息 ID LOC-0513-0002、位于安全区圆外的新有效位置并查询告警事件。
- 预期结果
  1. 仅新增 GT-E2-2101 的围栏设备账号关系，设备分配本身不复制物理关系。
  2. 物理关系仍为 1 条，lastInside 仍为 true，判定水位不因新增账号关系回到空值。
  3. 重复绑定幂等返回，账号关系、绑定数量和物理关系均不重复，基线不重置。
  4. 因既有基线仍在，本次圆外有效位置生成 1 条“离开安全区”事件，而不是被误当作首次定位跳过告警。
