# US-012 管理围栏与设备关联

> 口径依据：地理围栏大纲 7.3、8.4、10.3、13.1～13.2 章。围栏内解绑按操作账号向下删除账号关系；父级关系不受影响；只要仍有任一有效账号关系，设备×围栏物理关系与唯一基线继续保留，最后一个账号关系删除后才清除。

## [P1] 验证三级解绑只删除三级关系且保留父级基线
- 测试类型
  - 功能
- 前置条件
  1. GF-A-0520 与 GT-D-000101 已建立三级、二级、一级围栏设备账号关系
  2. 唯一物理关系 lastInside = false，最近判定水位为 2026-10-12 09:00:00
- 测试步骤
  1. 以 GT-E3-3101 从 GF-A-0520 解绑 GT-D-000101。
  2. 分别以 GT-E3-3101、GT-E2-2101、GT-E1-1001 查询该围栏的设备列表。
  3. 查询 GT-D-000101×GF-A-0520 的物理关系和基线。
- 预期结果
  1. 仅删除 GT-E3-3101 的围栏设备账号关系，解绑操作不产生围栏告警。
  2. 三级不再显示该设备；二级和一级仍显示且可继续管理。
  3. 因仍有二级、一级关系，物理关系、lastInside=false 和判定水位全部保留。

## [P1] 验证二级解绑级联删除本级和下游三级但保留一级
- 测试类型
  - 功能
- 前置条件
  1. GF-A-0521 与 GT-D-000101 已建立 GT-E1-1001、GT-E2-2101、GT-E3-3101 三个账号关系
  2. 同一一级下另有二级 GT-E2-2201，但未获得 GF-A-0521 围栏关系
  3. 唯一物理关系 lastInside = true
- 测试步骤
  1. 以 GT-E2-2101 从 GF-A-0521 解绑 GT-D-000101。
  2. 查询三级、操作二级、一级及另一二级的围栏设备账号关系。
  3. 查询物理关系和 lastInside。
  4. 上报消息 ID LOC-0521-0002、位于安全区圆外的新有效位置。
- 预期结果
  1. 删除 GT-E2-2101 及其下游 GT-E3-3101 的账号关系。
  2. GT-E1-1001 的关系保留；GT-E2-2201 不被新增或误删任何关系。
  3. 因一级关系仍有效，物理关系和 lastInside=true 不清除。
  4. 新位置沿用原基线完成判定并只生成 1 条围栏事件，不按已删除账号重复生成。

## [P1] 验证一级解绑删除整条下游关系并在最后关系删除时清除基线
- 测试类型
  - 功能
- 前置条件
  1. GF-A-0522 与 GT-D-000101 仅存在 GT-E1-1001、GT-E2-2101、GT-E3-3101 三个同链账号关系
  2. 唯一物理关系 lastInside = true，已存在最近判定水位
- 测试步骤
  1. 以 GT-E1-1001 从 GF-A-0522 解绑 GT-D-000101。
  2. 查询一级、二级、三级围栏设备账号关系。
  3. 查询 GT-D-000101×GF-A-0522 的物理关系、lastInside 和判定水位。
  4. 继续上报消息 ID LOC-0522-0003 的新有效位置并查询 GF-A-0522 判定结果。
- 预期结果
  1. 一级解绑向下删除 GT-E1-1001、GT-E2-2101、GT-E3-3101 的全部账号关系。
  2. 三个账号均不再显示 GT-D-000101，围栏本体和设备本体仍保留。
  3. 最后一个账号关系删除后，设备×围栏物理关系被删除，lastInside 和判定水位一并清空。
  4. 后续位置不再进入 GF-A-0522 判定，不生成该围栏的幽灵告警。

## [P2] 验证部分解绑不清基线而全部解绑后重绑重新建立基线
- 测试类型
  - 可靠性
- 前置条件
  1. 禁入区 GF-A-0523 与 GT-D-000102 存在一级、二级两个账号关系，lastInside = false
  2. 设备当前可上报圆内有效位置
- 测试步骤
  1. 以 GT-E2-2101 解绑 GT-D-000102，再上报圆内位置 LOC-0523-0002。
  2. 核对本次告警及 lastInside 后，以 GT-E1-1001 解绑同一设备。
  3. 重新由 GT-E1-1001 绑定 GT-D-000102，并上报圆内位置 LOC-0523-0003。
  4. 再上报一条不同消息 ID 的圆内位置 LOC-0523-0004。
- 预期结果
  1. 二级部分解绑后一级关系仍在，原基线不清除；LOC-0523-0002 生成 1 条“进入禁入区”事件。
  2. 一级解绑删除最后关系后物理关系和基线清空。
  3. 重绑新建物理关系，LOC-0523-0003 只建立圆内基线，不生成告警。
  4. LOC-0523-0004 在已有基线且仍处危险侧，生成 1 条“进入禁入区”事件。
