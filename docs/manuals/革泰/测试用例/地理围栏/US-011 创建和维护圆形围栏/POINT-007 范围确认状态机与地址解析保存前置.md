# US-011 创建和维护圆形围栏

> 口径依据：大纲第 4.5、5.2～5.4、13.1、13.3 章。半径右侧 Save 只确认当前准星圆心与半径的本地草稿；圆心或半径变化使原确认失效，缩放和切换图层不改变范围；地址解析成功后底部 Save 才能整单提交，解析失败整单不落库并保留草稿，重试必须幂等。

## [P1] 验证范围确认后地址成功才允许底部正式保存
- 测试类型
  - 功能
- 前置条件
  1. ent_l1 已进入新增围栏页并输入名称「RangeStateFence01」
  2. 地址服务对 WGS84(116.397128,39.916527) 返回「北京市东城区景山前街4号」
- 测试步骤
  1. 将固定准星对准 WGS84(116.397128,39.916527)，输入半径 500m，尚未点击半径右侧 Save。
  2. 查看范围状态并尝试点击底部 Save。
  3. 点击半径右侧 Save，等待地址解析完成。
  4. 查看地址和底部 Save 状态后完成保存。
- 预期结果
  1. 圆心和半径处于未确认或待确认新范围状态，未写入已确认草稿。
  2. 底部 Save 不可用或保存被阻止，不提交正式围栏。
  3. 范围变为已确认，本地草稿记录圆心与 500m 半径并发起地址解析，半径右侧 Save 本身不写服务端。
  4. 地址显示「北京市东城区景山前街4号」，底部 Save 可用并统一提交正式围栏和关系数据。

## [P1] 验证圆心半径变化使确认失效而缩放图层不失效
- 测试类型
  - 功能
- 前置条件
  1. ent_l2 已确认圆心 WGS84(116.397128,39.916527) 与半径 500m
  2. 当前范围状态为已确认
- 测试步骤
  1. 缩放地图并切换一次地图图层，查看范围状态和草稿值。
  2. 拖动地图使准星圆心变化，查看范围状态。
  3. 重新确认新圆心后，将半径从 500m 修改为 600m但不确认。
  4. 再次点击半径右侧 Save。
- 预期结果
  1. 缩放和图层切换只改变视觉表现，已确认状态保持，草稿圆心和实际半径仍为 WGS84(116.397128,39.916527)、500m。
  2. 原范围确认立即失效并进入待确认新范围，底部保存不可用或被阻止。
  3. 修改半径后状态为未确认，原 500m 组合不可作为正式提交范围。
  4. 新圆心与 600m 半径组合确认成功，草稿和圆形预览同步更新。

## [P3][反向] 验证定位按钮移动视野后仍需重新确认范围
- 测试类型
  - 功能
- 前置条件
  1. ent_l3 已确认圆心 WGS84(116.397128,39.916527) 与半径 500m
  2. 测试手机当前位置为 WGS84(121.473701,31.230416)
- 测试步骤
  1. 点击定位按钮，使地图视野移动到手机当前位置。
  2. 查看已确认草稿圆心和范围状态。
  3. 未点击半径右侧 Save，直接尝试底部保存。
  4. 点击半径右侧 Save 后查看草稿圆心。
- 预期结果
  1. 地图视野和固定准星移动到 WGS84(121.473701,31.230416) 对应位置。
  2. 定位操作不直接把手机位置写入已确认草稿，范围进入待确认新范围。
  3. 底部保存不可用或保存被阻止，不以未确认手机位置覆盖正式圆心。
  4. 重新确认后草稿圆心才更新为 WGS84(121.473701,31.230416)。

## [P3][反向] 验证地址解析失败整单不落库并保留草稿幂等重试
- 测试类型
  - 可靠性
- 前置条件
  1. personal01 已完成草稿：名称「AddressRetryFence01」、圆心 WGS84(116.397128,39.916527)、半径 500m、类型安全区、设备 GT-S10U-0001
  2. 首次地址解析模拟超时，第二次解析返回「北京市东城区景山前街4号」
  3. 本次新增请求 ID 为 gf-address-20261012-0001
- 测试步骤
  1. 点击半径右侧 Save 确认范围并触发首次地址解析超时。
  2. 查看名称、范围、类型、设备草稿以及正式数据。
  3. 在原页面重试地址解析，成功后使用请求 ID gf-address-20261012-0001 连续点击底部 Save 2 次。
  4. 查询围栏、账号关系、设备物理关系、设备账号关系和列表卡片。
- 预期结果
  1. 展示可读解析失败原因并明确地址未成功、正式保存不可继续，不使用空字符串、0.0.0.0 或未定位冒充地址。
  2. 围栏本体和三类关系均不落库，名称「AddressRetryFence01」、已确认范围、类型安全区和 GT-S10U-0001 选择全部保留。
  3. 地址成功回显后允许底部保存；重复点击按同一请求 ID 幂等处理，不重复执行事务。
  4. 仅创建一个围栏 ID、一组账号及设备关系和一张列表卡片，地址为「北京市东城区景山前街4号」。
