# US-011 创建和维护圆形围栏

> 口径依据：大纲第 2.1～2.3、3.1、4.4 章。地理围栏唯一主路径为「地图首页 → 围栏 → 电子围栏列表」；列表提供新增、编辑、设备、删除和统计入口；账号切换后从第一页重新查询当前账号有权围栏。

## [P1] 验证从地图首页围栏入口进入电子围栏列表
- 测试类型
  - 功能
- 前置条件
  1. 企业一级账号 ent_l1 已登录
  2. ent_l1 有权查看围栏「故宫安全区」
- 测试步骤
  1. 点击底部导航「地图」，进入地图首页。
  2. 查看地图底部快捷区。
  3. 点击快捷区「围栏」。
  4. 查看目标页面及「故宫安全区」卡片。
- 预期结果
  1. 地图首页正常展示。
  2. 快捷区展示实时追踪、围栏、全图概览入口。
  3. 进入电子围栏列表，未跳转到设备页或我的页。
  4. 列表按 ent_l1 当前权限展示「故宫安全区」。

## [P1] 验证列表底部添加入口进入新增围栏页
- 测试类型
  - 功能
- 前置条件
  1. 企业二级账号 ent_l2 已进入电子围栏列表
- 测试步骤
  1. 查看列表底部操作区。
  2. 点击「+ 添加」。
  3. 查看打开页面的字段和地图范围编辑区。
  4. 不修改任何字段，返回电子围栏列表。
- 预期结果
  1. 底部存在可用的「+ 添加」入口。
  2. 进入新增围栏页。
  3. 页面展示名称、固定中心准星、半径、类型和绑定设备入口。
  4. 无表单变化时直接返回列表，不创建围栏或关系数据。

## [P3][反向] 验证设备页和我的页不存在地理围栏常规入口
- 测试类型
  - 功能
- 前置条件
  1. 企业三级账号 ent_l3 已登录
- 测试步骤
  1. 进入底部导航「设备」页，检查常规菜单和快捷入口。
  2. 进入底部导航「我的」页，检查常规菜单和快捷入口。
  3. 返回「地图」页并点击快捷区「围栏」。
- 预期结果
  1. 设备页不展示地理围栏常规入口。
  2. 我的页不展示地理围栏常规入口。
  3. 仅通过地图首页快捷区进入电子围栏列表。

## [P3][反向] 验证账号切换后列表不残留上一账号越权围栏
- 测试类型
  - 安全性
- 前置条件
  1. 企业三级账号 ent_l3 创建围栏「三级共享围栏」，该围栏向 ent_l2、ent_l1 共享
  2. 企业一级账号 ent_l1 创建围栏「一级独享围栏」，该围栏不向 ent_l2、ent_l3 共享
  3. ent_l1 当前已登录并在列表看见上述两个围栏
- 测试步骤
  1. 从 ent_l1 切换登录为 ent_l3。
  2. 从地图首页进入电子围栏列表。
  3. 观察首次查询和列表卡片。
  4. 搜索「一级独享围栏」。
- 预期结果
  1. 账号切换成功，ent_l1 会话数据不再作为 ent_l3 权限依据。
  2. 列表从第一页重新请求 ent_l3 有权围栏。
  3. 展示「三级共享围栏」，不展示缓存中的「一级独享围栏」。
  4. 搜索不返回「一级独享围栏」，不得通过缓存或关键词扩大权限。
