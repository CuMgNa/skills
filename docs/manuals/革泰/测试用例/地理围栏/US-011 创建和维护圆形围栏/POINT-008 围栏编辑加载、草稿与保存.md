# US-011 创建和维护圆形围栏

> 口径依据：需求真源第 7.1～7.2 节、第 13.1 节。编辑页按围栏唯一 ID 加载当前整份配置；名称、范围、类型和设备调整在正式保存前均为草稿；保存成功后统一提交，保存失败时正式配置保持旧值、草稿保留且前端不得假成功；未明确的失败文案只断言能说明失败原因且可读。

## [P1] 验证编辑页按围栏唯一标识完整回显当前配置
- 测试类型
  - 功能
- 前置条件
  1. 账号 corp_level1_01 可编辑围栏 GF-EDIT-001
  2. GF-EDIT-001 当前配置为名称“上海仓库安全区”、圆心 WGS84（121.4737，31.2304）、半径 500 米、类型安全区、地址“上海市黄浦区人民广场”、配置版本 18
  3. 当前账号可见已绑定设备为 D4001、D4002、D4003，另有 D4004 已绑定但当前账号无设备可见权
- 测试步骤
  1. 从 GF-EDIT-001 卡片点击编辑。
  2. 核对名称、圆心、半径、圆形预览、类型和地址。
  3. 进入绑定设备选择页核对已选设备和数量。
  4. 通过接口或调试信息核对围栏 ID 与配置版本。
- 预期结果
  1. 编辑页按围栏 ID GF-EDIT-001 加载，不使用名称或列表位置定位。
  2. 页面回显名称“上海仓库安全区”、圆心（121.4737，31.2304）、半径 500 米、安全区、地址“上海市黄浦区人民广场”，圆形预览与该范围一致。
  3. 已选设备为 D4001、D4002、D4003，共 3 台；D4004 不向当前账号展示。
  4. 加载对象为 GF-EDIT-001、配置版本 18；版本用于追溯，不因显示异常替换为其他围栏快照。

## [P2] 验证编辑内容在底部保存前仅作为本地草稿
- 测试类型
  - 功能
- 前置条件
  1. GF-EDIT-002 正式配置为名称“杭州中心”、半径 800 米、类型关闭、已绑定 D4101
  2. 已进入 GF-EDIT-002 编辑页
- 测试步骤
  1. 将名称改为“杭州中心禁入区”，类型改为禁入区。
  2. 进入设备选择页，勾选 D4102、取消 D4101并确认返回编辑页。
  3. 未点击底部 Save，使用另一个客户端查询 GF-EDIT-002 正式配置和设备关系。
  4. 在编辑页点击返回，并在放弃修改确认中选择放弃。
- 预期结果
  1. 名称和类型变化仅写入当前页面草稿。
  2. 编辑页草稿显示已选 D4102、未选 D4101，但服务端设备关系尚未改变。
  3. 另一个客户端仍查询到名称“杭州中心”、类型关闭、绑定 D4101，未查询到 D4102 的正式关系。
  4. 返回前出现放弃修改确认；确认放弃后全部草稿丢弃，重进编辑页仍回显原正式配置。

## [P1] 验证编辑保存成功后整份配置与设备关系统一生效
- 测试类型
  - 功能
- 前置条件
  1. GF-EDIT-003 正式配置为名称“苏州仓”、圆心（120.5853，31.2989）、半径 300 米、类型关闭、绑定 D4201
  2. 新圆心（120.5900，31.3000）已逆解析为“江苏省苏州市姑苏区干将东路”，D4202 为当前账号可见且支持定位的设备
- 测试步骤
  1. 将名称改为“苏州仓安全区”，圆心改为（120.5900，31.3000），半径改为 600 米并重新确认范围。
  2. 将类型改为安全区，设备改为仅绑定 D4202。
  3. 点击底部 Save 并等待成功响应。
  4. 返回列表后重新进入编辑页，并查询服务端围栏与设备关系。
- 预期结果
  1. 新范围确认成功，地址回显“江苏省苏州市姑苏区干将东路”。
  2. 页面草稿完整包含新名称、新范围、新类型和 D4202。
  3. 一次业务保存成功后统一提交整份配置与设备关系，不出现围栏已更新但设备关系半成功。
  4. 列表及编辑页均显示名称“苏州仓安全区”、新圆心、半径 600 米、安全区、仅绑定 D4202；D4201 关系已移除。

## [P3][反向] 验证编辑保存失败保留草稿且不显示假成功
- 测试类型
  - 可靠性
- 前置条件
  1. GF-EDIT-004 正式配置为名称“南京仓”、圆心（118.7969，32.0603）、半径 400 米、类型安全区、绑定 D4301，D4301 的 lastInside=true
  2. 抓包工具可使编辑保存接口返回 HTTP 500
- 测试步骤
  1. 将名称改为“南京仓扩展区”、半径改为 900 米并重新确认，追加设备 D4302。
  2. 点击底部 Save，使保存接口返回 HTTP 500。
  3. 查看页面反馈、草稿内容和跳转结果。
  4. 使用另一个客户端查询 GF-EDIT-004 正式配置、设备关系和 D4301 基线。
- 预期结果
  1. 页面形成名称“南京仓扩展区”、半径 900 米、D4301+D4302 的完整草稿。
  2. 保存失败，不提交任何正式变更。
  3. 停留编辑页并保留全部草稿，展示能说明失败原因的可读反馈；不得返回列表并显示保存成功。
  4. 服务端仍为名称“南京仓”、半径 400 米、仅绑定 D4301，D4301 的 lastInside 仍为 true；不得提前清基线或建立 D4302 正式关系。
