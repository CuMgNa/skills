# US-011 创建和维护圆形围栏

> 口径依据：大纲第 5.2～5.3、10.1 章。当前仅支持 WGS84 圆形围栏；圆心必须为合法经纬度，半径必须是 50～20000 米整数；点击半径右侧 Save 才确认当前准星圆心和半径组合，地图视觉范围与正式值必须一致。

## [P1] 验证合法 WGS84 圆心与五百米半径确认成功
- 测试类型
  - 功能
- 前置条件
  1. ent_l1 已进入新增围栏页
  2. 地图可定位到 WGS84(116.397128,39.916527)
- 测试步骤
  1. 拖动地图使 WGS84(116.397128,39.916527) 对准固定中心准星。
  2. 输入半径整数 500m。
  3. 点击半径右侧 Save。
  4. 查看本地草稿和圆形预览。
- 预期结果
  1. 固定准星不移动，准星下坐标为 WGS84(116.397128,39.916527)。
  2. 半径字段接受整数 500m。
  3. 当前圆心与半径组合确认成功。
  4. 草稿记录该 WGS84 圆心和 500m 实际半径，圆形预览与组合一致且尚未写服务端。

## [P3][反向] 验证越界经纬度不能确认正式圆心
- 测试类型
  - 功能
- 前置条件
  1. ent_l2 已进入新增围栏页
  2. 可通过测试地图数据分别提供经度 180.000001、纬度 90.000001 的准星坐标
- 测试步骤
  1. 将准星坐标设置为 WGS84(180.000001,39.916527)，输入半径 500m并点击半径右侧 Save。
  2. 将准星坐标设置为 WGS84(116.397128,90.000001)，输入半径 500m并点击半径右侧 Save。
  3. 查看范围确认状态与圆形预览。
  4. 尝试点击底部 Save。
- 预期结果
  1. 经度超出 [-180,180]，圆心校验失败并展示可读原因，范围确认失败。
  2. 纬度超出 [-90,90]，圆心校验失败并展示可读原因，范围确认失败。
  3. 不生成基于非法圆心的已确认草稿或正式圆形预览。
  4. 底部保存不可用或保存被阻止，不写入围栏及关系数据。

## [P1] 验证半径五十米和二万米边界均可确认
- 测试类型
  - 功能
- 前置条件
  1. ent_l3 已将固定准星对准 WGS84(116.397128,39.916527)
- 测试步骤
  1. 输入最小整数半径 50m并点击半径右侧 Save。
  2. 查看草稿半径和圆形预览。
  3. 将半径改为最大整数 20000m并再次点击半径右侧 Save。
  4. 查看更新后的草稿半径和圆形预览。
- 预期结果
  1. 50m 通过边界校验并确认成功。
  2. 草稿半径为 50m，预览按 50m 实际范围绘制。
  3. 20000m 通过边界校验并确认成功。
  4. 草稿半径更新为 20000m，预览按 20000m 实际范围绘制。

## [P3][反向] 验证空值非整数和半径越界均不能确认
- 测试类型
  - 功能
- 前置条件
  1. personal01 已将固定准星对准 WGS84(116.397128,39.916527)
  2. 当前尚无已确认范围
- 测试步骤
  1. 半径留空并点击半径右侧 Save。
  2. 输入 49m并点击半径右侧 Save。
  3. 输入 20001m并点击半径右侧 Save。
  4. 输入 500.5m并点击半径右侧 Save。
- 预期结果
  1. 半径字段校验失败，展示可读原因并明确半径为空，范围确认失败。
  2. 半径字段校验失败，展示可读原因并明确小于 50m，范围确认失败。
  3. 半径字段校验失败，展示可读原因并明确大于 20000m，范围确认失败。
  4. 半径字段校验失败，展示可读原因并明确必须为整数；四次均不生成已确认范围或正式数据。
