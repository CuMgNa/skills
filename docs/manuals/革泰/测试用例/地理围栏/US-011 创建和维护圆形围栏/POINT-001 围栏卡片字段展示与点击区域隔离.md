# US-011 创建和维护圆形围栏

> 口径依据：大纲第 1.2、4.1～4.2、6.1 章。围栏卡片展示当前正式圆心范围、名称、半径、地址、当前账号可见绑定设备数、类型及操作入口；卡片主体与编辑、设备、删除操作隔离；类型标签只展示不可点击切换。

## [P1] 验证围栏卡片完整展示服务端正式字段
- 测试类型
  - 功能
- 前置条件
  1. ent_l1 有权围栏 ID GF-0001，名称「故宫安全区」，圆心 WGS84(116.397128,39.916527)，半径 500m，类型为安全区
  2. GF-0001 已保存地址「北京市东城区景山前街4号」，并绑定 ent_l1 可见设备 GT-S10U-0001、GT-S10U-0002
- 测试步骤
  1. 使用 ent_l1 进入电子围栏列表并定位 GF-0001 卡片。
  2. 查看卡片缩略图、主标题、半径和地址。
  3. 查看绑定设备数量和右上角类型标签。
  4. 将卡片展示值与 GF-0001 服务端正式配置比对。
- 预期结果
  1. 列表仅展示一张 GF-0001 卡片。
  2. 缩略图对应正式圆心及 500m 圆形范围，标题为「故宫安全区」，半径为 500m，地址为「北京市东城区景山前街4号」。
  3. 显示已绑定 2 台设备，类型标签为「安全区」。
  4. 各字段与服务端正式值一致，不展示旧圆心、旧半径或未解析地址。

## [P1] 验证点击卡片主体按围栏唯一 ID 进入统计页
- 测试类型
  - 功能
- 前置条件
  1. ent_l2 列表存在两张合法唯一名称卡片：GF-0002「北门统计围栏」、GF-0003「南门统计围栏」
  2. GF-0002 绑定 GT-S10U-0001，GF-0003 绑定 GT-S10U-0003
- 测试步骤
  1. 点击 GF-0002 卡片主体的非操作区域。
  2. 查看统计页加载的围栏标识与设备列表。
  3. 返回列表后点击 GF-0003 卡片主体。
- 预期结果
  1. 进入 GF-0002 单围栏统计页。
  2. 页面按 GF-0002 唯一 ID 加载，仅展示其绑定设备 GT-S10U-0001。
  3. 进入 GF-0003 统计页并展示 GT-S10U-0003，不按名称或列表索引串栏。

## [P3][反向] 验证编辑设备删除操作不触发卡片主体跳转
- 测试类型
  - 可靠性
- 前置条件
  1. ent_l1 电子围栏列表存在围栏 GF-0001「故宫安全区」
- 测试步骤
  1. 点击 GF-0001 卡片「编辑」，观察页面跳转。
  2. 返回列表后点击 GF-0001 卡片「设备」，观察页面跳转。
  3. 返回列表后点击 GF-0001 卡片「删除」，观察页面反馈。
  4. 检查三次操作期间是否打开单围栏统计页。
- 预期结果
  1. 仅进入 GF-0001 编辑页，不先进入统计页。
  2. 仅进入 GF-0001 绑定设备选择页，不先进入统计页。
  3. 仅打开 GF-0001 删除二次确认，不先进入统计页。
  4. 操作区点击事件与卡片主体隔离，无重复导航或页面闪跳。

## [P3][反向] 验证卡片类型标签不可直接切换围栏类型
- 测试类型
  - 功能
- 前置条件
  1. ent_l3 可见围栏 GF-0004「默认关闭围栏」，类型为关闭
  2. 已记录 GF-0004 当前配置版本和类型
- 测试步骤
  1. 在列表点击 GF-0004 右上角「关闭」类型标签。
  2. 连续点击该标签 5 次并观察卡片。
  3. 刷新列表并查询 GF-0004 服务端配置。
- 预期结果
  1. 标签不响应类型切换，不打开快捷选择器。
  2. 卡片类型保持「关闭」，不触发编辑保存请求。
  3. 刷新后仍为「关闭」，配置版本和服务端类型均未变化；修改类型只能进入编辑页统一保存。
