# US-011 创建和维护圆形围栏

> 口径依据：大纲第 3.2、5.2、12.6 章。围栏名称保存前去除首尾空格、保留内部空格，长度为 1～30 字符且纯空格禁止；企业一级至三级整条账号链内全局唯一，个人账号仅在自己的围栏范围内唯一。

## [P1] 验证名称一字符三十字符及空格归一化均可保存
- 测试类型
  - 功能
- 前置条件
  1. personal01 名下不存在名称「A」「123456789012345678901234567890」「HQ Safe Zone」的围栏
  2. 三次新增均使用圆心 WGS84(116.397128,39.916527)、半径 500m且地址解析成功
- 测试步骤
  1. 输入 1 字符名称「A」并完成保存。
  2. 输入 30 字符名称「123456789012345678901234567890」并完成保存。
  3. 输入名称「  HQ Safe Zone  」并完成保存。
  4. 返回列表并查询三条正式名称。
- 预期结果
  1. 1 字符名称通过校验并保存为「A」。
  2. 30 字符名称通过校验且完整保存，不截断。
  3. 首尾空格被去除，内部单个空格保留，正式名称为「HQ Safe Zone」。
  4. 列表与服务端分别存在三条归一化后的唯一名称。

## [P3][反向] 验证空名称纯空格和三十一字符均阻止保存
- 测试类型
  - 功能
- 前置条件
  1. personal01 已确认圆心 WGS84(116.397128,39.916527) 与半径 500m
  2. 地址已解析成功，除名称外其他字段均合法
- 测试步骤
  1. 名称留空并点击底部 Save。
  2. 输入 3 个空格「   」并点击底部 Save。
  3. 输入 31 字符名称「1234567890123456789012345678901」并点击底部 Save。
  4. 查询围栏列表和服务端新增记录。
- 预期结果
  1. 名称字段校验失败，展示可读原因并明确名称不能为空，保存被阻止。
  2. 归一化后为空，名称字段校验失败且保存被阻止。
  3. 名称字段校验失败，展示可读原因并明确超过 30 字符，保存被阻止。
  4. 三次操作均不新增围栏、账号关系或设备关系。

## [P3][反向] 验证企业整条一级二级三级链同名不可重复
- 测试类型
  - 功能
- 前置条件
  1. ent_l3、ent_l2、ent_l1 属于同一企业账号链
  2. ent_l3 已创建围栏「ChainFence01」并向 ent_l2、ent_l1 共享
- 测试步骤
  1. 使用 ent_l2 新增围栏并输入名称「ChainFence01」，其他字段合法后保存。
  2. 使用 ent_l1 新增围栏并输入名称「ChainFence01」，其他字段合法后保存。
  3. 分别查看两次失败后的页面草稿。
  4. 查询该企业链名称为「ChainFence01」的围栏记录数。
- 预期结果
  1. ent_l2 保存失败，展示围栏名称已存在，未创建新围栏。
  2. ent_l1 保存失败，展示围栏名称已存在，未创建新围栏。
  3. 两端名称、范围、类型和设备草稿均保留，可修改名称后重试。
  4. 企业链内仅保留 ent_l3 创建的一个围栏 ID，不因层级不同产生同名副本。

## [P1] 验证个人与企业名称隔离且个人范围内仍唯一
- 测试类型
  - 功能
- 前置条件
  1. ent_l1 企业链已存在围栏「SharedName01」
  2. personal01 名下暂不存在「SharedName01」
- 测试步骤
  1. personal01 使用名称「SharedName01」、圆心 WGS84(116.397128,39.916527)、半径 500m完成新增。
  2. 查看 personal01 列表和 ent_l1 列表。
  3. personal01 再次使用名称「SharedName01」新增围栏。
  4. 查询个人与企业范围内该名称的围栏记录。
- 预期结果
  1. personal01 可成功创建同名个人围栏，企业名称不参与个人范围判重。
  2. personal01 只看见自己的「SharedName01」，ent_l1 只看见企业链中的同名围栏，两者围栏 ID 不同且不共享。
  3. personal01 第二次保存失败，展示围栏名称已存在并保留草稿。
  4. 个人范围和企业范围各有一个「SharedName01」，个人范围内无重复记录。
