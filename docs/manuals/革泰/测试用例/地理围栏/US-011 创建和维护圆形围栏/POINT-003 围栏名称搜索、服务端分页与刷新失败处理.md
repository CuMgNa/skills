# US-011 创建和维护圆形围栏

> 口径依据：大纲第 4.3～4.4、13.1 章。名称搜索采用去首尾空格后的包含匹配且英文大小写不敏感，只查询当前账号有权围栏；列表统一使用服务端分页、稳定排序、唯一 ID 去重并支持刷新；分页失败不得伪装为空列表或没有更多。

## [P1] 验证名称包含搜索归一化且不扩大账号权限
- 测试类型
  - 功能
- 前置条件
  1. ent_l1 有权围栏「North Gate Safe」「Warehouse  A」和「南门禁入区」
  2. 其他企业链存在 ent_l1 无权围栏「North Secret Fence」
- 测试步骤
  1. 输入关键词「  gate  」并发起搜索。
  2. 输入关键词「NORTH」并发起搜索。
  3. 输入包含两个内部空格的关键词「Warehouse  A」并发起搜索。
  4. 输入关键词「Secret」并发起搜索。
- 预期结果
  1. 搜索前去除首尾空格，返回「North Gate Safe」。
  2. 英文大小写不敏感，返回 ent_l1 有权的「North Gate Safe」。
  3. 内部两个空格保留，精确参与包含匹配并返回「Warehouse  A」。
  4. 不返回其他企业链的「North Secret Fence」，搜索不扩大权限。

## [P1] 验证空关键词恢复列表且无结果时保留新增入口
- 测试类型
  - 易用性
- 前置条件
  1. personal01 有权围栏「Home Safe Zone」「School Safe Zone」
  2. personal01 已进入电子围栏列表
- 测试步骤

  2. 查看无结果页面和底部新增入口。
  3. 清空搜索框并重新查询。
  4. 查看恢复后的围栏列表。
- 预期结果
  1. 服务端从第一页执行当前账号范围内搜索。
  2. 展示「未找到匹配围栏」，「+ 添加」入口仍可用。
  3. 空关键词触发从第一页查询 personal01 全部有权围栏。
  4. 恢复展示「Home Safe Zone」「School Safe Zone」，不沿用无结果状态。

## [P1] 验证下拉刷新和上拉分页按稳定顺序去重
- 测试类型
  - 功能
- 前置条件
  1. ent_l2 有权 23 个围栏，测试服务端页大小配置为 10
  2. 服务端按更新时间倒序、围栏唯一 ID 倒序返回，GF-0010 因共享关系在相邻页原始结果中重复命中
- 测试步骤
  1. 首次进入列表并记录第一页卡片顺序和数量。
  2. 连续上拉加载第二页、第三页。
  3. 统计已渲染围栏唯一 ID 和卡片总数。
  4. 下拉刷新并再次加载全部分页。
- 预期结果
  1. 首次从第一页加载 10 张卡片，顺序符合稳定排序。
  2. 后续分页由服务端返回，已加载数据持续保留。
  3. GF-0010 只展示一张卡片，最终按唯一 ID 去重后共 23 张，无固定最大条数或静默截断。
  4. 下拉刷新从第一页重查，重新加载后仍为 23 个唯一围栏且顺序稳定。

## [P3][反向] 验证第一页和下一页失败均保留有效数据并可重试
- 测试类型
  - 稳定性
- 前置条件
  1. ent_l3 上一次成功加载 10 张围栏卡片，其中包含「三级共享围栏」
  2. 可分别模拟第一页请求失败和下一页请求失败
- 测试步骤
  1. 模拟下拉刷新时第一页请求失败。
  2. 查看列表数据、失败状态和重试入口。
  3. 恢复第一页请求并点击重试，使第一页成功。
  4. 上拉加载下一页时模拟服务端失败。
  5. 查看已加载卡片、分页状态并恢复服务后重试。
- 预期结果
  1. 第一页请求明确进入失败态。
  2. 保留上一次 10 张有效卡片并展示可读失败原因及重试操作，不用空数组表示账号无围栏。
  3. 重试后刷新为最新第一页数据。
  4. 下一页请求明确进入失败态。
  5. 已加载卡片不丢失，展示可重试入口且不标记为「没有更多」；重试成功后追加下一页并按唯一 ID 去重。
