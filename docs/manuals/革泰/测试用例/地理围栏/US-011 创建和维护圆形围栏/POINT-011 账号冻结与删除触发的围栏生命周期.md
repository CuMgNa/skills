# US-011 创建和维护圆形围栏

> 口径依据：地理围栏大纲 3.4、9.2、12.6 章。冻结账号只限制登录，不中断其已创建围栏的判定和共享管理；解冻后读取服务端最新状态。删除账号只删除该账号创建的围栏，复用围栏全局清理规则，同时保留设备及历史位置、轨迹和告警。

## [P1] 验证创建账号冻结后围栏继续判定并可由父级管理
- 测试类型
  - 功能
- 前置条件
  1. 安全区 GF-A-0560 由 GT-E3-3101 创建，已共享给 GT-E2-2101、GT-E1-1001
  2. GT-D-000101 已绑定 GF-A-0560，lastInside = true
  3. 冻结前围栏和设备关系均有效
- 测试步骤
  1. 冻结 GT-E3-3101 并验证该账号不能继续登录。
  2. 让 GT-D-000101 上报圆外有效位置 LOC-0560-0002。
  3. 以 GT-E2-2101、GT-E1-1001 查询 GF-A-0560、设备关系和本次告警。
  4. 以 GT-E2-2101 修改 GF-A-0560 名称为“冻结期间父级维护”并保存。
- 预期结果
  1. GT-E3-3101 登录受限，但围栏本体、账号关系、设备关系和基线不删除。
  2. 围栏继续判定，LOC-0560-0002 生成 1 条“离开安全区”事件。
  3. 二级、一级仍可查看围栏、设备及有权告警关系。
  4. 父级同权管理有效，名称修改成功且作用于原围栏 ID。

## [P2] 验证账号解冻后按服务端最新围栏状态恢复展示
- 测试类型
  - 功能
- 前置条件
  1. GT-E3-3101 处于冻结状态
  2. 冻结期间父级已将 GF-A-0560 改名为“冻结期间父级维护”并新增绑定设备 GT-D-000102
  3. 冻结期间已新增 2 条围栏告警
- 测试步骤
  1. 解冻 GT-E3-3101并登录 APP。
  2. 进入电子围栏列表和 GF-A-0560 统计页。
  3. 查询绑定设备与冻结期间告警。
- 预期结果
  1. GT-E3-3101 恢复登录，原围栏账号关系继续有效。
  2. 页面从服务端读取名称“冻结期间父级维护”，不显示冻结前旧缓存。
  3. GT-D-000102 和 2 条冻结期间告警按当前权限可见，系统不因解冻重建或重复生成关系。

## [P1] 验证删除账号仅删除其创建围栏并保留其他账号创建围栏
- 测试类型
  - 功能
- 前置条件
  1. GT-E3-3101 创建 GF-A-0561“三级自建栏”，该围栏已向上共享
  2. GT-E2-2101 创建 GF-A-0562“二级自建栏”，GT-E3-3101 不拥有该围栏关系，GT-E1-1001 可见
  3. GT-D-000103 同时参与 GF-A-0561、GF-A-0562，设备本体和历史轨迹均已存在
- 测试步骤
  1. 删除账号 GT-E3-3101。
  2. 以 GT-E2-2101、GT-E1-1001 查询 GF-A-0561。
  3. 以 GT-E2-2101、GT-E1-1001 查询 GF-A-0562 及其设备关系和基线。
  4. 查询 GT-D-000103 设备本体与历史轨迹。
- 预期结果
  1. 账号删除触发 GT-E3-3101 创建围栏的删除流程。
  2. GF-A-0561 对所有原关联账号全局消失，不因已共享给父级而继续保留。
  3. 其他账号创建的 GF-A-0562、其设备关系和基线保持有效，不被扩大删除范围。
  4. GT-D-000103 设备本体和历史轨迹保留，账号删除不删除物理设备及历史位置事实。

## [P1] 验证删除账号引起的围栏删除完成全局清理并保留历史告警
- 测试类型
  - 可靠性
- 前置条件
  1. GT-E3-3101 创建的 GF-A-0563 已关联三级、二级、一级账号及 GT-D-000106
  2. GF-A-0563 存在物理关系、lastInside、判定水位和配置缓存
  3. GF-A-0563 已有 1 条已处理和 2 条未处理历史告警
- 测试步骤
  1. 删除 GT-E3-3101并等待账号删除事务完成。
  2. 查询 GF-A-0563 本体、账号关系、设备账号关系、物理关系、基线和缓存。
  3. 上报一条 GT-D-000106 的新有效危险侧位置 LOC-0563-0005。
  4. 以仍有设备访问权的 GT-E1-1001 查询 3 条历史告警及处理状态。
- 预期结果
  1. 账号删除复用围栏删除规则，GF-A-0563 对原共享链全局删除。
  2. 围栏本体、全部有效关系、物理关系、lastInside、判定水位和缓存均清理，无孤儿关系。
  3. 新位置不再触发 GF-A-0563 判定或告警。
  4. 3 条历史告警及发生时围栏快照保留，1 条仍为已处理、2 条仍为未处理，不因账号或围栏删除被改写。
