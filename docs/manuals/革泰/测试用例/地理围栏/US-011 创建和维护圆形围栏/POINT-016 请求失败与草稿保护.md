# US-011 创建和维护圆形围栏

> 口径依据：地理围栏大纲 4.5、5.4、13.1。写操作失败不得前端假成功或产生部分关系；新增、编辑及地址解析失败保留草稿；列表和统计失败不得用空数组或全 0 冒充真实结果。

## [P3][反向] 验证地址解析失败时新增整单不落库并保留草稿
- 测试类型
  - 可靠性
- 前置条件
  1. 进入新增围栏页，名称填写 GF-DRAFT-01，圆心 151.220000°E、33.880000°S，半径 500m，类型安全区
  2. 已选择 DEV-GF-100、DEV-GF-101，地址逆解析服务可模拟超时
- 测试步骤
  1. 确认圆心和半径后触发地址解析超时。
  2. 尝试提交底部保存。
  3. 查询围栏本体、账号关系、物理关系和设备账号关系。
  4. 恢复地址服务并在原页重试解析。
- 预期结果
  1. 地址未解析成功，页面显示可识别失败状态。
  2. 正式保存不可成功，不使用空字符串、0.0.0.0或未定位等值冒充地址。
  3. 四类正式数据均不落库，不出现部分成功。
  4. 名称、圆心、半径、类型和两台已选设备草稿完整保留，可直接重试。

## [P3][反向] 验证编辑失败保持旧配置和原基线
- 测试类型
  - 可靠性
- 前置条件
  1. GF-DRAFT-02正式配置为圆心 151.200000°E、33.860000°S、半径 500m、安全区
  2. DEV-GF-102已建立圆内基线，编辑接口可模拟 500 响应
- 测试步骤
  1. 将草稿改为圆心 151.230000°E、33.890000°S、半径 800m、禁入区并提交。
  2. 查看页面失败状态与草稿。
  3. 查询服务端正式配置、配置版本和基线。
- 预期结果
  1. 编辑请求失败，不显示保存成功或提前刷新为新配置。
  2. 新圆心、800m、禁入区草稿保留供重试。
  3. 服务端仍为原圆心、500m、安全区和原配置版本，原圆内基线未提前清空。

## [P3][反向] 验证删除、绑定与解绑失败均不产生部分副作用
- 测试类型
  - 可靠性
- 前置条件
  1. GF-DRAFT-03已绑定 DEV-GF-103、DEV-GF-104并存在完整账号关系和基线
  2. 可分别模拟删除、绑定 DEV-GF-105、解绑 DEV-GF-103请求失败
- 测试步骤
  1. 提交删除 GF-DRAFT-03并模拟失败。
  2. 提交绑定 DEV-GF-105并模拟关系事务失败。
  3. 提交解绑 DEV-GF-103并模拟失败。
  4. 查询围栏、三台设备关系、基线和页面状态。
- 预期结果
  1. 删除失败后围栏卡片、关系和基线继续存在。
  2. DEV-GF-105不建立任何部分账号关系或物理关系。
  3. DEV-GF-103原账号关系、物理关系和基线均保持，页面不得假显示已解绑。
  4. DEV-GF-104不受三次失败请求影响。

## [P3][反向] 验证列表和统计加载失败保留最近有效数据
- 测试类型
  - 功能
- 前置条件
  1. 当前账号最近一次成功加载 12 个围栏，GF-DRAFT-04统计为在线 8、离线 2、告警设备 3
  2. 可模拟列表第一页和统计接口失败
- 测试步骤
  1. 下拉刷新列表并模拟第一页失败。
  2. 查看列表数据和重试能力。
  3. 进入 GF-DRAFT-04统计页并模拟统计接口失败。
  4. 查看统计展示状态。
- 预期结果
  1. 列表显示明确失败状态，不把失败解释为账号无围栏。
  2. 最近有效的 12 个围栏继续保留，并提供可重试入口。
  3. 统计页显示加载失败状态。
  4. 不用在线 0、离线 0、告警 0冒充真实统计；上次有效值如保留，必须与失败状态明确区分。
