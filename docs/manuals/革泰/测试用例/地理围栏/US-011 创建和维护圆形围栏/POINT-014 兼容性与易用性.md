# US-011 创建和维护圆形围栏

> 口径依据：地理围栏大纲页面链路、范围确认、加载失败和模块联动规则。验证不同平台、屏幕、网络与交互条件下的核心能力；未明确的按钮文案、提示文案和视觉像素值不在用例中伪造。

## [P2] 验证 Android 与 iOS 核心围栏流程一致
- 测试类型
  - 兼容性
- 前置条件
  1. Android 15设备和 iOS 26设备均安装同一构建版本并登录 testuser01
  2. 账号可见 DEV-GF-120，准备创建名称 GF-COMPAT-01、半径 500m、安全区围栏
- 测试步骤
  1. 两端分别完成地图入口、范围确认、地址解析、设备选择和正式保存。
  2. 两端查看列表卡片、编辑回显、统计页和实时追踪下钻。
  3. 在一端编辑半径为 800m，另一端刷新查看。
- 预期结果
  1. 两端均能完成同一业务流程，字段校验、事务结果和设备关系一致。
  2. 两端均展示同一正式围栏 ID、配置和统计数据，核心操作无平台缺失。
  3. 另一端最终刷新到 800m正式配置，不因平台缓存继续展示旧值。

## [P2] 验证小屏、大屏与横竖屏下关键控件可用
- 测试类型
  - 兼容性
- 前置条件
  1. 准备 360×800小屏、430×932大屏手机及一台支持旋转的平板
  2. 进入 GF-COMPAT-02新增页和设备选择页
- 测试步骤
  1. 在各尺寸竖屏查看固定中心准星、半径输入、范围确认、类型选择和底部正式保存入口。
  2. 打开键盘输入 20000m半径和30字符名称，滚动并收起键盘。
  3. 在平板横竖屏切换后继续选择 DEV-GF-121、DEV-GF-122并返回表单。
- 预期结果
  1. 关键控件可见、可触达，不被刘海、系统导航、底部安全区或浮层永久遮挡。
  2. 长名称和最大合法半径不导致字段重叠、保存入口不可达或草稿丢失。
  3. 旋转后两台设备选择和已确认范围状态保持，页面不重复提交。

## [P2] 验证弱网、断网与重试交互可理解且不误导
- 测试类型
  - 易用性
- 前置条件
  1. GF-USABLE-01列表已有 8 条最近有效数据
  2. 网络可切换为 30%丢包、800ms延迟和完全断网
- 测试步骤
  1. 弱网下执行列表翻页和名称搜索。
  2. 断网下尝试地址解析和正式保存新增草稿 GF-USABLE-02。
  3. 恢复网络后使用页面提供的重试能力继续操作。
- 预期结果
  1. 加载过程有明确状态，失败时保留已加载数据，不把失败显示为没有更多或无围栏。
  2. 地址解析和保存失败可被用户识别，GF-USABLE-02全部草稿保留且无正式数据落库。
  3. 恢复后可在原上下文重试，不要求重新输入，不因重复点击创建两个围栏。

## [P2] 验证操作区、状态标签与结果反馈不易误触误解
- 测试类型
  - 易用性
- 前置条件
  1. 列表存在关闭 GF-USABLE-03、安全区 GF-USABLE-04、禁入区 GF-USABLE-05
  2. 每张卡片均展示主体区域及编辑、设备、删除操作
- 测试步骤
  1. 分别点击三张卡片的类型标签和卡片主体。
  2. 分别点击编辑、设备、删除操作区。
  3. 在删除确认界面取消，再次进入并确认删除 GF-USABLE-03。
- 预期结果
  1. 类型标签仅展示，不直接切换类型；卡片主体进入对应围栏统计页。
  2. 编辑、设备、删除操作不会先触发卡片主体跳转，各自进入正确流程。
  3. 取消删除不产生变化；确认删除后该围栏及有效关系清理，其他两张卡片、设备本体和历史告警不受影响。
