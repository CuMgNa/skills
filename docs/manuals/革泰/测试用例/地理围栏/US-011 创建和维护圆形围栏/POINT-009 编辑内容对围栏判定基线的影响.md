# US-011 创建和维护圆形围栏

> 口径依据：需求真源第 7.3～7.4 节、第 10.3 节、第 11.9 节。仅修改名称不重置 lastInside；修改圆心、半径、安全区与禁入区互切、关闭后重新启用均须清空或重建判定基线，配置变更后的第一条有效位置只建立新基线，不把配置变化当作设备跨界或补发历史告警。

## [P1] 验证仅修改名称不重置判定基线
- 测试类型
  - 功能
- 前置条件
  1. GF-RESET-001 为安全区，名称“浦东安全区”，圆心（121.5440，31.2210），半径 500 米
  2. D5001 已绑定且 lastInside=true，历史有 1 条名称快照为“浦东安全区”的已处理告警
- 测试步骤
  1. 仅将围栏名称改为“浦东一号安全区”并保存。
  2. 查询 D5001 在 GF-RESET-001 下的 lastInside。
  3. 上报新有效位置 M5001-02，使 D5001 距圆心 620 米。
  4. 核对新告警与历史告警的围栏名称快照。
- 预期结果
  1. 名称保存成功，圆心、半径、类型和设备关系不变。
  2. lastInside 保持 true，未被名称变更清空。
  3. M5001-02 位于安全区圆外且已有基线，生成 1 条“离开安全区”告警。
  4. 新告警名称快照为“浦东一号安全区”；历史告警仍显示“浦东安全区”，不被改名覆盖。

## [P1] 验证修改圆心或半径后首条有效位置仅重建基线
- 测试类型
  - 功能
- 前置条件
  1. GF-RESET-002 为安全区，原圆心（121.4737，31.2304）、半径 500 米
  2. D5002 已建立 lastInside=true，当前无未处理告警
- 测试步骤
  1. 将圆心改为（121.4900，31.2304）并保存，使 D5002 到新圆心距离为 700 米；随后上报 M5002-02。
  2. 再上报新消息 M5002-03，位置与 M5002-02 相同且消息 ID 不同。
  3. 将半径由 500 米改为 200 米并保存；随后上报 M5002-04，位置距当前圆心 300 米。
  4. 再上报新消息 M5002-05，位置与 M5002-04 相同且消息 ID 不同。
- 预期结果
  1. 圆心变更与 lastInside 清空原子生效；M5002-02 只建立圆外基线，不生成告警。
  2. M5002-03 为已有新基线后的危险侧新有效位置，生成 1 条“离开安全区”告警。
  3. 半径变更再次清空 lastInside；M5002-04 只建立圆外基线，不生成告警。
  4. M5002-05 生成 1 条“离开安全区”告警；圆心移动和范围缩小本身均未被当作设备跨界。

## [P1] 验证安全区与禁入区双向切换均重建基线
- 测试类型
  - 功能
- 前置条件
  1. GF-RESET-003 当前为安全区，D5003 已建立 lastInside=true
  2. D5003 位于圆内 100 米处，当前无未处理告警
- 测试步骤
  1. 将 GF-RESET-003 从安全区切换为禁入区并保存，随后上报圆内位置 M5003-02。
  2. 再上报相同圆内坐标的新消息 M5003-03。
  3. 将 GF-RESET-003 从禁入区切换回安全区并保存，随后上报距圆心 650 米的 M5003-04。
  4. 再上报相同圆外坐标的新消息 M5003-05。
- 预期结果
  1. 类型切换后 lastInside 清空，M5003-02 虽位于禁入区危险侧也只建立基线，不告警。
  2. M5003-03 生成 1 条“进入禁入区”告警。
  3. 切回安全区后再次清空基线，M5003-04 只建立圆外基线，不告警。
  4. M5003-05 生成 1 条“离开安全区”告警；两次类型切换均不补发切换前的历史告警。

## [P1] 验证切换为关闭后暂停判定且重新启用时重建基线
- 测试类型
  - 功能
- 前置条件
  1. GF-RESET-004 当前为安全区，D5004 已建立 lastInside=true
  2. D5004 历史有 2 条围栏告警
- 测试步骤
  1. 将 GF-RESET-004 类型切换为关闭并保存。
  2. 关闭期间依次上报圆外位置 M5004-02、M5004-03。
  3. 将 GF-RESET-004 重新启用为安全区并保存，上报圆外位置 M5004-04。
  4. 再上报相同圆外坐标的新消息 M5004-05。
  5. 核对历史告警、物理绑定关系和最终基线。
- 预期结果
  1. 设备物理关系保留，有效判定基线暂停并清空。
  2. 关闭期间不判断、不更新 lastInside、不生成新告警。
  3. 重新启用后 M5004-04 只建立圆外基线，不生成告警。
  4. M5004-05 为已有基线后的危险侧新有效位置，生成 1 条“离开安全区”告警。
  5. 原 2 条历史告警仍保留，设备绑定关系未因关闭被删除，最终 lastInside=false。
