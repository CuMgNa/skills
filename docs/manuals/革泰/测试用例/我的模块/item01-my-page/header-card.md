# 用户故事：头部卡片展示交互与账号隔离

> 口径依据：大纲第 4 章。头像圆形、默认头像兜底、无任何角标；头部整块可点进资料页、不弹编辑组件；第二行按版本分流（国内 = 登录手机号完整不脱敏，海外 = 邮箱、无邮箱整行隐藏）；数据来自服务端、换绑跟随最新值；账号切换三元素全部切换不残留。

## [P1] 验证国内版头部第二行显示完整登录手机号
- 测试类型
  - 功能
- 前置条件
  1. 国内版 APP，账号 testuser01 绑定手机号 13800138000，已登录
- 测试步骤
  1. 进入「我的」页，查看头部卡片。
  2. 核对第一行账号名与第二行登录标识。
  3. 核对手机号展示形式。
- 预期结果
  1. 头部卡片展示头像（圆形）+ 两行文字。
  2. 第一行为账号名，第二行为登录手机号。
  3. 显示完整 13800138000，不脱敏（无 138****8000 形式）。

## [P2] 验证海外版头部第二行邮箱展示与无邮箱隐藏
- 测试类型
  - 功能
- 前置条件
  1. 海外版 APP，账号 testuser01@outlook.com（已验证邮箱）已登录
  2. 另一无邮箱账号 testuser02（手机号注册）已注册
- 测试步骤
  1. 用 testuser01@outlook.com 登录，查看头部第二行。
  2. 退出，用无邮箱账号 testuser02 登录，查看头部第二行。
  3. 核对无邮箱时第二行区域形态。
- 预期结果
  1. 第二行显示 testuser01@outlook.com（服务端原样，大小写 / 空格不二次处理）。
  2. testuser02 无邮箱。
  3. 第二行整行隐藏，不留空白占位行。

## [P2] 验证点头像与点头部区域均进资料页且不弹编辑组件
- 测试类型
  - 功能
- 前置条件
  1. 账号 testuser01 已登录
- 测试步骤
  1. 点击头部头像。
  2. 返回我的页，点击头部卡片的账号名 / 第二行文字区域。
  3. 检查两次交互是否出现编辑组件（如底部菜单、弹窗）。
- 预期结果
  1. 点击头像进入资料页。
  2. 点击头部文字区域同样进入资料页（头部整块可点）。
  3. 全程不弹任何编辑组件（我的页头像纯展示，编辑单一入口在资料页）。

## [P2] 验证后台换绑手机号后头部第二行跟随更新
- 测试类型
  - 功能
- 前置条件
  1. 国内版，账号 testuser01 当前绑定手机号 13800138000，已登录
  2. 后台可将该账号换绑为 13900139000
- 测试步骤
  1. 记录当前头部第二行显示。
  2. 通过后台将账号换绑为 13900139000。
  3. 回到 APP 我的页下拉刷新 / 重进页面，查看第二行。
- 预期结果
  1. 换绑前显示 13800138000。
  2. 换绑操作成功。
  3. 第二行更新为 13900139000，不残留旧号。

## [P3][反向] 验证账号切换后头部三元素不残留上一账号
- 测试类型
  - 功能
- 前置条件
  1. 账号 A（testuserA，自定义头像 avatarA.jpg，手机号 13800138000）已登录
  2. 账号 B（testuserB，默认头像，手机号 13900139000）已注册
- 测试步骤
  1. 记录账号 A 头部三元素（头像 / 账号名 / 手机号）。
  2. 退出登录，账号 B 登录。
  3. 检查头部三元素展示。
- 预期结果
  1. A 的三元素记录成功。
  2. 切换成功。
  3. 头像 / 账号名 / 手机号全部切换为 B 的数据（默认头像 + testuserB + 13900139000），无 A 的任何残留。

## [P4] 验证自定义头像弱网加载失败回退默认头像
- 测试类型
  - 功能
- 前置条件
  1. 账号 testuser01 已设置自定义头像，当前处于弱网（限速工具就绪）
- 测试步骤
  1. 将网络限速至头像 URL 无法加载完成。
  2. 杀进程冷启动 APP，进入「我的」页查看头像。
  3. 恢复网络后重进页面。
- 预期结果
  1. 弱网环境生效。
  2. 头像区域回退默认头像占位，不允许空白 / 破图。
  3. 恢复网络后自定义头像正常加载显示。
