# 用户故事：邮箱行展示与已验证口径

> 口径依据：大纲 5.3 章。邮箱只读无点击；已验证邮箱才显值；无邮箱时行恒在显示占位（不用模拟邮箱代替真实数据）；后续补充 / 验证邮箱后由占位变展示（4.4 场景 3）。邮箱验证状态字段依赖后端契约（联调项）。

## [P2] 验证已验证邮箱正常显值且只读
- 测试类型
  - 功能
- 前置条件
  1. 账号 testuser01 绑定已验证邮箱 testuser01@outlook.com，已登录
- 测试步骤
  1. 资料页查看邮箱行。
  2. 点击邮箱行。
  3. 长按邮箱行尝试复制 / 编辑。
- 预期结果
  1. 邮箱行显示 testuser01@outlook.com。
  2. 点击无响应（只读、无弹窗）。
  3. 不出现编辑态（邮箱不可修改入口）。

## [P3] 验证无邮箱账户邮箱行恒在显示占位
- 测试类型
  - 功能
- 前置条件
  1. 账号 testuser02 为纯手机号注册，未绑定邮箱，已登录
- 测试步骤
  1. 资料页查看邮箱行。
  2. 核对行是否显示占位（而非隐藏）。
  3. 检查占位内容是否使用模拟邮箱数据。
- 预期结果
  1. 邮箱行可见。
  2. 行恒在、显示占位状态（与头部第二行「无邮箱整行隐藏」形成口径差异）。
  3. 占位不是模拟邮箱（不用 demo@xxx.io 之类假数据冒充真值）。

## [P4] 验证补充验证邮箱后邮箱行由占位变显值
- 测试类型
  - 功能
- 前置条件
  1. 海外版账号 testuser02 当前无邮箱（邮箱行占位），已登录
  2. 可通过账号安全流程为该账号补充并验证邮箱 user02@gmail.com
- 测试步骤
  1. 记录资料页邮箱行当前占位状态。
  2. 通过流程补充并验证邮箱 user02@gmail.com。
  3. 重进资料页查看邮箱行。
  4. 查看我的页头部第二行。
- 预期结果
  1. 占位状态记录成功。
  2. 邮箱补充验证成功。
  3. 邮箱行由占位变为显示 user02@gmail.com（已验证才显值）。
  4. 头部第二行由隐藏变为显示邮箱（4.4 场景 3 联动）。
