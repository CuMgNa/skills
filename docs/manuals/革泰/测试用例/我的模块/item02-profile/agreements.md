# 用户故事：协议区两弹窗

> 口径依据：大纲 5.5 章。用户协议 + 隐私政策两个独立入口；弹窗只读正文 + 底部「确认」；确认仅关闭弹窗，不出现同意 / 不同意，不改变登录协议同意状态。

## [P1] 验证用户协议与隐私政策各自弹窗展示
- 测试类型
  - 功能
- 前置条件
  1. 账号 testuser01 已登录
- 测试步骤
  1. 资料页板块三点「用户协议」。
  2. 查看弹窗内容与底部按钮。
  3. 关闭后点「隐私政策」。
  4. 查看弹窗内容与底部按钮。
- 预期结果
  1. 弹出用户协议弹窗。
  2. 只读正文 + 底部「确认」按钮，无同意 / 不同意选项。
  3. 弹出隐私政策弹窗。
  4. 同样只读正文 + 确认按钮（两入口各自独立弹窗）。

## [P2] 验证点确认与点遮罩均仅关闭弹窗
- 测试类型
  - 功能
- 前置条件
  1. 账号 testuser01 已登录
- 测试步骤
  1. 打开用户协议弹窗，点底部「确认」。
  2. 查看弹窗状态与页面状态。
  3. 再次打开弹窗，点遮罩区域 / 系统返回键。
  4. 查看弹窗状态。
- 预期结果
  1. 确认被点击。
  2. 弹窗关闭，返回资料页，无其他跳转或状态变化。
  3. 遮罩被点击。
  4. 同样仅关闭弹窗（确认语义 = 关闭，不承载任何同意动作）。

## [P3] 验证弹窗确认后登录协议同意状态不变
- 测试类型
  - 功能
- 前置条件
  1. 账号 testuser01 已登录（登录时已勾选协议同意）
- 测试步骤
  1. 资料页打开用户协议弹窗并点确认关闭，重复一次隐私政策。
  2. 退出登录回登录页。
  3. 查看登录页协议勾选状态。
  4. 用账号 testuser01 正常登录。
- 预期结果
  1. 两弹窗确认关闭完成。
  2. 回到登录页。
  3. 登录协议同意状态与之前一致（资料页确认不改变登录侧同意状态）。
  4. 登录流程正常（弹窗交互对登录链路零影响）。
