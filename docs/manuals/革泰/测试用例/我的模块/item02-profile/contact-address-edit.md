# 用户故事：联系人与地址单字段弹窗编辑

> 口径依据：大纲 5.3 章。单字段弹窗一次只改一项、各自弹窗、无统一保存；联系人 1–20 字符任意文本、可空；地址多行输入总计 ≤ 200 字符、可空；保存成功回显、取消 / 关弹窗保留原值；空值允许保存回显空。

## [P1] 验证联系人字段弹窗编辑保存与回显
- 测试类型
  - 功能
- 前置条件
  1. 账号 testuser01 已登录，联系人当前为空
- 测试步骤
  1. 资料页点击联系人行。
  2. 在弹窗输入「张三」，点保存。
  3. 查看资料页联系人行回显。
  4. 再点联系人行，改为「李四」后点取消 / 关闭弹窗。
- 预期结果
  1. 弹出联系人单字段编辑弹窗（一次只改一项）。
  2. 保存成功。
  3. 联系人行显示「张三」。
  4. 取消后保留原值「张三」（取消 / 关弹窗不落库）。

## [P4] 验证联系人长度边界（1 / 20 / 21 字符）
- 测试类型
  - 功能
- 前置条件
  1. 账号 testuser01 已登录
  2. 备好测试数据：1 字符「张」、20 字符「张一二三四五六七八九十一二三四五六七八九」、21 字符「张一二三四五六七八九十一二三四五六七八九甲」
- 测试步骤
  1. 联系人弹窗输入 1 字符「张」，点保存。
  2. 改输入 20 字符串，点保存。
  3. 再输入 21 字符串，点保存。
  4. 查看各次结果与回显。
- 预期结果
  1. 1 字符保存通过，回显「张」。
  2. 20 字符保存通过，回显完整 20 字。
  3. 21 字符被拦截提示（1–20 字符限制）。
  4. 联系人保持 20 字符值。

## [P4] 验证地址长度边界与多行输入（200 / 201 字符）
- 测试类型
  - 功能
- 前置条件
  1. 账号 testuser01 已登录
  2. 备好 200 字符地址：字符串「地址\n」后连续拼接 197 个「测」；201 字符地址：字符串「地址\n」后连续拼接 198 个「测」；使用 Unicode 字符计数工具分别确认长度为 200、201（换行计 1 字符）
- 测试步骤
  1. 地址弹窗输入多行 200 字符文本（含换行），点保存。
  2. 查看回显。
  3. 改输入 201 字符文本，点保存。
  4. 查看结果。
- 预期结果
  1. 200 字符（含换行）保存通过。
  2. 地址行回显多行文本（总计 ≤ 200 字符合法）。
  3. 201 字符提交。
  4. 被拦截提示超长，地址保持原值。

## [P3] 验证联系人与地址清空保存回显空
- 测试类型
  - 功能
- 前置条件
  1. 账号 testuser01 已登录，联系人 =「张三」、地址 =「北京市朝阳区测试路1号」
- 测试步骤
  1. 联系人弹窗清空全部内容，点保存。
  2. 地址弹窗清空全部内容，点保存。
  3. 查看两行回显。
  4. 退出重登后再查看两行。
- 预期结果
  1. 联系人空值保存成功（可空）。
  2. 地址空值保存成功。
  3. 两行回显为空。
  4. 重登后仍为空（空值持久化，不回填默认值）。

## [P2] 验证地址编辑后取消或关闭弹窗不改变原值
- 测试类型
  - 功能
- 前置条件
  1. 账号 testuser01 已登录，地址当前为「北京市朝阳区测试路1号」
- 测试步骤
  1. 点击地址行，在弹窗输入「上海市浦东新区测试路2号」，点击取消。
  2. 查看地址行回显。
  3. 再次打开地址弹窗，输入「广州市天河区测试路3号」，点击遮罩或系统返回键关闭。
  4. 重新打开地址弹窗并查看当前值。
- 预期结果
  1. 取消操作关闭弹窗且不发保存请求。
  2. 地址行仍显示「北京市朝阳区测试路1号」。
  3. 关闭操作不发保存请求。
  4. 弹窗当前值仍为「北京市朝阳区测试路1号」，两次未保存输入均未落库。

## [P3][反向] 验证联系人保存失败时提示失败并保留本次输入
- 测试类型
  - 可靠性
- 前置条件
  1. 账号 testuser01 已登录，联系人当前为「张三」
  2. 抓包工具可让联系人保存接口返回 500
- 测试步骤
  1. 打开联系人弹窗，将内容改为「李四」。
  2. 点击保存并模拟接口返回 500。
  3. 查看失败提示、弹窗输入和资料页联系人回显。
  4. 恢复接口后再次点击保存。
- 预期结果
  1. 弹窗显示本次输入「李四」。
  2. 保存失败，不更新服务端联系人值。
  3. 页面出现明确失败反馈，输入「李四」保留供重试，资料页已保存值仍为「张三」，不出现 UI 假成功。
  4. 重试成功后弹窗关闭，资料页联系人更新为「李四」。
