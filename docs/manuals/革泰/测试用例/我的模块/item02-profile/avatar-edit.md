# 用户故事：头像编辑与限制

> 口径依据：大纲 5.2 章。资料页头像是全 APP 唯一头像编辑入口；底部菜单［拍照｜从相册选择］；点遮罩 / 返回仅关闭菜单无变更；格式 jpg / png / webp；大小 ≤ 5MB 超限提示；1:1 圆形裁剪；不提供恢复默认头像；默认头像兜底。

## [P1] 验证资料页点头像弹出底部菜单与取消不变更
- 测试类型
  - 功能
- 前置条件
  1. 账号 testuser01 已登录，当前为默认头像
- 测试步骤
  1. 进入资料页，点击板块一头像。
  2. 查看弹出的底部菜单选项。
  3. 点击菜单外遮罩区域 / 按返回键关闭菜单。
  4. 查看头像状态。
- 预期结果
  1. 弹出底部菜单。
  2. 菜单仅含「拍照」「从相册选择」两项。
  3. 菜单关闭。
  4. 头像保持原样，无任何变更（取消仅关闭，无草稿）。

## [P2] 验证从相册选择图片完成 1:1 裁剪并上传成功
- 测试类型
  - 功能
- 前置条件
  1. 账号 testuser01 已登录，相册中备有 2MB 的 jpg 图片 avatar_test.jpg
- 测试步骤
  1. 资料页点头像 → 底部菜单点「从相册选择」。
  2. 系统选图器选择 avatar_test.jpg。
  3. 在裁剪界面调整裁剪框并确认。
  4. 等待上传完成，查看资料页与我的页头像。
- 预期结果
  1. 拉起系统选图器。
  2. 图片选中成功。
  3. 裁剪界面为 1:1 圆形裁剪，确认后进入上传。
  4. 上传成功，资料页与我的页头像同步更新为新图（同一数据源，两处同步）。

## [P2] 验证拍照上传头像成功
- 测试类型
  - 功能
- 前置条件
  1. 账号 testuser01 已登录，相机权限已授予
- 测试步骤
  1. 资料页点头像 → 底部菜单点「拍照」。
  2. 系统相机完成拍摄。
  3. 确认裁剪并等待上传。
  4. 查看资料页头像。
- 预期结果
  1. 拉起系统相机。
  2. 拍摄完成。
  3. 裁剪确认后上传成功。
  4. 资料页头像更新为拍摄照片。

## [P4] 验证头像大小边界（5MB 通过 / 5.1MB 拦截）
- 测试类型
  - 功能
- 前置条件
  1. 账号 testuser01 已登录，相册备有两张 png：avatar_5mb.png（大小 5MB）、avatar_51mb.png（大小 5.1MB）
- 测试步骤
  1. 资料页点头像 → 从相册选择 avatar_5mb.png，裁剪确认提交。
  2. 查看上传结果。
  3. 再点头像 → 从相册选择 avatar_51mb.png，裁剪确认提交。
  4. 查看提示与头像状态。
- 预期结果
  1. 5MB 图片选中提交。
  2. 上传成功，头像更新。
  3. 5.1MB 图片选中提交。
  4. 提示超限（大小超 5MB 不上传），头像保持原样。

## [P3][反向] 验证不支持格式与损坏图片拦截
- 测试类型
  - 功能
- 前置条件
  1. 账号 testuser01 已登录，相册备有：avatar.gif（GIF 格式）、broken.jpg（内容损坏但扩展名为 jpg）
- 测试步骤
  1. 资料页点头像 → 从相册选择 avatar.gif。
  2. 观察选择结果。
  3. 再选择 broken.jpg 提交。
  4. 观察提示与头像状态。
- 预期结果
  1. GIF 文件被选中尝试提交。
  2. 格式不支持被拦截并提示重选（仅支持 jpg / png / webp）。
  3. 损坏文件提交。
  4. 提示重选，不上传半截数据，头像不变。

## [P3][反向] 验证相机与存储权限拒绝的引导
- 测试类型
  - 功能
- 前置条件
  1. 账号 testuser01 已登录，APP 相机权限、存储权限均为「拒绝且不再询问」状态（可先清除授权）
- 测试步骤
  1. 资料页点头像 → 点「拍照」（相机权限被拒）。
  2. 观察引导行为。
  3. 再点头像 → 点「从相册选择」（存储权限被拒）。
  4. 观察引导行为与页面状态。
- 预期结果
  1. 「拍照」被触发但相机不可用。
  2. 引导跳转系统设置开启相机权限，不崩溃不白屏。
  3. 「从相册选择」被触发但选图不可用。
  4. 同样引导系统设置，对应菜单项保持不可用状态直至授权，全程无崩溃。
