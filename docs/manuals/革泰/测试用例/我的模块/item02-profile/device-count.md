# 用户故事：已绑定设备数口径

> 口径依据：大纲 5.4 章。个人账户 = 自己绑定 + 后台代绑去重数；企业主 = 自己绑定 + 后台代绑（含向下分配链可见范围）去重数；企业子 = 父级分配的可见设备数（非亲自绑定数，不应显示 0）；数字只读、无点击、不跳设备列表；服务端按可见范围去重统计返回。

## [P2] 验证个人账户已绑定设备数等于自己绑定加后台代绑去重数
- 测试类型
  - 功能
- 前置条件
  1. 个人账号 testuser01 已登录
  2. 该账号自己绑定设备 3 台（DEV0001、DEV0002、DEV0003），后台代绑 2 台（DEV0004、DEV0005），其中 DEV0002 同时存在代绑记录（重复）
- 测试步骤
  1. 资料页查看「已绑定设备」行数值。
  2. 核对数值与实际去重统计（3 + 2 - 1 重复 = 4 台）。
  3. 点击该行。
- 预期结果
  1. 行显示数值。
  2. 显示 4（自己绑定 + 后台代绑去重，重复不双计）。
  3. 点击无响应、不跳设备列表（只读展示）。

## [P2] 验证企业主账号设备数含向下分配链可见范围
- 测试类型
  - 功能
- 前置条件
  1. 企业主账号 owner01 已登录
  2. 结构：自己绑定 2 台 + 后台代绑 3 台 + 分配给子账号后仍对主账号可见的 2 台（无重复）
- 测试步骤
  1. 资料页查看「已绑定设备」行数值。
  2. 核对数值（2 + 3 + 2 = 7 台，分配链形成的可见范围计入）。
  3. 与设备列表页可见设备数交叉核对。
- 预期结果
  1. 行显示数值。
  2. 显示 7。
  3. 与设备列表可见数一致（同源统计，不由前端遍历计算）。

## [P3][反向] 验证企业子账号设备数为父级分配可见数（非 0）
- 测试类型
  - 功能
- 前置条件
  1. 企业子账号 sub01 已登录（父级 owner01 分配其可见设备 5 台）
  2. 子账号无自助绑定设备入口
- 测试步骤
  1. 资料页查看「已绑定设备」行数值。
  2. 核对数值是否为 5。
  3. 检查是否显示 0 或空。
- 预期结果
  1. 行显示数值。
  2. 显示 5（父级分配的可见设备数）。
  3. 不显示 0 / 空（子账号无绑定入口 ≠ 0 台，5.4 口径关键断言）。

## [P4] 验证权限变化后设备数跟随更新
- 测试类型
  - 功能
- 前置条件
  1. 企业子账号 sub01 当前可见设备 5 台，已登录
  2. 父级可调整其分配范围为 3 台
- 测试步骤
  1. 记录当前资料页设备数（5）。
  2. 父级将 sub01 可见范围调整为 3 台。
  3. sub01 退出重登 / 重进资料页查看数值。
- 预期结果
  1. 记录成功。
  2. 调整完成。
  3. 设备数更新为 3（随服务端可见范围去重统计实时跟随，契约 #6）。
