# 用户故事：资料页结构与只读字段

> 口径依据：大纲 5.1 / 5.2 / 5.3 章。资料页三板块：板块一（头像 + 账号名 + 账号类型）、板块二（联系人 / 电话 / 邮箱 / 地址 / 时区 / 已绑定设备 / APP 版本）、板块三（用户协议 + 隐私政策）。只读字段（账号名 / 邮箱 / 时区 / 已绑定设备 / APP 版本）无点击无编辑；资料页无修改密码入口（口径变更）。

## [P1] 验证资料页三板块结构完整展示
- 测试类型
  - 功能
- 前置条件
  1. 账号 testuser01（个人账号）已登录
- 测试步骤
  1. 进入「我的 → 资料」页。
  2. 核对板块一：头像、账号名、账号类型标签。
  3. 核对板块二：联系人、电话、邮箱、地址、时区、已绑定设备、APP 版本 7 个字段行。
  4. 核对板块三：用户协议、隐私政策两个入口。
- 预期结果
  1. 资料页正常展示。
  2. 板块一三元素齐全，账号类型显示「个人账号」标签（三分类只读）。
  3. 板块二 7 个字段行全部展示。
  4. 板块三两入口存在。

## [P2] 验证只读字段无点击响应与时区行纯展示
- 测试类型
  - 功能
- 前置条件
  1. 账号 testuser01 已登录，当前 APP 时区为 Beijing
- 测试步骤
  1. 在资料页依次点击邮箱行、时区行、已绑定设备行、APP 版本行。
  2. 观察是否出现弹窗、跳转或编辑态。
  3. 核对时区行显示值。
- 预期结果
  1. 四行均可点击但无响应。
  2. 不出现任何弹窗 / 跳转 / 编辑态（时区行纯展示口径变更；修改只走「我的 → 时区设置」）。
  3. 时区行回显当前配置 Beijing（与时区设置页同源）。

## [P2] 验证账号名只读且任何资料保存不能改变账号名
- 测试类型
  - 功能
- 前置条件
  1. 账号 testuser01 已登录，账号名显示 testuser01
  2. 抓包工具就绪
- 测试步骤
  1. 检查资料页账号名是否有编辑入口（点击 / 长按）。
  2. 依次编辑联系人（输入「张三」）、电话（输入 +86 138 0013 8000）、地址（输入「北京市朝阳区」）并保存。
  3. 返回资料页查看账号名，并重进我的页查看头部账号名。
  4. 抓包核对资料保存请求 / 响应中账号名字段的处理。
- 预期结果
  1. 账号名无任何编辑入口（只读）。
  2. 三项资料保存成功。
  3. 账号名两处仍为 testuser01，不变。
  4. 即使保存请求被构造携带账号名字段，服务端也忽略该字段（契约 #1 越权防线，可配合后端造包验证）。

## [P3][反向] 验证资料页不存在修改密码入口
- 测试类型
  - 功能
- 前置条件
  1. 账号 testuser01 已登录
- 测试步骤
  1. 遍历资料页全部板块与字段行。
  2. 查找修改密码相关入口。
  3. 回「我的」页核对修改密码入口位置。
- 预期结果
  1. 资料页全部元素遍历完成。
  2. 资料页不存在修改密码入口（口径变更：入口在「我的」区域二）。
  3. 修改密码入口位于我的页区域二，位置正确。
