# 用户故事：头像异常与多端同步

> 口径依据：大纲 5.2 章「头像交互流 / 头像异常场景」。上传中断网 / 超时 → 原头像不变，不得出现「本地已换服务端未换」半更新态；多端同时改头像后写覆盖；无恢复默认头像入口；成功后两处同步。

## [P3][反向] 验证头像上传中断网保持原头像
- 测试类型
  - 功能
- 前置条件
  1. 账号 testuser01 已登录，当前头像为 avatar_old.jpg
  2. 抓包工具可模拟上传接口断网 / 超时
- 测试步骤
  1. 在上传请求发出前将网络断开（选图裁剪完成后立即断网再点确认）。
  2. 提交头像上传。
  3. 查看提示、资料页与我的页头像。
  4. 恢复网络，杀进程重进 APP 查看头像。
- 预期结果
  1. 断网时机就位。
  2. 上传失败并提示。
  3. 头像保持 avatar_old.jpg 不变，我的页头像同样未变（无本地已换服务端未换的半更新态）。
  4. 重进后仍以服务端数据 avatar_old.jpg 为准。

## [P3] 验证多端改头像后写覆盖
- 测试类型
  - 功能
- 前置条件
  1. 账号 testuser01 已在手机 A、手机 B 同时登录，当前头像均为 avatar_old.jpg
  2. 手机 A 备有 avatar_A.jpg、手机 B 备有 avatar_B.jpg
- 测试步骤
  1. 手机 A 先上传 avatar_A.jpg 成功。
  2. 手机 B 随后上传 avatar_B.jpg 成功。
  3. 手机 A 下拉刷新 / 重进资料页查看头像。
  4. 检查全程是否出现冲突提示。
- 预期结果
  1. A 上传成功，两端短暂显示 avatar_A.jpg。
  2. B 上传成功。
  3. 手机 A 拉取后头像更新为 avatar_B.jpg（后写覆盖，以服务端为准）。
  4. 无任何冲突提示弹窗。

## [P2] 验证头像修改成功后我的页与资料页同步更新
- 测试类型
  - 功能
- 前置条件
  1. 账号 testuser01 已登录，当前为默认头像
  2. 相册备有 avatar_new.png
- 测试步骤
  1. 资料页上传 avatar_new.png 成功。
  2. 返回「我的」页查看头部头像。
  3. 再次进入资料页查看头像。
- 预期结果
  1. 上传成功。
  2. 我的页头像已同步为 avatar_new.png（同一数据源）。
  3. 资料页头像同样为 avatar_new.png，两处一致。

## [P5] 验证不提供恢复默认头像入口
- 测试类型
  - 功能
- 前置条件
  1. 账号 testuser01 已登录，当前为自定义头像 avatar_new.png
- 测试步骤
  1. 资料页点头像查看底部菜单。
  2. 遍历资料页全部元素查找「恢复默认 / 移除头像」类入口。
  3. 查看菜单可选项。
- 预期结果
  1. 底部菜单打开。
  2. 无任何恢复默认头像入口。
  3. 菜单仅「拍照 / 从相册选择」两项（恢复默认头像能力不提供，拍板口径）。
