# 用户故事：电话字段宽松校验与登录凭证解耦

> 口径依据：大纲 5.3 章（🔴 重大口径变更）。电话为普通可编辑资料字段（默认空、手动维护），与登录凭证完全无关；5–20 字符；宽松字符集：数字 / 空格 / `( ) + -`；不做国家归属校验；字母拦截；改电话不触碰登录手机号（服务端契约硬断言）。

## [P1] 验证国际格式电话均可保存（宽松字符集）
- 测试类型
  - 功能
- 前置条件
  1. 账号 testuser01 已登录，电话当前为空
  2. 备好四组国际格式：+1 (555) 123-4567（美国）、+61 412 345 678（澳大利亚）、+358 40 1234567（芬兰）、+55 11 91234-5678（巴西）
- 测试步骤
  1. 电话弹窗依次输入四组格式，各保存一次。
  2. 查看每次保存后的回显。
  3. 再输入座机格式 555-123-4567 与 (11) 1234-5678 各保存一次。
- 预期结果
  1. 四组手机格式全部保存成功（位数 / 分隔符差异不强校验，不做国家归属校验）。
  2. 回显与输入一致（空格 / 括号 / 加号 / 连字符原样保留）。
  3. 座机格式同样保存成功（宽松字符集全覆盖）。

## [P4] 验证电话长度边界（4 / 5 / 20 / 21 字符）
- 测试类型
  - 功能
- 前置条件
  1. 账号 testuser01 已登录
  2. 备好边界数据：4 字符「1234」、5 字符「12345」、20 字符「+86 138 0013 8000 1」（恰 20 字符）、21 字符「+86 138 0013 8000 12」
- 测试步骤
  1. 电话弹窗输入 4 字符「1234」，点保存。
  2. 改输入 5 字符「12345」，点保存。
  3. 改输入 20 字符串，点保存。
  4. 改输入 21 字符串，点保存。
- 预期结果
  1. 4 字符被拦截提示（最短 5 字符）。
  2. 5 字符保存通过。
  3. 20 字符保存通过。
  4. 21 字符被拦截提示（最长 20 字符）。

## [P3][反向] 验证电话纯字母与非法字符拦截
- 测试类型
  - 功能
- 前置条件
  1. 账号 testuser01 已登录
  2. 备好：纯字母「abcdefgh」、含非法字符「138&0013」、含中文「13800138000号」
- 测试步骤
  1. 电话弹窗输入纯字母「abcdefgh」，点保存。
  2. 改输入「138&0013」，点保存。
  3. 改输入「13800138000号」，点保存。
  4. 查看电话行回显。
- 预期结果
  1. 纯字母被拦截（仅允许数字 / 空格 / `( ) + -`）。
  2. 含 & 字符被拦截。
  3. 含中文字符被拦截。
  4. 电话保持原值，未保存任何非法输入。

## [P1] 验证修改资料电话不影响登录手机号（解耦硬断言）
- 测试类型
  - 功能
- 前置条件
  1. 国内版账号 testuser01，登录手机号 13800138000，已登录
  2. 资料电话当前为空
- 测试步骤
  1. 资料页电话弹窗输入 +1 (555) 123-4567，保存成功。
  2. 查看我的页头部第二行登录手机号。
  3. 退出登录，分别用原手机号 13800138000 + 密码 Test@1234 登录。
  4. 再尝试用资料电话 +1 (555) 123-4567 作为登录账号登录。
- 预期结果
  1. 资料电话保存成功。
  2. 头部第二行仍显示 13800138000（登录手机号不受影响）。
  3. 原手机号 + 密码登录成功（登录凭证未变）。
  4. 资料电话无法作为登录账号（字段解耦，改资料不触碰登录标识——服务端契约硬断言，契约 #2）。
