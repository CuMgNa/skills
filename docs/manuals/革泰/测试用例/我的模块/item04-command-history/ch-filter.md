# 用户故事：指令记录筛选面板

> 口径依据：大纲 7.3 章。⚠️ 页面形态待确认：本 POINT 按 PRD 筛选面板口径编写（五整体状态 + 类型单选 + 设备号精确 + 备注模糊 + 显式应用）；若产品拍板 UI 三 Tab 形态须重写。填写不立即查询，点应用按交集更新；面板重置仅重置草稿并保留入口锁定设备、须再应用；列表清除筛选清空全部并立即恢复账号可见记录。

## [P1] 验证四条件应用后按交集筛选
- 测试类型
  - 功能
- 前置条件
  1. 账号 testuser01 有 20 条记录
  2. 其中仅一条同时满足：类型 SET_INTERVAL、整体状态 COMPLETED、设备号 DEV0001、设备备注含「牛群」
- 测试步骤
  1. 从我的页进入指令记录，打开筛选面板。
  2. 类型选 SET_INTERVAL，状态选「已确认（COMPLETED）」，设备号输入 DEV0001，设备备注输入「牛群」。
  3. 点「应用」。
  4. 查看列表与总数。
- 预期结果
  1. 筛选面板打开。
  2. 四条件录入成功。
  3. 发起交集查询。
  4. 仅显示同时满足四条件的 1 条记录，总数 = 1。

## [P2] 验证筛选编辑中未点应用不立即查询
- 测试类型
  - 功能
- 前置条件
  1. 指令记录当前显示全部 20 条
- 测试步骤
  1. 打开筛选面板，输入设备号 DEV0001。
  2. 不点应用，等待 5 秒。
  3. 关闭面板查看列表。
- 预期结果
  1. 草稿值录入。
  2. 不触发查询，列表不刷新。
  3. 列表仍为全部 20 条（填写条件不立即查询）。

## [P2] 验证设备号精确匹配与备注模糊匹配
- 测试类型
  - 功能
- 前置条件
  1. 有设备号 DEV0001（备注「北区牛群一号」）和 DEV00010（备注「南区牛群十号」）的记录
- 测试步骤
  1. 筛选设备号输入 DEV0001，点应用。
  2. 查看是否混入 DEV00010。
  3. 清除筛选后，设备备注输入「牛群」，点应用。
  4. 查看匹配记录。
- 预期结果
  1. 设备号筛选执行。
  2. 仅命中 DEV0001，不混入 DEV00010（精确匹配）。
  3. 备注筛选执行。
  4. 同时命中「北区牛群一号」「南区牛群十号」（模糊匹配，与设备号分别输入）。

## [P2] 验证面板重置只重置草稿且保留入口锁定设备
- 测试类型
  - 功能
- 前置条件
  1. 从 DEV0002 设备指令页进入记录页（入口锁定 DEV0002，共 2 条）
  2. 筛选面板已应用类型 SET_INTERVAL，当前列表 1 条
- 测试步骤
  1. 打开面板修改草稿为状态 REJECTED（不应用）。
  2. 点击面板「重置」。
  3. 关闭面板查看列表。
  4. 再打开面板点「应用」。
- 预期结果
  1. 草稿被修改但未查询。
  2. 类型 / 状态等本次可编辑草稿重置，入口锁定 DEV0002 保留。
  3. 列表仍保持原已应用结果 1 条（重置本身不查询）。
  4. 应用后恢复 DEV0002 的 2 条记录（仅入口设备范围生效）。

## [P2] 验证列表清除筛选立即恢复全部可见记录
- 测试类型
  - 功能
- 前置条件
  1. 从设备 DEV0002 入口进入且应用了类型 / 状态筛选，当前 1 条
  2. 账号全部可见记录 20 条
- 测试步骤
  1. 点击列表页「清除筛选」。
  2. 查看列表、总数与筛选状态。
  3. 点击返回。
- 预期结果
  1. 立即触发查询。
  2. 设备范围、设备查询、类型、状态及全部草稿均清空，列表恢复账号可见全部 20 条；不删除记录。
  3. 返回路径仍回 DEV0002 原设备页（不改变返回路径或原选中设备上下文）。

## [P3][反向] 验证权限范围外设备号不能扩大记录权限
- 测试类型
  - 安全性
- 前置条件
  1. 账号 testuser01 无权查看设备 SECRET999，但已知其编号
- 测试步骤
  1. 指令记录筛选设备号输入 SECRET999，点应用。
  2. 查看列表、总数与接口响应。
  3. 尝试设备备注模糊输入该设备名称关键字。
- 预期结果
  1. 查询发出。
  2. 返回 0 条 / 无权限安全响应，不泄露 SECRET999 的记录、状态或数量。
  3. 备注模糊同样不能绕过权限谓词（四条件 + 权限谓词服务端完成）。
