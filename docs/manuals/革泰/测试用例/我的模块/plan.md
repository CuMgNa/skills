## 已知风险与待确认项（影响断言口径）

1. **指令记录页面形态待确认（原文 16 章 #1）**：本集按第 7.3 节 PRD 筛选面板口径（五整体状态 + 设备号精确 / 备注模糊 + 显式应用）生成用例；若拍板为 UI 三 Tab（All/Delivered/Failed）形态，item04 的 ch-filter 用例需改写
2. 未立项待确认项：通知提醒加载失败态展示（#3）、资料保存失败文案（#4，仅断言「提示+输入保留」已有部分）、头像 loading 文案（#5）、账号名超长折行（#6）、改密是否 trim（#10，用例按「原样计长不 trim」口径断言并标注）
3. 修改密码安全硬断言（6.5/6.7）：旧密码立即失效、全端会话失效、改密+踢线原子性——item03 会话 POINT 重点覆盖

## 断言纪律

- 密码规则仅长度 8–64、不校验复杂度（纯数字 / 纯字母合法），与注册 / 重置统一
- 「改资料不能改变账号名 / 登录手机号」为服务端契约硬断言（第 14 章 #1/#2），需抓包或后端协同验证
- 通知提醒「全关 ≠ 免打扰」：推送 / 记录 / 处理状态不受两开关影响
