# 用户故事：必填校验与错误提示定位

> 口径依据：大纲 6.3 / 6.4 / 6.6 章。点保存后按顺序校验：①三字段逐个判空（同层多空同时提示）→ ②新密码长度 → ③新/确认一致性 → ④新旧相同 → ⑤服务端当前密码。错误在对应输入框下展示，非单条 Toast；跨层不重复报；所有失败路径保留三框输入。

## [P3][反向] 验证三字段全空时三框同时提示必填
- 测试类型
  - 功能
- 前置条件
  1. 账号 testuser01 已登录，处于修改密码页
- 测试步骤
  1. 三字段保持全空，点 Save。
  2. 查看三框下方提示。
  3. 检查是否发出修改密码请求。
- 预期结果
  1. 本地必填校验触发。
  2. 当前密码、新密码、确认密码三个输入框下同时显示必填提示（同层多字段同时标出，非逐个弹）。
  3. 不发服务端请求，按钮恢复可点。

## [P3][反向] 验证仅当前密码为空时只标当前密码框
- 测试类型
  - 功能
- 前置条件
  1. 账号 testuser01 已登录
- 测试步骤
  1. 当前密码留空，新密码 / 确认均输入 NewPass56。
  2. 点 Save。
  3. 查看三框提示与输入内容。
- 预期结果
  1. 输入完成。
  2. 必填校验触发。
  3. 仅当前密码框下提示必填；新密码 / 确认不报错且 NewPass56 内容保留。

## [P3][反向] 验证新密码与确认密码为空时同层同时提示
- 测试类型
  - 功能
- 前置条件
  1. 账号 testuser01 已登录
- 测试步骤
  1. 当前密码输入 Test@1234，新密码与确认密码留空。
  2. 点 Save。
  3. 查看提示与当前密码内容。
- 预期结果
  1. 输入完成。
  2. 本地校验触发。
  3. 新密码框、确认密码框同时显示必填；当前密码 Test@1234 保留且不报错。

## [P3][反向] 验证确认密码不一致时提示定位到确认框
- 测试类型
  - 功能
- 前置条件
  1. 账号 testuser01 当前密码 Test@1234，已登录
- 测试步骤
  1. 输入当前密码 Test@1234、新密码 NewPass56、确认密码 NewPass57。
  2. 点 Save。
  3. 查看提示位置与三框内容。
  4. 检查是否发请求。
- 预期结果
  1. 三字段非空且新密码长度合法。
  2. 一致性校验触发。
  3. 仅确认密码框下提示「两次密码不一致」类文案，三框内容全部保留。
  4. 不发服务端请求（1–4 层均为前端本地校验）。

## [P3][反向] 验证长度不合规时不叠报一致性问题
- 测试类型
  - 功能
- 前置条件
  1. 账号 testuser01 已登录
- 测试步骤
  1. 输入当前密码 Test@1234、新密码 Test123（7 字符）、确认密码 Different99（与新密码不一致）。
  2. 点 Save。
  3. 查看新密码框与确认密码框下提示。
- 预期结果
  1. 输入完成。
  2. 长度层先命中。
  3. 仅新密码框下提示 8–64 字符；确认框不叠报不一致（跨层不重复报，校验顺序明确）。
