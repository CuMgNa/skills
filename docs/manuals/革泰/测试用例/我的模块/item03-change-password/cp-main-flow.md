# 用户故事：修改密码主流程与页面结构

> 口径依据：大纲 6.2 / 6.4 章。三字段（当前密码 / 新密码 / 确认密码）各带独立眼睛图标；底部 Save 主按钮；点保存才校验（输入中不提示）；点保存后 loading + 禁用；成功后提示并踢回登录页。测试账号密码：当前 Test@1234 → 新 NewPass56。

## [P1] 验证修改密码页面结构与三字段展示
- 测试类型
  - 功能
- 前置条件
  1. 账号 testuser01（密码 Test@1234）已登录
- 测试步骤
  1. 进入「我的 → 修改密码」页。
  2. 核对三字段：Current Password、New Password、Confirm Password。
  3. 依次点击三个字段的眼睛图标。
  4. 核对底部 Save 按钮。
- 预期结果
  1. 页面正常打开。
  2. 三字段齐全，均为密码框默认密文。
  3. 各眼睛图标独立切换对应字段的明文 / 密文（互不影响其他框）。
  4. Save 按钮为底部主按钮，初始可点。

## [P1] 验证合法输入修改密码成功并踢回登录页
- 测试类型
  - 功能
- 前置条件
  1. 账号 testuser01 当前密码 Test@1234，已登录
- 测试步骤
  1. 修改密码页输入：当前密码 Test@1234、新密码 NewPass56、确认密码 NewPass56。
  2. 点 Save。
  3. 观察保存过程与结果提示。
  4. 观察成功后的页面去向。
- 预期结果
  1. 三字段输入完成。
  2. 按钮进入 loading + 禁用，请求发出。
  3. 提示修改成功，按钮恢复。
  4. 踢回登录页，不保持登录态（成功后当前端登出，拍板定版）。

## [P2] 验证输入过程中不触发校验提示
- 测试类型
  - 功能
- 前置条件
  1. 账号 testuser01 已登录，处于修改密码页
- 测试步骤
  1. 在当前密码框输入 3 个字符后停顿。
  2. 在新密码框输入 5 个字符后停顿。
  3. 在确认密码框输入与前者不同的内容后停顿。
  4. 检查三框下方与页面提示。
- 预期结果
  1. 当前密码框下无提示。
  2. 新密码框下无长度提示。
  3. 确认框下无不一致提示。
  4. 全程无任何校验提示出现（校验时机定版：点保存才检查，输入中不提示）。

## [P5] 验证眼睛图标切换明文密文互不干扰
- 测试类型
  - 功能
- 前置条件
  1. 账号 testuser01 已登录，三字段已分别输入 Test@1234 / NewPass56 / NewPass56
- 测试步骤
  1. 点击当前密码框眼睛图标。
  2. 查看三框明密文状态。
  3. 再点击确认密码框眼睛图标。
  4. 再次查看三框状态。
- 预期结果
  1. 当前密码框切换为明文。
  2. 新密码、确认密码框仍为密文。
  3. 确认密码框切换为明文。
  4. 三框明密文状态各自独立（当前明文、新密码密文、确认明文，UI 原型口径）。
