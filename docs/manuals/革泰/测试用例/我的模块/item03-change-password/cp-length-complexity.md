# 用户故事：密码长度与复杂度规则

> 口径依据：大纲 6.3 / 6.6 章。新密码仅长度 8–64 字符，无复杂度要求；纯数字 / 纯字母合法；7 字符、65 字符拦截；失败后全部输入保留；含首尾空格 / 表情按原样字符计长、不 trim（待联调 #10，本集按当前文档口径断言）。

## [P4] 验证新密码长度下边界（7 拦截 / 8 通过）
- 测试类型
  - 功能
- 前置条件
  1. 账号 testuser01 当前密码 Test@1234，已登录
- 测试步骤
  1. 输入当前密码 Test@1234，新密码 / 确认密码均输入 7 字符 Test123，点 Save。
  2. 查看提示位置与三框内容。
  3. 将新密码 / 确认密码改为 8 字符 Test1234，点 Save。
  4. 查看提交结果。
- 预期结果
  1. 7 字符被本地拦截，不发请求。
  2. 新密码框下提示 8–64 字符要求，三框输入全部保留。
  3. 8 字符通过本地长度校验并提交。
  4. 当前密码正确时修改成功。
