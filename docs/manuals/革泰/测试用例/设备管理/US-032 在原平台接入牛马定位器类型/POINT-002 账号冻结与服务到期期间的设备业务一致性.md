# US-032 在原平台接入牛马定位器类型
> 口径依据：设备管理逻辑大纲第 5.2～5.3、7、9～10 节。账号冻结期间沿用原冻结结果拦截访问，但设备上报继续入库；解冻后读取服务端最新事实。服务到期只验证沿用原规则只读或降级且不存在自助续费入口，未确认的页面级能力矩阵不得写成验收结论。

## [P1] 验证账号冻结期间 APP 访问沿用原冻结结果拦截且设备上报继续入库
- 测试类型
  - 功能
- 前置条件
  1. 企业一级账号 GT-E1-13301 已绑定在线设备 GT-D-13301
  2. 冻结前最后有效上报为 REP-13301-001，定位时间 2026-10-12 09:00:00，电量 68%
  3. 管理后台可查询设备原始上报记录与账号冻结状态
- 测试步骤
  1. 在管理后台冻结 GT-E1-13301，并记录原冻结策略对 APP 设备业务的拦截结果。
  2. 使用 GT-E1-13301 在 APP 进入设备业务并尝试访问 GT-D-13301。
  3. 冻结期间让 GT-D-13301 上报 REP-13301-002，定位时间 2026-10-12 09:05:00，电量 67%。
  4. 在管理后台查询 REP-13301-002 的接收、存储和设备事实更新时间。
- 预期结果
  1. 账号冻结状态生效，冻结策略结果保持原系统口径，不删除账号、设备归属或历史数据。
  2. APP 访问按同一冻结结果被拦截，不因新客户端绕过账号状态校验。
  3. 设备上报链路不因账号冻结停止，REP-13301-002 被正常接收。
  4. REP-13301-002 成功入库，设备最新事实更新为 2026-10-12 09:05:00 与 67%，且不产生重复上报记录。

## [P1] 验证账号解冻后读取冻结期间最新入库数据而非冻结前缓存
- 测试类型
  - 功能
- 前置条件
  1. GT-E1-13301 处于冻结状态，设备归属关系保持有效
  2. 冻结前 APP 缓存为 REP-13301-001，定位时间 2026-10-12 09:00:00，电量 68%
  3. 冻结期间已入库 REP-13301-002，定位时间 2026-10-12 09:05:00，电量 67%
- 测试步骤
  1. 在管理后台解冻 GT-E1-13301。
  2. 使用 GT-E1-13301 重新登录 APP 并进入 GT-D-13301 设备列表。
  3. 打开 GT-D-13301 详情抽屉并刷新。
  4. 对照服务端上报记录核对页面时间、电量和记录身份。
- 预期结果
  1. 解冻状态生效，原设备归属关系继续有效，无需重新绑定。
  2. APP 重新从服务端加载当前设备事实，不复用冻结前访问结果。
  3. 详情展示冻结期间已入库的最新有效数据，定位时间为 2026-10-12 09:05:00，电量为 67%。
  4. 页面数据对应 REP-13301-002，不重复生成绑定、分组或上报记录。

## [P1] 验证服务到期账号严格沿用当前原规则的只读或降级结果
- 测试类型
  - 功能
- 前置条件
  1. 企业账号 GT-E1-13302 的服务到期日期为 2026-10-11，测试日期为 2026-10-12
  2. 已从原监控平台当前生效行为形成到期策略快照 EXP-POLICY-20261012，记录允许只读与被降级动作的实际结果
  3. APP 与监控平台 Web 使用同一账号状态和设备关系服务
- 测试步骤
  1. 使用 GT-E1-13302 登录 APP，按 EXP-POLICY-20261012 执行其中的只读样本动作。
  2. 在 APP 按同一策略快照执行其中的降级样本动作。
  3. 使用 GT-E1-13302 在监控平台 Web 执行相同样本动作。
  4. 对比 APP、Web 与 EXP-POLICY-20261012 的准入、只读和拦截结果。
- 预期结果
  1. APP 对只读样本的处理与原规则快照一致，不因服务到期额外扩大或缩小能力。
  2. APP 对降级样本按原规则限制，不产生越过到期策略的写入副作用。
  3. Web 对同一批样本返回与原规则一致的结果，设备归属和历史数据不因到期被删除。
  4. 两端结果与 EXP-POLICY-20261012 一致；本用例不据此虚构或固化未确认的具体页面能力矩阵。

## [P2] 验证服务到期场景不存在 APP 或 Web 自助续费入口
- 测试类型
  - 易用性
- 前置条件
  1. GT-E1-13302 已服务到期，服务端按原规则返回只读或降级结果
  2. 到期日期 2026-10-11 可在设备资料对应只读字段中按原数据展示
  3. APP 与监控平台 Web 均无已确认的自助续费业务能力
- 测试步骤
  1. 使用 GT-E1-13302 浏览 APP 中与设备服务到期提示相邻的可达界面和反馈弹层。
  2. 检查是否出现“续费”“立即续费”“购买套餐”等可执行入口。
  3. 在监控平台 Web 对相同到期账号执行同样检查。
  4. 核对页面未通过外链、按钮或自动跳转发起自助续费流程。
- 预期结果
  1. APP 可按原规则展示到期结果，但不新增本大纲未确认的页面访问能力。
  2. APP 不提供可点击的自助续费、购买套餐或等价入口。
  3. Web 同样不提供自助续费入口，处理仍沿用原规则只读或降级。
  4. 两端均不发起续费订单、支付或套餐购买请求；需要后续服务处理时不得伪造自助续费闭环。
