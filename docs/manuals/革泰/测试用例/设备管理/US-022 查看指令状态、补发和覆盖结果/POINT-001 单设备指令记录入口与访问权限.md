# US-022 查看指令状态、补发和覆盖结果
> 口径依据：唯一业务真源《革泰 APP 设备管理逻辑点梳理 plan》第 2.4、6.2、10 节。设备 More 菜单不直接提供指令记录入口；单设备下发页底部常驻指令记录入口，记录页限定当前有权账号与当前设备唯一标识，设备失权或标识无效时必须拦截。

## [P1] 验证下发页底部指令记录入口及返回链路
- 测试类型
  - 功能
- 前置条件
  1. 个人账号 GT-P-1231 可见设备 GT-D-123101
  2. GT-D-123101 已存在当前账号有权查看的指令记录 CMD-123101-01 和 CMD-123101-02
- 测试步骤
  1. 从 GT-D-123101 的 More 菜单点击 Send Command进入单设备下发页。
  2. 滚动到下发页底部并点击常驻的“指令记录”入口。
  3. 检查指令记录页的设备唯一标识和记录列表。
  4. 点击返回按钮。
- 预期结果
  1. 进入设备唯一标识为 GT-D-123101 的单设备下发页。
  2. 下发页底部显示“指令记录”入口并进入 GT-D-123101 的记录页。
  3. 页面设备身份为 GT-D-123101，显示 CMD-123101-01、CMD-123101-02，不混入其他设备记录。
  4. 返回原 GT-D-123101 单设备下发页，设备上下文和页面位置未切换到其他设备。

## [P2] 验证设备 More 菜单不直接提供指令记录入口
- 测试类型
  - 功能
- 前置条件
  1. 企业一级账号 GT-E1-1231 可见设备 GT-D-123111
  2. GT-D-123111 存在历史指令记录 CMD-123111-01
- 测试步骤
  1. 打开 GT-D-123111 的 More 菜单。
  2. 检查菜单全部操作项并尝试定位“指令记录”或同义入口。
  3. 点击 Send Command并检查下发页底部。
- 预期结果
  1. More 菜单正常打开。
  2. More 菜单不显示指令记录入口，不能从设备列表直接进入记录页。
  3. 进入 GT-D-123111 单设备下发页后，底部显示“指令记录”入口，记录访问链路未被错误放置到 More 菜单。

## [P3][反向] 验证设备关系失效后拦截旧页面访问指令记录
- 测试类型
  - 安全性
- 前置条件
  1. 企业二级账号 GT-E2-1231 原可见设备 GT-D-123121，并已打开该设备单设备下发页
  2. GT-D-123121 存在受保护指令记录 CMD-123121-01
  3. 测试期间由直属企业一级账号回收 GT-E2-1231 对 GT-D-123121 的分配关系
- 测试步骤
  1. 在分配关系回收后，从旧下发页点击“指令记录”。
  2. 观察权限校验结果和页面展示内容。
  3. 返回设备列表并刷新当前账号设备范围。
  4. 尝试通过旧记录页地址再次访问 GT-D-123121。
- 预期结果
  1. 服务端按最新设备关系校验并拒绝进入 GT-D-123121 指令记录页。
  2. 页面展示统一的无权限或数据不可访问结果，不展示 CMD-123121-01 的内容及其他受保护字段。
  3. 刷新后 GT-E2-1231 的设备列表不再显示 GT-D-123121。
  4. 旧地址直访继续被拦截，不因客户端缓存恢复旧设备权限。

## [P3][反向] 验证无效或越权设备唯一标识不能读取指令记录
- 测试类型
  - 安全性
- 前置条件
  1. 企业三级账号 GT-E3-1231 仅可见设备 GT-D-123131
  2. 同企业其他分支设备 GT-D-123132 存在指令记录 CMD-123132-01，但未分配给 GT-E3-1231
  3. 不存在设备唯一标识 GT-D-999999
- 测试步骤
  1. 以 GT-E3-1231 请求 GT-D-123132 的指令记录页。
  2. 检查越权请求的响应和页面内容。
  3. 以 GT-E3-1231 请求无效标识 GT-D-999999 的指令记录页。
  4. 检查两次失败请求是否泄露设备名称、记录 ID 或指令内容。
- 预期结果
  1. GT-D-123132 的记录请求被权限校验拒绝。
  2. 页面不展示 CMD-123132-01，也不返回其他分支设备的记录数量和详情。
  3. GT-D-999999 按统一无效标识或数据不可访问规则处理，不进入空壳记录页伪装成功。
  4. 两次失败均不泄露设备名称、记录 ID、指令参数或执行结果。

## [P3][反向] 验证同名设备记录按唯一标识隔离
- 测试类型
  - 可靠性
- 前置条件
  1. 个人账号 GT-P-1232 可见设备 GT-D-123141 和 GT-D-123142，两台设备备注均为“南场定位器”
  2. GT-D-123141 有记录 CMD-123141-01，GT-D-123142 有记录 CMD-123142-01
- 测试步骤
  1. 从 GT-D-123141 下发页进入指令记录并记录列表内容。
  2. 返回设备列表，从 GT-D-123142 下发页进入指令记录并记录列表内容。
  3. 比对两次记录页携带的设备唯一标识。
- 预期结果
  1. GT-D-123141 记录页仅显示 CMD-123141-01，不显示 CMD-123142-01。
  2. GT-D-123142 记录页仅显示 CMD-123142-01，不残留 CMD-123141-01。
  3. 两次查询分别使用 GT-D-123141、GT-D-123142 作为设备身份，不以相同备注“南场定位器”合并或串读记录。
