## 本次 v2.3 修订

### 真源冲突修正

1. 详情定位三字段仍要求经纬度和定位时间来自同一完整记录；地图「位置」入口单独以完整合法经纬度为准，定位时间非法不阻断地图聚焦。
2. SIM 卡状态统一采用 `account_status` 八个已知码及未知/空值处理，删除旧“五态、第六种状态错误”的冲突口径。
3. 同一设备连续刷新明确采用最新请求上下文，迟到旧响应不得覆盖最新结果。

### 新增覆盖

- 设备列表刷新、整群轨迹、分组管理、指令下发四类操作及路由隔离。
- 企业一级经 Web 用户管理移除指定三级，仅清理目标三级关系。
- 解绑确认取消后关系、分组、围栏、数量和历史数据零副作用。
- 批量入口普通指令离线/未连接提交及高危指令逐设备实时复检。
- 个人账号 Web 绑定牛马定位器、企业二三级 Web 无入口及构造请求拒绝。
- Web/管理后台未入库一致拦截、手工无效卡号第一层拦截、后台代绑目标一级配额校验。
- 高危指令在线成功和设备恢复在线刷新后重新提交。
- 分组新增失败保留输入、服务端分组总量上限、删除非当前组保留筛选、确认后并发加入设备阻止删除。
- SIM 的 MSISDN/ICCID/IMSI 服务端选择及产品字段空值矩阵。
- 定位频率已有目标时本地非法输入、服务端非法参数、路由失败及记录页重发页面恢复。
- 到期日期不增加未确认样式、详情 ICCID 窄屏换行、设备图标不可编辑。
