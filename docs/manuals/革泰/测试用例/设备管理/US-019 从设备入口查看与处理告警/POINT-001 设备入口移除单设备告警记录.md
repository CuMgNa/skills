# US-019 从设备入口查看与处理告警
> 口径依据：唯一业务真源《革泰 APP 设备管理逻辑点梳理 plan》第 2.2、2.4、6.1、10 节。设备 More 菜单与详情抽屉均移除单设备告警入口，但既有历史告警数据不删除，告警查看仍从告警模块现有入口进入。

## [P1] 验证各状态设备 More 菜单均移除告警记录入口
- 测试类型
  - 功能
- 前置条件
  1. 个人账号 GT-P-1201 可见在线设备 GT-D-120101、离线设备 GT-D-120102、初始化未连接设备 GT-D-120103、告警设备 GT-D-120104
  2. 四台设备卡片右上角均显示 More 入口
- 测试步骤
  1. 依次打开 GT-D-120101、GT-D-120102、GT-D-120103、GT-D-120104 的 More 菜单。
  2. 检查每个 More 菜单的全部操作项。
  3. 分别关闭四个 More 菜单并观察页面导航。
- 预期结果
  1. 四种状态设备均可正常打开各自的 More 菜单。
  2. 菜单仅保留实时追踪、历史轨迹、物联网卡查询、发送指令和解绑设备，不显示 Device Alert History、设备告警记录或同义入口。
  3. 关闭菜单后停留在设备列表，未进入单设备告警记录页，且未触发告警查询请求。

## [P1] 验证各状态设备详情抽屉底部均不提供告警入口
- 测试类型
  - 功能
- 前置条件
  1. 企业一级账号 GT-E1-1201 可见在线设备 GT-D-120111、离线设备 GT-D-120112、初始化未连接设备 GT-D-120113、告警设备 GT-D-120114
- 测试步骤
  1. 依次点击四台设备的卡片本体打开半屏详情抽屉。
  2. 检查每个详情抽屉的标题区、字段区和底部操作区。
  3. 关闭每个详情抽屉并检查是否发生额外跳转。
- 预期结果
  1. 四种状态设备均在当前列表上方打开对应设备的半屏详情抽屉。
  2. 四个详情抽屉均不显示告警记录、历史报警或进入告警处理的按钮、链接和可点击区域。
  3. 关闭后恢复原设备列表，不进入单设备告警记录页。

## [P2] 验证移除设备入口后历史告警数据仍可从告警模块查询
- 测试类型
  - 功能
- 前置条件
  1. 设备唯一标识 GT-D-120121 已产生历史告警记录 AL-120121-01 和 AL-120121-02
  2. 个人账号 GT-P-1202 当前仍有权查看 GT-D-120121
  3. 已记录移除设备入口前两条历史告警的告警时间、设备唯一标识和记录 ID
- 测试步骤
  1. 在设备列表打开 GT-D-120121 的 More 菜单和详情抽屉，确认无告警入口。
  2. 从告警模块现有入口按设备唯一标识 GT-D-120121 查询历史告警。
  3. 将查询结果与已记录的 AL-120121-01、AL-120121-02 比对。
  4. 查询历史告警数据存储或服务端记录总数。
- 预期结果
  1. 设备 More 菜单和详情抽屉均不提供告警入口。
  2. 告警模块返回当前账号权限范围内 GT-D-120121 的历史告警。
  3. AL-120121-01、AL-120121-02 的记录 ID、设备唯一标识和告警时间保持不变。
  4. 历史告警记录总数未因设备入口移除而减少，数据未被删除或重建。

## [P3][反向] 验证设备入口不残留旧告警跳转链路
- 测试类型
  - 可靠性
- 前置条件
  1. 企业二级账号 GT-E2-1201 可见告警设备 GT-D-120131
  2. 客户端已升级为移除 Device Alert History 入口的版本
- 测试步骤
  1. 打开 GT-D-120131 的 More 菜单并点击菜单内各保留项之外的空白区域。
  2. 打开 GT-D-120131 的详情抽屉并点击底部空白区域。
  3. 监测两次操作产生的页面路由和告警查询请求。
- 预期结果
  1. More 菜单空白区域不响应旧 Device Alert History 跳转。
  2. 详情抽屉底部空白区域不响应旧告警入口点击事件。
  3. 不生成单设备告警记录路由，不发起由设备模块触发的告警历史查询请求，也不出现双页面或隐藏热区误触。
