# US-018 编辑设备资料并查询物联网卡
> 口径依据：唯一业务需求真源《革泰 APP 设备管理逻辑点梳理 plan.md》第 5.3、5.5、5.9、9、10 节。在线、离线、未连接设备均可选择并提交普通 UPLOAD，通信状态不是拒绝条件；服务端仍需校验登录、设备关系、路由、型号、参数、幂等键和容量。

## [P1] 验证在线设备可提交定位频率并进入普通队列
- 测试类型
  - 功能
- 前置条件
  1. 当前账号对在线设备 GT-LOC-1121 有编辑权限
  2. 设备 confirmedValue 为 600 秒且无在途目标
- 测试步骤
  1. 从详情抽屉进入独立编辑页。
  2. 选择“1 分钟（耗电模式）”并点击整页 Save。
  3. 查询保存响应、指令记录和编辑页展示。
- 预期结果
  1. 在线状态不影响进入编辑页和选择频率。
  2. 请求通过服务端校验后创建参数 60 秒的 UPLOAD 任务。
  3. 任务进入 SENDING，编辑页显示 1 分钟并标记“设置中”，卡片仍显示确认值 10 分钟。

## [P1] 验证离线设备可提交定位频率且页面不额外拦截
- 测试类型
  - 功能
- 前置条件
  1. 当前账号对离线设备 GT-LOC-1122 有编辑权限
  2. 设备 confirmedValue 为 3600 秒且普通队列容量可用
- 测试步骤
  1. 进入 GT-LOC-1122 独立编辑页。
  2. 核对页面是否显示离线专属阻断提示。
  3. 选择自定义 30 分钟并点击整页 Save。
  4. 查询保存响应、队列和页面展示。
- 预期结果
  1. 离线设备可正常进入并编辑 Location Interval。
  2. 页面不因离线额外置灰 Save，也不展示要求先上线的提示。
  3. 服务端受理参数 1800 秒的 UPLOAD 任务，不以离线为拒绝原因。
  4. 任务进入普通队列，编辑页显示“自定义模式（30 分钟）”“设置中”。

## [P1] 验证未连接设备可提交定位频率并保留目标
- 测试类型
  - 功能
- 前置条件
  1. 当前账号对初始化未连接设备 GT-LOC-1123 有编辑权限，设备列表按离线口径展示
  2. 设备无 confirmedValue、无历史频率任务
- 测试步骤
  1. 进入 GT-LOC-1123 独立编辑页。
  2. 选择“10 分钟（默认模式）”并点击整页 Save。
  3. 退出编辑页后重新进入。
- 预期结果
  1. 页面初始显示“请选择定位频率”，允许选择和保存。
  2. 服务端创建参数 600 秒的 UPLOAD 任务，未连接状态不构成普通指令拒绝条件。
  3. 重新进入后显示 10 分钟并标记“设置中”，设备卡片因尚无 confirmedValue 继续隐藏频率。

## [P3][反向] 验证非通信原因校验失败独立形成 FAILURE
- 测试类型
  - 安全性
- 前置条件
  1. 设备 GT-LOC-1124 当前显示离线
  2. 当前账号已失去 GT-LOC-1124 操作权限，但客户端编辑页仍保留旧缓存
  3. 客户端选择自定义 20 分钟并生成幂等键 idem-loc-1124-01
- 测试步骤
  1. 在旧编辑页点击整页 Save。
  2. 查询服务端校验结果和指令记录。
  3. 刷新设备列表与编辑页。
- 预期结果
  1. 请求到达服务端后按实时权限校验，不因客户端旧缓存放行。
  2. 创建参数 1200 秒的 FAILURE 记录，失败原因指向权限或设备关系，不得写成设备离线。
  3. 受保护数据被清理，当前账号不能继续查看或编辑该设备，confirmedValue 不更新。

## [P1] 验证离线任务明确 FAILURE 后上线不自动创建任务
- 测试类型
  - 可靠性
- 前置条件
  1. 离线设备 GT-LOC-1125-A、GT-LOC-1125-B 均对当前账号可编辑，confirmedValue 均为 600 秒
  2. 两台设备各有一条参数 1800 秒且已明确进入 FAILURE 的离线任务：cmd-loc-1125-a / att-loc-1125-a-01、cmd-loc-1125-b / att-loc-1125-b-01
  3. 两条失败记录均保留失败原因，其中 cmd-loc-1125-b 按既有规则具备记录页重发入口
- 测试步骤
  1. 记录两台设备当前 commandId、attemptId、四态记录数和有效目标后，将 GT-LOC-1125-A、GT-LOC-1125-B 恢复在线。
  2. 完成一次设备状态刷新并查询两台设备的任务、尝试、队列和编辑页展示。
  3. 对 GT-LOC-1125-A 由用户在编辑页重新选择 30 分钟并点击整页 Save。
  4. 对 GT-LOC-1125-B 从原 FAILURE 记录执行重新发送，再次查询两台设备的任务与尝试链。
- 预期结果
  1. 上线前两条任务均保持 FAILURE，失败参数不再作为有效 desiredValue，编辑页回退 confirmedValue 10 分钟。
  2. 设备上线和状态刷新不得自动新建 commandId、attemptId 或 SENDING 记录，两台设备的失败记录数及标识保持不变。
  3. 只有 GT-LOC-1125-A 的用户重新设置动作允许创建新的 commandId 和首个 attemptId，并按普通队列进入 SENDING。
  4. 只有 GT-LOC-1125-B 的记录页重发动作允许在原 commandId cmd-loc-1125-b 下创建新 attemptId 并进入 SENDING；上线事件本身不产生任何补发任务或重复记录。
