## [P3][反向] 验证底部入口快速切换不串设备或重复导航
- 测试类型
  - 可靠性
- 前置条件
  1. 账号 GT-P-1802 可见 deviceId=GT-D-180141 和 GT-D-180142，两台设备备注均为「快速切换牛」
  2. 已开启客户端路由日志，可统计页面实例、deviceId 和触发来源
- 测试步骤
  1. 打开 GT-D-180141 详情抽屉并快速连续点击「轨迹」3 次。
  2. 返回设备列表后立即打开 GT-D-180142 详情抽屉并点击「编辑」。
  3. 核对页面栈、路由日志和两个页面的设备数据。
  4. 返回列表并检查两个详情抽屉是否仍同时存在。
- 预期结果
  1. 首次有效点击只创建一个 GT-D-180141 历史轨迹页面实例，重复点击不生成额外页面。
  2. 第二次只进入 GT-D-180142 的独立编辑页，不沿用 GT-D-180141 的路由参数或资料缓存。
  3. 路由日志分别记录 GT-D-180141 的轨迹导航和 GT-D-180142 的编辑导航，同备注不导致身份混淆。
  4. 页面栈不存在两个同时悬挂的详情抽屉，返回后恢复对应设备列表上下文。

## [P3][反向] 验证绑定确认页和独立编辑页均不能修改设备图标
- 测试类型
  - 功能
- 前置条件
  1. 已入库牛马定位器 GT-D-180151 的设备类型图标由系统固定映射
  2. 个人账号 GT-P-1803 可绑定该设备，绑定成功后具备资料编辑权限
- 测试步骤
  1. 进入 GT-D-180151 绑定确认页，检查全部字段和可操作控件。
  2. 完成绑定后从详情抽屉进入独立编辑页。
  3. 检查编辑页全部字段和图标区域的可操作性。
  4. 修改备注、分组并保存后核对列表和详情抽屉图标。
- 预期结果
  1. 绑定确认页仅允许编辑已确认资料，不提供图标上传、选择或替换控件。
  2. 独立编辑页只包含设备备注、真实分组和定位频率，不提供设备图标修改入口。
  3. 图标区域不可点击修改，构造资料保存也不包含图标字段。
  4. 备注和分组更新后设备仍展示类型对应的固定图标，图标不因资料编辑发生变化。
