# US-018 编辑设备资料并查询物联网卡

> 口径依据：唯一业务真源《革泰 APP 设备管理逻辑点梳理 plan.md》2.4.2～2.4.4。无卡号、第三方错误、超时、网络失败、非 JSON 或缺少 data 时统一进入失败态：保留设备摘要，SIM 明细显示“—”，展示可读原因并提供刷新；错误文案未固定时只验证原因可读、失败字段和失败态。

## [P3][反向] 验证第三方 502 返回统一失败态
- 测试类型
  - 可靠性
- 前置条件
  1. 设备 GT-DEV-SIM-0601 名称为“北区备用机”，型号为 GT-CATTLE-X2
  2. 第三方查询返回 code=502
- 测试步骤
  1. 进入 GT-DEV-SIM-0601 的 IoT SIM Query 页面。
  2. 等待查询结束并核对设备摘要、SIM 明细和异常区域。
  3. 核对刷新按钮状态。
- 预期结果
  1. 查询在有限时间内结束，不持续显示加载中。
  2. 页面保留“北区备用机”和 GT-CATTLE-X2，SIM 明细均显示“—”，异常区域展示物联卡不存在或未启用类别的可读原因；不要求未明确的精确文案。
  3. 刷新按钮仍可操作，502 不被展示成卡状态。

## [P3][反向] 验证第三方 505 返回可恢复的频率受限失败态
- 测试类型
  - 稳定性
- 前置条件
  1. 设备 GT-DEV-SIM-0602 名称为“南区追踪器”，型号为 GT-HORSE-X2
  2. 第三方查询返回 code=505
- 测试步骤
  1. 查询 GT-DEV-SIM-0602 的物联卡信息。
  2. 查看查询结束后的失败原因和 SIM 明细。
  3. 在第三方恢复后点击一次刷新，服务端返回 code=200 和 ICCID 89860400123456789602。
- 预期结果
  1. 页面进入访问频率受限失败态且不无限加载。
  2. 页面保留设备摘要，SIM 明细均显示“—”，展示频率受限类别的可读原因和刷新入口；不虚构固定倒计时或冷却规则。
  3. 刷新成功后清除本次失败态并展示 ICCID 89860400123456789602，不残留 505 作为卡状态。

## [P3][反向] 验证超时、网络失败和非 JSON 均不产生伪成功数据
- 测试类型
  - 可靠性
- 前置条件
  1. 设备 GT-DEV-SIM-0603 名称为“西区追踪器”，型号为 GT-CATTLE-X3
  2. 可依次模拟第三方请求超时、网络连接失败、返回文本 maintenance
- 测试步骤
  1. 模拟请求超时并查询页面。
  2. 模拟网络连接失败并刷新页面。
  3. 模拟返回非 JSON 文本 maintenance 并刷新页面。
- 预期结果
  1. 页面结束加载并进入超时失败态，保留设备摘要，SIM 明细均显示“—”，展示可读失败原因和刷新入口。
  2. 页面结束加载并进入网络失败态，保留设备摘要，SIM 明细均显示“—”，不沿用未确认的伪成功数据。
  3. 页面结束加载并进入响应异常失败态，保留设备摘要，SIM 明细均显示“—”，不崩溃且不编造卡资料。

## [P3][反向] 验证 code=200 但缺少 data 时按失败处理
- 测试类型
  - 兼容性
- 前置条件
  1. 设备 GT-DEV-SIM-0604 名称为“东区追踪器”，型号为 GT-HORSE-X3
  2. 第三方响应包含 code=200，但 data 字段缺失
- 测试步骤
  1. 查询 GT-DEV-SIM-0604 的物联卡信息。
  2. 核对页面设备摘要、SIM 明细和查询状态。
  3. 检查页面是否把接口 code=200 直接视为业务成功。
- 预期结果
  1. 页面保留“东区追踪器”和 GT-HORSE-X3 设备摘要。
  2. 页面进入响应异常失败态，SIM 明细均显示“—”，展示可读原因和刷新入口。
  3. 页面不因接口 code=200 伪造成功字段，不展示上一次未确认的卡资料。

## [P3][反向] 验证成功后刷新失败时清除旧成功明细
- 测试类型
  - 可靠性
- 前置条件
  1. 设备 GT-DEV-SIM-0605 名称为“刷新失败测试机”，型号为 GT-CATTLE-X4
  2. 首次查询成功展示 active=true、iccid=89860400123456789605、account_status=00、expiry_date=2027-05-31；下一次刷新模拟请求超时
- 测试步骤
  1. 进入页面并等待首次查询成功，记录设备摘要和全部 SIM 明细。
  2. 点击刷新按钮一次并等待本次请求超时。
  3. 核对刷新失败后的设备摘要、SIM 明细、失败原因和刷新能力。
- 预期结果
  1. 首次页面展示“刷新失败测试机”、GT-CATTLE-X4、Active、ICCID 89860400123456789605、正使用和 2027-05-31。
  2. 刷新仍查询设备 GT-DEV-SIM-0605，提供基础加载反馈，并在超时后结束加载进入失败态。
  3. 页面保留设备名称与型号摘要，全部 SIM 明细显示“—”，旧 ICCID、状态和有效期不得残留；展示超时类别的可读原因且刷新按钮仍可操作。
