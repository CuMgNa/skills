# US-018 编辑设备资料并查询物联网卡

> 口径依据：大纲第 5.2、5.9、8、10 章。详情抽屉只读展示型号、电量、最后有效定位、到期时间和 ICCID；普通字段缺失或非法时按字段整体隐藏，电量仅 0～100 有效且 0、100 不得被当作空值。

## [P1] 验证详情普通字段按服务端有效值原样展示
- 测试类型
  - 功能
- 前置条件
  1. 设备 DEV-FLD-001 的实际硬件型号为 S18，服务到期日期为 2027-12-31
  2. DEV-FLD-001 当前 ICCID 为 08986001000000000001，电量为 58
- 测试步骤
  1. 点击 DEV-FLD-001 卡片本体打开详情抽屉。
  2. 查看类型、电量、到期时间和 ICCID 字段。
  3. 将展示内容与服务端当前设备详情响应比对。
- 预期结果
  1. 抽屉按 DEV-FLD-001 唯一标识加载详情。
  2. 类型显示 S18，电量显示 58%，到期时间显示 2027-12-31，ICCID 完整显示 08986001000000000001。
  3. 字段与服务端值一致；ICCID 保留前导零，不转数值、不插入分组空格，类型不从备注、卡号或图标推断。

## [P4] 验证电量 0 和 100 均作为有效边界值展示
- 测试类型
  - 功能
- 前置条件
  1. DEV-FLD-002 最新有效电量为 0，DEV-FLD-003 最新有效电量为 100
  2. 两台设备详情中的其他字段均有效
- 测试步骤
  1. 打开 DEV-FLD-002 详情抽屉并查看电量字段。
  2. 关闭后打开 DEV-FLD-003 详情抽屉并查看电量字段。
  3. 核对两个边界值的字段可见性和颜色分类。
- 预期结果
  1. DEV-FLD-002 显示 0%，字段不隐藏，按低于 20% 使用红色。
  2. DEV-FLD-003 显示 100%，字段不隐藏，按大于等于 20% 使用绿色。
  3. 0 和 100 均按有效电量处理，不被转换为无值或占位内容。

## [P3][反向] 验证普通字段单独缺失或非法时仅隐藏当前字段
- 测试类型
  - 可靠性
- 前置条件
  1. DEV-FLD-006 的有效基线为型号 S18、电量 58、到期时间 2027-12-31、ICCID 08986001000000000006
  2. DEV-FLD-006 存在完整有效定位记录，经纬度和定位时间均合法；可逐次只替换一个普通字段，其余字段保持基线值
- 测试步骤
  1. 仅将型号改为 null，打开 DEV-FLD-006 详情抽屉。
  2. 恢复型号 S18，仅将到期时间改为非法日期 2026-02-30，重新打开抽屉。
  3. 恢复到期时间 2027-12-31，仅将 ICCID 改为空字符串，重新打开抽屉。
  4. 恢复 ICCID 08986001000000000006，仅将电量改为 null，重新打开抽屉。
  5. 核对四次详情中的完整有效定位三项。
- 预期结果
  1. 仅隐藏类型字段；电量 58%、到期时间 2027-12-31、ICCID 08986001000000000006 和定位三项正常展示。
  2. 仅隐藏到期时间字段；型号 S18、电量 58%、ICCID 08986001000000000006 和定位三项正常展示。
  3. 仅隐藏 ICCID 字段；型号 S18、电量 58%、到期时间 2027-12-31 和定位三项正常展示，不恢复旧 ICCID。
  4. 仅隐藏电量字段；不得把缺失电量显示为 0%，型号 S18、到期时间 2027-12-31、ICCID 08986001000000000006 正常展示。
  5. 四次均成组展示同一条合法定位记录，普通字段异常不扩大为整页或定位组隐藏。

## [P3][反向] 验证电量越界和类型非法时隐藏电量字段
- 测试类型
  - 功能
- 前置条件
  1. 可依次将 DEV-FLD-007 的最新电量响应设置为 -0.01、100.01、字符串 high
  2. DEV-FLD-007 的标题、型号和 ICCID 均有效
- 测试步骤
  1. 以电量 -0.01 打开 DEV-FLD-007 详情抽屉。
  2. 以电量 100.01 重新请求 DEV-FLD-007 详情。
  3. 以电量字符串 high 重新请求 DEV-FLD-007 详情。
  4. 核对三次响应下其他有效字段的展示。
- 预期结果
  1. -0.01 小于有效下限，电量字段整体隐藏，不按 0% 展示。
  2. 100.01 大于有效上限，电量字段整体隐藏，不截断或钳制为 100%。
  3. high 为非法类型，电量字段整体隐藏，页面不报错。
  4. 标题、型号和 ICCID 继续显示本设备有效值，电量异常不扩大为整页失败。
