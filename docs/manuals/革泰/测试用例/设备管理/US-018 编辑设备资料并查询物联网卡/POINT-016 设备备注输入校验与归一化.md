# US-018 编辑设备资料并查询物联网卡
> 口径依据：大纲第 5.3、5.8～5.9、8、10 章。设备备注非必填，长度为 0～40 字符并支持 Unicode；保存时去除首尾空格、纯空格归一为空、内部空格保留且允许不同设备重名，不能套用分组名称的空格或唯一性规则。

## [P1] 验证设备备注裁剪首尾空格保留内部空格且允许重名
- 测试类型
  - 功能
- 前置条件
  1. 个人账号 personal_01 可编辑设备 DEV-EDIT-1001，卡号为 898600100000001001，当前备注为「旧备注」
  2. 同账号下设备 DEV-EDIT-1002 的卡号为 898600100000001002，备注已为「马厩 A 区」
  3. DEV-EDIT-1001 当前分组为「东区设备」且其他编辑字段保持合法
- 测试步骤
  1. 进入 DEV-EDIT-1001 独立编辑页，在 Device Name 输入「  马厩 A 区  」。
  2. 点击 Save 并等待普通资料保存成功。
  3. 返回设备列表，分别查看 DEV-EDIT-1001 与 DEV-EDIT-1002 的完整标题，并依次打开两台设备详情抽屉核对完整标题。
  4. 重新进入 DEV-EDIT-1001 编辑页核对备注原值。
- 预期结果
  1. 输入被接受，保存前只按设备备注规则处理，不因分组名称规则或已有同名备注而拦截。
  2. 首尾两个空格被去除，内部单个空格保留，DEV-EDIT-1001 正式备注保存为「马厩 A 区」。
  3. APP 列表与详情抽屉中，DEV-EDIT-1001 完整标题均为「马厩 A 区（898600100000001001）」，DEV-EDIT-1002 完整标题均为「马厩 A 区（898600100000001002）」；相同备注不合并设备，也不省略各自卡号。
  4. 编辑页回显纯备注字段「马厩 A 区」，不包含卡号、不恢复首尾空格且不压缩内部空格。

## [P1] 验证空字符串与纯空格均可保存为空备注
- 测试类型
  - 功能
- 前置条件
  1. 个人账号 personal_01 可编辑设备 DEV-EDIT-1003，卡号为 898600100000001003，当前备注为「北门定位器」
  2. DEV-EDIT-1003 当前分组和定位频率均为合法已保存状态
- 测试步骤
  1. 清空 Device Name 后点击 Save。
  2. 重新进入编辑页，在 Device Name 输入 6 个空格「      」并点击 Save。
  3. 查询设备资料接口中 DEV-EDIT-1003 的共享备注值。
  4. 刷新设备列表与详情抽屉并查看标题展示。
- 预期结果
  1. 空字符串作为合法的 0 字符备注保存成功，不提示必填错误。
  2. 纯空格经首尾裁剪后归一为空并保存成功，不保留 6 个空格。
  3. 服务端共享备注为空，不生成空格字符串、默认昵称或账户独立备注副本。
  4. APP 列表与详情抽屉均只显示卡号「898600100000001003」，不继续显示旧备注「北门定位器」，也不显示「（898600100000001003）」、空括号「() / （）」或其他空备注占位。

## [P4] 验证四十字符上界与 Unicode 备注均可完整保存
- 测试类型
  - 兼容性
- 前置条件
  1. 企业一级账号 corp_l1_01 可编辑设备 DEV-EDIT-1004 与 DEV-EDIT-1005
  2. 两台设备均已选择当前账号有权限的真实分组，除备注外其他字段合法
- 测试步骤
  1. 在 DEV-EDIT-1004 输入 40 字符备注「1234567890123456789012345678901234567890」并保存。
  2. 在 DEV-EDIT-1005 输入 Unicode 备注「牛马定位器🚜 东区 αβ」并保存。
  3. 重新进入两台设备编辑页并查询设备资料接口。
  4. 使用完整 Unicode 备注「牛马定位器🚜 东区 αβ」搜索设备。
- 预期结果
  1. 40 字符边界通过校验并完整保存，不截断第 40 个字符。
  2. 中文、Emoji、空格和希腊字母均可保存，内部空格保持不变且不出现乱码。
  3. 页面与接口分别返回完整的 40 字符备注和「牛马定位器🚜 东区 αβ」。
  4. 搜索结果必须包含设备唯一标识 DEV-EDIT-1005，并按该唯一标识打开正确设备；不要求在未证明其他设备四个检索字段均不命中时武断断言结果仅一台。

## [P3][反向] 验证四十一字符备注阻止保存且不污染正式资料
- 测试类型
  - 功能
- 前置条件
  1. 个人账号 personal_02 可编辑设备 DEV-EDIT-1006
  2. DEV-EDIT-1006 正式备注为「牧场南区」，正式分组为「南区设备」
  3. 编辑页除备注外未修改其他字段
- 测试步骤
  1. 输入 41 字符备注「12345678901234567890123456789012345678901」。
  2. 点击 Save，记录客户端是否发出普通资料更新请求及服务端响应。
  3. 查看页面校验状态与当前输入内容。
  4. 使用另一客户端查询 DEV-EDIT-1006 正式备注、分组、其他资料字段及新增 UPLOAD 数量。
- 预期结果
  1. 输入内容完整保留在本地草稿中，系统识别其超过 40 字符上限。
  2. 可由客户端在请求前拦截，也可提交后由服务端拒绝；不强制必须本地拦截，但任何路径均不得保存 41 字符正式备注或创建定位频率任务。
  3. 页面展示可读的长度超限原因，仍停留编辑页供修改，不截断后假保存。
  4. 正式备注仍为「牧场南区」、分组仍为「南区设备」，其他资料字段不变且 UPLOAD 新增数为 0，无任何部分更新副作用。
