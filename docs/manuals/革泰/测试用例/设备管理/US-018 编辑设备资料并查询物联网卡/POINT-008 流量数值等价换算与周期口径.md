# US-018 编辑设备资料并查询物联网卡

> 口径依据：唯一业务真源《革泰 APP 设备管理逻辑点梳理 plan.md》2.4.3、2.4.4。流量可在 MB、GB 间进行可读且数值等价的换算，但第三方单卡字段单位及“已用流量”来源字段仍待服务端契约确认；以下明确单位与统计口径的服务端响应均为测试夹具，不代表最终来源单位契约。套餐周期不得仅凭 data_plan 推导。

## [P1] 验证明确声明为 MB 的测试响应换算后数值等价
- 测试类型
  - 功能
- 前置条件
  1. 设备 GT-DEV-SIM-0401 关联 ICCID 89860400123456789401
  2. 服务端测试响应明确声明套餐流量 9876 MB、当前周期已用流量 1423 MB、剩余流量 8453 MB，并携带本次响应适用的单位换算规则；该测试夹具不代表最终来源单位契约或固定换算基数
- 测试步骤
  1. 查询 GT-DEV-SIM-0401 的物联卡信息。
  2. 记录页面套餐、已用和剩余流量的数值及单位。
  3. 按本次响应声明的同一换算规则，将页面三项展示值逆向还原为 MB 并与测试响应比较。
- 预期结果
  1. 页面成功展示三项流量，不混用其他设备或其他统计周期的数据。
  2. 页面可保留 9876 MB、1423 MB、8453 MB，也可按本次响应声明的规则转换为可读 GB 表达；未确认最终契约前不固定具体 GB 数字、换算基数或舍入位数。
  3. 三项展示值按同一规则逆向还原后分别等于 9876 MB、1423 MB、8453 MB，换算过程可逆且数值守恒。

## [P1] 验证非整单位数值换算不丢失流量
- 测试类型
  - 可靠性
- 前置条件
  1. 设备 GT-DEV-SIM-0402 关联 ICCID 89860400123456789402
  2. 服务端测试响应明确声明剩余流量 1537 MB，并携带本次响应适用的单位换算规则；该测试夹具仅用于验证换算等价，不代表最终来源单位契约或固定换算基数
- 测试步骤
  1. 查询 GT-DEV-SIM-0402 的物联卡信息。
  2. 记录页面剩余流量展示值和单位。
  3. 按本次响应声明的同一规则，将页面展示值逆向还原为 MB 并与 1537 MB 比较。
- 预期结果
  1. 页面成功取得剩余流量 1537 MB 对应数据。
  2. 页面可直接保留 1537 MB；如转换为 GB，不得因截断或舍入造成不可逆的可见流量偏差，且不固定展示小数位数。
  3. 展示值按同一规则逆向还原后与 1537 MB 数值等价，换算过程可逆且不丢失流量。

## [P1] 验证已用流量按服务端声明的统计口径展示
- 测试类型
  - 功能
- 前置条件
  1. 设备 GT-DEV-SIM-0403 关联 ICCID 89860400123456789403
  2. 服务端测试响应声明“当前周期已用流量”、数值 2048、单位 MB；该夹具不指定第三方来源字段，不代表 data_usage 或 cycle_data_usage 的最终产品契约
- 测试步骤
  1. 查询 GT-DEV-SIM-0403 的物联卡信息。
  2. 核对页面已用流量数值、单位和统计周期文案。
  3. 将展示值换算回 MB 并与服务端声明比较。
- 预期结果
  1. 页面按服务端提供的产品可见字段渲染，不由 APP 猜测第三方来源字段。
  2. 页面展示与“当前周期”一致的已用流量口径，不擅自改写为当月口径。
  3. 展示值换算回 MB 后等于 2048，且测试结果不据此宣称最终来源字段已确定。

## [P3][反向] 验证无真实套餐周期时不从 data_plan 推导周期
- 测试类型
  - 功能
- 前置条件
  1. 设备 GT-DEV-SIM-0404 关联 ICCID 89860400123456789404
  2. 服务端成功结果包含 data_plan=12 GB，但未提供真实套餐周期配置
- 测试步骤
  1. 查询 GT-DEV-SIM-0404 的物联卡信息。
  2. 查看流量套餐字段。
  3. 检查套餐字段是否出现月、年或其他周期后缀。
- 预期结果
  1. 页面成功展示已取得的套餐容量。
  2. 流量套餐展示 12 GB 或等价容量表达。
  3. 页面不得仅凭 data_plan 增加 /month、/year 或其他未确认周期。

## [P3][反向] 验证共享累计卡剩余流量为空时不伪造为零
- 测试类型
  - 功能
- 前置条件
  1. 设备 GT-DEV-SIM-0405 关联共享累计卡 ICCID 89860400123456789405
  2. 服务端成功结果包含套餐流量 50 GB、已用流量 7 GB，data_balance=null
- 测试步骤
  1. 查询 GT-DEV-SIM-0405 的物联卡信息。
  2. 核对套餐流量和已用流量。
  3. 核对剩余流量字段。
- 预期结果
  1. 页面按成功结果渲染，不因 data_balance 为空进入整页失败态。
  2. 套餐流量和已用流量分别展示 50 GB、7 GB 或数值等价表达。
  3. 剩余流量标签保留且显示“—”，不得伪造为 0，也不得由 APP 自行推算流量池数据。
