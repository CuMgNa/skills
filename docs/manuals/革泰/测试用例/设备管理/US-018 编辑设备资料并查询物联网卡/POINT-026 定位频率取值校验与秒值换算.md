# US-018 编辑设备资料并查询物联网卡
> 口径依据：唯一业务需求真源《革泰 APP 设备管理逻辑点梳理 plan.md》第 5.3、5.4、8、10 节。Location Interval 仅接受 1～1440 整数分钟，预设值与自定义值统一换算为 UPLOAD 秒参数；空、0、1441、小数和非整数均不得发出请求。

## [P1] 验证三个预设分钟值按固定模式正确换算
- 测试类型
  - 功能
- 前置条件
  1. 当前账号可编辑设备 GT-LOC-1101
  2. 设备 confirmedValue 为 600 秒，编辑页已正常加载
- 测试步骤
  1. 选择“1 分钟（耗电模式）”并点击整页 Save。
  2. 再次进入编辑页，选择“10 分钟（默认模式）”并点击整页 Save。
  3. 再次进入编辑页，选择“1 小时（省电模式）”并点击整页 Save。
- 预期结果
  1. 首次提交创建一条参数为 60 秒的 UPLOAD 任务。
  2. 第二次提交创建一条参数为 600 秒的 UPLOAD 任务。
  3. 第三次提交创建一条参数为 3600 秒的 UPLOAD 任务，不得按 60 秒发送。

## [P4] 验证自定义整数分钟的上点与内点均可提交
- 测试类型
  - 功能
- 前置条件
  1. 当前账号可编辑设备 GT-LOC-1102
  2. 设备当前无在途频率任务
- 测试步骤
  1. 输入自定义值 37 分钟，确认选择并点击整页 Save。
  2. 查询新建频率任务的参数和页面文案。
  3. 待首条请求返回后输入 1440 分钟，确认选择并点击整页 Save。
  4. 查询第二条频率任务的参数和页面文案。
- 预期结果
  1. 37 为有效整数，保存请求正常发出。
  2. 任务参数为 2220 秒，文案为“自定义模式（37 分钟）”。
  3. 1440 为有效上边界，保存请求正常发出。
  4. 任务参数为 86400 秒，文案为“自定义模式（1440 分钟）”。

## [P4][反向] 验证空值和范围离点不创建频率任务
- 测试类型
  - 功能
- 前置条件
  1. 当前账号可编辑设备 GT-LOC-1103
  2. 设备 confirmedValue 为 600 秒，当前无 desiredValue
  3. 可查询该设备的指令记录数量
- 测试步骤
  1. 清空自定义输入框并尝试确认后点击 Save。
  2. 输入 0 分钟并尝试确认后点击 Save。
  3. 输入 1441 分钟并尝试确认后点击 Save。
  4. 查询网络请求和该设备指令记录。
- 预期结果
  1. 空值校验不通过，不形成 localEditValue，不发出频率请求。
  2. 0 低于有效下限，页面明确阻止提交。
  3. 1441 高于有效上限，页面明确阻止提交。
  4. 三次操作均未新增 UPLOAD 记录，confirmedValue 仍为 600 秒。

## [P4][反向] 验证小数和非整数文本不创建频率任务
- 测试类型
  - 功能
- 前置条件
  1. 当前账号可编辑设备 GT-LOC-1104
  2. 设备 confirmedValue 为 3600 秒，当前无 desiredValue
  3. 可观察 Save 请求和指令记录
- 测试步骤
  1. 输入 1.5 分钟并尝试确认后点击 Save。
  2. 输入文本“十分钟”并尝试确认后点击 Save。
  3. 输入字符串“10min”并尝试确认后点击 Save。
  4. 退出并重新进入编辑页。
- 预期结果
  1. 1.5 不是整数，页面阻止提交且不换算为 90 秒。
  2. “十分钟”不是合法整数，页面阻止提交。
  3. “10min”不是合法整数，页面阻止提交，三次均不新增 UPLOAD 记录。
  4. 页面仍回显 confirmedValue 对应的“1 小时（省电模式）”，不保留非法输入。

## [P3][反向] 验证已有在途目标时本地非法输入不破坏当前有效目标
- 测试类型
  - 可靠性
- 前置条件
  1. 设备 GT-LOC-1105 的 confirmedValue 为 600 秒
  2. 最新有效 desiredValue 为 1800 秒，状态为 SENT 且尚未确认成功，编辑页显示自定义 30 分钟“设置中”
  3. 可观察本地表单、网络请求和服务端分层值
- 测试步骤
  1. 在编辑页输入自定义值 0 分钟并尝试确认。
  2. 输入 1.5 分钟并尝试确认。
  3. 输入 1441 分钟并点击整页 Save。
  4. 退出并重新进入编辑页，查询 desiredValue、confirmedValue 和指令记录。
- 预期结果
  1. 0 分钟被本地校验拒绝，不形成新的 localEditValue 或请求。
  2. 1.5 分钟被拒绝，不清除服务端现有 desiredValue。
  3. 1441 分钟被拒绝且不新增 FAILURE 或其他指令记录，因为请求未发出。
  4. 重进后仍显示原 1800 秒目标“设置中”，confirmedValue 保持 600 秒，非法本地输入不得使页面错误回退确认值。
