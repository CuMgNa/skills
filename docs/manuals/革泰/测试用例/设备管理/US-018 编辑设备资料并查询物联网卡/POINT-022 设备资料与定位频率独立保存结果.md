# US-018 编辑设备资料并查询物联网卡
> 口径依据：唯一业务需求真源《革泰 APP 设备管理逻辑点梳理 plan.md》第 5.3、5.6、5.9 节。设备资料与定位频率虽由一次整页 Save 触发，但结果独立且互不回滚；频率未形成意图、受理、校验失败或受理结果未知时均按各自口径处理。

## [P1] 验证只修改资料成功时不创建频率任务
- 测试类型
  - 功能
- 前置条件
  1. 设备 GT-LOC-1161 的备注为“牧场北区”、当前账户 groupId 为 group-1161-a
  2. confirmedValue 为 600 秒，用户未打开频率选择层
- 测试步骤
  1. 将备注改为“牧场北区一号”，分组改为 group-1161-b。
  2. 不选择定位频率，点击整页 Save。
  3. 查询资料、分组、频率任务和页面刷新结果。
- 预期结果
  1. 仅形成备注与分组资料变更。
  2. 资料保存成功并返回详情抽屉。
  3. 备注和当前账户分组更新，列表、抽屉及分组数量刷新；不创建 UPLOAD，confirmedValue 仍为 600 秒。

## [P1] 验证资料成功且频率受理时两个结果分别生效
- 测试类型
  - 功能
- 前置条件
  1. 设备 GT-LOC-1162 的备注为“西门设备”，groupId 为 group-1162-a
  2. confirmedValue 为 600 秒
- 测试步骤
  1. 将备注改为“西门设备二号”，分组改为 group-1162-b。
  2. 选择自定义 30 分钟并点击整页 Save。
  3. 查询资料结果、频率任务和再次进入编辑页的展示。
- 预期结果
  1. 整页请求包含明确的资料变更和 1800 秒频率意图。
  2. 资料保存成功；频率独立创建 SENDING 任务，二者不互相等待终端反馈。
  3. 列表和抽屉显示新备注及新分组，编辑页显示 30 分钟“设置中”，卡片继续显示确认值 10 分钟。

## [P3][反向] 验证资料失败但频率已受理时不回滚频率任务
- 测试类型
  - 可靠性
- 前置条件
  1. 设备 GT-LOC-1163 的原备注为“东侧设备”，groupId 为 group-1163-a
  2. 可模拟资料保存返回失败，同时频率服务成功受理 3600 秒
- 测试步骤
  1. 将备注改为“东侧设备新”、分组改为 group-1163-b，并选择 1 小时。
  2. 点击 Save，使资料结果失败、频率结果已受理。
  3. 查询资料、频率任务、页面提示和重进编辑页展示。
- 预期结果
  1. 两类变更均被独立处理，不使用同一事务强制共同回滚。
  2. 资料保持原备注“东侧设备”和 group-1163-a；频率任务进入 SENDING。
  3. 页面明确区分资料失败与频率已受理，重进后显示 1 小时“设置中”，不得重复创建频率任务。

## [P3][反向] 验证资料成功但频率校验失败时不回滚资料
- 测试类型
  - 可靠性
- 前置条件
  1. 设备 GT-LOC-1164 的原备注为“南区设备”，groupId 为 group-1164-a
  2. 当前设备型号不支持普通 UPLOAD，但账号可修改资料
- 测试步骤
  1. 将备注改为“南区设备三号”，分组改为 group-1164-b，并选择 60 分钟。
  2. 点击整页 Save。
  3. 查询资料结果、FAILURE 记录和页面状态。
- 预期结果
  1. 请求包含资料变更与 3600 秒频率意图。
  2. 资料保存成功；频率因型号校验失败形成 FAILURE，confirmedValue 不更新。
  3. 新备注和 group-1164-b 保持生效，不因频率失败回滚；页面独立提示频率未更新。

## [P3] 验证频率受理结果未知时不重复资料或任务副作用
- 测试类型
  - 可靠性
- 前置条件
  1. 设备 GT-LOC-1165 的原备注为“北区设备”
  2. 本次修改备注为“北区设备四号”，频率为 20 分钟，幂等键为 idem-loc-1165-01
  3. 可模拟资料成功、频率已受理但 Save 响应中断
- 测试步骤
  1. 点击整页 Save 并在服务端处理后中断响应。
  2. 客户端使用 idem-loc-1165-01 查询原受理结果。
  3. 查询设备资料、频率任务数和审计副作用。
- 预期结果
  1. 客户端将频率标记为受理结果未知，不自动发起新建任务请求。
  2. 查询返回原 1200 秒任务，复用原幂等键，不重复保存资料。
  3. 备注仅更新一次为“北区设备四号”，频率仅新增一条任务，不产生重复刷新计数或重复记录。
