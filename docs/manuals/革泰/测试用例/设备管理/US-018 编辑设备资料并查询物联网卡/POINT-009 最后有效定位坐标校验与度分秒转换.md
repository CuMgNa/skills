# US-018 编辑设备资料并查询物联网卡

> 口径依据：大纲第 5.2、5.9、8、10 章。经度、纬度和定位时间必须来自同一条完整有效记录并成组展示或隐藏；经度范围为 [-180,180]、纬度范围为 [-90,90]，十进制度转换为秒保留两位的度分秒并追加 E/W/N/S。

## [P1] 验证东西经与南北纬正确转换为度分秒
- 测试类型
  - 功能
- 前置条件
  1. DEV-COORD-001 最后有效定位记录 LOC-001 为经度 113.9950388889、纬度 39.916527、定位时间 2026-10-10 08:00:00
  2. DEV-COORD-002 最后有效定位记录 LOC-002 为经度 -73.985656、纬度 -33.8688、定位时间 2026-10-10 09:00:00
- 测试步骤
  1. 打开 DEV-COORD-001 详情抽屉并查看经纬度。
  2. 关闭后打开 DEV-COORD-002 详情抽屉并查看经纬度。
  3. 核对两条记录的方向字母、度分秒和秒精度。
- 预期结果
  1. DEV-COORD-001 显示经度 113°59'42.14"E、纬度 39°54'59.50"N。
  2. DEV-COORD-002 显示经度 73°59'8.36"W、纬度 33°52'7.68"S。
  3. 正经度使用 E、负经度使用 W、正纬度使用 N、负纬度使用 S，秒统一保留两位小数。

  - 功能
