# US-018 编辑设备资料并查询物联网卡

> 口径依据：唯一业务真源《革泰 APP 设备管理逻辑点梳理 plan.md》2.4.2～2.4.4，以及第 10 章第 1 条。ICCID 必须属于当前设备并按字符串原值展示；前导零、长数字和字母不得丢失、数值化或转为科学计数法，设备切换和异步返回不得串卡。

## [P1] 验证 ICCID 前导零完整保留
- 测试类型
  - 功能
- 前置条件
  1. 设备 GT-DEV-SIM-0301 当前关联 ICCID 字符串 00089860400123456789301
  2. 服务端成功结果原样返回该 ICCID
- 测试步骤
  1. 打开 GT-DEV-SIM-0301 的 IoT SIM Query 页面。
  2. 复制页面展示的 ICCID 并统计字符数。
  3. 将展示值与服务端原始字符串逐字符比较。
- 预期结果
  1. 页面查询身份为 GT-DEV-SIM-0301。
  2. 展示值为 00089860400123456789301，开头三个 0 均保留且字符数一致。
  3. 展示值与原始字符串完全相同，不发生整数转换。

## [P1] 验证超长纯数字 ICCID 不转为科学计数法
- 测试类型
  - 兼容性
- 前置条件
  1. 设备 GT-DEV-SIM-0302 当前关联 ICCID 字符串 898604001234567893020123456789
  2. 服务端成功结果原样返回该 30 位字符串
- 测试步骤
  1. 查询 GT-DEV-SIM-0302 的物联卡信息。
  2. 核对页面 ICCID 的完整文本和字符数。
  3. 返回设备列表后重新进入并再次核对。
- 预期结果
  1. 页面成功加载 GT-DEV-SIM-0302 的 SIM 数据。
  2. ICCID 完整展示为 898604001234567893020123456789，不截断、不舍入、不使用科学计数法。
  3. 再次进入后的展示值保持一致，不因缓存序列化丢位。

## [P1] 验证含字母 ICCID 按字符串原值展示
- 测试类型
  - 功能
- 前置条件
  1. 设备 GT-DEV-SIM-0303 当前关联 ICCID 字符串 89AB0400123456789303C
  2. 服务端成功结果原样返回该 ICCID
- 测试步骤
  1. 查询 GT-DEV-SIM-0303 的物联卡信息。
  2. 核对 ICCID 中字母、数字及其顺序。
  3. 点击刷新并再次核对 ICCID。
- 预期结果
  1. 查询成功且未因 ICCID 非纯数字拒绝渲染。
  2. 页面展示 89AB0400123456789303C，字母大小写和字符顺序与服务端一致。
  3. 刷新后仍完整展示同一字符串，不出现空值或数值化结果。

## [P3][反向] 验证异步返回乱序时不得把旧设备 ICCID 覆盖到新设备
- 测试类型
  - 可靠性
- 前置条件
  1. 设备 GT-DEV-SIM-0304 关联 ICCID 89860400123456789304，设备 GT-DEV-SIM-0305 关联 ICCID 89860400123456789305
  2. 可控制 GT-DEV-SIM-0304 查询延迟 3 秒、GT-DEV-SIM-0305 查询延迟 200 毫秒
- 测试步骤
  1. 发起 GT-DEV-SIM-0304 查询后立即返回列表。
  2. 进入 GT-DEV-SIM-0305 的 IoT SIM Query 页面并等待其结果先返回。
  3. 再等待 GT-DEV-SIM-0304 的延迟结果返回，核对当前页面。
- 预期结果
  1. 第一个请求绑定设备唯一标识 GT-DEV-SIM-0304。
  2. 当前页面展示 GT-DEV-SIM-0305 摘要和 ICCID 89860400123456789305。
  3. GT-DEV-SIM-0304 的旧响应不得覆盖当前页面，ICCID 始终属于 GT-DEV-SIM-0305。

## [P3][反向] 验证关联卡变更后刷新不保留旧 ICCID
- 测试类型
  - 可靠性
- 前置条件
  1. 设备 GT-DEV-SIM-0306 初始关联 ICCID 89860400123456789306，页面已成功展示该卡
  2. 服务端随后将设备当前关联卡切换为 ICCID 89860400123456789316
- 测试步骤
  1. 保持 GT-DEV-SIM-0306 页面打开并完成服务端关联卡切换。
  2. 点击刷新按钮重新查询。
  3. 核对刷新后的 ICCID 及其他 SIM 明细。
- 预期结果
  1. 页面在刷新前保留已有结果但不自行拼接卡号。
  2. 刷新按 GT-DEV-SIM-0306 的当前关联关系重新查询。
  3. 页面展示 ICCID 89860400123456789316 及新卡明细，不残留或混合旧卡 89860400123456789306 的受保护数据。
