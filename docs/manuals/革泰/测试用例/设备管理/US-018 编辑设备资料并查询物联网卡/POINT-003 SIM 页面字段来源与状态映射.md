# US-018 编辑设备资料并查询物联网卡

> 口径依据：唯一业务真源《革泰 APP 设备管理逻辑点梳理 plan.md》2.4.3、2.4.4，以及第 10 章第 10 条。页面固定控件、设备摘要、active、ICCID、运营商、account_status、流量和有效期分别按已定义来源展示，接口 code、激活标识和卡状态不得混用。

## [P1] 验证全量有值时页面字段按来源完整展示
- 测试类型
  - 功能
- 前置条件
  1. 设备 GT-DEV-SIM-0101 名称为“东区牛群定位器”，型号为 GT-CATTLE-X1
  2. 服务端产品字段测试响应包含 active=true、iccid=89860400123456789101、carrier=中国移动、account_status=00、流量套餐=20 GB、真实套餐周期=月、当前周期已用流量=3 GB、剩余流量=17 GB、expiry_date=2027-12-31；该测试响应不指定已用流量来自 data_usage 或 cycle_data_usage
- 测试步骤
  1. 打开 GT-DEV-SIM-0101 的 IoT SIM Query 页面并等待查询完成。
  2. 核对页面固定控件、设备摘要和激活标识。
  3. 核对 ICCID、运营商、卡状态、三项流量和有效期。
- 预期结果
  1. 页面标题、返回按钮和刷新按钮固定展示且可识别。
  2. 页面展示“东区牛群定位器”、GT-CATTLE-X1 和 Active，激活标识取自 active=true。
  3. 页面展示 ICCID 89860400123456789101、中国移动、正使用、20 GB/month、当前周期已用流量 3 GB、剩余流量 17 GB 和 2027-12-31，各字段与服务端产品字段测试响应及映射一致；不据此确定第三方来源字段。

## [P1] 验证 active 与 account_status 独立展示
- 测试类型
  - 功能
- 前置条件
  1. 设备 GT-DEV-SIM-0102 关联 ICCID 89860400123456789102
  2. 服务端成功结果包含 active=false、account_status=10
- 测试步骤
  1. 查询 GT-DEV-SIM-0102 的物联卡信息。
  2. 查看页面顶部激活标识。
  3. 查看 SIM 明细中的卡状态。
- 预期结果
  1. 查询成功并展示 GT-DEV-SIM-0102 对应数据。
  2. 顶部展示 Inactive，false 作为有效布尔值处理。
  3. 明细卡状态展示“测试期”，不使用 Inactive 替代 account_status 的映射结果。

## [P1] 验证已定义卡状态码逐项映射
- 测试类型
  - 功能
- 前置条件
  1. 设备 GT-DEV-SIM-0103 关联测试卡 ICCID 89860400123456789103
  2. 测试服务可依次返回 account_status=00、10、02、03、04、11、12、15
- 测试步骤
  1. 依次返回 account_status=00、10、02、03 并逐次刷新页面。
  2. 依次返回 account_status=04、11、12、15 并逐次刷新页面。
  3. 记录每次页面卡状态和原始状态码。
- 预期结果
  1. 页面依次展示“正使用”“测试期”“停机”“预销号”。
  2. 页面依次展示“销号”“沉默期”“停机保号”“库存期”。
  3. 每次仅按 account_status 映射卡状态，字符串 00 不因数值化而变为空值或未激活。

## [P3][反向] 验证未知卡状态码稳定降级为未知
- 测试类型
  - 兼容性
- 前置条件
  1. 设备 GT-DEV-SIM-0104 关联 ICCID 89860400123456789104
  2. 测试服务可分别返回 account_status=99 和 account_status=88
- 测试步骤
  1. 返回 account_status=99 并查询页面。
  2. 返回未定义新码 account_status=88 并刷新页面。
  3. 检查页面完整性和排查信息。
- 预期结果
  1. 卡状态展示“未知”，页面其他字段正常展示。
  2. 未定义新码同样展示“未知”，页面不空白、不崩溃。
  3. 页面或诊断信息可保留原始码用于排查，但不得虚构新的产品状态。

## [P3][反向] 验证接口 code 不被展示成卡状态
- 测试类型
  - 功能
- 前置条件
  1. 设备 GT-DEV-SIM-0105 的第三方查询可模拟 code=502 和 code=505
  2. 页面查询前未缓存 GT-DEV-SIM-0105 的成功卡状态
- 测试步骤
  1. 模拟第三方返回 code=502 并完成查询。
  2. 模拟第三方返回 code=505 并再次查询。
  3. 核对两次页面卡状态区域和查询异常区域。
- 预期结果
  1. 页面进入统一失败态并展示物联卡不存在或未启用类别的可读原因，卡状态明细显示“—”。
  2. 页面进入访问频率受限失败态并展示可读原因，卡状态明细显示“—”。
  3. 502、505 仅作为接口状态用于失败排查，不显示成卡状态或扩展出新的卡状态。
