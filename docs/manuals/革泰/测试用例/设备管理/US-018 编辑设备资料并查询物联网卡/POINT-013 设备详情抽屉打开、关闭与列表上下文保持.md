# US-018 编辑设备资料并查询物联网卡

> 口径依据：大纲第 5.1、5.3、5.9、10 章。详情是设备列表上方的半屏抽屉，唯一入口为设备卡片本体；More 不提供详情；在线、离线、未连接及告警叠加场景均可按设备唯一标识打开，告警不取代在线 / 离线底层通信差异；支持三种关闭方式并保留列表上下文。

## [P1] 验证在线、离线、未连接及告警叠加场景均可打开半屏详情抽屉
- 测试类型
  - 功能
- 前置条件
  1. 账号 ent_l1 的设备列表存在在线无告警设备 DEV-DTL-001、离线无告警设备 DEV-DTL-002、未连接无告警设备 DEV-DTL-003、在线叠加告警设备 DEV-DTL-004、离线叠加告警设备 DEV-DTL-005
  2. 五台设备均在当前账号可见范围内，卡号依次为 898600100000000001、898600100000000002、898600100000000003、898600100000000004、898600100000000005
- 测试步骤
  1. 点击 DEV-DTL-001 卡片本体并查看详情承载形式和设备标题。
  2. 关闭抽屉后，依次点击 DEV-DTL-002、DEV-DTL-003 卡片本体并查看详情。
  3. 依次点击 DEV-DTL-004、DEV-DTL-005 卡片本体，核对告警展示及底层在线 / 离线差异。
  4. 核对五次详情查询携带的设备身份。
- 预期结果
  1. 在当前设备列表上方打开半屏详情抽屉，不跳转旧独立详情页；标题对应 DEV-DTL-001。
  2. DEV-DTL-002 与底层尚未建立有效通信的 DEV-DTL-003 均能打开各自详情抽屉；两者 UI 状态标签都明确显示「离线」，DEV-DTL-003 不得出现第四种「未连接」标签。
  3. DEV-DTL-004 与 DEV-DTL-005 均展示告警叠加语义，同时分别保留在线、离线底层差异；告警不被当作独立通信状态。
  4. 五次查询分别携带 DEV-DTL-001、DEV-DTL-002、DEV-DTL-003、DEV-DTL-004、DEV-DTL-005 的设备唯一标识，不使用卡号、备注或列表位置作为身份。

## [P3][反向] 验证 More 菜单不提供详情且点击 More 不打开抽屉
- 测试类型
  - 功能
- 前置条件
  1. 设备 DEV-DTL-005 在线且显示在设备列表，当前详情抽屉已关闭
- 测试步骤
  1. 点击 DEV-DTL-005 卡片右上角 More 入口。
  2. 检查 More 菜单全部项目。
  3. 关闭 More 菜单并观察设备列表与详情抽屉状态。
- 预期结果
  1. 仅打开 DEV-DTL-005 的 More 操作面板，不先打开详情抽屉。
  2. 菜单中不存在 Device Information 或其他设备详情入口。
  3. 返回设备列表后详情抽屉仍为关闭状态；只有点击卡片本体才可打开详情。

## [P1] 验证三种关闭方式均保留设备列表上下文
- 测试类型
  - 易用性
- 前置条件
  1. 账号 ent_l2 已选择状态「离线」、分组「牧场西区」、关键词「牦牛」，列表停留在第 18 台设备 DEV-DTL-018
  2. DEV-DTL-018 详情抽屉已打开，打开前列表数据与滚动位置已记录
- 测试步骤
  1. 点击标题区右侧下箭头关闭抽屉并核对列表上下文。
  2. 再次打开 DEV-DTL-018，点击抽屉外空白区域关闭并核对列表上下文。
  3. 再次打开 DEV-DTL-018，点击系统返回虚拟键关闭并核对列表上下文。
  4. 对比三次关闭前后的筛选、分组、关键词、列表数据和滚动位置。
- 预期结果
  1. 抽屉关闭，状态仍为「离线」、分组仍为「牧场西区」、关键词仍为「牦牛」，列表停留在 DEV-DTL-018 附近。
  2. 抽屉关闭且列表上下文保持不变，不跳到列表顶部。
  3. 系统返回虚拟键优先关闭抽屉，不退出设备列表；列表上下文保持不变。
  4. 三种关闭方式结果一致，均不清空筛选、不重置列表数据、不改变滚动位置。

## [P3][反向] 验证同备注设备及列表排序变化不导致详情串设备
- 测试类型
  - 可靠性
- 前置条件
  1. DEV-DTL-021 与 DEV-DTL-022 的备注均为「一号牛」，卡号分别为 898600100000000021、898600100000000022
  2. DEV-DTL-021 电量为 35%，DEV-DTL-022 电量为 76%，两台设备均在当前账号可见范围内
- 测试步骤
  1. 点击 DEV-DTL-021 卡片本体并核对抽屉标题和电量。
  2. 关闭抽屉，将列表排序调整为 DEV-DTL-022 位于 DEV-DTL-021 之前。
  3. 点击排序后的 DEV-DTL-022 卡片本体并核对抽屉标题和电量。
  4. 查询两次详情请求的设备唯一标识。
- 预期结果
  1. 抽屉展示「一号牛（898600100000000021）」和 35%，数据属于 DEV-DTL-021。
  2. 排序变化不改变两台设备的唯一身份和详情映射。
  3. 抽屉展示「一号牛（898600100000000022）」和 76%，不残留 DEV-DTL-021 的字段。
  4. 两次请求分别使用 DEV-DTL-021、DEV-DTL-022，不按相同备注或列表索引查询。
