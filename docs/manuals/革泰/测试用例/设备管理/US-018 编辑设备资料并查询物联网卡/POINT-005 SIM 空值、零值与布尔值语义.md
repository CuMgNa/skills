# US-018 编辑设备资料并查询物联网卡

> 口径依据：唯一业务真源《革泰 APP 设备管理逻辑点梳理 plan.md》2.4.2～2.4.4。单字段为 null、空字符串或缺失时保留标签并显示“—”；false 和数值 0 是有效值，不得按空值处理；其他已取得字段继续正常展示。

## [P3][反向] 验证 null 字段显示占位且不污染其他字段
- 测试类型
  - 功能
- 前置条件
  1. 设备 GT-DEV-SIM-0201 关联 ICCID 89860400123456789201
  2. 服务端成功结果为 active=true、carrier=null、account_status=00、data_balance=512 MB、expiry_date=2027-06-30
- 测试步骤
  1. 查询 GT-DEV-SIM-0201 的物联卡信息。
  2. 核对运营商字段。
  3. 核对激活标识、卡状态、剩余流量和有效期。
- 预期结果
  1. code=200 的成功结果正常渲染，不因单字段为空进入整页失败态。
  2. 运营商标签保留，值显示“—”。
  3. 页面仍展示 Active、正使用、512 MB 和 2027-06-30，不用 carrier 的空值覆盖其他字段。

## [P3][反向] 验证空字符串和缺失字段统一显示占位
- 测试类型
  - 兼容性
- 前置条件
  1. 设备 GT-DEV-SIM-0202 关联 ICCID 89860400123456789202
  2. 服务端成功结果包含 carrier=""、active=true、account_status=10，且不返回 expiry_date 字段
- 测试步骤
  1. 查询 GT-DEV-SIM-0202 的物联卡信息。
  2. 核对运营商和有效期字段。
  3. 核对激活标识与卡状态。
- 预期结果
  1. 页面完成成功态渲染，不因空字符串或字段缺失崩溃。
  2. 运营商和有效期标签均保留，值均显示“—”。
  3. Active 和“测试期”正常展示，不受两个空字段影响。

## [P1] 验证流量 0 和 0.000 均作为有效零值展示
- 测试类型
  - 功能
- 前置条件
  1. 设备 GT-DEV-SIM-0204 关联 ICCID 89860400123456789204
  2. 服务端测试响应明确声明已用流量数值分别为 0 MB 和 0.000 MB；该测试夹具仅验证零值语义，不代表最终来源单位契约
- 测试步骤
  1. 返回已用流量 0 MB 并查询页面。
  2. 返回已用流量 0.000 MB 并刷新页面。
  3. 核对两次已用流量字段与空值占位。
- 预期结果
  1. 已用流量展示 0 及对应单位，不显示“—”。
  2. 已用流量仍按有效零值展示 0 及对应单位，不显示“—”。
  3. 两次结果均不把数值零归类为 null、空字符串或字段缺失。

## [P3][反向] 验证 SIM 各产品字段逐项为空时仅当前字段显示占位
- 测试类型
  - 兼容性
- 前置条件
  1. 准备七组 code=200 的成功响应，依次将设备名称、设备型号、active、iccid、account_status、data_plan、已用流量字段设置为 null、空字符串或缺失
  2. 每组响应的其他字段均使用固定有效值：设备名「空值矩阵设备」、型号 GT-CATTLE-4G、active=true、ICCID 89860400123456789205、account_status=00、data_plan=1024 MB、已用流量 128 MB
  3. 每次查询均绑定到 deviceId=GT-DEV-SIM-0205，响应组编号从 EMPTY-01 至 EMPTY-07
- 测试步骤
  1. 依次使用 EMPTY-01、EMPTY-02 查询，核对设备名称和型号为空时的页面。
  2. 依次使用 EMPTY-03、EMPTY-04 查询，核对 active 和 ICCID 为空时的页面。
  3. 依次使用 EMPTY-05、EMPTY-06 查询，核对卡状态和流量套餐为空时的页面。
  4. 使用 EMPTY-07 查询，核对已用流量为空时的页面及其他字段。
- 预期结果
  1. 设备名称或型号为空时仅对应值显示“—”，另一摘要字段及 SIM 明细正常展示。
  2. active 为空时激活标识显示“—”；ICCID 为空时 ICCID 标签保留且值显示“—”，不得沿用上一响应值。
  3. account_status 为空时卡状态显示“—”而不是“未知”；data_plan 为空时套餐显示“—”，其他字段正常。
  4. 已用流量为空时显示“—”而不是 0；每组都只影响当前空字段，不进入整页失败态或混入上一组缓存。
