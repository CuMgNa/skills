# US-018 编辑设备资料并查询物联网卡

> 口径依据：大纲第 5.2、5.3、5.9、8、10 章。切换 APP 时区时只转换同一定位记录的定位时间，不改变经纬度；设备恢复通信但没有新有效定位时继续展示上一条有效位置及其原定位时间，禁止用通信时间冒充定位时间。

## [P4] 验证切换时区仅转换定位时间并正确处理跨日
- 测试类型
  - 功能
- 前置条件
  1. DEV-TIME-001 最后有效定位记录 LOC-TIME-001 的 UTC 时间为 2026-10-10 00:30:00，经度为 151.2093，纬度为 -33.8688
  2. APP 当前时区为 UTC+08:00
- 测试步骤
  1. 打开 DEV-TIME-001 详情抽屉并记录定位时间和经纬度。
  2. 将 APP 时区切换为 UTC-05:00 后重新打开 DEV-TIME-001 详情抽屉。
  3. 对比切换前后的定位记录身份、经纬度和定位时间。
- 预期结果
  1. UTC+08:00 下定位时间显示 2026-10-10 08:30:00，经纬度来自 LOC-TIME-001。
  2. UTC-05:00 下定位时间显示 2026-10-09 19:30:00，正确回退到前一自然日。
  3. 两次均引用 LOC-TIME-001，经纬度及 E/W/N/S 方向不变，只有定位时间按 APP 时区转换。

## [P1] 验证恢复通信但无新位置时继续展示旧有效位置和旧定位时间
- 测试类型
  - 可靠性
- 前置条件
  1. DEV-TIME-002 离线前最后有效定位 LOC-TIME-002 为经度 116.397128、纬度 39.916527、定位时间 2026-10-10 08:00:00
  2. DEV-TIME-002 于 2026-10-10 09:15:00 恢复在线通信，但恢复后尚无新有效定位上报
- 测试步骤
  1. 在设备离线时打开 DEV-TIME-002 详情抽屉并记录定位三项。
  2. 使设备于 2026-10-10 09:15:00 恢复通信但不发送位置，再等待列表既有刷新周期更新详情。
  3. 核对恢复通信后的状态、经纬度、定位时间和定位记录身份。
- 预期结果
  1. 离线时展示 LOC-TIME-002 的经纬度和定位时间 2026-10-10 08:00:00。
  2. 设备状态可按最新通信事实更新为在线，但定位三项仍引用 LOC-TIME-002。
  3. 经纬度保持不变，定位时间仍为 2026-10-10 08:00:00，不显示通信恢复时间 2026-10-10 09:15:00。

## [P3][反向] 验证新上报位置非法时不得覆盖上一条有效定位
- 测试类型
  - 可靠性
- 前置条件
  1. DEV-TIME-003 已有有效记录 LOC-TIME-030：经度 113.9950388889、纬度 39.916527、定位时间 2026-10-10 10:00:00
  2. DEV-TIME-003 随后上报 LOC-TIME-031：经度 181、纬度 39.9166、定位时间 2026-10-10 10:05:00
- 测试步骤
  1. 打开 DEV-TIME-003 详情抽屉并等待最新详情响应。
  2. 查看经度、纬度和定位时间。
  3. 查询详情采用的最后有效定位记录标识。
- 预期结果
  1. LOC-TIME-031 因经度 181 越界，不能成为最后有效定位。
  2. 抽屉继续成组展示 LOC-TIME-030 的坐标和定位时间 2026-10-10 10:00:00，不混入 LOC-TIME-031 的时间。
  3. 详情引用 LOC-TIME-030，不以较新的非法记录覆盖旧有效记录。

## [P3][反向] 验证通信时间变化不触发定位时间单独刷新
- 测试类型
  - 功能
- 前置条件
  1. DEV-TIME-004 最后有效定位时间为 2026-10-10 12:00:00
  2. DEV-TIME-004 在 2026-10-10 12:03:00、12:06:00 连续上报心跳，均不包含有效经纬度
- 测试步骤
  1. 打开 DEV-TIME-004 详情抽屉并记录定位三项。
  2. 接收 12:03:00 心跳后等待列表刷新周期。
  3. 接收 12:06:00 心跳后再次等待列表刷新周期。
  4. 比对三次定位时间和经纬度。
- 预期结果
  1. 初次显示最后有效位置及定位时间 2026-10-10 12:00:00。
  2. 心跳可更新通信相关状态，但定位时间不变为 12:03:00。
  3. 第二次心跳后定位时间仍不变为 12:06:00。
  4. 三次定位三项保持同一有效记录，不出现只有时间变化、坐标未变化的伪新位置。
