# US-020 选择参数并向单设备发送指令
> 口径依据：唯一业务真源《革泰 APP 设备管理逻辑点梳理 plan》第 2.2～2.4、6.2、10 节。当前账号所有可见设备均可从 More 菜单进入对应单设备下发页，导航以设备唯一标识为准；本文件只验证入口、目标页和返回链路，不展开具体指令参数与执行闭环。

## [P1] 验证在线设备从 More 菜单进入对应单设备下发页
- 测试类型
  - 功能
- 前置条件
  1. 个人账号 GT-P-1221 可见在线设备 GT-D-122101，设备卡号为 898604781201000001
  2. GT-D-122101 卡片右上角显示 More 入口
- 测试步骤
  1. 打开 GT-D-122101 的 More 菜单。
  2. 点击 Send Command。
  3. 检查打开页面的设备唯一标识和页面类型。
- 预期结果
  1. More 菜单正常打开并显示 Send Command。
  2. More 菜单关闭且只执行一次页面跳转。
  3. 进入 GT-D-122101 对应的单设备下发页，页面身份参数为 GT-D-122101，不进入批量下发页或其他设备页面。

## [P1] 验证离线未连接和告警设备均可进入同一类型下发页
- 测试类型
  - 功能
- 前置条件
  1. 企业一级账号 GT-E1-1221 可见离线设备 GT-D-122111、初始化未连接设备 GT-D-122112、告警加在线设备 GT-D-122113、告警加离线设备 GT-D-122114
- 测试步骤
  1. 从 GT-D-122111 的 More 菜单点击 Send Command并记录目标页。
  2. 返回列表后，从 GT-D-122112 的 More 菜单点击 Send Command并记录目标页。
  3. 返回列表后，依次从 GT-D-122113、GT-D-122114 的 More 菜单点击 Send Command并记录目标页。
  4. 比对四次导航的页面类型和设备唯一标识。
- 预期结果
  1. GT-D-122111 可进入其单设备下发页，不因离线状态隐藏或禁用入口。
  2. GT-D-122112 可进入其单设备下发页，不因初始化未连接状态隐藏或禁用入口。
  3. GT-D-122113、GT-D-122114 均可进入各自单设备下发页，告警叠加状态不改变导航目标。
  4. 四次均进入同一类型的单设备下发页，但页面设备唯一标识分别与被点击设备一致；本导航不预判具体指令能否提交。

## [P3][反向] 验证同名设备和备注变化不导致发送指令串设备
- 测试类型
  - 可靠性
- 前置条件
  1. 企业二级账号 GT-E2-1221 可见设备 GT-D-122121 和 GT-D-122122，两台设备备注均为“北区定位器”
  2. GT-D-122121 卡号为 898604781221000001，GT-D-122122 卡号为 898604781221000002
- 测试步骤
  1. 从 GT-D-122121 的 More 菜单点击 Send Command并记录目标页设备标识。
  2. 返回列表，将 GT-D-122121 备注修改为“北区定位器-A”并保存。
  3. 再次从 GT-D-122121 的 More 菜单点击 Send Command并记录目标页设备标识。
  4. 返回列表，从仍名为“北区定位器”的 GT-D-122122 进入 Send Command。
- 预期结果
  1. 首次目标页绑定设备唯一标识 GT-D-122121，不因两台设备同名串到 GT-D-122122。
  2. 备注保存后列表显示“北区定位器-A”，设备唯一标识不变。
  3. 再次进入的目标页仍绑定 GT-D-122121，不使用旧备注或列表位置作为身份。
  4. 最后一次目标页绑定 GT-D-122122，页面未残留 GT-D-122121 的设备上下文。

## [P2] 验证从单设备下发页返回后恢复原设备列表上下文
- 测试类型
  - 易用性
- 前置条件
  1. 企业三级账号 GT-E3-1221 的设备列表当前选择告警状态、分组“北区牧场”、关键词“122131”
  2. 当前筛选结果包含设备 GT-D-122131，列表已滚动至该设备卡片
- 测试步骤
  1. 从 GT-D-122131 的 More 菜单点击 Send Command进入单设备下发页。
  2. 在下发页点击系统返回或页面返回按钮。
  3. 检查返回后的状态筛选、分组、关键词和滚动位置。
  4. 检查 GT-D-122131 的归属、分组、基础通信状态和告警状态。
- 预期结果
  1. 进入设备唯一标识为 GT-D-122131 的单设备下发页。
  2. 返回设备列表而非其他设备详情页或批量下发页。
  3. 告警状态、“北区牧场”、关键词“122131”和原滚动位置均保留。
  4. 单纯进入并返回下发页未改变 GT-D-122131 的设备归属、分组、基础通信状态或告警状态。
