# US-015 筛选设备并打开快捷操作
> 口径依据：设备管理逻辑大纲第 2.1～2.2、3.1.6、3.3～3.4、4.7～4.9、5.8、9～10 节。设备总数和状态数量按当前账户可见设备唯一标识去重，在线数加离线数等于总数，告警为叠加分类；绑定、解绑、分配和改组成功后刷新受影响账户与分组数量。

## [P1] 验证绑定离线未连接设备后总数、状态数量和直属分组数量同步增加
- 测试类型
  - 功能
- 前置条件
  1. 个人账号 GT-P-13101 当前可见 4 台设备，全部 4、在线 2、离线 2、告警 1
  2. 真实一级分组“东区牧场”直属设备数为 2
  3. GT-D-13105 已入库且从未有效上报，满足个人绑定条件
- 测试步骤
  1. 在 APP 将 GT-D-13105 绑定到 GT-P-13101，并选择“东区牧场”。
  2. 返回设备列表并刷新全部、在线、离线、告警数量。
  3. 打开分组选择器，核对“全部分组”和“东区牧场”的数量。
  4. 在监控平台 Web 刷新同一账号的设备与状态统计。
- 预期结果
  1. 绑定成功，GT-D-13105 只新增 1 条可见设备记录并归属“东区牧场”。
  2. APP 显示全部 5、在线 2、离线 3、告警 1，在线数加离线数等于 5，未连接设备归入离线。
  3. “全部分组”显示 5，“东区牧场”直属设备数显示 3，不出现“未分组”数量。
  4. Web 同步显示总数 5 及相同状态归属，不因跨端读取重复计数。

## [P1] 验证逐级分配后目标账号总数、状态数量和承接分组数量刷新
- 测试类型
  - 功能
- 前置条件
  1. 企业一级 GT-E1-13101 已可见在线告警设备 GT-D-13106
  2. 直属二级 GT-E2-13101 当前全部 2、在线 1、离线 1、告警 0，真实一级分组“我的分组”直属设备数为 1
  3. 直属三级 GT-E3-13101 当前全部 0、在线 0、离线 0、告警 0
- 测试步骤
  1. GT-E1-13101 在 Web 以“仅分配设备”方式将 GT-D-13106 分配给 GT-E2-13101。
  2. 刷新二级账号 APP 的列表、状态数量和分组选择器。
  3. GT-E2-13101 在 Web 将 GT-D-13106 分配给 GT-E3-13101。
  4. 刷新三级账号 APP，并再次核对一级、二级账号的设备数量。
- 预期结果
  1. 二级获得分配关系，一级仍可见，设备不占二级直接绑定名额。
  2. 二级显示全部 3、在线 2、离线 1、告警 1；GT-D-13106 进入“我的分组”，该组直属设备数由 1 变为 2。
  3. 三级获得分配关系，二级和一级继续可见，未产生三级直接绑定关系。
  4. 三级显示全部 1、在线 1、离线 0、告警 1；一级、二级总数不因向下分配减少或重复增加。

## [P1] 验证二级移除自己的设备后本分支数量级联刷新且一级数量不变
- 测试类型
  - 功能
- 前置条件
  1. GT-E1-13101 当前全部 5、在线 3、离线 2、告警 1
  2. GT-E2-13101 当前全部 3、在线 2、离线 1、告警 1，其中离线无告警设备 GT-D-13107 已继续分配给 GT-E3-13101
  3. GT-E3-13101 当前全部 1、在线 0、离线 1、告警 0，GT-D-13107 在二级分组“北区”和三级分组“牛舍”中各直属计数 1
- 测试步骤
  1. GT-E2-13101 在 APP 对 GT-D-13107 执行 Unbind Device。
  2. 刷新 GT-E2-13101 的设备列表、状态数量和“北区”分组数量。
  3. 刷新 GT-E3-13101 的设备列表、状态数量和“牛舍”分组数量。
  4. 刷新 GT-E1-13101 的设备列表和状态数量。
- 预期结果
  1. 本次动作删除二级分配关系，并级联删除该二级下 GT-E3-13101 的分配关系，不删除一级直接绑定。
  2. 二级显示全部 2、在线 2、离线 0、告警 1，“北区”直属设备数由 1 变为 0。
  3. 三级显示全部 0、在线 0、离线 0、告警 0，“牛舍”直属设备数由 1 变为 0。
  4. 一级仍显示全部 5、在线 3、离线 2、告警 1，其他二级分支数量不受影响。

## [P1] 验证设备改组后账户总数不变且来源组和目标组数量分别刷新
- 测试类型
  - 功能
- 前置条件
  1. 企业一级 GT-E1-13102 当前全部 6、在线 4、离线 2、告警 2
  2. 在线告警设备 GT-D-13108 当前直属归属一级分组“一区”，该组全部 3、在线 2、离线 1、告警 1
  3. 目标二级分组“二区-牛舍”当前全部 2、在线 1、离线 1、告警 0
- 测试步骤
  1. 在 GT-D-13108 独立编辑页将所属分组从“一区”改为“二区-牛舍”并整页保存。
  2. 刷新虚拟“全部分组”下的设备总数与状态数量。
  3. 选择“一区”并核对直属设备数及状态数量。
  4. 选择“二区-牛舍”并核对直属设备数及状态数量。
- 预期结果
  1. 改组成功，仅更新 GT-E1-13102 账户下的 groupId，设备仍只有一条可见记录。
  2. 账户总量保持全部 6、在线 4、离线 2、告警 2。
  3. “一区”直属设备数变为 2，状态数量变为全部 2、在线 1、离线 1、告警 0。
  4. “二区-牛舍”直属设备数变为 3，状态数量变为全部 3、在线 2、离线 1、告警 1，父组不额外聚合该设备。

## [P2] 验证重复绑定和重复分配请求不重复增加任何数量
- 测试类型
  - 可靠性
- 前置条件
  1. GT-P-13102 已绑定在线设备 GT-D-13109，当前全部 1、在线 1、离线 0、告警 0
  2. GT-D-13109 在“个人牧场”直属设备数为 1
  3. GT-E2-13102 已通过分配可见 GT-D-13110，当前全部 1，承接分组直属设备数为 1
- 测试步骤
  1. GT-P-13102 连续两次提交 GT-D-13109 的绑定请求并刷新 APP、Web。
  2. 查询个人绑定关系数、设备总数、状态数量和“个人牧场”数量。
  3. 企业一级对 GT-E2-13102 连续两次提交 GT-D-13110 的同一分配请求。
  4. 查询二级分配关系数、设备总数、状态数量和承接分组数量。
- 预期结果
  1. 两次个人重复绑定均不新增关系，页面提示已绑定或返回等价幂等结果。
  2. 个人绑定关系仍为 1 条，全部 1、在线 1、离线 0、告警 0，“个人牧场”数量仍为 1。
  3. 重复分配不新增第二条有效分配关系，不消耗额外分配配额。
  4. 二级设备与分组数量均保持 1，状态数量不重复累计。
