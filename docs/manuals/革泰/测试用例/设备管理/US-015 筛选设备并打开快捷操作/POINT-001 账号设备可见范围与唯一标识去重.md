# US-015 筛选设备并打开快捷操作

> 口径依据：设备管理大纲第 1.3～1.4、3.1.6、3.4、9 节及第 10 节关键规则。账号按直接绑定或直属父级逐级分配加载设备范围；同一账号通过多条可见关系访问同一设备时按设备唯一标识只计一台，不以设备名称代替唯一标识。

## [P1] 验证四类账号按各自关系来源加载设备范围
- 测试类型
  - 功能
- 前置条件
  1. 个人账号 GT-P-1301直接绑定 GT-DEV-013001，卡号 898604121000013001，备注“个人红马”，通信状态为在线，设备数量为 1
  2. 企业一级 GT-E1-1301直接绑定 GT-DEV-013002，卡号 898604121000013002，备注“企业青牛”，通信状态为离线，设备数量为 1
  3. GT-E1-1301已将 GT-DEV-013002分配给直属二级 GT-E2-2301，GT-E2-2301已继续分配给直属三级 GT-E3-3301
- 测试步骤
  1. 分别使用 GT-P-1301、GT-E1-1301、GT-E2-2301、GT-E3-3301查询 APP 设备列表。
  2. 使用四个账号查询监控平台 Web 设备列表并核对 deviceId、卡号、备注和通信状态。
  3. 查询四个账号的设备关系类型和可见设备数量。
- 预期结果
  1. GT-P-1301仅显示 GT-DEV-013001；企业三级链路三个账号均显示 GT-DEV-013002，列表数量各为 1。
  2. APP 与 Web 对每个账号返回一致的设备范围；GT-DEV-013001显示备注“个人红马”、在线，GT-DEV-013002显示备注“企业青牛”、离线。
  3. GT-P-1301和 GT-E1-1301为直接绑定关系，GT-E2-2301和 GT-E3-3301为逐级分配关系，未创建 APP 独立授权副本。

## [P1] 验证同一账号通过多条可见关系访问同一设备仅计一台
- 测试类型
  - 可靠性
- 前置条件
  1. 企业二级 GT-E2-2302 状态为正常，服务端测试数据中存在关系记录 REL-013003-A、REL-013003-B，两条当前有效可见关系均指向同一 deviceId GT-DEV-013003
  2. GT-DEV-013003卡号为 898604121000013003，备注为“多关系白马”，通信状态为在线
  3. GT-E2-2302除该设备外无其他可见设备；本用例只验证多关系下的设备去重结果，不约束两条关系的底层来源类型或存储实现
- 测试步骤
  1. 使用 GT-E2-2302刷新 APP 设备列表、全部设备分组和地图可见设备。
  2. 查询设备总数、在线数量、离线数量和相关分组设备数量。
  3. 查询监控平台 Web 列表、设备总数及在线数量。
- 预期结果
  1. APP 列表、全部设备分组和地图均只显示 1 台 deviceId GT-DEV-013003，不出现重复卡片或重复点位。
  2. 设备总数为 1、在线数量为 1、离线数量为 0；各统计不按关系条数重复累加。
  3. Web 同样只显示 1 台设备，设备总数和在线数量均为 1；无论可见关系如何存储，展示和计数均按 deviceId GT-DEV-013003去重。

## [P1] 验证同名设备以不同 deviceId 分别展示和计数
- 测试类型
  - 功能
- 前置条件
  1. 个人账号 GT-P-1302已直接绑定 deviceId GT-DEV-013004，卡号 898604121000013004，备注“东区定位器”，通信状态为在线
  2. GT-P-1302已直接绑定另一台 deviceId GT-DEV-013005，卡号 898604121000013005，备注同为“东区定位器”，通信状态为离线
  3. GT-P-1302当前可见设备数量为 2
- 测试步骤
  1. 使用 GT-P-1302在 APP 搜索备注“东区定位器”。
  2. 核对搜索结果中的 deviceId、卡号、通信状态和设备总数。
  3. 在监控平台 Web 使用相同备注搜索并核对结果数量。
- 预期结果
  1. 搜索结果同时返回 GT-DEV-013004和 GT-DEV-013005，共 2 台设备。
  2. 两条结果分别保留卡号 898604121000013004和 898604121000013005；在线数量为 1、离线数量为 1，不因备注相同错误合并。
  3. Web 同样返回 2 台设备，去重键使用 deviceId而不是备注“东区定位器”。

## [P3][反向] 验证未建立关系的账号不能因卡号或备注命中获得可见性
- 测试类型
  - 安全性
- 前置条件
  1. 企业链 A 的 GT-E1-1303直接绑定 deviceId GT-DEV-013006，卡号 898604121000013006，备注“链A黑牛”，通信状态为在线，并已分配给直属 GT-E2-2303
  2. 企业链 B 的二级账号 GT-E2-2399状态为正常，当前可见设备数量为 0，与 GT-E1-1303无直属关系
- 测试步骤
  1. 使用 GT-E2-2399在 APP 按完整卡号 898604121000013006搜索。
  2. 使用 GT-E2-2399按备注“链A黑牛”搜索，并尝试通过 deviceId GT-DEV-013006打开设备详情。
  3. 查询 GT-E2-2399的设备列表数量、统计数量和设备关系记录。
- 预期结果
  1. 卡号搜索结果数量为 0，不返回 GT-DEV-013006。
  2. 备注搜索和 deviceId直访均不能获得设备详情，不返回位置、电量、通信状态等设备事实。
  3. GT-E2-2399设备列表数量和统计数量保持为 0，不新增直接绑定、分配或 APP 独立授权关系。
