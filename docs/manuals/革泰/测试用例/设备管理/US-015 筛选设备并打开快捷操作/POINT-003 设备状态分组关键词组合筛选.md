# US-015 筛选设备并打开快捷操作

> 口径依据：设备管理大纲第 2.2 节、第 4.8 节。状态、分组、设备关键词三个条件取交集；切换任一条件不清空其他有效条件，清空关键词恢复当前状态与分组范围；选择父组时只包含直接归属设备，不聚合后代分组设备。

## [P1] 验证状态分组关键词三条件按交集筛选
- 测试类型
  - 功能
- 前置条件
  1. 账号 corp_l2_04 的“东区组”直接归属 deviceId=dev-4001、卡号 8600040001、备注“Rescue Alpha 一号”、在线无告警；deviceId=dev-4002、卡号 8600040002、备注“Rescue Beta 一号”、在线无告警；deviceId=dev-4003、卡号 8600040003、备注“Rescue Alpha 二号”、离线无告警；deviceId=dev-4004、卡号 8600040004、备注“Rescue Alpha 三号”、告警且在线
  2. “西区组”直接归属 deviceId=dev-4005、卡号 8600040005、备注“Rescue Alpha 四号”、在线无告警
  3. 当前选择虚拟“全部分组”、“全部”状态且关键词为空，可见设备共 5 台
- 测试步骤
  1. 选择状态“在线”。
  2. 选择分组“东区组”。
  3. 输入关键词“rescue alpha”执行搜索。
  4. 核对最终列表的 deviceId、状态和数量。
- 预期结果
  1. 列表保留在线基础状态设备 dev-4001、dev-4002、dev-4004、dev-4005。
  2. 列表缩小为直接归属东区组且在线的 dev-4001、dev-4002、dev-4004。
  3. 三个条件按交集生效，列表保留 dev-4001、dev-4004。
  4. 最终展示 2 台设备；dev-4003 因离线排除，dev-4005 因属于西区组排除。

## [P1] 验证修改状态条件不清空已有分组和关键词
- 测试类型
  - 功能
- 前置条件
  1. 账号 corp_l2_04 已选择状态“在线”、分组“东区组”、关键词“rescue alpha”
  2. 当前结果为 dev-4001、dev-4004，其中 dev-4004 为告警且在线，卡号 8600040004、备注“Rescue Alpha 三号”
- 测试步骤
  1. 将状态从“在线”切换为“告警”。
  2. 查看分组选择值和搜索框关键词。
  3. 核对列表 deviceId 与数量。

  3. 列表仅展示 dev-4004 共 1 台，不展示无告警的 dev-4001。
