# US-015 筛选设备并打开快捷操作

> 口径依据：设备管理大纲第 2.4、2.4.1 节。More 菜单仅保留实时追踪、历史轨迹、物联网卡查询、发送指令和解绑设备；设备详情和设备告警记录已移除。在线、离线、未连接和告警设备均保留入口，菜单项点击后关闭面板并只执行一次目标动作。

## [P1] 验证 More 菜单仅展示五个已保留操作项
- 测试类型
  - 功能
- 前置条件
  1. 账号 personal_more_01 可见 deviceId=gt-device-0081，卡号 GT2026100081，备注「巡检牛81」，状态为在线
  2. 当前设备卡片未打开详情抽屉
- 测试步骤
  1. 点击 gt-device-0081 卡片右上角竖向三点。
  2. 记录 More 操作面板中的全部菜单项和数量。
  3. 将菜单项与本期保留清单比对。
- 预期结果
  1. 打开 gt-device-0081 的 More 操作面板。
  2. 面板共展示 5 个设备操作项。
  3. 五项分别为实时追踪、历史轨迹、物联网卡查询、发送指令、解绑设备，不出现额外设备业务入口。

## [P1] 验证在线离线未连接和告警设备的保留菜单项均可执行导航
- 测试类型
  - 功能
- 前置条件
  1. 企业一级账号 corp_more_l1 可见 gt-device-0082 在线、gt-device-0083 离线、gt-device-0084 初始化未连接、gt-device-0085 告警且离线
  2. 四台设备卡号依次为 GT2026100082、GT2026100083、GT2026100084、GT2026100085，gt-device-0083 已有 2026-10-11 的历史轨迹
- 测试步骤
  1. 打开 gt-device-0082 的 More 菜单并点击「实时追踪」，核对目标设备后返回。
  2. 打开 gt-device-0083 的 More 菜单并点击「历史轨迹」，查询 2026-10-11 的已有轨迹后返回。
  3. 打开 gt-device-0084 的 More 菜单并点击「发送指令」，核对目标设备后返回。
  4. 打开 gt-device-0085 的 More 菜单并点击「物联网卡查询」，核对目标设备摘要。
- 预期结果

  2. 离线设备的「历史轨迹」可点击，进入 deviceId=gt-device-0083 的历史轨迹页并可查询已有轨迹，不因离线禁用入口。
  3. 初始化未连接设备的「发送指令」可点击，进入 deviceId=gt-device-0084 的单设备指令详情页；通信状态不改变导航目标。
  4. 告警且离线设备的「物联网卡查询」可点击，进入 deviceId=gt-device-0085 的查询页；目标页按自身规则展示设备状态和查询结果。

- 前置条件

## [P1] 验证各状态设备解绑确认取消不产生任何业务副作用
- 测试类型
  - 可靠性
- 前置条件
  1. 当前账号分别可见在线设备 gt-device-0090、离线设备 gt-device-0091、初始化未连接设备 gt-device-0092、告警设备 gt-device-0093
  2. 四台设备均存在有效当前账号关系、真实分组和围栏关联，设备总数及状态数量已记录
  3. 四台设备的 More 菜单均包含 Unbind Device
- 测试步骤
  1. 打开 gt-device-0090 的 More 菜单并点击 Unbind Device，在确认界面点击取消。
  2. 对 gt-device-0091、gt-device-0092、gt-device-0093 重复进入解绑确认并取消。
  3. 刷新当前账号 APP 与 Web 设备列表、分组和围栏数据。
  4. 查询四台设备的关系记录、总数、状态数量和历史数据。
- 预期结果
  1. 在线设备进入明确的解绑确认界面，取消后返回原列表且不提交解绑请求。
  2. 离线、未连接和告警设备均可进入同一解绑确认流程，取消结果一致。
  3. 四台设备的绑定或分配关系、真实分组和围栏关联全部保持不变。
  4. 设备总数、在线/离线/告警数量及历史位置、轨迹、告警和指令数据均不变化，不出现取消后先解绑再补偿的瞬时副作用。
