# US-015 筛选设备并打开快捷操作

> 口径依据：设备管理大纲第 2.2、2.3 节。设备图标表达在线、离线或未连接等基础通信状态；存在未处理告警时优先展示告警主体，同时必须保留告警设备在线与离线的底层差异。告警角标的具体颜色、形状及在线/离线角标视觉方案尚未确认，不以像素或具体角标形式作为通过标准。

## [P1] 验证无告警设备保留在线与离线基础状态差异
- 测试类型
  - 功能
- 前置条件
  1. 账号 personal_icon_01 可见 deviceId=gt-device-0051，卡号 GT2026100051，状态为在线且无告警
  2. 同一账号可见 deviceId=gt-device-0052，卡号 GT2026100052，状态为离线且无告警
  3. 同一账号可见 deviceId=gt-device-0053，卡号 GT2026100053，状态为初始化未连接且无告警
- 测试步骤
  1. 进入设备列表并同时查看 gt-device-0051、gt-device-0052、gt-device-0053 的左侧设备图标。
  2. 对比在线设备与离线设备的基础状态表达。
  3. 对比离线设备与初始化未连接设备在设备列表中的状态归类。
- 预期结果
  1. 三张卡片均展示与设备类型对应的固定设备图标，图标不因备注或卡号变化而改变形态。
  2. gt-device-0051 的图标主体为绿色，gt-device-0052 的图标主体为灰色，且均未显示告警主体。
  3. gt-device-0052 与 gt-device-0053 的图标主体均为灰色并按离线口径展示，不新增「未连接」独立状态标签。

## [P1] 验证告警在线设备展示告警主体并保留在线差异
- 测试类型
  - 功能
- 前置条件
  1. 企业一级账号 corp_icon_l1 可见 deviceId=gt-device-0054，卡号 GT2026100054，存在未处理告警 ALARM-20261012-054
  2. gt-device-0054 当前基础通信状态为在线，最近更新时间为「2026-10-12 10:05:00」
  3. 同列表存在无告警在线设备 gt-device-0051 作为对照
- 测试步骤
  1. 进入设备列表并查看 gt-device-0054 的左侧图标状态。
  2. 将 gt-device-0054 与无告警在线设备 gt-device-0051 对比。
  3. 查看 gt-device-0054 是否仍包含可识别的在线底层状态信息。
- 预期结果
  1. gt-device-0054 的图标主体为红色并优先表达告警，不仅展示普通在线绿色状态。
  2. gt-device-0054 与绿色主体的无告警在线设备 gt-device-0051 可区分，能够识别前者存在告警。
  3. gt-device-0054 在红色告警主体下仍保留在线底层差异；不以某种指定角标颜色、形状或像素位置作为本用例通过条件。

## [P1] 验证告警离线与告警未连接设备按离线底层差异展示
- 测试类型
  - 功能
- 前置条件
  1. 账号 personal_icon_02 可见 deviceId=gt-device-0055，卡号 GT2026100055，存在告警 ALARM-20261012-055，基础通信状态为离线
  2. 同一账号可见 deviceId=gt-device-0056，卡号 GT2026100056，存在告警 ALARM-20261012-056，设备初始化后从未建立有效通信
  3. 两台设备均有最后确认定位频率 10 分钟
- 测试步骤
  1. 查看 gt-device-0055 的左侧图标与卡片第三行。
  2. 查看 gt-device-0056 的左侧图标与卡片第三行。
  3. 对比两台设备的告警主体和底层通信状态归类。
- 预期结果
  1. gt-device-0055 的图标主体为红色并保留离线底层差异，第三行展示「10分钟定位（默认模式）」。
  2. gt-device-0056 的图标主体为红色并按离线底层差异处理，第三行同样展示「10分钟定位（默认模式）」。
  3. 两台设备均不展示「无法下发指令」文案，不为未连接设备新增独立角标通过标准。

## [P3][反向] 验证告警在线与告警离线不会退化为完全相同状态
- 测试类型
  - 可靠性
- 前置条件
  1. 账号 corp_icon_l1 可见告警在线设备 gt-device-0057，卡号 GT2026100057，告警编号 ALARM-20261012-057
  2. 同一账号可见告警离线设备 gt-device-0058，卡号 GT2026100058，告警编号 ALARM-20261012-058
  3. 两台设备型号均为 S18、备注均为「告警牛」，仅基础通信状态不同
- 测试步骤
  1. 在同一列表同时查看 gt-device-0057 与 gt-device-0058 的设备图标状态。
  2. 核对两张卡片是否都表达告警主体。
  3. 核对两张卡片是否仍能区分在线与离线底层状态。
  4. 记录当前构建实际采用的差异表达方式。
- 预期结果
  1. 两张卡片分别对应 gt-device-0057 与 gt-device-0058，不因备注和型号相同串用状态。
  2. 两张卡片图标主体均为红色并明确表达存在告警，告警优先级未被在线或离线状态覆盖。
  3. 在相同红色告警主体下，在线与离线底层差异仍可辨识，不退化为完全相同且无法区分的告警状态。
  4. 记录现状用于后续视觉方案确认，但不把具体颜色、角标形状或像素位置写成正式验收标准。
