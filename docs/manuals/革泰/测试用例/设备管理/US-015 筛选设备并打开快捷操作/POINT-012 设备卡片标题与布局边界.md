# US-015 筛选设备并打开快捷操作

> 口径依据：设备管理大纲第 2.2、2.3 节。卡片第一行有备注时展示“备注（卡号）”，无备注时直接展示卡号；标题单行尾部省略，不得挤压设备图标或右上角更多入口，备注与卡号仅用于展示而非设备身份。

## [P1] 验证有备注时第一行展示备注和卡号
- 测试类型
  - 功能
- 前置条件
  1. 个人账号 personal_card_01 可见设备 deviceId=gt-device-0031，卡号 GT2026100031，备注「北区牛群定位器」，状态为在线
  2. 设备列表当前筛选为「全部」、分组为「牧场一组」，列表中共 6 台设备
- 测试步骤
  1. 使用账号 personal_card_01 进入设备列表并定位 deviceId=gt-device-0031 的卡片。
  2. 查看卡片第一行标题内容。
  3. 将标题中的备注和卡号与设备资料比对。
- 预期结果
  1. 列表展示 deviceId=gt-device-0031 对应的一张设备卡片。
  2. 第一行展示「北区牛群定位器（GT2026100031）」。
  3. Device Name（设备备注）与卡号分别等于该设备当前资料，不使用分组名称或序列号替代。

## [P1] 验证无备注时第一行仅展示卡号
- 测试类型
  - 功能
- 前置条件
  1. 企业一级账号 corp_card_l1 可见设备 deviceId=gt-device-0032，卡号 GT2026100032，备注为空字符串，状态为离线
  2. 设备 deviceId=gt-device-0032 归属分组「西区牛舍」，序列号为 SN-GT-0032
- 测试步骤
  1. 使用账号 corp_card_l1 进入设备列表并定位 deviceId=gt-device-0032 的卡片。
  2. 查看卡片第一行标题。
  3. 查看标题附近是否出现空括号、分组名或序列号。
- 预期结果
  1. 列表展示 deviceId=gt-device-0032 对应的设备卡片。
  2. 第一行仅展示卡号「GT2026100032」。
  3. 不展示空括号，不把「西区牛舍」或「SN-GT-0032」补作标题。

## [P1] 验证长备注在窄屏下单行省略且更多入口可用
- 测试类型
  - 兼容性
- 前置条件
  1. Android 15 手机分辨率为 360×800，系统字体大小设置为最大档
  2. 账号 personal_card_02 可见设备 deviceId=gt-device-0033，卡号 GT2026100033，备注「内蒙古东部示范牧场三号牛舍重点观察牛群定位终端」，状态为告警
- 测试步骤
  1. 使用账号 personal_card_02 进入设备列表并定位 deviceId=gt-device-0033 的卡片。
  2. 查看第一行长标题的行数和尾部展示。
  3. 查看左侧设备图标与右上角更多入口是否被标题遮挡。
  4. 点击右上角更多入口。
- 预期结果
  1. 卡片正常渲染，未因长备注产生横向滚动或页面错位。
  2. 第一行保持单行，超出可用区域的内容在尾部省略。
  3. 设备图标和更多入口保持可见、未被文本挤压或遮挡。
  4. 打开 deviceId=gt-device-0033 的 More 操作面板，不因标题省略导致入口不可点击。

## [P3][反向] 验证相同备注设备不被标题合并或串用卡号
- 测试类型
  - 可靠性
- 前置条件
  1. 账号 corp_card_l1 可见两台设备：deviceId=gt-device-0034、卡号 GT2026100034、备注「一号牛」；deviceId=gt-device-0035、卡号 GT2026100035、备注「一号牛」
  2. 两台设备均归属分组「育肥区」，gt-device-0034 状态为在线，gt-device-0035 状态为离线
- 测试步骤
  1. 进入「育肥区」设备列表并搜索关键词「一号牛」。
  2. 查看搜索结果中的卡片数量和两张卡片第一行。
  3. 分别核对两张卡片绑定的 deviceId 与卡号。
- 预期结果
  1. 搜索结果展示 2 张设备卡片，不因备注相同合并为一张。
  2. 两张卡片分别展示「一号牛（GT2026100034）」和「一号牛（GT2026100035）」。
  3. 每张卡片的卡号与自身 deviceId 对应，不串用另一设备卡号，后续身份仍以 deviceId 为准。

## [P3][反向] 验证卡片任意区域只保留三行字段及图标和 More
- 测试类型
  - 功能
- 前置条件
  1. 账号 corp_card_l2 可见 deviceId=gt-device-0036，卡号 GT2026100036，备注「南区种牛36」，归属分组「南区繁育重点观察组」，序列号为 SN-GT-0036
  2. gt-device-0036状态为告警且初始化未连接，有效电量为 66%，最近更新时间为「2026-10-12 10:26:36」，最后确认定位频率为 10分钟
- 测试步骤
  1. 使用 corp_card_l2进入设备列表并定位 gt-device-0036卡片。
  2. 从左到右、从上到下检查卡片全部可见区域和三行文本。
  3. 核对分组名称、序列号独立字段、额外字段分隔符和右侧状态文字是否出现。
  4. 核对左侧设备图标和右上角 More 入口。
- 预期结果
  1. 列表仅渲染一张对应 deviceId=gt-device-0036的卡片，不因字段较多扩展额外信息区。
  2. 第一行展示「南区种牛36（GT2026100036）」；第二行展示电池图标、66% 和最近更新时间；第三行展示「10分钟定位（默认模式）」。
  3. 卡片任意区域均不展示分组名称「南区繁育重点观察组」、序列号独立字段「SN-GT-0036」、三行之外的额外字段分隔符或右侧“告警”“未连接”等状态文字标签；第一行规则要求的备注与卡号括号不属于额外字段分隔符。
  4. 左侧设备图标按告警与离线底层差异表达状态，右上角 More 入口保持可见且可点击；卡片不出现真源三行、左侧图标和 More 之外的业务字段。
