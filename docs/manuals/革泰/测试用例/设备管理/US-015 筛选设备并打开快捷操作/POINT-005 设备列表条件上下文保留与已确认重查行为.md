# US-015 筛选设备并打开快捷操作

> 口径依据：设备管理大纲第 2.2 节、第 2.4.1 节、第 4.8 节、第 5.1 节。首次进入与账号切换使用虚拟“全部分组”；同一登录会话离开再返回保留有效分组；清空关键词恢复当前状态与分组；从单设备页面返回或关闭详情抽屉保留筛选和滚动上下文；已选分组失效时在 APP 获取最新数据后回退并提示。本文件不把未确认的默认排序、状态刷新时机或通用刷新机制作为通过标准。

## [P1] 验证首次进入和切换账号后从全部分组开始
- 测试类型
  - 功能
- 前置条件
  1. 账号 corp_l1_08 可见 4 台设备，其中 dev-6001、卡号 8600060001、备注“东区在线机”、状态在线，归属“东区组”
  2. 账号 personal_08 可见 2 台设备，其中 dev-6002、卡号 8600060002、备注“个人离线机”、状态离线，归属“家庭组”
  3. corp_l1_08 和 personal_08 均为本次登录会话中的首次进入设备首页
- 测试步骤
  1. 使用 corp_l1_08 首次进入设备首页并查看分组选择。
  2. 将 corp_l1_08 的分组切换为“东区组”。
  3. 退出 corp_l1_08 并切换登录 personal_08，再进入设备首页。
- 预期结果
  1. corp_l1_08 默认选择虚拟“全部分组”，列表范围为该账号可见的 4 台设备。
  2. corp_l1_08 当前分组变为“东区组”，列表包含直接归属的 dev-6001。
  3. personal_08 默认选择虚拟“全部分组”，不复用“东区组”，列表范围为 personal_08 可见的 2 台设备。

- 前置条件

  2. 列表当前滚动位置位于第 12 张卡片区域，已记录当前位置锚点为 deviceId=dev-6301；本用例不固定卡片状态、电量或最近更新时间在返回期间是否刷新
  3. dev-6301 可进入 More 菜单“历史轨迹”，也可点击卡片本体打开详情抽屉

  3. 点击 dev-6301 卡片本体打开详情抽屉，再点击标题区下箭头关闭。

## [P3][反向] 验证已选分组失效后在获取最新数据时回退全部分组并提示
- 测试类型
  - 可靠性
- 前置条件
  1. 账号 corp_l2_10 当前选择“临时牧场组”，该组直接归属 dev-6401、卡号 8600064001、备注“临时组在线机”、状态在线，当前列表数量为 1
  2. APP 保持当前设备列表会话时，另一端删除“临时牧场组”或移除 corp_l2_10 对该组的权限
  3. 服务端最新分组查询返回“临时牧场组”不存在或 corp_l2_10 已无权限
- 测试步骤
  1. 在 APP 设备首页点击当前分组栏，打开 Select Group 分组选择器。
  2. 等待 Select Group 完成当前账号最新分组结构和直属设备数查询。
  3. 核对分组选择、提示文案和列表统计范围。
- 预期结果
  1. 打开 Select Group 触发当前账号最新分组数据查询；本用例不据此写死其他页面或其他时机的自动刷新行为。
  2. APP 识别原选择“临时牧场组”已被另一端删除或当前账号已失权，不继续使用旧分组数据。
  3. 分组切换为虚拟“全部分组”，展示原分组已失效的可读提示；列表和顶部数量按 corp_l2_10 当前全部可见设备重新计算，不继续固定显示 dev-6401 或数量 1。
