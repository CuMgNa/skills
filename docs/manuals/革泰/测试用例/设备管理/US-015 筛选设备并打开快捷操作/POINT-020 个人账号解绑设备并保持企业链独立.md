- 测试类型
  - 功能
- 前置条件

  2. enterprise_l1_a 已将 GT-DEV-0701 分配给二级账号 enterprise_l2_a1，enterprise_l2_a1 已分配给三级账号 enterprise_l3_a11
  3. personal_0701 的分组「个人巡检组」和围栏「个人仓库围栏」均关联 GT-DEV-0701
  4. 企业链分组「企业运输组」和围栏「企业园区围栏」均关联 GT-DEV-0701
  5. GT-DEV-0701 存在设备主数据、库存记录、物联网卡 ICCID 8986040701000000001、历史位置 POS-0701、轨迹 TRAJ-0701 和告警 ALM-0701
- 测试步骤
  1. 记录 GT-DEV-0701 的个人关系、企业关系、设备主数据、库存、物联网卡和历史数据快照。
  2. personal_0701 在 APP 设备卡片右上角更多中执行 Unbind Device。
  3. 分别刷新 personal_0701、enterprise_l1_a、enterprise_l2_a1、enterprise_l3_a11 的 APP 与 Web 设备列表。
  4. 查询个人侧与企业侧分组、围栏设备关联。
  5. 查询 GT-DEV-0701 的设备主数据、库存、物联网卡及历史数据。

  2. 个人解绑成功，仅 personal_0701 的直接绑定关系失效。
  3. personal_0701 在 APP 与 Web 均不可见 GT-DEV-0701；enterprise_l1_a、enterprise_l2_a1、enterprise_l3_a11 仍可见，企业链不受影响。
  4. 「个人巡检组」和「个人仓库围栏」对 GT-DEV-0701 的关联被清除；「企业运输组」和「企业园区围栏」关联保持不变。
  5. 设备主数据、库存记录、ICCID 8986040701000000001、POS-0701、TRAJ-0701、ALM-0701 均保留且未被解绑动作删除。
