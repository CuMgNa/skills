# US-015 筛选设备并打开快捷操作

> 口径依据：设备管理大纲第 2.3 节。有效电量时第二行展示电池图标、百分比和接口返回的最近更新时间，在线与离线均适用；电量小于 20% 显示红色，达到或超过 20% 显示绿色；无有效电量时隐藏电池图标和数值，不展示技术状态占位文案，第二行布局高度保持不变。

## [P1] 验证在线设备展示有效电量和最近更新时间
- 测试类型
  - 功能
- 前置条件
  1. 账号 personal_battery_01 可见设备 deviceId=gt-device-0041，卡号 GT2026100041，备注「种牛A41」，状态为在线
  2. 设备接口返回有效电量 76%，最近更新时间为「2026-10-12 09:35:20」
- 测试步骤
  1. 使用账号 personal_battery_01 进入设备列表并定位 deviceId=gt-device-0041 的卡片。
  2. 查看卡片第二行的电池图标、电量和最近更新时间。
  3. 将展示值与接口返回值比对。
- 预期结果
  1. 列表展示 deviceId=gt-device-0041 对应的设备卡片。
  2. 第二行展示电池图标、76% 和接口对应的「最近更新于」时间，电池图标为绿色。
  3. 电量为 76%，时间对应「2026-10-12 09:35:20」，未改用设备在线时间或定位时间。

## [P1] 验证低电量阈值 19% 与 20% 的颜色边界
- 测试类型
  - 功能
- 前置条件
  1. 企业一级账号 corp_battery_l1 可见 deviceId=gt-device-0042，卡号 GT2026100042，状态为离线，有效电量为 19%，最近更新时间为「2026-10-12 08:10:00」
  2. 同一账号可见 deviceId=gt-device-0043，卡号 GT2026100043，状态为在线，有效电量为 20%，最近更新时间为「2026-10-12 08:11:00」
- 测试步骤
  1. 进入设备列表并查看 gt-device-0042 的第二行。
  2. 查看 gt-device-0043 的第二行。
  3. 对比两台设备的电量数值、图标颜色和最近更新时间。
- 预期结果
  1. gt-device-0042 展示 19% 和对应更新时间，电池图标为红色，离线状态不隐藏有效电量。
  2. gt-device-0043 展示 20% 和对应更新时间，电池图标为绿色。
  3. 两台设备均按展示百分比跨越 20% 边界处理，19% 与 20% 不使用相同阈值结果，时间不串用。

## [P1] 验证有效电量 0% 与 100% 均按真实值展示
- 测试类型
  - 功能
- 前置条件
  1. 账号 personal_battery_02 可见 deviceId=gt-device-0044，卡号 GT2026100044，有效电量为 0%，状态为告警且离线
  2. 同一账号可见 deviceId=gt-device-0045，卡号 GT2026100045，有效电量为 100%，状态为在线
- 测试步骤
  1. 查看 gt-device-0044 卡片第二行。
  2. 查看 gt-device-0045 卡片第二行。
  3. 核对两台设备是否都保留百分号和对应电池图标。
- 预期结果
  1. gt-device-0044 展示 0%，不把数值 0 当作空值，电池图标为红色。
  2. gt-device-0045 展示 100%，电池图标为绿色。
  3. 两台设备均展示电池图标和真实百分比，不显示「—」、负数或超过 100% 的派生值。

## [P3][反向] 验证无有效电量时不伪造百分比或技术占位文案
- 测试类型
  - 可靠性
- 前置条件
  1. 账号 corp_battery_l1 可见三台离线设备：gt-device-0046 当前有效电量字段为 null，gt-device-0047 当前有效电量字段缺失，gt-device-0048 当前有效电量字段为 null 且不存在可用历史有效电量
  2. 三台设备卡号分别为 GT2026100046、GT2026100047、GT2026100048，最近更新时间均未返回
  3. 同列表存在有效电量 55% 的设备 gt-device-0049，用于比对第二行布局高度
- 测试步骤
  1. 依次查看 gt-device-0046、gt-device-0047、gt-device-0048 的第二行。
  2. 检查三张卡片是否展示电池图标、百分比或技术状态文案。
  3. 将三张卡片第二行布局与 gt-device-0049 的第二行对比。
- 预期结果
  1. 三台无有效电量设备均保留第二行布局区域，但不展示无依据的电量值。
  2. 三张卡片均隐藏电池图标和数值，不展示 0%、null 或「无数据」等技术状态占位文案。
  3. 第二行布局高度与 gt-device-0049 保持一致，后续第三行和更多入口未发生上下错位。

## [P3][反向] 验证负数超上限和非法类型电量均不按百分比展示
- 测试类型
  - 可靠性
- 前置条件
  1. 账号 personal_battery_03 可见 deviceId=gt-device-0050，卡号 GT2026100050，接口电量为 -1，状态为在线
  2. 同一账号可见 deviceId=gt-device-0059，卡号 GT2026100059，接口电量为 101，状态为离线
  3. 同一账号可见 deviceId=gt-device-0060，卡号 GT2026100060，接口电量为字符串 unknown，状态为告警且在线
- 测试步骤
  1. 查看 gt-device-0050 卡片第二行的电量区域。
  2. 查看 gt-device-0059 卡片第二行的电量区域。
  3. 查看 gt-device-0060 卡片第二行的电量区域。
- 预期结果
  1. -1 被判定为无效电量，卡片隐藏电池图标和数值，不展示 -1% 或按 0% 处理。
  2. 101 被判定为无效电量，卡片隐藏电池图标和数值，不展示 101% 或截断为 100%。
  3. 字符串 unknown 被判定为非法类型，卡片隐藏电池图标和数值，页面不崩溃且不展示技术状态占位文案。

## [P1] 验证支持范围最窄屏下第二行电量和完整最近更新时间不截断
- 测试类型
  - 兼容性
- 前置条件
  1. 使用产品支持范围内可用宽度最窄的手机屏幕，系统字体大小设置为产品支持范围内最大档
  2. 账号 personal_battery_04 可见 deviceId=gt-device-0061，卡号 GT2026100061，备注「超长牧场名称下重点观察种牛六十一号定位终端」，状态为离线
  3. 接口返回有效电量 68%，完整最近更新时间文案为「最近更新于 2026-10-12 09:35:20」，最后确认定位频率为 1440分钟，对应第三行源文案为「自定义模式（1440分钟）」
- 测试步骤
  1. 使用 personal_battery_04进入设备列表并定位 gt-device-0061卡片。
  2. 查看卡片第二行的电池图标、68% 和完整最近更新时间。
  3. 查看第一行、第三行在窄屏下的溢出处理。
  4. 查看并点击右上角 More 入口。
- 预期结果
  1. 卡片在支持范围最窄屏和最大字体档下正常渲染，不产生横向滚动、字段重叠或页面错位。
  2. 第二行完整展示电池图标、68% 和「最近更新于 2026-10-12 09:35:20」，电量与更新时间均不被截断、换成其他时间或被 More 遮挡。
  3. 第一行可按单行尾部省略规则处理；第三行以「自定义模式（1440分钟）」为源文案并可按单行过长尾部省略规则处理；两行均不得挤占第二行的完整展示空间。
  4. More 入口保持可见且不遮挡第二行，点击后打开 deviceId=gt-device-0061的操作面板。
