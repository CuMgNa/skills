# US-015 筛选设备并打开快捷操作

> 口径依据：设备管理大纲第 2.4.1 节。从 More 菜单目标页返回设备列表时，必须保留进入前的状态筛选、分组、关键词与滚动位置；查看单设备扩展项不得改变设备归属、分组、在线状态或告警处理状态。

- 测试类型
  - 功能
- 前置条件
  1. 账号 personal_return_01 在设备列表选择状态「在线」、分组「东区牧场」、关键词「种牛」
  2. 交集结果共 18 台设备，已滚动到第 14 张卡 deviceId=gt-device-0101、卡号 GT2026100101、备注「种牛101」
  3. gt-device-0101 状态为在线，归属分组「东区牧场」
- 测试步骤
  1. 从 gt-device-0101 的 More 菜单进入「实时追踪」。
  2. 确认目标页加载 gt-device-0101 后点击页面返回按钮。
  3. 查看设备列表的状态、分组和关键词控件。
  4. 查看返回后的首屏可见卡片与滚动位置。
- 预期结果
  1. 实时追踪页按 deviceId=gt-device-0101 加载。

  3. 状态仍为「在线」、分组仍为「东区牧场」、关键词仍为「种牛」。
  4. 返回后 gt-device-0101 在视口内的纵向位置与进入实时追踪前一致，列表滚动偏移保持不变且不跳回顶部。
