# US-015 筛选设备并打开快捷操作

> 口径依据：设备管理大纲第 2.2、2.4.1～2.4.2 节。More 菜单所有跳转均携带被点击设备的唯一标识，不得使用名称、备注、卡号或列表位置作为查询身份；重复备注、备注变化及连续查看不同设备时仍必须指向原设备。

## [P1] 验证相同备注设备按 deviceId 进入各自实时追踪页
- 测试类型
  - 功能
- 前置条件
  1. 账号 personal_route_01 可见 deviceId=gt-device-0091、卡号 GT2026100091、备注「母牛A」和 deviceId=gt-device-0092、卡号 GT2026100092、备注「母牛A」
  2. gt-device-0091 最新位置为东经 116.397128、北纬 39.916527，gt-device-0092 最新位置为东经 116.410000、北纬 39.920000
- 测试步骤
  1. 打开卡号 GT2026100091 卡片的 More 菜单并点击「实时追踪」。
  2. 核对实时追踪页的路由参数、设备摘要和地图聚焦设备。
  3. 返回列表后打开卡号 GT2026100092 卡片的 More 菜单并点击「实时追踪」。
  4. 核对第二次进入页面的路由参数、设备摘要和位置。
- 预期结果
  1. 第一次跳转携带 deviceId=gt-device-0091。
  2. 页面设备摘要展示卡号 GT2026100091，地图聚焦 gt-device-0091 对应设备标记，不因相同备注加载 gt-device-0092。
  3. 第二次跳转携带 deviceId=gt-device-0092。
  4. 页面设备摘要展示卡号 GT2026100092，地图聚焦 gt-device-0092 对应设备标记，不残留 gt-device-0091 的设备摘要或地图目标。

## [P1] 验证备注变化后历史轨迹仍查询原 deviceId
- 测试类型
  - 可靠性
- 前置条件
  1. 企业一级账号 corp_route_l1 可见 deviceId=gt-device-0093，卡号 GT2026100093，原备注为「育肥牛93」
  2. gt-device-0093 在「2026-10-11 08:00:00～10:00:00」存在 18 个历史轨迹点
  3. 打开 More 菜单前，Web 端将该设备备注改为「重点观察牛93」，deviceId 和卡号不变
- 测试步骤
  1. APP 设备列表获取最新资料并定位显示「重点观察牛93（GT2026100093）」的卡片。
  2. 打开该卡片 More 菜单并点击「历史轨迹」。
  3. 查询「2026-10-11 08:00:00～10:00:00」轨迹。
  4. 核对请求身份和返回轨迹点所属设备。
- 预期结果
  1. 卡片展示新备注，仍对应 deviceId=gt-device-0093。
  2. 跳转携带 deviceId=gt-device-0093，不携带新旧备注作为查询身份。
  3. 返回 18 个属于 gt-device-0093 的轨迹点。
  4. 不因备注变化查询不到数据，也不跳转到其他同名设备。

## [P1] 验证连续查询不同设备物联网卡时 deviceId 与卡信息同步切换
- 测试类型
  - 功能
- 前置条件
  1. 账号 personal_route_02 可见 deviceId=gt-device-0094，卡号 GT2026100094，关联 ICCID=898604001026100094
  2. 同一账号可见 deviceId=gt-device-0095，卡号 GT2026100095，关联 ICCID=898604001026100095
  3. 两台设备备注均为「物联卡测试牛」
- 测试步骤
  1. 从 gt-device-0094 的 More 菜单进入「物联网卡查询」。
  2. 核对查询请求和页面 ICCID 后返回设备列表。
  3. 从 gt-device-0095 的 More 菜单进入「物联网卡查询」。
  4. 核对第二次查询请求、设备摘要和 ICCID。
- 预期结果
  1. 第一次查询只提交 deviceId=gt-device-0094。
  2. 页面设备摘要对应 GT2026100094，ICCID 为 898604001026100094。
  3. 第二次查询只提交 deviceId=gt-device-0095。
  4. 页面设备摘要对应 GT2026100095，ICCID 为 898604001026100095，不残留 gt-device-0094 的摘要或卡信息。

## [P3][反向] 验证发送指令不使用列表位置或卡片备注识别设备
- 测试类型
  - 安全性
- 前置条件
  1. 账号 corp_route_l1 当前列表第 1 张卡为 deviceId=gt-device-0096、卡号 GT2026100096、备注「一号牛」
  2. 当前列表第 2 张卡为 deviceId=gt-device-0097、卡号 GT2026100097、备注「二号牛」
  3. 应用关键词「二号牛」后列表仅剩 gt-device-0097，且当前账号有该设备发送指令权限
- 测试步骤
  1. 在关键词筛选结果中打开 gt-device-0097 的 More 菜单。
  2. 点击「发送指令」。
  3. 核对指令详情页的路由参数和设备摘要。
  4. 返回列表并检查导航日志中是否存在指向 gt-device-0096 的误跳转。
- 预期结果
  1. More 面板关联 deviceId=gt-device-0097，不使用筛选前的列表索引 2 作为身份。
  2. 跳转只携带 deviceId=gt-device-0097。
  3. 指令详情页展示卡号 GT2026100097 和备注「二号牛」。
  4. 导航日志不存在指向 gt-device-0096 的目标页记录，证明路由未按列表首位或相近备注串设备。
