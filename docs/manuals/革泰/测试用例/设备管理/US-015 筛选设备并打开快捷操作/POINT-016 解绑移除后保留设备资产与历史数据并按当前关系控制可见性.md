# US-015 筛选设备并打开快捷操作

> 口径依据：唯一业务真源《革泰 APP 设备管理逻辑点梳理 plan.md》第 1.1～1.4、3.3、8～10 章。解绑或分配回收不等于删除设备；设备主数据、库存、物联网卡、历史位置、轨迹、告警保留，可见性按当前关系控制；指令记录按专项规则分层处理。

## [P1] 验证个人解绑后历史位置轨迹告警保留但当前账号不可见
- 测试类型
  - 可靠性
- 前置条件
  1. personal_0750 绑定 GT-DEV-0750，当前可查看历史位置 POS-0750、轨迹 TRAJ-0750 和告警 ALM-0750
  2. GT-DEV-0750 存在设备主数据、库存记录和物联网卡 ICCID 8986040750000000050
  3. 企业一级 enterprise_l1_0750 独立绑定 GT-DEV-0750
- 测试步骤
  1. 记录 GT-DEV-0750 的资产和三类历史数据标识。
  2. personal_0750 解绑 GT-DEV-0750。
  3. personal_0750 从原历史入口查询 POS-0750、TRAJ-0750、ALM-0750。
  4. enterprise_l1_0750 按当前有效关系查询相同历史数据。
  5. 在数据层查询设备主数据、库存、物联网卡和三类历史记录。
- 预期结果
  1. POS-0750、TRAJ-0750、ALM-0750 与资产记录在解绑前均存在。
  2. personal_0750 的直接绑定失效，企业绑定保持有效。
  3. personal_0750 不再因已失效关系访问三类历史数据，历史入口不可达或查询被当前关系鉴权拦截。
  4. enterprise_l1_0750 仍可按当前有效关系查看 POS-0750、TRAJ-0750、ALM-0750。
  5. 设备主数据、库存、ICCID 8986040750000000050 及三类历史记录均保留，未被物理删除。

## [P1] 验证企业一级解绑后历史数据不随全链级联删除
- 测试类型
  - 可靠性
- 前置条件
  1. enterprise_l1_0751 绑定 GT-DEV-0751，并逐级分配给 enterprise_l2_0751、enterprise_l3_0751
  2. GT-DEV-0751 存在位置 POS-0751、轨迹 TRAJ-0751、告警 ALM-0751 和设备指令记录 CMD-DEV-0751
  3. GT-DEV-0751 存在设备主数据、库存记录和物联网卡 ICCID 8986040751000000051
- 测试步骤
  1. enterprise_l1_0751 解绑 GT-DEV-0751。
  2. 刷新企业三级账号的设备与历史入口。
  3. 查询失效链内分组、围栏及历史数据存储记录。
  4. 查询设备主数据、库存、物联网卡和 CMD-DEV-0751 的后台记录。
- 预期结果
  1. 一级绑定及其下二级、三级分配全部失效。
  2. 企业三级账号均不可见设备，设备历史入口按当前关系不可达。
  3. 失效链内分组和围栏关系被清除；POS-0751、TRAJ-0751、ALM-0751 仍保留。
  4. 设备主数据、库存、ICCID 8986040751000000051 和后台设备指令记录 CMD-DEV-0751 均保留。

## [P1] 验证账号解绑后自己下发的批量指令仍可从我的查看
- 测试类型
  - 功能
- 前置条件
  1. enterprise_l2_0752 当前可见 GT-DEV-0752
  2. enterprise_l2_0752 已从批量入口下发记录 CMD-MY-0752，记录归属为当前账号自己的「我的」记录
  3. enterprise_l1_0752 计划在用户管理中回收 enterprise_l2_0752 的 GT-DEV-0752
- 测试步骤
  1. enterprise_l1_0752 回收 enterprise_l2_0752 的 GT-DEV-0752。
  2. enterprise_l2_0752 刷新设备列表并尝试进入 GT-DEV-0752 的设备指令入口。
  3. enterprise_l2_0752 进入「我的」批量指令记录。
  4. 查询 CMD-MY-0752 与该设备后台指令历史。
- 预期结果
  1. enterprise_l2_0752 的分配关系失效。
  2. 设备卡片消失，设备指令记录因设备入口消失而在 APP 内不可达。
  3. enterprise_l2_0752 仍可从「我的」查看自己下发的 CMD-MY-0752。
  4. CMD-MY-0752 和设备后台指令历史均保留，不因关系回收被删除。

## [P1] 验证三级仅分配设备后进入我的分组并按当前关系恢复历史可见性
- 测试类型
  - 功能
- 前置条件
  1. enterprise_l3_0753 当前可见 GT-DEV-0753，并可查看 POS-0753、TRAJ-0753、ALM-0753
  2. enterprise_l2_0753 对 GT-DEV-0753 的分配关系持续有效
  3. enterprise_l3_0753 的旧分组「三级历史组」和旧围栏「三级历史围栏」关联 GT-DEV-0753，且目标账号已存在精确名称为「我的分组」的真实一级分组
  4. GT-DEV-0753 存在设备主数据、库存和物联网卡 ICCID 8986040753000000053
- 测试步骤
  1. enterprise_l3_0753 自行移除 GT-DEV-0753。
  2. 查询 POS-0753、TRAJ-0753、ALM-0753 的存储状态和 enterprise_l3_0753 的访问结果。
  3. enterprise_l2_0753 在 Web 使用「仅分配设备」模式，选择目标账号 enterprise_l3_0753 后重新分配 GT-DEV-0753；父级界面不查看或选择下级 groupId。
  4. enterprise_l3_0753 刷新设备、历史页面和「我的分组」。
  5. 查询旧分组、旧围栏、设备主数据、库存和物联网卡。
- 预期结果
  1. 仅 enterprise_l3_0753 的分配关系失效，旧分组和旧围栏关系同步清除。
  2. 三类历史数据仍保留，但 enterprise_l3_0753 在关系失效期间不可按旧授权访问。
  3. 重新建立三级分配关系，不创建重复设备记录，也不采用同步覆盖分组模式。
  4. enterprise_l3_0753 按当前恢复的关系重新可见设备及 POS-0753、TRAJ-0753、ALM-0753；系统自动复用该账号下精确名称为「我的分组」的真实一级分组承接 GT-DEV-0753。
  5. 「三级历史组」和「三级历史围栏」关联不自动恢复；设备主数据、库存和 ICCID 8986040753000000053 均保留。
