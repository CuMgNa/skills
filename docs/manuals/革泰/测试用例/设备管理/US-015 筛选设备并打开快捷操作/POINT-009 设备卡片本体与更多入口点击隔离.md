# US-015 筛选设备并打开快捷操作

> 口径依据：设备管理大纲第 2.3、2.4.1 节。所有设备状态均保留右上角竖向三点更多入口；更多入口独立于卡片本体点击，点击更多不得先打开详情抽屉，点击卡片本体只打开对应设备半屏详情抽屉。

## [P1] 验证所有设备状态均保留可操作的更多入口
- 测试类型
  - 功能
- 前置条件
  1. 账号 personal_hit_01 可见四台设备：gt-device-0071 在线、gt-device-0072 离线、gt-device-0073 初始化未连接、gt-device-0074 告警且在线
  2. 四台设备卡号依次为 GT2026100071、GT2026100072、GT2026100073、GT2026100074，均有当前账号访问权限
- 测试步骤
  1. 进入设备列表并查看 gt-device-0071 与 gt-device-0072 卡片右上角。
  2. 查看 gt-device-0073 与 gt-device-0074 卡片右上角。
  3. 依次点击四张卡片的竖向三点入口并在每次查看后关闭面板。
- 预期结果
  1. 在线与离线设备均展示右上角竖向三点入口。
  2. 未连接与告警设备均展示右上角竖向三点入口，不因状态隐藏。
  3. 四次均打开各自设备的 More 操作面板，入口可点击且未串到其他设备。

## [P1] 验证点击更多入口只打开当前设备操作面板
- 测试类型
  - 功能
- 前置条件
  1. 企业一级账号 corp_hit_l1 可见 deviceId=gt-device-0075，卡号 GT2026100075，备注「东栏75」，状态为在线
  2. 设备列表未打开任何详情抽屉或操作面板
- 测试步骤
  1. 点击 gt-device-0075 卡片右上角竖向三点。
  2. 查看当前显示的浮层或面板及其关联设备。
  3. 检查卡片半屏详情抽屉是否同时打开。
- 预期结果
  1. 点击事件由更多入口独立响应。
  2. 打开 gt-device-0075 的 More 操作面板，面板关联 deviceId=gt-device-0075。
  3. 不打开半屏详情抽屉，不出现先开详情再弹菜单的闪跳或叠层。

## [P1] 验证点击卡片本体只打开对应设备详情抽屉
- 测试类型
  - 功能
- 前置条件
  1. 账号 personal_hit_02 可见 deviceId=gt-device-0076，卡号 GT2026100076，备注「西栏76」，状态为告警且离线
  2. gt-device-0076 卡片右上角更多入口可见，当前未打开操作面板
- 测试步骤
  1. 点击 gt-device-0076 卡片标题与第二行之间的本体区域。
  2. 查看打开的详情载体和设备摘要。
  3. 检查 More 操作面板是否同时打开。
- 预期结果
  1. 卡片本体点击事件被独立响应，不误触右上角更多入口。
  2. 在当前列表上方打开 gt-device-0076 的半屏详情抽屉，摘要对应卡号 GT2026100076。
  3. More 操作面板保持关闭，不出现重复导航或两个交互层同时打开。

## [P3][反向] 验证长文本与大字体不会覆盖更多入口点击区域
- 测试类型
  - 易用性
- 前置条件
  1. iOS 26 手机分辨率为 390×844，系统字体大小设置为最大档
  2. 账号 personal_hit_03 可见 deviceId=gt-device-0077，卡号 GT2026100077，备注「高海拔冬季牧场重点观察区域七号牛群定位终端」，最后确认频率为 30 分钟
  3. gt-device-0077 有效电量为 88%，最近更新时间为「2026-10-12 11:20:00」
- 测试步骤
  1. 进入设备列表并查看 gt-device-0077 卡片的标题、第二行、第三行和更多入口。
  2. 点击标题尾部省略区域，观察响应目标。
  3. 返回列表后点击右上角竖向三点入口。
  4. 连续重复步骤 2 和步骤 3 各 3 次。
- 预期结果
  1. 长标题与大字体不遮挡更多入口，卡片各行不覆盖右上角操作区域。
  2. 点击标题省略区域按卡片本体处理，仅打开 gt-device-0077 详情抽屉。
  3. 点击竖向三点仅打开 gt-device-0077 的 More 操作面板。
  4. 6 次操作均按各自点击区域稳定响应，无误触、无同时打开详情与菜单、无串设备。
