# US-015 筛选设备并打开快捷操作

> 口径依据：设备管理大纲第 2 节、第 4.8 节、第 10 节。状态筛选为全部、在线、离线、告警且一次只选一项；未连接设备统一进入离线筛选；告警筛选命中告警设备，同时保留其在线或离线底层差异。

## [P1] 验证在线状态筛选仅展示当前范围内在线设备
- 测试类型
  - 功能
- 前置条件
  1. 账号 corp_l1_02 当前选择虚拟“全部分组”，可见 deviceId=dev-2001、卡号 8600020001、备注“在线巡检机”、在线无告警；deviceId=dev-2002、卡号 8600020002、备注“离线巡检机”、离线无告警；deviceId=dev-2003、卡号 8600020003、备注“在线告警机”、告警且在线
  2. 当前范围顶部在线数量为 2
- 测试步骤
  1. 使用 corp_l1_02 进入设备首页并选择“在线”。
  2. 核对状态控件选中项和列表 deviceId。
  3. 核对筛选结果数量与顶部“在线”数量。
- 预期结果
  1. “在线”成为唯一选中的状态项。
  2. 列表仅展示 dev-2001、dev-2003，不展示 dev-2002。
  3. 列表展示 2 台设备，与当前范围“在线 2”一致。

## [P1] 验证离线状态筛选同时包含离线与初始化未连接设备
- 测试类型
  - 功能
- 前置条件
  1. 账号 personal_02 可见 deviceId=dev-2101、卡号 8600021001、备注“西门离线机”，已有通信记录但当前离线
  2. personal_02 可见 deviceId=dev-2102、卡号 8600021002、备注“新绑牛舍机”，初始化绑定后无上报且未完成有效通信，实际情况为未连接
  3. personal_02 可见 deviceId=dev-2103、卡号 8600021003、备注“东门在线机”，当前在线
- 测试步骤
  1. 使用 personal_02 进入设备首页并选择“离线”。
  2. 核对列表中的 deviceId、卡号和备注。
  3. 核对 dev-2101 与 dev-2102 的卡片状态视觉。
- 预期结果
  1. “离线”成为唯一选中的状态项。
  2. 列表展示 dev-2101“西门离线机”和 dev-2102“新绑牛舍机”共 2 台，不展示 dev-2103。
  3. dev-2101 与 dev-2102 均按离线口径展示，不因 dev-2102 未连接而漏筛。

## [P1] 验证告警筛选命中在线告警与离线告警设备
- 测试类型
  - 功能
- 前置条件
  1. 账号 corp_l2_02 可见 deviceId=dev-2201、卡号 8600022001、备注“南场告警在线机”，告警且在线
  2. corp_l2_02 可见 deviceId=dev-2202、卡号 8600022002、备注“北场告警离线机”，告警且离线
  3. corp_l2_02 可见 deviceId=dev-2203、卡号 8600022003、备注“普通在线机”，在线且无告警
- 测试步骤
  1. 使用 corp_l2_02 进入设备首页并选择“告警”。
  2. 核对列表 deviceId 和左侧设备图标的告警状态表达。
  3. 核对 dev-2201、dev-2202 的在线或离线角标。
- 预期结果
  1. “告警”成为唯一选中的状态项。
  2. 列表仅展示 dev-2201、dev-2202 共 2 台；两张卡片均通过左侧设备图标表达告警，不新增右侧状态文字标签，且不展示 dev-2203。
  3. dev-2201 展示在线角标，dev-2202 展示离线角标，底层通信差异未丢失。

## [P3][反向] 验证页面不提供未连接独立筛选且零数量状态不串入其他设备
- 测试类型
  - 功能
- 前置条件
  1. 账号 corp_l3_02 当前选择“东区组”，该组直接归属 deviceId=dev-2301、卡号 8600023001、备注“东区离线机”，状态为离线无告警
  2. “东区组”直接归属设备数为 1，状态数量为全部 1、在线 0、离线 1、告警 0
- 测试步骤
  1. 查看状态筛选项并尝试定位“未连接”选项。
  2. 选择数量为 0 的“告警”。
  3. 核对当前分组和列表渲染的 deviceId 数量。
- 预期结果
  1. 页面仅提供全部、在线、离线、告警四项，无法定位“未连接”独立选项。
  2. “告警”成为唯一选中项，筛选结果为 0 台。
  3. 分组仍为“东区组”，列表不展示 dev-2301，也不串入其他分组或其他状态设备。
