# US-015 筛选设备并打开快捷操作

> 口径依据：设备管理大纲第 2 节、第 10 节。设备状态仅展示在线、离线、告警三种，筛选项为全部、在线、离线、告警；未连接统一归入离线；在线与离线构成基础状态全集，告警可与在线或离线叠加；全部及各状态数量均按设备唯一标识去重。

## [P1] 验证在线离线基础状态数量覆盖当前账户全部设备
- 测试类型
  - 功能
- 前置条件
  1. 账号 corp_l1_01 当前可见 5 台唯一设备：deviceId=dev-1001、卡号 8600010001、备注“北门在线机”、在线且无告警；deviceId=dev-1002、卡号 8600010002、备注“南门离线机”、离线且无告警；deviceId=dev-1003、卡号 8600010003、备注“新绑未连接机”、未连接且无告警；deviceId=dev-1004、卡号 8600010004、备注“东区告警机”、告警且在线；deviceId=dev-1005、卡号 8600010005、备注“西区告警机”、告警且离线
  2. corp_l1_01 当前设备范围不存在其他可见设备
- 测试步骤
  1. 使用 corp_l1_01 进入设备首页，查看“全部 / 在线 / 离线 / 告警”数量。
  2. 分别统计在线基础状态和离线基础状态对应的唯一 deviceId。
  3. 核对“在线”数量与“离线”数量之和。
- 预期结果
  1. 顶部显示全部 5、在线 2、离线 3、告警 2。
  2. 在线设备为 dev-1001、dev-1004；离线设备为 dev-1002、dev-1003、dev-1005，未连接的 dev-1003 归入离线。
  3. 在线 2 + 离线 3 = 全部 5，告警数量不作为第三类基础状态重复加入等式。

## [P3][反向] 验证未连接设备不生成独立状态和额外数量
- 测试类型
  - 功能
- 前置条件
  1. 账号 personal_01 仅可见 deviceId=dev-1101、卡号 8600011001、备注“仓库新设备”，设备初始化绑定后无数据上报且未完成有效通信，当前状态为未连接
  2. personal_01 无其他可见设备
- 测试步骤
  1. 使用 personal_01 进入设备首页并查看状态筛选项。
  2. 查看 dev-1101 的卡片状态视觉和顶部数量。
  3. 核对页面是否出现“未连接”独立筛选项或独立计数。
- 预期结果
  1. 状态筛选仅有全部、在线、离线、告警，不出现“未连接”独立筛选项。
  2. dev-1101 以离线口径展示，顶部显示全部 1、在线 0、离线 1、告警 0。
  3. 页面不存在“未连接 1”或导致全部数量变为 2 的重复统计。

## [P1] 验证告警设备保留在线离线底层归属并优先展示告警
- 测试类型
  - 功能
- 前置条件
  1. 账号 corp_l2_01 可见 deviceId=dev-1201、卡号 8600012001、备注“牛舍温控机”，状态为告警且在线
  2. corp_l2_01 可见 deviceId=dev-1202、卡号 8600012002、备注“草场巡检机”，状态为告警且离线
  3. 当前范围仅有上述 2 台设备
- 测试步骤
  1. 使用 corp_l2_01 进入设备首页并查看顶部状态数量。
  2. 查看 dev-1201 和 dev-1202 卡片左侧设备图标的告警主体及在线、离线底层差异。
  3. 分别进入在线、离线、告警筛选核对两台设备的命中情况。
- 预期结果
  1. 顶部显示全部 2、在线 1、离线 1、告警 2。
  2. 两张卡片均通过左侧设备图标优先表达告警主体；dev-1201 保留在线底层差异，dev-1202 保留离线底层差异，卡片内不新增右侧状态文字标签。
  3. 在线命中 dev-1201，离线命中 dev-1202，告警同时命中 dev-1201、dev-1202。

## [P3][反向] 验证同一设备经多条可见关系时各状态数量不重复
- 测试类型
  - 可靠性
- 前置条件
  1. 账号 corp_l3_01 的服务端关系数据中存在 2 条指向同一 deviceId=dev-1301 的当前有效分配关系；该设备卡号为 8600013001、备注“重复关系告警机”，状态为告警且在线
  2. corp_l3_01 另可见 deviceId=dev-1302、卡号 8600013002、备注“单关系离线机”，状态为离线且无告警
  3. 服务端原始关系记录共 3 条，但唯一 deviceId 仅 dev-1301、dev-1302 两个
- 测试步骤
  1. 使用 corp_l3_01 进入设备首页，记录列表卡片 deviceId 和顶部数量。
  2. 进入在线筛选并统计 dev-1301 的卡片数。
  3. 进入告警筛选并统计 dev-1301 的卡片数。
  4. 进入全部筛选并核对唯一设备总数。
- 预期结果
  1. 列表仅展示 dev-1301、dev-1302 两张卡片，顶部显示全部 2、在线 1、离线 1、告警 1。
  2. 在线列表仅出现 1 张 dev-1301 卡片，数量为 1。
  3. 告警列表仅出现 1 张 dev-1301 卡片，数量为 1。
  4. 全部数量按 deviceId 去重为 2，不按 3 条关系记录计数。

## [P1] 验证告警与初始化未连接叠加时同时归入离线和告警并按 deviceId 去重
- 测试类型
  - 功能
- 前置条件
  1. 账号 corp_l2_03 的服务端关系数据中存在 2 条指向同一 deviceId=dev-1401的当前有效分配关系；卡号为 8600014001，备注“新绑告警未连接机”
  2. dev-1401初始化绑定后尚无数据上报且未完成有效通信，同时存在未处理告警，实际状态为告警 + 初始化未连接
  3. corp_l2_03 当前设备范围不存在其他唯一设备
- 测试步骤
  1. 使用 corp_l2_03进入设备首页，查看状态筛选项、顶部数量和列表卡片数。
  2. 选择“离线”筛选，核对 dev-1401的命中数量。
  3. 选择“告警”筛选，核对 dev-1401的命中数量。
  4. 核对页面是否出现“未连接”独立状态、筛选项或计数，并查询各数量的 deviceId 去重结果。
- 预期结果
  1. 顶部显示全部 1、在线 0、离线 1、告警 1，列表仅展示 1 张 dev-1401卡片。
  2. 离线筛选命中且仅命中 1 张 dev-1401卡片，初始化未连接归入离线口径。
  3. 告警筛选命中且仅命中 1 张 dev-1401卡片，同一设备同时计入离线和告警。
  4. 页面不提供“未连接”独立状态、筛选项或数量；全部、离线、告警均按 deviceId=dev-1401去重，不按 2 条关系重复展示或计数。
