# US-015 筛选设备并打开快捷操作

> 口径依据：设备管理大纲第 2.2、4.1、6.2、10 章。设备列表必须提供刷新、整群轨迹、分组管理和指令下发四类操作能力；各入口只能执行对应动作，刷新不得改变筛选上下文，分组管理沿用「当前分组栏 → Select Group → Manage Groups」链路，指令下发进入多选模式。本文件只验证入口完整性与路由，不扩展整群轨迹和批量指令专项规则。

## [P1] 验证设备列表四类操作均完整可达
- 测试类型
  - 功能
- 前置条件
  1. 企业一级账号 GT-E1-1521 当前可见 6 台设备，已选择真实分组「东区牧场」和状态「在线」
  2. 当前版本已配置设备列表刷新、整群轨迹、分组管理和指令下发能力
- 测试步骤
  1. 进入设备列表并记录当前页面全部列表级操作入口。
  2. 定位并检查刷新入口。
  3. 定位并检查整群轨迹入口。
  4. 通过当前分组栏打开 Select Group 并检查 Manage Groups，同时检查列表级指令下发入口。
- 预期结果
  1. 当前设备列表提供刷新、整群轨迹、分组管理和指令下发四类已确认操作能力，不因设备状态组合缺失其中一类。
  2. 刷新入口可操作且属于当前设备列表，不与单设备 More 菜单混淆。
  3. 整群轨迹入口可操作，不被错误替换成单设备历史轨迹入口。
  4. Manage Groups 可按正式链路进入，指令下发入口可进入多选模式；四类能力均可从设备列表上下文到达。

## [P1] 验证刷新设备列表保留状态分组关键词和滚动位置
- 测试类型
  - 易用性
- 前置条件
  1. 企业二级账号 GT-E2-1521 已选择状态「离线」、分组「西区牧场」、关键词「巡检」
  2. 当前交集结果包含 deviceId=GT-D-152101，列表滚动锚点为该设备
  3. 服务端已更新 GT-D-152101 的电量和最近更新时间，但设备关系及筛选条件未变化
- 测试步骤
  1. 点击设备列表刷新入口。
  2. 等待当前列表查询完成。
  3. 核对状态、分组、关键词和滚动锚点。
  4. 核对 GT-D-152101 的电量和最近更新时间。
- 预期结果
  1. 刷新请求使用当前账号及现有状态、分组、关键词上下文重新查询。
  2. 页面完成加载反馈并更新当前列表数据，不跳转到其他业务页面。
  3. 状态仍为「离线」、分组仍为「西区牧场」、关键词仍为「巡检」，滚动位置保持在 GT-D-152101 附近。
  4. GT-D-152101 展示服务端最新电量和最近更新时间，刷新不改变设备归属、分组或告警处理状态。

## [P1] 验证整群轨迹入口与单设备历史轨迹入口路由隔离
- 测试类型
  - 可靠性
- 前置条件
  1. 企业一级账号 GT-E1-1522 当前选择真实分组「北区牧场」
  2. 分组内存在 deviceId=GT-D-152111、GT-D-152112，GT-D-152111 的 More 菜单包含单设备历史轨迹入口
  3. 已开启客户端路由日志，可核对入口来源和页面类型
- 测试步骤
  1. 点击设备列表级整群轨迹入口并记录路由类型和当前分组上下文后返回。
  2. 打开 GT-D-152111 的 More 菜单并点击历史轨迹。
  3. 对比两次导航的入口来源、页面类型和身份参数。
  4. 返回设备列表并检查原筛选上下文。
- 预期结果
  1. 第一次进入整群轨迹目标页并携带当前账号和「北区牧场」分组上下文，不预先绑定为 GT-D-152111 的单设备页面。
  2. 第二次进入 deviceId=GT-D-152111 的单设备历史轨迹页。
  3. 两次导航类型和身份参数明确隔离，不因名称相似或上一次页面缓存发生串路由。
  4. 返回后继续保留原状态、分组、关键词和滚动位置。

## [P3][反向] 验证四类操作连续切换不会触发重复或错误动作
- 测试类型
  - 可靠性
- 前置条件
  1. 个人账号 GT-P-1521 当前设备列表存在 deviceId=GT-D-152121
  2. 已开启查询日志和页面路由日志，可统计刷新请求及目标页面实例
- 测试步骤
  1. 快速点击刷新入口两次并等待当前有效刷新完成。
  2. 点击当前分组栏进入 Select Group 后直接返回，不点击 Manage Groups。
  3. 点击指令下发进入多选模式后取消。
  4. 点击整群轨迹并核对最终页面栈和请求日志。
- 预期结果
  1. 刷新只更新设备列表，不打开轨迹、分组管理或指令页面；迟到旧响应不得覆盖当前有效刷新结果。
  2. 未点击 Manage Groups 时不进入分组管理页，也不改变当前分组筛选。
  3. 取消多选后不创建指令记录或设备副作用。
  4. 最终只新增一个整群轨迹页面实例，四类操作不会互相串路由或叠加重复页面。
