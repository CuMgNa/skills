# US-017 管理账户内设备分组
> 口径依据：大纲第 4.2、4.3、4.8、4.10、10 章。虚拟「全部分组」只用于设备首页筛选，不进入管理页且不能作为设备归属；允许创建同名真实一级组，一个设备在当前账户必须且只能归属一个真实一级、二级或三级组，分组关系按账户隔离。

## [P1] 验证虚拟全部分组仅用于筛选且不可作为设备归属
- 测试类型
  - 功能
- 前置条件
  1. personal01 有真实一级组「牧场东区」和设备 GT-D-0801
  2. GT-D-0801 当前归属「牧场东区」
- 测试步骤
  1. 在设备首页打开 Select Group 并选择虚拟「全部分组」。
  2. 进入 Device Groups 分组管理页查找「全部分组」。
  3. 打开 GT-D-0801 编辑页并查看所属分组候选项。
- 预期结果
  1. 虚拟「全部分组」可筛选 personal01 全部可见设备，但不改变 GT-D-0801 的真实归属。
  2. 管理页不展示虚拟「全部分组」及其增删改入口。
  3. 所属分组候选只包含真实业务组，虚拟「全部分组」不能被写入 groupId。

## [P1] 验证虚拟与真实同名全部分组的数量和选择范围可区分
- 测试类型
  - 功能
- 前置条件
  1. personal01 可见 GT-D-0801、GT-D-0802、GT-D-0803、GT-D-0804、GT-D-0805 共 5 台唯一设备
  2. 真实一级组「全部分组」直属 GT-D-0801、GT-D-0802，其他 3 台分别归属「牧场东区」及其后代组
- 测试步骤
  1. 打开 Select Group 查看两个「全部分组」条目。
  2. 选择固定置顶且无 Level 的虚拟「全部分组」。
  3. 再次打开选择器，选择显示 Level 1 的真实「全部分组」。
  4. 分别核对两次设备列表和当前分组标识。
- 预期结果
  1. 虚拟项显示数量 5、固定置顶且无 Level；真实项显示直属数量 2、Level 1，并使用独立真实 groupId。
  2. 选择虚拟项后列表显示 GT-D-0801 至 GT-D-0805 共 5 台。
  3. 选择真实同名组后列表只显示 GT-D-0801、GT-D-0802 共 2 台。
  4. 两次选择分别使用虚拟筛选语义和真实 groupId，不因名称相同混淆范围。

## [P3][反向] 验证设备不能同时归属两个真实分组或处于未分组状态
- 测试类型
  - 可靠性
- 前置条件
  1. personal01 有一级组「牧场东区」、二级组「牛群A区」和设备 GT-D-0806
  2. GT-D-0806 当前唯一 groupId 指向「牧场东区」
- 测试步骤
  1. 将 GT-D-0806 改组为「牛群A区」并完成整页保存。
  2. 查询当前账户下 GT-D-0806 的分组关系记录。
  3. 构造不带真实 groupId 的设备资料保存请求。
- 预期结果
  1. 保存成功后 GT-D-0806 从「牧场东区」迁移到「牛群A区」，不是新增第二个并存归属。
  2. personal01 下仅有一条有效真实分组关系，目标为「牛群A区」。
  3. 无真实 groupId 的保存被拒绝，不产生「未分组」状态，也不回退到虚拟「全部分组」。

## [P1] 验证同一物理设备在不同账户的分组关系相互隔离
- 测试类型
  - 功能
- 前置条件
  1. 设备 GT-D-0807 同时对 personal01 和 ent_l1_01 可见
  2. personal01 下归属「个人牛群」，ent_l1_01 下归属「企业牧场」
- 测试步骤
  1. personal01 将 GT-D-0807 改组为「个人隔离区」并保存。
  2. ent_l1_01 刷新设备列表和设备编辑页。
  3. 分别查询两个账户下 GT-D-0807 的 groupId。
- 预期结果
  1. personal01 的分组关系更新为「个人隔离区」。
  2. ent_l1_01 仍显示「企业牧场」，不跟随个人账户改组。
  3. 两个账户各保留一个独立真实 groupId，设备事实共享但账户分组不串改。
