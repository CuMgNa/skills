# US-017 管理账户内设备分组
> 口径依据：大纲第 4.7、4.8、4.10 章。选择器按分组名称做关键词包含匹配，仅展示命中项并保留数量、Level 和直接父组；单选后立即应用，无结果或取消不改变原筛选，每次打开重新获取最新服务端数据。

## [P1] 验证关键词包含匹配返回不同层级命中组
- 测试类型
  - 功能
- 前置条件
  1. ent_l2_15 有一级组「华南牧场」、二级组「广州牛群」、三级组「广州牛群A区」
  2. 三组直属设备数分别为 1、2、3
- 测试步骤
  1. 打开 Select Group 并输入关键词「广州」。
  2. 核对搜索结果条目。
  3. 核对每条结果的数量、Level 和直接父组信息。
- 预期结果
  1. 搜索按分组名称包含匹配执行。
  2. 仅显示命中的「广州牛群」「广州牛群A区」，不显示未命中的「华南牧场」。
  3. 二级组显示数量 2、Level 2、父组「华南牧场」；三级组显示数量 3、Level 3、父组「广州牛群」。

## [P2] 验证命中子组时不自动带出未命中祖先组
- 测试类型
  - 功能
- 前置条件
  1. 一级组「华东区域」下有二级组「苏州牧场」
  2. 二级组「苏州牧场」直属设备数为 4
- 测试步骤
  1. 在 Select Group 搜索「苏州」。
  2. 查看结果是否包含「华东区域」。
  3. 点击「苏州牧场」。
- 预期结果
  1. 搜索结果命中「苏州牧场」。
  2. 未命中的祖先组「华东区域」不作为额外结果展示，但「苏州牧场」仍显示父组信息。
  3. 选择器立即关闭并应用「苏州牧场」，设备列表仅加载其直属设备。

## [P3][反向] 验证搜索无结果不改变原分组筛选
- 测试类型
  - 功能
- 前置条件
  1. personal15 当前已选择真实一级组「东区牛群」
  2. 账户内不存在名称包含「不存在分组999」的分组
- 测试步骤
  1. 打开 Select Group 并输入「不存在分组999」。
  2. 查看无结果状态。
  3. 直接关闭选择器返回设备列表。
- 预期结果
  1. 搜索不命中任何分组。
  2. 页面展示无匹配分组提示，不自动选中虚拟「全部分组」。
  3. 返回后当前筛选仍为「东区牛群」，设备列表范围不变。

## [P2] 验证未选择直接返回保留原筛选
- 测试类型
  - 功能
- 前置条件
  1. personal15 当前筛选为「西区牛群」
  2. Select Group 可显示「东区牛群」「西区牛群」
- 测试步骤
  1. 打开 Select Group。
  2. 不点击任何分组，使用返回操作关闭选择器。
  3. 查看设备列表顶部当前分组和列表数据。
- 预期结果
  1. 选择器打开但尚未改变筛选。
  2. 返回操作仅关闭选择器，不提交默认项或首项。
  3. 当前分组仍为「西区牛群」，原列表数据保持不变。

## [P1] 验证重新打开选择器读取 Web 新增分组
- 测试类型
  - 可靠性
- 前置条件
  1. ent_l2_15 已打开过 Select Group，旧数据只有「华南牧场」
  2. Web 可为 ent_l2_15 创建二级组
- 测试步骤
  1. 关闭 Select Group 后在 Web 创建二级组「Web新增牛群」。
  2. APP 再次打开 Select Group。
  3. 搜索「Web新增」并选择该组。
- 预期结果
  1. Web 创建成功并写入服务端同一分组主数据。
  2. APP 重新查询后显示「Web新增牛群」，不被旧选择器缓存隐藏。
  3. 搜索命中并可单选该真实组，选择后立即应用其 groupId。
