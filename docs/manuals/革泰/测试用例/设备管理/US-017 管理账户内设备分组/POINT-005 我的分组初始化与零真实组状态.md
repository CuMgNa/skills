# US-017 管理账户内设备分组
> 口径依据：大纲第 4.2、4.4、4.10、9 章。账号初始化自动创建普通一级组「我的分组」；该组可改名、可在为空时删除，最后一个真实组删除后不自动重建并允许零真实组；已有业务组时绑定默认选择排序最靠前一级组，仅分配设备按精确名称创建或复用「我的分组」。

## [P1] 验证新账号初始化创建普通一级我的分组
- 测试类型
  - 功能
- 前置条件
  1. 新账号 personal08 已完成账号初始化但尚未进行分组操作
  2. personal08 当前没有设备
- 测试步骤
  1. personal08 首次进入 Select Group。
  2. 进入 Device Groups 查看真实分组。
  3. 查看「我的分组」的层级及操作入口。
- 预期结果
  1. 选择器包含虚拟「全部分组」和真实「我的分组」。
  2. 管理页展示一个真实一级「我的分组」，不展示虚拟项。
  3. 「我的分组」显示 Level 1，并具有与普通一级组相同的重命名和删除入口。

## [P1] 验证我的分组改名删除后不自动重建并释放名称
- 测试类型
  - 功能
- 前置条件
  1. personal08 仅有真实一级组「我的分组」且无设备、无子组
- 测试步骤
  1. 将「我的分组」重命名为「默认牛群」。
  2. 新增一个真实一级组，名称填写「我的分组」。
  3. 依次确认删除两个空组。
  4. 刷新管理页和选择器。
- 预期结果
  1. 原分组仅名称变为「默认牛群」，groupId 保持不变且系统不自动补建同名组。
  2. 已释放的「我的分组」名称可再次创建，并获得新的 groupId。
  3. 两个普通一级组均可按空组规则删除，包括账户最后一个真实组。
  4. 账户保持零真实组，选择器只剩虚拟「全部分组」，系统不自动重建「我的分组」。

## [P1] 验证已有分组绑定默认选择排序最靠前一级组且可改选任意真实层级
- 测试类型
  - 功能
- 前置条件
  1. personal09 有一级组「A牧场」排序值 1、一级组「B牧场」排序值 2
  2. 「B牧场」下有二级组「B牛群」，其下有三级组「B牛群一队」
  3. GT-D-0804 满足其他绑定条件
- 测试步骤
  1. 发起 GT-D-0804 绑定并进入确认页。
  2. 查看 Group 默认选中项。
  3. 将 Group 改选为三级组「B牛群一队」并保存。
- 预期结果
  1. 绑定确认页加载当前账户全部真实一级、二级、三级组。
  2. 默认选中排序最靠前的一级组「A牧场」，不默认选择二级、三级或虚拟项。
  3. 用户可改选三级真实组，绑定成功后 GT-D-0804 唯一归属「B牛群一队」。

## [P1] 验证零真实组绑定时创建新组并返回自动选中
- 测试类型
  - 功能
- 前置条件
  1. personal10 当前为零真实组状态
  2. 设备 GT-D-0805 已入库、类型支持、无同类槽位占用且 personal10 有剩余绑定配额
- 测试步骤
  1. personal10 发起 GT-D-0805 绑定并进入确认流程。
  2. 在无真实分组提示下进入 Device Groups，创建一级组「新建牛群」。
  3. 返回绑定确认页并提交绑定。
- 预期结果
  1. 绑定确认流程不能把虚拟「全部分组」作为默认归属，并引导进入同一分组管理页。
  2. 「新建牛群」创建成功后返回绑定流程并被自动选中。
  3. 绑定成功后 GT-D-0805 唯一归属真实组「新建牛群」，账户不再是零真实组状态。

## [P2] 验证仅分配设备按精确名称创建复用我的分组且不覆盖原数据
- 测试类型
  - 功能
- 前置条件
  1. ent_l2_08 已有一级组「我的分组␠」承载 GT-D-0801，其中 ␠ 表示名称末尾一个 U+0020 空格
  2. ent_l2_08 已有一级组「我的分组-历史」承载 GT-D-0802，以及一级组「既有牛群」承载 GT-D-0803
  3. ent_l1_08 可向 ent_l2_08 仅分配 GT-D-0806、GT-D-0807，当前不存在精确名称「我的分组」
- 测试步骤
  1. 仅分配 GT-D-0806 给 ent_l2_08。
  2. 核对新建分组、原有三个分组及 GT-D-0801 至 GT-D-0803 的归属。
  3. 再仅分配 GT-D-0807 给 ent_l2_08。
  4. 查询精确名称「我的分组」的记录数和两台新设备归属。
- 预期结果
  1. 近似名称不算精确命中，系统新建普通一级组「我的分组」承接 GT-D-0806。
  2. 「我的分组␠」「我的分组-历史」「既有牛群」及其原设备关系全部保留，不被全量覆盖或迁移。
  3. 第二次分配复用新建的精确同名组，不重复创建。
  4. 精确名称记录数为 1，GT-D-0806、GT-D-0807 均归属该组，原三台设备仍保持原归属。
