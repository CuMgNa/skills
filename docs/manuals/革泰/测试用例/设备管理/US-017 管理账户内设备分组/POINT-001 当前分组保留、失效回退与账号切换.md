# US-017 管理账户内设备分组
> 口径依据：大纲第 4.1、4.8、4.10、9、10 章。同一登录会话保留上次有效分组；获取最新数据后，当前 groupId 已删除或失权则回退虚拟「全部分组」并刷新，失败查询不能误判失效；切换账号不得复用上一账号筛选或泄露分组设备。

## [P1] 验证同一会话和管理页返回时保留有效 groupId
- 测试类型
  - 功能
- 前置条件
  1. personal16 已选择真实一级组「南区牛群」，groupId 为 G-L1-1601
  2. 「南区牛群」直属 2 台设备且 personal16 仍有权限
- 测试步骤
  1. 从设备首页进入其他业务页面后返回。
  2. 从 Select Group 进入 Manage Groups，再返回设备首页。
  3. 核对当前分组、设备列表和服务端查询记录。
- 预期结果
  1. 同一登录会话返回后仍选择 G-L1-1601，不重置为虚拟「全部分组」。
  2. 管理页返回触发重新查询；因 groupId 仍有效，继续保留「南区牛群」。
  3. 列表仍显示该组 2 台直属设备，查询按 groupId 而非名称恢复筛选。

## [P3][反向] 验证当前分组被删除后回退全部分组并刷新具体数量
- 测试类型
  - 可靠性
- 前置条件
  1. personal16 当前选择空组「临时筛选组」，groupId 为 G-L1-1603
  2. personal16 全部可见设备 6 台，其中在线 2 台、离线含未连接 4 台、告警 1 台
- 测试步骤
  1. 在 APP 保持设备首页不刷新，在 Web 删除 G-L1-1603。
  2. APP 重新进入 Select Group 或从管理页返回。
  3. 核对当前筛选、提示、设备列表和顶部状态数量。
- 预期结果
  1. 服务端删除成功后 G-L1-1603 已失效，APP 旧缓存不能继续作为有效选择。
  2. APP 获取最新数据后回退虚拟「全部分组」并提示原分组已失效。
  3. 列表显示 6 台，顶部数量依次为全部 6、在线 2、离线 4、告警 1。

## [P3][反向] 验证当前分组失权后回退且不泄露原组设备
- 测试类型
  - 安全性
- 前置条件
  1. ent_l2_16 当前选择真实组「受限牛群」，groupId 为 G-L2-1604，直属 GT-D-0861 在线、GT-D-0862 离线且告警
  2. ent_l2_16 除该组外仍有权查看 GT-D-0863 在线、GT-D-0864 未连接并按离线统计
- 测试步骤
  1. 在 Web 撤销 ent_l2_16 对 G-L2-1604 及 GT-D-0861、GT-D-0862 的访问关系，但不删除分组主数据。
  2. APP 重新打开 Select Group 获取最新权限范围。
  3. 核对当前选择、选择器结果、设备列表和顶部状态数量。
- 预期结果
  1. G-L2-1604 因当前账号失权而失效，服务端不再向 ent_l2_16 返回该组及两台设备。
  2. APP 回退虚拟「全部分组」并提示原分组已失效，选择器不展示「受限牛群」。
  3. 列表仅显示 GT-D-0863、GT-D-0864，顶部数量依次为全部 2、在线 1、离线 1、告警 0，不泄露 GT-D-0861、GT-D-0862 的名称、数量或状态。

## [P3][反向] 验证最新分组查询失败时不误判当前组已失效
- 测试类型
  - 可靠性
- 前置条件
  1. personal16 当前选择有效组「缓存保留组」
  2. 本次重新打开 Select Group 时模拟接口超时
- 测试步骤
  1. 打开 Select Group 触发最新数据查询。
  2. 等待接口超时并关闭失败提示。
  3. 返回设备列表查看当前筛选。
- 预期结果
  1. APP 发起查询但未取得可用于判断删除或失权的成功结果。
  2. 页面展示可重试失败提示，不用空数组认定「缓存保留组」已失效。
  3. 当前有效页面状态和「缓存保留组」筛选保持不变，不错误回退「全部分组」。

## [P1] 验证切换登录账号后不复用上一账号分组
- 测试类型
  - 安全性
- 前置条件
  1. personal16 上次选择分组「南区牛群」
  2. personal17 仅有真实组「北区牛群」，且没有「南区牛群」
- 测试步骤
  1. 退出 personal16 并登录 personal17。
  2. 进入 personal17 设备首页。
  3. 打开 Select Group 查看当前项和可见分组。
- 预期结果
  1. 账号切换清除 personal16 的分组筛选上下文。
  2. personal17 首次进入默认选择虚拟「全部分组」。
  3. 选择器只展示 personal17 的虚拟项和「北区牛群」，不泄露或复用「南区牛群」。
