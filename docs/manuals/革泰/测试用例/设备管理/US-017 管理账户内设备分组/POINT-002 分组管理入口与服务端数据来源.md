# US-017 管理账户内设备分组
> 口径依据：大纲第 4.1、4.3、4.10、9、10 章。分组管理唯一常规入口为设备列表的分组选择器内 Manage Groups；选择器和管理页分别重新请求当前账号的服务端分组主数据，包含空组及 Web 创建的二、三级组，并按账号隔离。

## [P1] 验证常规页面检查范围内仅分组选择器提供管理入口
- 测试类型
  - 功能
- 前置条件
  1. 账号 personal01 已登录 APP 并进入设备首页
  2. 已启用页面导航与点击事件记录
- 测试步骤
  1. 检查设备首页顶部导航、设备卡片本体、卡片右上角更多菜单和页面底部操作区。
  2. 检查「我的」页面、首页全局菜单和无设备空状态页。
  3. 点击设备列表当前分组栏打开 Select Group。
  4. 点击 Select Group 底部 Manage Groups。
- 预期结果
  1. 所列设备首页区域均不展示 Manage Groups 或其他分组管理入口，卡片入口不会导航到 Device Groups。
  2. 「我的」、全局菜单和无设备空状态均不提供分组管理常规入口。
  3. Select Group 正常打开，底部唯一展示 Manage Groups 入口。
  4. 进入 Device Groups 分组管理页，导航记录仅对应「设备列表→Select Group→Manage Groups」。

## [P1] 验证选择器和管理页分别请求最新服务端分组数据
- 测试类型
  - 功能
- 前置条件
  1. personal01 服务端存在一级组「牧场东区」
  2. 已记录分组选择器查询和分组管理页查询的请求次数
- 测试步骤
  1. 点击当前分组栏打开 Select Group。
  2. 在服务端新增一级组「牧场西区」后点击 Manage Groups。
  3. 核对 Device Groups 页面及两次分组查询记录。
- 预期结果
  1. Select Group 打开时完成第一次查询并展示「牧场东区」。
  2. Manage Groups 进入管理页时重新发起第二次全量查询，不只复用选择器快照。
  3. 管理页展示「牧场东区」「牧场西区」，两次请求均使用 personal01 的有效会话范围。

## [P1] 验证新增弹窗固定创建无父组的一级分组
- 测试类型
  - 功能
- 前置条件
  1. personal01 已进入 Device Groups
  2. personal01 不存在名称「新增一级牛群」的分组
- 测试步骤
  1. 点击 Device Groups 标题栏加号打开新增弹窗。
  2. 检查弹窗可填写和可选择字段。
  3. 输入「新增一级牛群」并保存。
  4. 查询新增分组的 groupId、Level 和 parentId。
- 预期结果
  1. 打开新增一级组弹窗。
  2. 弹窗只提供名称输入，不提供 Level 或父组选择控件。
  3. 保存成功后管理页新增「新增一级牛群」并显示 Level 1。
  4. 服务端记录 Level 为 1、parentId 为空，不会挂到现有一级、二级或三级组下。

## [P1] 验证管理页展示空组和 Web 创建的二三级组
- 测试类型
  - 功能
- 前置条件
  1. ent_l2_01 名下存在一级组「华南牧场」、Web 创建的二级组「广州区」和三级空组「天河区」
  2. 「天河区」直属设备数为 0，当前设备列表未返回该组设备
- 测试步骤
  1. 使用 ent_l2_01 进入 Device Groups 分组管理页。
  2. 核对「华南牧场」「广州区」「天河区」的层级和父组信息。
  3. 核对页面是否展示虚拟「全部分组」及设备数量行。
- 预期结果
  1. 页面从分组主数据返回并展示三个真实分组，空组「天河区」不会因设备列表为空而消失。
  2. 「广州区」显示 Level 2 且直属父组为「华南牧场」；「天河区」显示 Level 3 且直属父组为「广州区」。
  3. 管理页不展示虚拟「全部分组」，也不展示 Devices: 0 或其他设备数量行。

## [P3][反向] 验证越权参数和查询失败均不污染当前账号数据
- 测试类型
  - 安全性
- 前置条件
  1. personal01 名下存在「个人牧场」，personal02 名下存在「他人牧场」
  2. personal01 上次成功加载「个人牧场」，本次可模拟接口超时
- 测试步骤
  1. 将分组请求中的可修改账号参数替换为 personal02 后发起查询。
  2. 使用 personal01 正常打开 Manage Groups 并模拟接口超时。
  3. 查看失败页面后恢复服务并点击重试。
- 预期结果
  1. 服务端按 personal01 有效会话鉴权，不返回 personal02 的「他人牧场」。
  2. 页面保留上次有效的「个人牧场」并展示可重试提示，不用空数组冒充零分组。
  3. 重试后只展示 personal01 最新全量分组，越权响应或失败缓存均不写入当前页面。
