# US-017 管理账户内设备分组
> 口径依据：大纲第 4.6、4.8、4.10、8 章。一级、二级、三级真实组均展示删除入口，仅在无子组且无直属设备时可二次确认删除；服务端实时校验先子组、后直属设备，删除不级联、不迁移，当前筛选组删除后回退虚拟「全部分组」。

## [P3][反向] 验证二级组同时有三级子组和直属设备时优先提示子组阻塞
- 测试类型
  - 功能
- 前置条件
  1. ent_l1_13 的一级组「综合牧场」下有二级组「牛群一区」，其下有三级组「犊牛一队」
  2. GT-D-0821 直属二级组「牛群一区」
- 测试步骤
  1. 在 Device Groups 核对一级「综合牧场」、二级「牛群一区」、三级「犊牛一队」均展示红色删除入口。
  2. 点击二级组「牛群一区」的删除按钮。
  3. 查看服务端校验结果并查询父子组和 GT-D-0821 归属。
- 预期结果
  1. APP 对三个真实层级均提供删除入口，不因层级或创建端隐藏。
  2. 服务端先命中三级子组条件，只提示先处理子分组，不进入二次确认，也不混合直属设备提示。
  3. 三个分组及 GT-D-0821 原归属全部保留，不发生级联删除或迁移。

## [P3][反向] 验证三级组有直属设备时提示先迁移设备
- 测试类型
  - 功能
- 前置条件
  1. personal13 的三级组「犊牛二队」没有下一层子组
  2. GT-D-0822 唯一直属「犊牛二队」
- 测试步骤
  1. 点击三级组「犊牛二队」的红色删除按钮。
  2. 查看是否进入二次确认及阻塞原因。
  3. 查询 GT-D-0822 的 groupId 和三级组记录。
- 预期结果
  1. 服务端跳过不存在的下一层子组后校验直属设备。
  2. 不弹出可确认删除对话框，页面提示先迁移组内设备。
  3. 三级组和 GT-D-0822 原 groupId 均不变，不产生未分组状态。

## [P1] 验证空三级组取消后可再次确认删除
- 测试类型
  - 功能
- 前置条件
  1. personal13 的三级组「待删除空组」无子组且无直属设备
- 测试步骤
  1. 点击「待删除空组」删除按钮并在二次确认中选择取消。
  2. 再次点击删除并核对确认框中的分组名称。
  3. 点击确认删除并刷新管理页。
  4. 查询「待删除空组」的服务端记录和其父组。
- 预期结果
  1. 取消后三级组完整保留，未提交删除副作用。
  2. 确认框明确展示「待删除空组」，目标 groupId 未串到父组或同级组。
  3. 确认后三级空组删除成功，管理页不再展示该组。
  4. 目标 groupId 已删除，直属父组继续存在且结构不变。

## [P1] 验证删除当前筛选空组后回退全部分组并刷新状态数量
- 测试类型
  - 功能
- 前置条件
  1. personal13 当前设备首页筛选空一级组「临时空组」，该组无子组且无直属设备
  2. personal13 全部可见设备共 5 台，其中在线 2 台、离线含未连接 3 台、告警 2 台
- 测试步骤
  1. 从当前分组选择器进入 Manage Groups，删除「临时空组」并确认。
  2. 返回设备首页等待分组和设备数据刷新。
  3. 核对当前分组、设备列表及顶部全部、在线、离线、告警数量。
- 预期结果
  1. 「临时空组」删除成功，原筛选 groupId 立即失效。
  2. APP 自动切换到虚拟「全部分组」，不保留已删除名称或进入未分组状态。
  3. 列表显示 5 台唯一设备，顶部数量依次为全部 5、在线 2、离线 3、告警 2。

## [P3][反向] 验证二次确认后删除接口失败时保留分组和当前筛选直至重试成功
- 测试类型
  - 可靠性
- 前置条件
  1. personal13 当前设备首页筛选空一级组「重试删除组」，groupId 为 G-L1-1302，该组无子组且无直属设备
  2. personal13 全部可见设备共 5 台；服务端可模拟 G-L1-1302 第一次删除返回 HTTP 500 和可读原因「分组服务暂时不可用」，第二次删除成功
- 测试步骤
  1. 从当前分组选择器进入 Manage Groups，点击「重试删除组」删除并完成二次确认。
  2. 等待第一次删除接口失败，核对管理页提示及服务端分组记录。
  3. 返回设备首页核对当前分组筛选，再进入管理页对同一 groupId 重试删除并确认。
  4. 待第二次删除成功后返回设备首页，核对分组、列表和顶部状态数量。
- 预期结果
  1. 二次确认后才提交第一次删除请求；请求处理中不得提前从本地移除分组或回退筛选。
  2. 接口失败后 G-L1-1302 与「重试删除组」完整保留，页面展示可读原因「分组服务暂时不可用」和重试能力。
  3. 第一次失败后当前筛选仍为「重试删除组」，不提前切换虚拟「全部分组」；重试继续使用 G-L1-1302，不串到其他组。
  4. 仅第二次服务端删除成功后移除该组并回退虚拟「全部分组」，再刷新 5 台设备及对应状态数量；不存在失败阶段的部分删除或筛选闪退。

## [P3][反向] 验证旧页面空组在并发新增子组后按实时状态拒绝删除
- 测试类型
  - 可靠性
- 前置条件
  1. APP 已加载一级空组「并发父组」，groupId 为 G-L1-1301
  2. Web 可在 G-L1-1301 下创建二级组
- 测试步骤
  1. 保持 APP 管理页不刷新，在 Web 创建二级组「并发子组」。
  2. APP 在旧页面点击「并发父组」删除。
  3. 刷新 APP 并查询父子组记录。
- 预期结果
  1. Web 创建成功后服务端最新状态已存在子组，APP 旧快照不代表可删除。
  2. 删除请求被实时子组校验拦截并提示先处理子分组，不进入确认删除成功态。
  3. 刷新后同时显示「并发父组」和「并发子组」，缓存不会造成误删。

## [P3][反向] 验证二次确认后并发加入直属设备时服务端重新阻止删除
- 测试类型
  - 可靠性
- 前置条件
  1. APP 已对空一级组「并发设备组」打开删除二次确认，groupId 为 G-L1-1303
  2. 在用户尚未点击最终确认时，Web 可将设备 GT-D-0825 改组至 G-L1-1303
- 测试步骤
  1. 保持 APP 删除确认弹窗打开，在 Web 将 GT-D-0825 保存到「并发设备组」。
  2. APP 点击最终确认删除。
  3. 查询删除请求的实时校验结果。
  4. 刷新 APP 分组管理页和设备首页。
- 预期结果
  1. Web 改组成功后服务端最新状态为该组存在一台直属设备。
  2. 最终删除请求不得沿用弹窗打开时的空组快照直接删除。
  3. 服务端重新校验直属设备并拒绝删除，提示先迁移组内设备。
  4. G-L1-1303 与 GT-D-0825 的归属完整保留，设备不进入未分组状态。
