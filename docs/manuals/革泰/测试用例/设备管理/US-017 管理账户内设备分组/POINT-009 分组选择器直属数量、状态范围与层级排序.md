# US-017 管理账户内设备分组
> 口径依据：大纲第 4.1、4.3、4.7、4.8、4.10、10 章。选择器展示服务端返回的账户全部设备去重数和各组直属设备数，父组筛选及状态数量不聚合后代；管理页不显示数量；虚拟项固定置顶，真实组按父子连续平铺并使用已确认排序值、无排序值时按创建时间升序。

## [P1] 验证重复可见关系按设备标识去重且父组状态只统计直属设备
- 测试类型
  - 功能
- 前置条件
  1. ent_l1_14 原始可见关系共 6 条：GT-D-0831 两条、GT-D-0832 两条、GT-D-0833 一条、GT-D-0834 一条，对应 4 个唯一设备标识
  2. 一级组「广东省」直属 GT-D-0831 在线无告警、GT-D-0832 离线且告警
  3. 二级组「广州市」直属 GT-D-0833 在线且告警，三级组「天河区」直属 GT-D-0834 未连接并按离线统计
- 测试步骤
  1. 打开 Select Group 核对虚拟「全部分组」和三个业务组数量。
  2. 选择一级组「广东省」。
  3. 核对设备列表和顶部全部、在线、离线、告警数量。
  4. 切换到虚拟「全部分组」并核对设备唯一标识集合。
- 预期结果
  1. 虚拟项显示 4；「广东省」显示直属数 2，「广州市」显示 1，「天河区」显示 1，重复可见关系不重复计数。
  2. 列表只显示 GT-D-0831、GT-D-0832，不聚合二级和三级设备。
  3. 顶部数量依次为全部 2、在线 1、离线 1、告警 1，告警与在线或离线叠加而不计为第三种通信状态。
  4. 全部分组列表恰好显示 GT-D-0831 至 GT-D-0834 共 4 台，每个设备唯一标识一条记录。

## [P1] 验证设备数量只在选择器展示而管理页不展示
- 测试类型
  - 易用性
- 前置条件
  1. personal14 的一级组「东区」直属 3 台设备，一级组「西区」直属 0 台设备
- 测试步骤
  1. 打开 Select Group 查看「东区」「西区」。
  2. 点击 Manage Groups 进入管理页。
  3. 核对两个分组卡片的展示字段。
- 预期结果
  1. 选择器中「东区」显示 3、「西区」显示 0。
  2. 管理页展示两个真实分组，但不沿用选择器数量行。
  3. 分组卡片只展示名称、Level、必要父组信息及重命名和删除入口，不展示 Devices: 3、Devices: 0 或其他设备数量。

## [P1] 验证有排序值的一级组和同父子组按服务端排序值展示
- 测试类型
  - 功能
- 前置条件
  1. ent_l1_14 的一级组「浙江省」排序值为 10，「广东省」排序值为 20
  2. 「广东省」下二级组「深圳市」排序值为 1，「广州市」排序值为 2
  3. 「广州市」下三级组「天河区」排序值为 1
- 测试步骤
  1. 打开 Select Group 并记录虚拟项后的业务组顺序。
  2. 核对「广东省」后代的连续平铺顺序。
  3. 进入 Manage Groups 核对同源结构顺序。
- 预期结果
  1. 虚拟「全部分组」固定第一；业务一级组按排序值显示「浙江省」后「广东省」。
  2. 「广东省」后连续显示「深圳市」「广州市」「天河区」，不会先跳到下一一级组；同父二级按排序值 1、2 排列。
  3. 管理页按同一父子结构展示，Level 和直接父组信息与 groupId 关系一致。

## [P1] 验证分页和部分加载时直属设备数始终使用服务端统计字段
- 测试类型
  - 可靠性
- 前置条件
  1. ent_l1_14 共可见 73 台唯一设备，设备列表分页大小为 20，当前客户端仅加载第一页 20 台
  2. 一级组「北方牧场」服务端统计直属设备数 `directDeviceCount=37`，其中第一页仅出现 8 台该组设备
  3. 当前切换到状态「在线」并输入设备关键词「牦牛-命中」，列表交集只剩 GT-D-0861、GT-D-0862、GT-D-0863 共 3 台；该组其余设备的设备编号、名称、备注、序列号均不命中该关键词
- 测试步骤
  1. 在只加载第一页时打开 Select Group，记录分组查询响应中的账户总数和「北方牧场」直属统计字段。
  2. 核对虚拟「全部分组」和「北方牧场」括号数量。
  3. 保持选择器关闭，切换在线状态并输入关键词「牦牛-命中」，确认设备列表缩小为 3 台后再次打开 Select Group。
  4. 加载设备列表第二页后再次打开 Select Group，并对比三次分组查询和展示数量。
- 预期结果
  1. 分组查询返回账户全部设备去重数 73 和「北方牧场」`directDeviceCount=37`，统计口径不依赖当前已加载设备页。
  2. 虚拟「全部分组」显示 73，「北方牧场」显示 37，不得按当前页 20、当前页命中的 8 台或客户端遍历结果计算。
  3. 状态与设备关键词只把列表缩小为 GT-D-0861～GT-D-0863；重新打开选择器仍显示 73 和 37，不随当前状态或关键词缩小。
  4. 加载第二页不会使分组数量递增或重算；三次均直接展示服务端统计字段，客户端不得遍历当前页或已加载页拼装直属设备数。

## [P4] 验证无排序值的同级组按创建时间升序展示
- 测试类型
  - 功能
- 前置条件
  1. personal14 的一级组「早建牧场」创建于 2026-10-01 09:00:00，无排序值
  2. personal14 的一级组「晚建牧场」创建于 2026-10-02 09:00:00，无排序值
  3. 两组没有子组
- 测试步骤
  1. 打开 Select Group 查看两个一级组顺序。
  2. 关闭后重新打开 Select Group。
  3. 进入 Manage Groups 查看顺序。
- 预期结果
  1. 无排序值时按创建时间升序显示「早建牧场」后「晚建牧场」。
  2. 重开选择器后顺序保持一致，不因客户端缓存或设备数变化随机抖动。
  3. 管理页读取服务端结构后保持相同创建时间顺序，不扩展未确认的排序冲突裁决。
