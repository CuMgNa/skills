# US-016 绑定牛马定位器

> 口径依据：设备管理大纲第 1.1～1.3、3.1.1、9 节及第 10 节关键规则。四类业务账号均可登录 APP，但只有个人账号和企业一级账号显示“设备管理 → 绑定设备”入口；企业二级、三级账号只读取直属父级逐级分配的设备，APP 不提供企业向下分配入口。

## [P1] 验证个人账号登录后仅在设备管理显示绑定入口
- 测试类型
  - 功能
- 前置条件
  1. 个人账号 GT-P-1001 状态为正常，可登录 APP，当前直接绑定设备数量为 0，服务端 bindingQuota 为 2
  2. 已入库牛马定位器 deviceId 为 GT-DEV-010001，设备卡号为 898604121000010001，备注为“北场黑马”，通信状态为离线
- 测试步骤
  1. 使用 GT-P-1001 登录 APP，核对首页和无设备空状态中的快捷入口。
  2. 进入“设备管理”，核对“绑定设备”入口及当前设备数量。
  3. 点击“绑定设备”，手动输入卡号 898604121000010001并进入设备查询流程。
- 预期结果
  1. GT-P-1001 登录成功；首页和无设备空状态不出现新增的绑定或全局扫码快捷入口。
  2. “设备管理”显示“绑定设备”，设备数量为 0。
  3. 系统按当前个人账号进入统一绑定校验流程，查询到 deviceId GT-DEV-010001，关系落点为 GT-P-1001而非其他账号。

## [P1] 验证企业一级账号登录后具备直接绑定入口
- 测试类型
  - 功能
- 前置条件
  1. 企业一级账号 GT-E1-1001 状态为正常，可登录 APP，当前直接绑定设备数量为 1，服务端 bindingQuota 为 3
  2. GT-E1-1001 已绑定 deviceId GT-DEV-010002，卡号 898604121000010002，备注“总部白马”，通信状态为在线
  3. 待查询设备 deviceId 为 GT-DEV-010003，卡号为 898604121000010003，备注为“东区黄牛”，通信状态为离线
- 测试步骤
  1. 使用 GT-E1-1001 登录 APP 并进入“设备管理”。
  2. 核对设备列表数量、已绑定设备 GT-DEV-010002和“绑定设备”入口。
  3. 点击“绑定设备”，扫码取得卡号 898604121000010003并进入设备查询流程。
- 预期结果
  1. GT-E1-1001 登录成功并进入企业一级账号视角。
  2. 列表显示 1 台设备 GT-DEV-010002，备注为“总部白马”、通信状态为在线，同时显示“绑定设备”入口。
  3. 系统按企业一级绑定槽位和 GT-E1-1001剩余 2 个 bindingQuota 进入统一校验流程，待建立关系的目标账号为 GT-E1-1001。

## [P3][反向] 验证企业二级和三级账号登录后不获得直接绑定入口
- 测试类型
  - 安全性
- 前置条件
  1. 企业二级账号 GT-E2-2101 状态为正常，直属一级为 GT-E1-1001，已获分配设备 GT-DEV-010004，卡号 898604121000010004，备注“二级巡检牛”，通信状态为在线，设备数量为 1
  2. 企业三级账号 GT-E3-3101 状态为正常，直属二级为 GT-E2-2101，已获分配同一设备 GT-DEV-010004，设备数量为 1
- 测试步骤
  1. 使用 GT-E2-2101 登录 APP，进入“设备管理”并核对设备列表和全部可操作入口。
  2. 使用 GT-E3-3101 登录 APP，进入“设备管理”并核对设备列表和全部可操作入口。
  3. 分别核对 GT-E2-2101、GT-E3-3101 的设备关系类型和 bindingQuota 消耗数量。
- 预期结果
  1. GT-E2-2101 登录成功并显示 1 台已分配设备 GT-DEV-010004，但不显示“绑定设备”和向下分配入口。
  2. GT-E3-3101 登录成功并显示 1 台已分配设备 GT-DEV-010004，但不显示“绑定设备”和向下分配入口。
  3. 两个账号的关系均为分配关系，直接绑定关系数量为 0，bindingQuota 消耗数量为 0。

## [P3][反向] 验证企业子账号零设备边界不追加权限说明或绑定入口
- 测试类型
  - 易用性
- 前置条件
  1. 企业二级账号 GT-E2-2201 状态为正常，直属一级为 GT-E1-1001，当前获分配设备数量为 0
  2. 设备 GT-DEV-010005 已入库，卡号为 898604121000010005，备注为“未分配灰马”，通信状态为离线，但未分配给 GT-E2-2201
- 测试步骤
  1. 使用 GT-E2-2201 登录 APP 并进入“设备管理”。
  2. 核对设备空状态的文案、按钮和可操作入口。
  3. 搜索卡号 898604121000010005或备注“未分配灰马”。
- 预期结果
  1. GT-E2-2201 登录成功，设备列表数量为 0。
  2. 页面沿用普通设备空状态，不显示“绑定设备”、全局扫码、“联系上级分配”或企业向下分配入口。
  3. 搜索结果数量为 0，不因设备已入库而将未分配的 GT-DEV-010005加入当前账号可见范围。

## [P3][反向] 验证企业二级和三级在监控平台 Web 无直接绑定入口
- 测试类型
  - 安全性
- 前置条件
  1. 企业二级账号 GT-E2-2202 和企业三级账号 GT-E3-3202 状态正常，均可登录监控平台 Web
  2. 两个账号各自存在父级分配设备，直接绑定关系数量均为 0
- 测试步骤
  1. 使用 GT-E2-2202 登录监控平台 Web，检查设备管理、空状态和全局操作区域。
  2. 使用 GT-E3-3202 登录监控平台 Web，检查相同区域。
  3. 核对两个账号的设备关系类型和可操作入口。
- 预期结果
  1. GT-E2-2202 可正常查看父级分配设备，但 Web 不展示直接绑定入口。
  2. GT-E3-3202 可正常查看直属二级分配设备，但 Web 不展示直接绑定入口。
  3. 两个账号只保留分配关系和相应设备业务能力，不因可登录 Web 获得直接绑定权。
