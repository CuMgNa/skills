# US-016 绑定牛马定位器

> 口径依据：大纲第 3.1.5、3.2、第 9～10 章。激活状态、无 SIM、SIM 未激活、停机、已拆机或异常、设备离线和从未上报均不是绑定前置；其他准入条件满足时必须建立归属，绑定后状态按实际数据展示。

## [P1] 验证设备未激活仍可完成绑定
- 测试类型
  - 功能
- 前置条件
  1. 个人账号 person_status_01 配额和个人槽位可用，拥有真实一级分组「未激活设备组」
  2. 管理后台已入库牛马定位器 GT-CARD-7001，设备激活状态为未激活
  3. person_status_01 未绑定 GT-CARD-7001
- 测试步骤
  1. 在 APP 绑定页输入 GT-CARD-7001 并提交。
  2. 选择「未激活设备组」并确认绑定。
  3. 刷新设备列表和详情，查看激活及通信相关展示。
- 预期结果
  1. 未激活状态不参与绑定拦截，系统继续完成其他前置校验并进入确认页。
  2. GT-CARD-7001 成功建立 person_status_01 的直接绑定关系。
  3. 列表和详情按实际状态展示，不因绑定成功伪造已激活或在线数据。

## [P1] 验证五类非正常 SIM 状态均不阻断绑定
- 测试类型
  - 兼容性
- 前置条件
  1. 企业一级账号 ent_l1_status_01 的服务端剩余直接绑定名额不少于 5，拥有真实一级分组「SIM 状态组」
  2. 已入库牛马定位器 GT-CARD-7101 无 SIM、GT-CARD-7102 SIM 未激活、GT-CARD-7103 SIM 停机、GT-CARD-7104 SIM 已拆机、GT-CARD-7105 SIM 状态异常
  3. 五台设备均未被 ent_l1_status_01 绑定且企业一级槽位可用
- 测试步骤
  1. 输入 GT-CARD-7101，选择「SIM 状态组」并确认绑定。
  2. 输入 GT-CARD-7102，选择「SIM 状态组」并确认绑定。
  3. 输入 GT-CARD-7103，选择「SIM 状态组」并确认绑定。
  4. 输入 GT-CARD-7104，选择「SIM 状态组」并确认绑定。
  5. 输入 GT-CARD-7105，选择「SIM 状态组」并确认绑定。
- 预期结果
  1. GT-CARD-7101 不因无 SIM 被拦截，成功建立一条绑定关系。
  2. GT-CARD-7102 不因 SIM 未激活被拦截，成功建立一条绑定关系。
  3. GT-CARD-7103 不因 SIM 停机被拦截，成功建立一条绑定关系。
  4. GT-CARD-7104 不因 SIM 已拆机被拦截，成功建立一条绑定关系。
  5. GT-CARD-7105 不因 SIM 状态异常被拦截，成功建立一条绑定关系；五台设备后续通信能力仍按实际状态处理。

## [P1] 验证在线离线和从未上报设备均可绑定
- 测试类型
  - 功能
- 前置条件
  1. 个人账号 person_status_02 的服务端剩余直接绑定名额不少于 3，拥有真实一级分组「通信状态组」
  2. 已入库牛马定位器 GT-CARD-7201 当前在线、GT-CARD-7202 当前离线、GT-CARD-7203 从未产生定位或通信上报
  3. 三台设备均未被 person_status_02 绑定且个人槽位可用
- 测试步骤
  1. 将 GT-CARD-7201 绑定到「通信状态组」。
  2. 将 GT-CARD-7202 绑定到「通信状态组」。
  3. 将 GT-CARD-7203 绑定到「通信状态组」。
  4. 刷新列表并核对三台设备的通信状态和位置数据展示。
- 预期结果
  1. 在线状态不作为额外准入条件，GT-CARD-7201 绑定成功。
  2. 离线状态不阻断绑定，GT-CARD-7202 绑定成功。
  3. 无定位和通信上报不阻断绑定，GT-CARD-7203 绑定成功。
  4. 三台设备均可见；GT-CARD-7202 和未明确在线的 GT-CARD-7203 按离线口径展示，不伪造位置、轨迹或有效通信数据。
