# US-016 绑定牛马定位器

> 口径依据：大纲第 1.3～1.4、3.1.2、3.1.6、3.2、第 8～10 章。绑定成功后 APP 与监控平台 Web 读取同一直接绑定关系，并刷新列表、状态数量、分组直属设备数和地图可见设备；不得自动创建下级分配、围栏关联或定位频率任务。

## [P1] 验证 APP 绑定后列表计数分组和地图同步刷新
- 测试类型
  - 功能
- 前置条件
  1. 个人账号 person_sync_01 已绑定在线设备 GT-CARD-8001 和离线告警设备 GT-CARD-8002
  2. 绑定前设备总数为 2、在线数为 1、离线数为 1、告警数为 1
  3. 真实一级分组「新绑定组」的直属设备数为 0
  4. 已入库牛马定位器 GT-CARD-8003 当前离线且无告警，个人槽位和配额可用
- 测试步骤
  1. 在 APP 将 GT-CARD-8003 绑定到「新绑定组」。
  2. 刷新 APP 设备列表和状态筛选数量。
  3. 打开分组选择器查看「新绑定组」直属设备数。
  4. 打开地图查看当前账号可见设备。
  5. 登录监控平台 Web 查看 person_sync_01 的设备列表和关系详情。
- 预期结果
  1. 建立一条 person_sync_01 到 GT-CARD-8003 的直接绑定关系。
  2. APP 列表新增一条 GT-CARD-8003；总数更新为 3、在线数为 1、离线数为 2、告警数仍为 1，在线加离线等于总数。
  3. 「新绑定组」直属设备数更新为 1，设备归属 groupId 与确认页选择一致。
  4. 地图可见设备范围包含 GT-CARD-8003；无有效位置时不伪造地图坐标。
  5. Web 读取同一绑定关系并显示 GT-CARD-8003，不创建 APP 独立授权副本。

## [P1] 验证监控平台 Web 绑定结果同步到 APP 且不重复计数
- 测试类型
  - 兼容性
- 前置条件
  1. 企业一级账号 ent_l1_sync_01 已同时登录 APP 与监控平台 Web
  2. 已入库牛马定位器 GT-CARD-8101 未被 ent_l1_sync_01 绑定，企业一级配额和槽位可用
  3. ent_l1_sync_01 当前设备总数为 4
- 测试步骤
  1. 在监控平台 Web 将 GT-CARD-8101 绑定到 ent_l1_sync_01。
  2. 返回 APP 刷新设备列表、状态数量和地图可见设备。
  3. 在 APP 搜索 GT-CARD-8101 并打开详情。
  4. 查询三端关系存储和当前账号去重计数。
- 预期结果
  1. Web 成功建立 ent_l1_sync_01 的企业一级直接绑定关系。
  2. APP 同步显示 GT-CARD-8101，设备总数由 4 更新为 5，状态数量按设备实际在线或离线归类。
  3. APP 仅返回一条 GT-CARD-8101，详情使用与 Web 相同的设备唯一标识和共享资料。
  4. APP 与 Web 指向同一绑定关系，当前账号按设备唯一标识计一台，不生成跨端重复副本。

## [P3][反向] 验证企业一级绑定后不自动分配给二级和三级
- 测试类型
  - 安全性
- 前置条件
  1. 企业一级账号 ent_l1_sync_02 的直属二级为 ent_l2_sync_02，后者直属三级为 ent_l3_sync_02
  2. 已入库牛马定位器 GT-CARD-8201 未被三个账号绑定或分配
  3. ent_l1_sync_02 配额和企业一级槽位可用，拥有真实一级分组「一级自有设备」
- 测试步骤
  1. 使用 ent_l1_sync_02 在 APP 将 GT-CARD-8201 绑定到「一级自有设备」。
  2. 使用 ent_l2_sync_02 刷新 APP 与 Web 设备列表。
  3. 使用 ent_l3_sync_02 刷新 APP 与 Web 设备列表。
  4. 查询 GT-CARD-8201 的直接绑定关系和企业分配链。
- 预期结果
  1. 仅建立 ent_l1_sync_02 的企业一级直接绑定关系，一级账号在 APP 与 Web 可见。
  2. 未经一级在 Web 分配前，ent_l2_sync_02 不可见 GT-CARD-8201。
  3. 未经一级到二级、二级到三级逐级分配前，ent_l3_sync_02 不可见 GT-CARD-8201。
  4. 分配链为空，不自动创建二级或三级可见关系，也不把直接绑定结果误记为分配成功。

## [P3][反向] 验证绑定成功不自动创建围栏关联或定位频率任务
- 测试类型
  - 可靠性
- 前置条件
  1. 个人账号 person_sync_03 已创建围栏「东区安全围栏」，当前绑定设备为 GT-CARD-8301
  2. 已入库牛马定位器 GT-CARD-8302 的后台确认定位频率为 30 分钟
  3. person_sync_03 未绑定 GT-CARD-8302，配额和个人槽位可用，拥有真实一级分组「东区设备」
- 测试步骤
  1. 在 APP 将 GT-CARD-8302 绑定到「东区设备」。
  2. 查询「东区安全围栏」的设备关联关系。
  3. 查询 GT-CARD-8302 的确认定位频率、待执行配置任务和设备上线后任务队列。
  4. 刷新 APP 与 Web 的分组、围栏和设备详情数据。
- 预期结果
  1. GT-CARD-8302 直接绑定成功并归属「东区设备」。
  2. 「东区安全围栏」仍仅关联 GT-CARD-8301，不自动追加 GT-CARD-8302。
  3. GT-CARD-8302 的确认定位频率仍为 30 分钟，不新增定位频率下发任务或等待上线执行任务。
  4. APP 与 Web 同步显示绑定和分组结果，围栏关联与定位任务保持绑定前状态。
