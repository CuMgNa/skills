# 用户故事：US-009 叠加查看整群轨迹 - POINT-006 颜色状态图标与地图视野
> 口径依据：《革泰 APP 整群轨迹逻辑点梳理 plan.md》v1.2，第8、14、16节；不固定待确认的20色色值和状态时效阈值。

## [P1] 验证不同设备颜色可辨且会话内保持稳定
- 测试类型
  - 效果（AI类、资源类）
- 前置条件
  1. 已选择DEV-GT-001、DEV-GT-002和DEV-GT-003并均有多点轨迹
  2. 当前整群轨迹页面会话未结束
- 测试步骤
  1. 查看三台设备的标签、轨迹线和颜色映射
  2. 提交2026-10-11 08:00至2026-10-11 09:00的新时间范围
  3. 取消DEV-GT-003后再次刷新DEV-GT-001和DEV-GT-002
- 预期结果
  1. 三台设备使用两两不同且可通过页面图例或标签明确对应的颜色
  2. 新范围查询后仍保留设备DEV-GT-001至DEV-GT-003原颜色，不读取服务端颜色字段替换
  3. DEV-GT-001和DEV-GT-002颜色继续稳定，移除其他设备不导致仍选设备重新洗牌

## [P2] 验证设备移除后释放颜色槽并允许新设备复用
- 测试类型
  - 功能
- 前置条件
  1. DEV-GT-001和DEV-GT-002已选择并占用两个不同颜色槽
  2. DEV-GT-003为未选候选
- 测试步骤
  1. 记录DEV-GT-001和DEV-GT-002的颜色槽身份
  2. 取消DEV-GT-001
  3. 选择DEV-GT-003并查看颜色分配
- 预期结果
  1. 两台已选设备颜色可唯一映射到各自稳定deviceId
  2. DEV-GT-001颜色槽被释放，DEV-GT-002颜色不变
  3. DEV-GT-003使用当前未占用颜色，允许按既定槽位策略复用已释放槽但不得与DEV-GT-002冲突

## [P4] 验证20台颜色同屏可区分（按当前暂定需求）
- 测试类型
  - 效果（AI类、资源类）
- 前置条件
  1. 按当前暂定需求已选择DEV-GT-001至DEV-GT-020
  2. 20台设备均有轨迹且部分轨迹存在重叠区域
  3. 使用实际支持的普通底图和卫星底图进行检查
- 测试步骤
  1. 在普通底图查看20台轨迹、标签或图例对应关系
  2. 切换卫星底图查看相同轨迹
  3. 聚焦轨迹重叠区域并逐台核对deviceId对应关系
- 预期结果
  1. 同屏20台轨迹颜色槽两两不同，用户可通过稳定标签或图例识别设备
  2. 切换底图不改变颜色映射，轨迹仍具备可辨识性
  3. 重叠区域不会因颜色语义混同而把不同设备轨迹误判为同一设备，具体色值不作为本用例固定断言
