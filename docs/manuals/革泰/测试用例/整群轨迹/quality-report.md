## 7. 硬编码 epoch 与 IANA 时区事实核对

- 在 13 个 POINT 文件中发现 27 处 13 位 epoch 字面量，共 13 个唯一值。
- 使用 Python `zoneinfo` 按对应 IANA 时区逐项换算，所有作为正确预期使用的 epoch 均匹配。
- `locTime` 与格式化字符串故意不一致的契约错误用例，以及倒序时间请求中的数值不作为“应相等”事实处理，场景本身与预期一致。

- `Europe/London` 2026-10-25 00:30 至 23:30 的 UTC 真实经过时间为 1440 分钟。

- `Asia/Shanghai` 2026-10-09 00:00 至 2026-10-10 00:00 为 1440 分钟。
