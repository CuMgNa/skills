# 整群轨迹专项测试计划与 POINT 映射

## 1. 计划目标

本专项验证 US-009「叠加查看整群轨迹」与 US-010「选择轨迹查询时间」的业务规则、状态隔离、时间边界、权限边界、异步一致性和异常恢复，并将现有 13 个 POINT 文件治理为可独立执行、可按用户故事合并、可自动校验的 Markdown v0.3 用例集。

## 2. 规则依据与优先级

1. 业务真源：`docs/manuals/革泰/逻辑大纲/革泰 APP 整群轨迹逻辑点梳理 plan.md` v1.2（2026-10-10）。
2. 格式规则：`testcase-generator` Markdown v0.3 层级列表规范。
3. 发生冲突时，按“v1.2 业务真源 > 当前原型已确认修订 > 旧 Notion / 旧中文原型 / 旧接口样例”的顺序处理。
4. 20 台上限与 FIFO 静默替换是**当前暂定需求**，不是已固化的平台规则；以最新正式需求版本为准。执行前重点核对真源第 6、14、16 章，并同步核对正式 PRD、原型、接口上限和验收标准。

## 3. 测试范围

### 3.1 US-009 叠加查看整群轨迹

- 唯一入口、首次初始化、页面实例和共享分组上下文。
- 全部可见设备与具体分组直属设备的候选范围。
- `addr` / `remark` 搜索、即时选择、标签删除和去重。
- 暂定 20 台边界、FIFO 淘汰、并发选择原子性。
- 轨迹点合法性、去重、稳定排序、单点与多点绘制。
- 会话内颜色稳定、当前状态双维表达、地图视野策略。
- `OK / NO_DATA / OUT_OF_SCOPE / TECHNICAL_FAILED`、整批原子失败与重试。
- 旧响应隔离、账号与页面实例隔离、授权、容量和隐私边界。

### 3.2 US-010 选择轨迹查询时间

- 整群 / 单设备 Calendar 来源隔离与绿色日期范围。
- 日期点选状态机、分钟级手动编辑、灰色和未来日期可选。
- Search 统一校验、零时长、24 小时及 DST 真实经过时间边界。
- Search 提交、直接返回、成功空态、同指纹复用和页面会话恢复。
- APP IANA 时区、UTC 毫秒时间戳、`[startUtc, endUtc)` 和服务端二次校验。

## 4. 不覆盖与执行前待确认

以下内容不写死为固定断言；取得正式结论后再补充或更新用例：

1. 20 台上限与 FIFO 是否转为正式规则；当前仅按暂定需求覆盖。
2. 20 台、24 小时范围的性能阈值，包括 P95/P99、响应字节、点数、首屏时间、绘制时间和内存。
3. 整群批量轨迹与月份 Calendar 的最终接口方法、路径、字段、错误码和分页 / 截断契约；用例不把当前缺口路径写成最终实现。
4. 无轨迹、加载失败、校验错误和范围变化的 UI 确切中英文文案、位置和样式；用例仅断言业务语义。
5. 20 色具体色板、槽位顺序及色弱 / 底图辨识验收标准；用例不固定十六进制色值。
6. 当前状态 `statusAsOf` 的来源与陈旧阈值。
7. `locStatus`、`0,0`、坐标转换和重复点的正式有效性策略。
8. 可查询年月范围、数据保留期及 Calendar 初始展示 Start 月还是 End 月。
9. 整群主页面是否提供进入单设备回放的入口。
10. 未分组数据模型与现行设备管理规则的最终统一结论。

## 7. 复用基线

1. 复用设备列表的登录态、账号设备授权、共享分组上下文和基础分组查询，不复制设备管理完整用例。
2. 复用 US-008 单设备历史轨迹的基础绘制 / 回放能力，只覆盖 Start / End、Calendar 来源隔离和共用契约的变更点。
3. 复用「我的 → 时区设置」产生的 APP 时区配置，只验证整群 / Calendar 页面联动，不复制时区设置模块全链路。
4. 复用标准认证、缓存隔离和日志脱敏基线，在本专项中验证轨迹位置数据的高敏感边界。
5. 复用候选设备、Calendar、轨迹、状态各资源的请求版本模型，但分别验证，禁止只用一个轨迹版本号覆盖全部资源。

## 8. 去重策略

1. 以“业务状态变化 + 可观察结果 + 风险类型”为最小用例单元；相同输入路径、相同缺陷机理和相同断言不重复建例。
2. 公共登录、设备绑定、分组创建、时区配置仅写为具体前置条件，不复制其他业务域用例。
3. US-009 负责设备集合、轨迹绘制、状态和异步一致性；US-010 负责时间草稿、提交、时区和查询边界，交叉处只保留必要的页面联动断言。
4. 旧规则已被 v1.2 明确废止时不生成兼容性用例，也不将其描述成从现有文件中删除。
5. `all_cases.md` 仅做结构化汇总，不增加新用例，不重复嵌入明细文件根标题和口径引用。
