## POINT：local-account-storage

# 用户故事：本地账号级存储与多端独立

> 口径依据：大纲第 2 章「配置模型与存储」、结论 3。时区为纯本地账号级数据，以账号为单位保存在本设备，不随设备共享、不上服务端；多端各自独立、可以不同；无同步、无冲突提示。

  - 功能
- 前置条件
  1. 账号 testuser01（密码 Test@1234）已在手机 A、手机 B 两台设备同时登录
  2. 两台设备当前时区均为 Beijing（GMT+8:00）
- 测试步骤
  1. 手机 A 打开「我的 → 时区设置」，改选 Sydney 行。
  2. 手机 A 返回监控页，查看设备「最近更新时间」的展示。
  3. 手机 B 不做任何时区操作，下拉刷新监控页，查看「最近更新时间」的展示。
  4. 手机 B 打开「我的 → 时区设置」查看当前选中行。
- 预期结果
  1. 手机 A 选中行对勾移动到 Sydney，立即写入本地。
  2. 手机 A 时间字段按 Sydney 偏移（执行日为夏令时段则 +11:00，标准时段则 +10:00，以当日 tzdata 现查为准）展示。
  3. 手机 B 时间字段仍按 Beijing（GMT+8:00）展示，无任何同步变化、无冲突提示弹窗。
  4. 手机 B 选中行仍为 Beijing，未被手机 A 的修改波及。

## [P2] 验证双设备同账号各自设置不同时区后展示各自自洽
- 测试类型
  - 功能

  1. 手机 A 展示值 = UTC 时刻 + Sydney 当日偏移。
  2. 手机 B 展示值 = UTC 时刻 + Brisbane (+10:00) 偏移，与手机 A 差值恰为两地偏移差。
  3. 两端各自自洽，服务端存储的同一事件时刻不变（守恒量）。
