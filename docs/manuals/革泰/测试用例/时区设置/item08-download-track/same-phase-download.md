# 用户故事：同相位下载正确性

> 口径依据：大纲第 10 章 10.1 节 S0、第 12 章。下载轨迹是唯一由后端做时区转换的场景；同相位（下载时刻与数据时段处于相同 DST 相位 / 无 DST 区）下载须严格断言通过——证明下载管线本身无 bug，孤立出 DST 是唯一变量。

## [P1] 验证 Brisbane 无 DST 区下载时间正确（S0 对照组）
- 测试类型
  - 功能
- 前置条件
  1. 账号 testuser01 已登录，已注入两点：A1（UTC 2026-01-15 00:30，存储 01-15 08:30）、A2（UTC 2026-01-15 13:30，存储 01-15 21:30）
  2. APP 时区选 Brisbane（+10:00 恒定，无 DST）
- 测试步骤
  1. 轨迹页选择含 A1、A2 的日期范围（2026-01-15），发起轨迹下载。
  2. 打开导出文件，核对 A1、A2 两点的时间。
  3. 与 10.1 节预期对照。
- 预期结果
  1. 下载成功，文件可打开。
  2. A1 显示 2026-01-15 10:30、A2 显示 2026-01-15 23:30（+10 恒定）。
  3. 两点均正确——孤立出 DST 变量，证明下载管线本身无 bug。
