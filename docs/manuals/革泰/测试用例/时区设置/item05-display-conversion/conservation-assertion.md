> 口径依据：大纲结论 16、第 8 章、第 11 章场景 21、第 12 章（金用例）。切换时区前后，不带日期筛选的列表记录数 / 统计值必须不变——切时区只改标签不改数据；带日期分组 / 筛选的场景因窗口随 tz 移动而变，属预期变化，须单独断言。

## [P1] 验证无筛选列表切时区前后记录数与统计值不变
- 测试类型
  - 功能
- 前置条件
  1. 账号 testuser01 已登录，当前时区 Beijing
  2. 告警页无筛选状态下共有 37 条记录，指令页无筛选共 12 条
- 测试步骤
  1. Beijing 口径下记录告警页总条数（37）与指令页总条数（12）。
  2. 改选 Chatham Islands（GMT+12:45）。
  3. 重进告警页与指令页，再次统计无筛选总条数。
  4. 改回 Beijing 复查一遍。
- 预期结果
  1. 记录成功。
  2. 改选成功。
  3. 告警仍为 37 条、指令仍为 12 条——切时区只改标签不改数据（守恒断言金用例）。
  4. 改回后条数依旧，全程无数据丢失或新增。

## [P2] 验证带日期筛选列表切时区后窗口移动属预期变化
- 测试类型
  - 功能
- 前置条件
  1. 账号 testuser01 已登录，当前时区 Beijing
  2. 已注入边界点：UTC 2026-09-20 15:30（= 北京 09-20 23:30 = 悉尼 09-21 01:30 次日）
- 测试步骤
  1. Beijing 口径下轨迹页筛选「今日 = 2026-09-20」，确认包含该边界点，记录点数。
  2. 改选 Sydney，重进轨迹页保持「今日」筛选，查看该边界点归属。
  3. 比较两次查询窗口覆盖的点集。
- 预期结果
  1. Beijing 口径下该点计入 09-20「今日」结果。
  2. Sydney 口径下「今日」窗口整体移动，该点计入 09-21（不再属于「今日」09-20）。
  3. 点集变化源于日期窗口随新时区重算，属预期变化（与守恒断言分开判定，不得误报缺陷）。

## [P2] 验证统计值（里程 / 点数总量）切时区前后不变
- 测试类型
  - 功能
- 前置条件
  1. 账号 testuser01 已登录，当前时区 Beijing
  2. 某设备当日总里程 128.5 km、总点数 260（Beijing 口径全天无筛选统计）
- 测试步骤
  1. Beijing 口径记录该设备全天统计值（128.5 km / 260 点）。
  2. 改选 Adelaide。
  3. 重进轨迹统计页查看全天（无日期筛选口径）统计值。
  4. 若统计按「今日」日界分组，另核对按日分组口径的变化并标注原因。
- 预期结果
  1. 记录成功。
  2. 改选成功。
  3. 无筛选口径下总里程仍 128.5 km、总点数仍 260（守恒）。
  4. 按日分组口径下「今日」窗口移动导致的组间变化属预期，单独说明，不判缺陷。
