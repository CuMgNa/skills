# 用户故事：资料页只读回显与单源同步

> 口径依据：大纲第 3 章、第 12 章、我的模块篇拍板口径。资料页时区行为纯展示不可改（无点击响应）；修改只能走「我的 → 时区设置」。单源三处回显：登录页、时区设置页、资料页共用同一份本地配置，改一处其余入口回显同步。

## [P1] 验证资料页时区行只读不可修改
- 测试类型
  - 功能
- 前置条件
  1. 账号 testuser01 已登录，当前时区为 Seoul（GMT+9:00）
- 测试步骤
  1. 进入「我的 → 资料页」，找到时区行。
  2. 点击时区行。
  3. 观察是否出现跳转、弹窗或编辑态。
- 预期结果
  1. 时区行显示 Seoul，回显当前配置。
  2. 点击无响应（纯展示不可改，我的模块篇拍板口径）。
  3. 不跳转时区列表、无弹窗、无编辑态。

## [P1] 验证单源三处回显同步（改一处其余两处同步）
- 测试类型
  - 功能
- 前置条件
  1. 账号 testuser01 已登录，当前时区为 Beijing
  2. 已知三入口：登录页时区项、我的 → 时区设置页选中行、资料页时区行
- 测试步骤
  1. 通过「我的 → 时区设置」改选 Havana（GMT-5:00 / 夏令期 GMT-4:00）。
  2. 进入资料页查看时区行。
  3. 退出登录，查看登录页时区项回显。
  4. 重新登录，进入「我的 → 时区设置」查看选中行。
- 预期结果
  1. 改选成功。
  2. 资料页时区行同步显示 Havana。
  3. 登录页时区项回显 Havana（单一本地真源）。
  4. 选中行为 Havana，三处一致。

## [P2] 验证登录页选定时区与个人中心回显一致
- 测试类型
  - 功能
- 前置条件
  1. 账号 testuser01 已退出登录，登录页时区项当前显示 Reykjavik（GMT+0:00 组 Monrovia, Reykjavik 行）
- 测试步骤
  1. 登录页时区项保持 Reykjavik，用 testuser01 登录。
  2. 进入「我的」查看资料页时区行。
  3. 进入「我的 → 时区设置」查看选中行。
- 预期结果
  1. 登录成功。
  2. 资料页时区行显示 Reykjavik。
  3. 选中行为 Reykjavik 对应行，登录页所选即本账号时区、进入个人中心回显相同值。

## [P2] 验证在时区设置页改选后返回资料页回显新值
- 测试类型
  - 功能
- 前置条件
  1. 账号 testuser01 已登录，资料页时区行当前显示 Brisbane（GMT+10:00）
- 测试步骤
  1. 进入「我的 → 时区设置」，改选 Darwin（GMT+9:30）。
  2. 左上返回到「我的」，再进入资料页查看时区行。
- 预期结果
  1. 改选成功，对勾移至 Darwin。
  2. 资料页时区行显示 Darwin（新值即时回显，无需重启 APP）。
