# 用户故事：登录页时区必选项

> 口径依据：大纲第 3 章入口链路、第 12 章。时区为登录必选项：未有效选中不能提交登录；登录成功后所选值即为本账号时区，进入个人中心回显相同值。注册流程带入：从登录页进入注册并自动进入业务页时沿用登录入口已选时区；直接进注册用默认时区。

## [P1] 验证登录页选定时区登录后配置生效并回显
- 测试类型
  - 功能
- 前置条件
  1. 账号 testuser01（密码 Test@1234）已注册
  2. 处于登录页，手机系统时区为 Asia/Shanghai
- 测试步骤
  1. 在登录页选择时区项为 Sydney（或当日标注 GMT+10:00/GMT+11:00 的悉尼行）。
  2. 输入账号 testuser01、密码 Test@1234，点击登录。
  3. 登录成功后进入「我的 → 时区设置」查看选中行。
  4. 进入资料页查看时区行显示。
- 预期结果
  1. 登录页时区项显示所选 Sydney。
  2. 登录提交成功。
  3. 时区设置页选中行为 Sydney（登录页选择即写入本账号配置）。
  4. 资料页时区行回显 Sydney，三入口同一值（单源三处回显）。

## [P3][反向] 验证登录页未选时区时不能提交登录
- 测试类型
  - 功能
- 前置条件
  1. 处于登录页，时区项为空 / 未有效选中（可用清缓存后首装态构造）
  2. 账号 testuser01（密码 Test@1234）有效
- 测试步骤
  1. 不选择时区，输入账号 testuser01、密码 Test@1234。
  2. 点击登录按钮。
  3. 检查页面反应与是否发出登录请求。
- 预期结果
  1. 账号密码正常输入。
  2. 登录被拦截，不能提交（PRD：必须有效选中）。
  3. 页面给出时区未选择的提示，无登录请求发出或请求被客户端拦截。

## [P2] 验证从登录页进入注册流程沿用已选时区
- 测试类型
  - 功能
- 前置条件
  1. 处于登录页，已在时区项选择 London（GMT+0:00 / 夏令期 GMT+1:00，按当日）
  2. 准备注册新账号 testuser_new（手机号 13800138000，密码 Test@1234）
- 测试步骤
  1. 从登录页点击注册入口，完成注册流程并自动进入业务页。
  2. 进入「我的 → 时区设置」查看选中行。
- 预期结果
  1. 注册成功并进入业务页。
  2. 选中行为 London，沿用登录入口已选时区（登录篇口径）。

## [P2] 验证直接进入注册流程使用默认时区
- 测试类型
  - 功能
- 前置条件
  1. 未经过登录页选时区，直接进入注册流程
  2. 手机系统时区为 Asia/Shanghai
- 测试步骤
  1. 完成注册并进入业务页。
  2. 进入「我的 → 时区设置」查看选中行。
- 预期结果
  1. 注册成功。
  2. 选中行为系统时区默认 Beijing（GMT+8:00）（直接注册用默认时区）。
