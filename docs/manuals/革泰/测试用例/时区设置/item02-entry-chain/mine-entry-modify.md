# 用户故事：我的时区设置入口与修改生效

> 口径依据：大纲第 3、4 章。「我的 → 区域三时区设置」为二级页，左上返回回「我的」；本页修改后全 APP 生效；点选即写入本地，无保存按钮、无确认弹窗、无草稿态——返回不回滚。

## [P1] 验证我的入口进入时区设置页并成功修改
- 测试类型
  - 功能
- 前置条件
  1. 账号 testuser01 已登录，当前时区为 Beijing
- 测试步骤
  1. 打开「我的」页，找到区域三中的「时区设置」入口，点击进入。
  2. 确认页面结构：顶部导航（返回 + 标题 Time Zone）→ 说明卡 → 单选列表。
  3. 点选 Perth（GMT+8:00）行。
  4. 点击左上返回键回到「我的」页，再次进入「时区设置」查看选中行。
- 预期结果
  1. 成功进入时区设置二级页。
  2. 页面结构完整：返回键 + Time Zone 标题 + 时区作用范围说明卡 + 单选列表。
  3. 对勾移动到 Perth 行，无保存按钮出现、无确认弹窗。
  4. 返回后再进，选中行仍为 Perth（已点选变更不因返回回滚，无草稿态）。

## [P1] 验证点选即写入本地并全 APP 生效
- 测试类型
  - 功能
- 前置条件
  1. 账号 testuser01 已登录，当前时区为 Beijing，名下有设备且当天有定位上报
- 测试步骤
  1. 记录当前监控页「最近更新时间」的展示值（Beijing 口径）。
  2. 进入「我的 → 时区设置」改选 Tokyo（GMT+9:00）。
  3. 返回监控页查看「最近更新时间」。
  4. 与工具计算的预期值对照（原值 +1 小时，跨日则日期同步进位）。
- 预期结果
  1. 记录成功。
  2. 改选即时生效。
  3. 监控页重渲染后时间按 Tokyo 偏移展示（下次渲染生效口径）。
  4. 展示值 = 原值 +1h，与 Python zoneinfo 现算一致。
