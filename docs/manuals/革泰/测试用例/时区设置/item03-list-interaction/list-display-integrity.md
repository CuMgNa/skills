# 用户故事：列表展示规范与完整性

> 口径依据：大纲第 4、5 章。数据源为手机系统 tzdata（IANA），呈现参照 Windows 精选视图（38 偏移档 / 138 项，Windows 同一行多城市按首城市展示）；一行一城 `GMT±H:MM 城市名` + 行尾对勾；固定按标准时偏移升序（-12:00 → +14:00），不随季节重排；含半小时 / 45 分钟档。测试时以当前系统 tzdata 现查为准，不背记快照。

## [P1] 验证列表行格式与对勾选中标识展示
- 测试类型
  - 功能
- 前置条件
  1. 账号 testuser01 已登录，当前时区为 Beijing
- 测试步骤
  1. 进入「我的 → 时区设置」。
  2. 检查列表行格式（偏移 + 城市名 + 行尾对勾）。
  3. 滚动列表查看当前选中行（Beijing 所在 +8:00 档）的对勾位置。
- 预期结果
  1. 列表正常加载。
  2. 每行格式为 `GMT+8:00 Beijing` 风格（偏移在前、城市名在后，一行一城），无多城同屏混排。
  3. 仅 Beijing 行行尾显示对勾标识，其余行无。

## [P2] 验证列表完整性（38 档全档位可见）
- 测试类型
  - 功能
- 前置条件
  1. 账号 testuser01 已登录
  2. 已用系统 tzdata / `tzutil /l`（Windows 视图）现查当日全量清单作对照基准
- 测试步骤
  1. 进入「我的 → 时区设置」，从头滚动到底。
  2. 记录首行与末行的偏移档位。
  3. 抽查各代表档位行存在性：-12:00 International Date Line West、-09:30 Marquesas Islands、+00:00 London 组、+05:45 Kathmandu、+08:45 Eucla、+09:30 Darwin、+10:30 Lord Howe Island、+12:45 Chatham Islands、+14:00 Kiritimati Island。
  4. 统计列表总项数与偏移档数。
- 预期结果
  1. 滚动流畅，无缺档、无重复行。
  2. 首行为 -12:00 档（International Date Line West），末行为 +14:00 档（Kiritimati Island）。
  3. 9 个抽查档位行全部可见（含半小时 / 45 分钟档）。
  4. 总项数约 138 项、偏移档数约 38 档，与当前系统 tzdata 现查结果一致（纯偏移占位条目按实际 UI 确认结果计数）。

## [P2] 验证列表固定按标准时偏移升序排列
- 测试类型
  - 功能
- 前置条件
  1. 账号 testuser01 已登录，执行时点为南半球夏令期（如 2026 年 1 月，Sydney 实际偏移 +11:00）
- 测试步骤
  1. 进入「我的 → 时区设置」。
  2. 找到 Sydney 行（标注 GMT+11:00）与其前方相邻行位置。
  3. 核对 Sydney 行按标准偏移 +10:00 档位排序（应排在 +10:00 档、+10:30 档 Lord Howe Island 之前）。
- 预期结果
  1. 列表正常展示。
  2. Sydney 行标注为 GMT+11:00（当日实际偏移，含 DST）。
  3. 排序仍按标准偏移 +10:00 定位（不随夏令时标注 +11:00 重排到 +11 档），排序固定保证断言稳定。

## [P2] 验证同组多城市按首城市展示且选取等同整组
- 测试类型
  - 功能
- 前置条件
  1. 账号 testuser01 已登录
  2. 对照 Windows 视图：+8:00 档 `Beijing, Chongqing, Hong Kong, Urumqi` 组
- 测试步骤
  1. 进入「我的 → 时区设置」，找到 +8:00 档 Beijing 组行。
  2. 确认该行只显示 Beijing 一个城市名（组首城）。
  3. 点选 Beijing 行。
  4. 查看资料页时区行回显值。
- 预期结果
  1. +8:00 档显示 Beijing 行。
  2. 行内仅显示首城市 Beijing（同组其余城市不逐个显示）。
  3. 点选成功，对勾移至该行。
  4. 回显 Beijing——选取结果等同整组（IANA 存储为 Asia/Shanghai）。

## [P4] 验证非整点偏移档位标注格式正确
- 测试类型
  - 功能
- 前置条件
  1. 账号 testuser01 已登录
- 测试步骤
  1. 进入「我的 → 时区设置」。
  2. 分别找到 Kathmandu、Chatham Islands、Adelaide、Newfoundland（GMT-3:30）四行。
  3. 核对各行偏移标注。
- 预期结果
  1. 列表正常展示。
  2. 四行均可找到。
  3. 标注分别为 GMT+5:45、GMT+12:45（或夏令期 +13:45 按当日）、GMT+9:30（夏令期 +10:30 按当日）、GMT-3:30（夏令期 -2:30 按当日）——分钟位 :30/:45 不得抹零成整点。
