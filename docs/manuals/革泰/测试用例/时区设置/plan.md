- 本用例集只覆盖 **APP 展示时区**（登录页 / 我的 → 时区设置，纯本地账号级配置）

## 断言纪律（继承大纲 7.3）

1. 预期偏移一律用工具计算（Python `zoneinfo`，与系统 tzdata 同源；交叉核对 timeanddate.com），禁止手算；本文所有预期值以 2026-09-18 当前 tzdata 相位预计算，执行时以设备当前 tzdata 为准现查
2. 测试时区列表以当前系统 tzdata 为准现查，不背记 138 项快照
3. 切换时区只改标签不改数据（守恒断言）；日期分组 / 筛选场景因窗口移动而变，属预期变化单独断言
