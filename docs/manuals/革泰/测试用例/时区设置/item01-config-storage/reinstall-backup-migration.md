# 用户故事：卸载重装与换机备份迁移

> 口径依据：大纲第 2 章。两条换机路径必须分别断言：① 卸载重装 / 清除数据 → 本地配置清除，回默认（系统时区预选）；② 整机备份恢复 / 换机迁移（iOS iCloud 备份、Android Auto Backup / 换机克隆）→ 本地配置随整机备份带回新设备。「换设备不带时区」仅指全新安装。

## [P3] 验证卸载重装后时区重置为系统默认
- 测试类型
  - 功能
- 前置条件
  1. 账号 testuser01 已登录，当前时区已改为 Sydney（非系统时区）
  2. 手机系统时区为 Asia/Shanghai（GMT+8:00）
- 测试步骤
  1. 卸载革泰 APP。
  2. 重新安装并打开 APP，进入登录页。
  3. 用账号 testuser01 登录，进入「我的 → 时区设置」查看选中行。
- 预期结果
  1. 卸载成功，本地数据清除。
  2. 登录页时区项预选系统时区对应行 Beijing（GMT+8:00），不残留 Sydney 旧值。
  3. 登录后时区设置页选中行为 Beijing，本地旧配置未残留。

## [P3] 验证清除应用数据（不卸载）后时区重置
- 测试类型
  - 功能
- 前置条件
  1. Android 测试机已登录账号 testuser01，当前时区为 Kathmandu（GMT+5:45）
  2. 手机系统时区为 Asia/Shanghai
- 测试步骤
  1. 系统设置 → 应用管理 → 革泰 APP → 存储 → 清除数据。
  2. 重新打开 APP，用账号 testuser01 登录。
  3. 进入「我的 → 时区设置」查看选中行。
- 预期结果
  1. 清除数据成功。
  2. 登录页时区预选 Beijing（系统时区）。
  3. 登录后选中行为 Beijing，Kathmandu 旧值不残留。

## [P2] 验证 Android 整机换机克隆 / Auto Backup 迁移保留时区
- 测试类型
  - 功能
- 前置条件
  1. 旧 Android 机（系统时区 Asia/Shanghai）已登录账号 testuser01，APP 时区为 Adelaide
  2. 新 Android 机准备好换机克隆工具（或已开启 Auto Backup 云恢复）
- 测试步骤
  1. 旧机执行整机迁移，将应用数据迁移到新机。
  2. 新机打开革泰 APP，用账号 testuser01 登录。
  3. 新机进入「我的 → 时区设置」查看选中行。
- 预期结果
  1. 迁移完成，APP 本地数据（含时区配置）随备份带入新机。
  2. 登录成功。
  3. 新机选中行为 Adelaide，本地配置随整机备份保留（不回默认）。

## [P2] 验证 iOS iCloud 备份恢复到新机保留时区
- 测试类型
  - 功能
- 前置条件
  1. 旧 iPhone 已登录账号 testuser01，APP 时区为 Chatham Islands
  2. 旧机已执行 iCloud 整机备份，新 iPhone 可用
- 测试步骤
  1. 新 iPhone 从 iCloud 备份恢复。
  2. 恢复完成后打开革泰 APP，用账号 testuser01 登录。
  3. 进入「我的 → 时区设置」查看选中行。
- 预期结果
  1. 备份恢复完成，APP 本地数据随整机备份带入。
  2. 登录成功。
  3. 新机选中行为 Chatham Islands，配置保留——与「全新安装不带时区」形成对照，两条换机路径分别断言均成立。
