前置条件：
1. 界面语言为 English，可打开 Subscribe（订阅）弹窗并进入 Step1 Select Devices

复现步骤：
1. 进入控制台，打开 Subscribe 弹窗

2. 停留在 Select Devices 步骤

3. 查看左侧操作按钮区：Select All / Cancel Select All / Fold / Expand（见截图红框）

实际结果：
1. Cancel Select All 按钮文本溢出（截图红字：按钮文本溢出），文案超出按钮边界、显示拥挤

2. 同排其余按钮文案完整，仅该按钮出现溢出

预期结果：
1. Cancel Select All 按钮文案须完整显示在按钮内，无溢出、无截断、不压边

2. 英文长文案场景下，按钮宽度须自适应文案或支持换行/省略号策略，且与同排按钮垂直对齐一致
