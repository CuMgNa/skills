前置条件：
1. 使用 OPPO Find X6 登录 Web 用户账号，“个人资料”中的联系人、电话、邮箱、地址、时区均有值，其中联系人和地址为长文本。

复现步骤：
1. 使用 OPPO Find X6 进入“个人资料”页面（见截图1）。
2. 查看联系人、电话、邮箱、地址、时区字段。
3. 对比字段名、字段值及右侧箭头的垂直位置。
4. 对照设计稿查看长文本换行布局。

实际结果：
1. 字段名与字段值未在同一水平线对齐；联系人和地址等长内容换行后上下错位，联系人值分成两行且第二行偏右，地址值分成三行并挤压右侧箭头，整体排版与设计稿不一致。

预期结果：
1. 各字段名、字段值与右侧箭头应在同一行垂直居中。
2. 长文本应限制在字段值区域内换行，每行右对齐且不得侵占字段名和箭头区域。
3. OPPO Find X6 上的页面布局应与设计稿保持一致，不得出现重叠、截断或错位。
