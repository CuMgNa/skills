前置条件：
1. 手机 APP 已登录，进入“电子围栏”。

2. Web 端已创建围栏“web网络”，半径 `500m`，地址为“广东省广州市黄埔区云埔街道广东拓思·北斗创新基地(西门)”。

3. Web 端已创建围栏“web”，半径 `10000m`，地址为“广东省广州市黄埔区云埔街道纳金科技产业园H2座荔枝公司”，关联设备 `3` 台。

复现步骤：
1. 进入 APP“电子围栏”，搜索并查看上述 2 个 Web 端围栏（见截图1）。

2. 查看围栏卡片是否展示多边形、矩形形状标识。

3. 点击卡片上的“编辑”。

实际结果：
1. APP 未按 Web 端围栏的多边形、矩形形状展示，卡片也没有形状标识。

2. 点击“编辑”后未提示“暂不支持在 APP 编辑多边形/矩形围栏，请前往 Web 平台修改”。

预期结果：
1. APP 必须展示 Web 端创建的多边形围栏和矩形围栏，卡片名称、半径、地址与 Web 端一致。

2. 围栏卡片必须展示 `1` 个形状标识，多边形与矩形使用不同标识，不得缺省。

3. 点击 Web 端多边形或矩形围栏卡片的“编辑”时，必须拦截编辑，并提示“暂不支持在 APP 编辑多边形/矩形围栏，请前往 Web 平台修改”。
